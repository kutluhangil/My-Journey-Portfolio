# 🎮 GameDeal — Cross-Platform Game Discount Tracker

## 1. Overview

**GameDeal** is a minimalist iOS mobile application designed to help gamers in **Turkey** discover the best prices for games across multiple platforms.

The app aggregates and compares game prices from different digital game stores such as:

- Steam
- Epic Games Store
- PlayStation Store
- Xbox Store
- Nintendo eShop
- Other supported platforms available in Turkey

Users can search for any game and instantly see:

- Current prices on each platform
- Discount percentages
- Historical lowest price
- Best current deal

When a user clicks a platform, the app redirects them to the official store to purchase the game.

The application will initially launch **for Turkey** and later expand globally.

The design philosophy follows **Apple-style minimalism**: clean UI, smooth animations, and focus on game artwork.

Users can search for any game.

|--------|------|------|------|

| Xbox Store | 849 TL | -25% | Xbox |

The **best deal is highlighted automatically**.

Features:

- search by game title
- search by franchise
- search by publisher
- search by platform
