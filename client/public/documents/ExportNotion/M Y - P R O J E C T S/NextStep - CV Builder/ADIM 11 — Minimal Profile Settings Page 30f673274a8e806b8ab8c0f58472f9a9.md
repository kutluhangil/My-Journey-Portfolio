# ADIM 11 — Minimal Profile / Settings Page

Bu ekran:

- Sade olacak
- Account bilgileri
- Plan bilgisi
- Dil ayarı
- Şifre değiştir
- Danger zone (hesap sil)

Ama yine:

Editorial.

Warm.

Calm.

Minimal.

Bu sayfa çok “dashboard-y” olmamalı.

Daha çok bir “account notebook” hissi vermeli.

Aşağıdaki promptu direkt Stitch’e gönder:

---

```
Create the Profile / Settings Page for:

"Remote Tech Jobs Resume Optimizer"

IMPORTANT:
Strictly follow the established editorial design system used across all pages.
Maintain:

- Warm beige background (#F3EFEA)
- Soft surface cards (#E8E1D9)
- Serif section headings
- Sans-serif body text
- Large rounded corners
- Subtle shadows
- Generous vertical spacing

Do NOT introduce new colors.
Do NOT use bright highlights.
Do NOT use blue tones.
Do NOT create a heavy admin dashboard layout.

This page should feel like a calm personal account notebook.

LAYOUT STRUCTURE:

1. Authenticated Navigation
Same as Dashboard and History.
Fully consistent.

2. Page Header

Large serif headline:
"Account Settings"

Subtext:
"Manage your account and preferences."

3. Profile Information Section

Rounded card.
Soft beige surface.

Section title (serif small):
"Profile Information"

Fields:
- Full Name
- Email Address

Editable inputs.
Rounded.
Soft borders.
Subtle focus state.

Small Save Changes button (muted dark tone).

4. Plan & Usage Section

Rounded card.

Title:
"Your Plan"

Display:
Current Plan (Free / Pro)
Remaining Credits (if applicable)

Subtle link:
"Upgrade Plan"

Keep layout minimal and clean.

5. Language Preference Section

Rounded card.

Title:
"Language"

Simple toggle:
English / Turkish

Minimal UI.
No aggressive switch components.

6. Security Section

Rounded card.

Title:
"Security"

Fields:
- Current Password
- New Password
- Confirm Password

Small muted helper text.

Button:
"Update Password"

7. Danger Zone Section (Bottom)

Rounded card but slightly separated.

Title:
"Delete Account"

Muted warning text:
"This action cannot be undone."

Outline button:
"Delete Account"

Subtle but clear.

STYLE RULES:

- Large spacing between sections
- Calm vertical rhythm
- No heavy borders
- No admin-panel styling
- Elegant typography hierarchy
- Consistent with Landing aesthetic

This profile page must feel:
Personal.
Calm.
Secure.
Intentional.

Generate a complete Profile / Settings page strictly consistent with the established editorial SaaS design system.
```
