# ADIM 3 — Login Page

Bu sayfa kritik çünkü:

- SaaS ciddiyeti burada başlar
- Güven duygusu burada oluşur
- Minimal estetik burada da korunmalı

Bu login sayfası:

- Sade
- Ortalanmış
- Journal hissi
- Aşırı form kalabalığı yok
- Sosyal login destekli

Aşağıdaki promptu direkt Stitch’e atabilirsin:

---

```
Create the Login Page for:

"Remote Tech Jobs Resume Optimizer"

Use the previously generated Design System.
Maintain the warm neutral editorial aesthetic.
This page must feel calm, secure, and minimal.

LAYOUT:

Centered layout.
Large vertical spacing.
Soft beige background (#F3EFEA).
No harsh contrast.
No heavy shadows.

STRUCTURE:

1. Minimal Navigation (Top)
- Small rounded nav container
- Logo on left
- Simple link on right: "Back to Home"
- No extra links

2. Login Card (Centered)
- Rounded large radius
- Soft beige surface (#E8E1D9)
- Subtle shadow
- Generous padding
- Max width ~420px

Inside the card:

Headline (serif):
"Welcome Back"

Subtext (sans-serif):
"Log in to optimize your resume for remote roles."

3. Login Form Fields

- Email input
- Password input
- Rounded fields
- Soft border
- Subtle focus state (slightly darker border)
- Spacious padding

4. Remember Me + Forgot Password
- Minimal layout
- Small muted text
- Soft hover

5. Primary Button
"Log In"
Rounded
Dark muted tone
Full width
Soft hover transition

6. Divider
Thin subtle line
Text centered:
"or continue with"

7. Social Login Buttons
- Continue with Google
- Continue with GitHub

Rounded buttons.
Outline style.
Minimal icon usage.
No bright brand colors.
Keep them neutral and consistent with design system.

8. Bottom Text
Small muted text:
"Don’t have an account? Sign up"

Sign up should be slightly emphasized but not flashy.

STYLE RULES:
- No gradients
- No bright blue
- No sharp corners
- No tech startup neon
- Maintain editorial calm mood
- Spacious breathing room

This login page must feel:
Secure.
Thoughtful.
Minimal.
Premium.

Generate a complete login page consistent with the established design system.
```
