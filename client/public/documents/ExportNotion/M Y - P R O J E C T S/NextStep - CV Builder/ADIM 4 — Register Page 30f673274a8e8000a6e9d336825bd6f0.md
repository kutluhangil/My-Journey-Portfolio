# ADIM 4 — Register Page

Login ile aynı estetikte olacak

ama biraz daha “encouraging” hissi verecek.

Burada iki şeye dikkat edeceğiz:

1. Form sade kalacak (MVP)
2. Remote niche hafif hissettirecek

Yine direkt copy-paste kullanabileceğin prompt aşağıda 👇

---

```
Create the Register (Sign Up) Page for:

"Remote Tech Jobs Resume Optimizer"

Use the previously generated Design System.
Maintain full visual consistency with the warm neutral editorial aesthetic.

This page should feel welcoming, thoughtful, and professional — not aggressive or sales-driven.

LAYOUT:

Centered layout.
Soft beige background (#F3EFEA).
Large vertical spacing.
No heavy shadows.
No harsh contrast.

STRUCTURE:

1. Minimal Navigation (Top)
- Small rounded nav container
- Logo on left
- Simple link on right: "Back to Home"

2. Register Card (Centered)
- Large rounded corners
- Soft beige surface (#E8E1D9)
- Subtle shadow
- Max width ~460px
- Generous padding

Inside the card:

Headline (serif):
"Create Your Account"

Subtext (sans-serif):
"Start optimizing your resume for remote tech roles."

3. Form Fields

- Full Name
- Email
- Password
- Confirm Password

Rounded input fields.
Soft borders.
Subtle focus state.
Spacious padding.

4. Optional Small Note
Muted text under password:
"Use at least 8 characters."

5. Primary Button
Text:
"Create Account"

Full width.
Rounded.
Muted dark tone.
Soft hover effect.

6. Divider
Thin subtle line.
Centered text:
"or sign up with"

7. Social Register Options
- Continue with Google
- Continue with GitHub

Outline style.
Neutral.
Minimal icon usage.
No bright brand colors.

8. Bottom Text
Small muted text:
"Already have an account? Log in"

Log in link slightly emphasized but subtle.

STYLE RULES:
- No gradients
- No strong blue focus states
- No sharp edges
- No flashy elements
- Maintain editorial calm mood
- Spacious and breathable layout

The register page must feel:
Inviting.
Calm.
Professional.
Crafted for serious developers.

Generate a complete sign-up page consistent with the established design system.
```
