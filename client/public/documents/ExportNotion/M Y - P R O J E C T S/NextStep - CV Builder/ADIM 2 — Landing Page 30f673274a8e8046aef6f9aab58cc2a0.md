# ADIM 2 — Landing Page

Bu sayfa:

- Ürünü 5 saniyede anlatmalı
- Güven vermeli
- “Remote dev niche” net göstermeli
- Signup’a yönlendirmeli

Blog estetiği korunacak. Ama bu bir SaaS.

Dengeyi kuruyoruz.

Aşağıdaki promptu direkt Stitch’e atabilirsin.

---

```
Create the Landing Page for:

"Remote Tech Jobs Resume Optimizer"

Use the previously generated Design System.
Maintain full visual consistency with the warm neutral editorial aesthetic.

This is a SaaS landing page, but it should feel calm, minimal, and thoughtful — not corporate and not hype-driven.

STRUCTURE:

1. Navigation Bar (Top)
- Rounded container
- Logo on left
- Links: Features, Pricing, About
- Language switch (EN / TR)
- Primary button on right: "Get Started"
- Soft hover states
- Subtle separation from background

2. Hero Section (Main Focus)
Layout:
- Two-column layout
- Left: Editorial headline + text + CTA
- Right: Product mockup preview (dashboard or score example)

Headline:
Large serif, bold but elegant.
Example tone:
"Optimize Your Resume for Remote Tech Jobs"

Subheading:
Calm, intelligent explanation:
"AI-powered resume optimization with ATS simulation and remote-readiness scoring."

CTA Buttons:
Primary: "Optimize Now"
Secondary: "See How It Works"

Below CTA:
Small subtle trust line:
"No signup required for first 3 optimizations."

Hero Mood:
Spacious.
Confident.
Quietly premium.

3. How It Works Section
Centered section.
Three minimal cards horizontally.

Step 1:
Paste Resume

Step 2:
Add Remote Job Description

Step 3:
Get ATS Score & Optimized Resume

Use soft rounded cards.
Include minimal line icons.
No heavy illustrations.

4. Remote-Specific Differentiator Section
Section title (serif):
"Built for Remote Developers"

Bullet points:
- Remote-readiness scoring
- Async communication keyword analysis
- Time-zone collaboration signals
- Git workflow & documentation evaluation

Layout:
Text left, subtle UI preview right.
Keep calm spacing.

5. Score Preview Section
Centered elegant score example.
Large serif percentage (e.g., 78%)
Keyword tags below.
Small explanation text.

Make it editorial and refined.
Not gamified.

6. Pricing Preview Section
Minimal 2 or 3 pricing cards.
Free and Pro.
Soft borders.
No flashy discount banners.

7. Footer
Soft beige surface.
Minimal links:
Privacy
Terms
Contact
Language toggle

STYLE RULES:
- Large vertical spacing between sections
- Serif headlines
- Sans-serif body
- Rounded containers
- No gradients
- No bright colors
- No pure white
- No pure black
- No tech neon
- Maintain warm editorial mood

The landing page must feel:
Calm.
Premium.
Trustworthy.
Crafted for serious remote developers.

Generate a complete landing layout consistent with the Design System.
```
