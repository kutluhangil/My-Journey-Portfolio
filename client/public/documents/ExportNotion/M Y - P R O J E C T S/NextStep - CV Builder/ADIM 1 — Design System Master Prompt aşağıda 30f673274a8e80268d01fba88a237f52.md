```
Create a complete Design System for a modern SaaS product called:

"Remote Tech Jobs Resume Optimizer"

The product is a minimalist AI-powered resume optimization tool for remote developers.

Design Direction:
- Warm neutral palette (not pure white, not dark mode)
- Inspired by minimalist personal blog aesthetics
- Soft beige backgrounds, warm gray text
- Calm, editorial, elegant
- Rounded containers (large radius)
- Spacious layout
- Clean and professional but not corporate cold
- Feels like a thoughtful personal blog + modern SaaS hybrid

VISUAL STYLE:

Color Palette:
- Primary Background: warm light beige (#F3EFEA or similar)
- Surface / Card Background: slightly darker beige (#E8E1D9 or similar)
- Primary Text: deep warm charcoal (#2F2E2C)
- Secondary Text: muted warm gray (#6E6A66)
- Accent Color: soft muted black or deep brown (#2C2A28)
- Border Color: subtle warm gray (#D8D2C9)
- No harsh contrast
- No pure white
- No pure black

Typography:
- Headlines: Elegant serif font (similar to Playfair Display or Cormorant)
- Body text: Clean sans-serif (similar to Inter or Manrope)
- Large editorial hero titles
- Generous line height
- Soft letter spacing

UI Tone:
- Calm
- Thoughtful
- Intelligent
- Minimal
- Premium but subtle
- Not flashy
- Not startup-hype

Components to Define:

1. Navigation Bar
   - Rounded container
   - Logo on left
   - Minimal links in center/right
   - Soft background contrast
   - Subtle hover states

2. Buttons
   - Primary button: rounded, soft dark tone
   - Secondary button: outline style
   - Large border radius
   - Smooth hover transitions
   - No gradients

3. Cards
   - Rounded corners (large radius)
   - Soft shadow
   - Beige surface
   - Clean spacing
   - Elegant typography hierarchy

4. Input Fields
   - Rounded
   - Soft border
   - Subtle focus state (border darkens slightly)
   - Clean, spacious
   - No aggressive blue focus ring

5. Text Areas (important for resume input)
   - Large
   - Comfortable padding
   - Calm design
   - Feels like writing in a journal

6. Tag / Badge Style
   - Soft muted background
   - Small rounded pill
   - Used for keywords and score labels

7. Score Display Component
   - Large serif number
   - Minimal circular or boxed indicator
   - Elegant and editorial
   - Not gamified

Layout Principles:
- Large white (beige) space
- Symmetrical grid
- Centered main content
- Max width container
- Soft section separation

Mood:
Feels like:
A thoughtful remote developer working from a wooden desk with coffee.
Minimal.
Intentional.
Crafted.

Do NOT:
- Use bright tech neon colors
- Use glassmorphism
- Use heavy gradients
- Use sharp corners
- Use aggressive contrast

Generate:
- Color system
- Typography system
- Spacing system
- Component examples
- Example button states
- Example card layout
- Example input field
- Example score component

This design system will be used consistently across all pages.
```
