# ADIM 6 — Optimize Page (Core Input Screen)

Bu ekran ürünün kalbi.

Burada kullanıcı:

- CV paste eder
- Job description paste eder
- Optimize butonuna basar

Ve burada tasarımın en çok “journal writing” hissi vermesi gerekiyor.

Aşağıdaki promptu direkt Stitch’e atabilirsin.

---

```
Create the Optimize Page for:

"Remote Tech Jobs Resume Optimizer"

IMPORTANT:
Strictly follow the existing Design System and previously generated UI.
Maintain the exact same warm neutral palette (#F3EFEA background, #E8E1D9 surface).
Preserve serif headlines, sans-serif body text, large rounded corners, soft shadows, and generous spacing.

Do NOT introduce new colors.
Do NOT use gradients.
Do NOT use bright highlights.
Do NOT use pure white or pure black.
Maintain the calm editorial aesthetic.

This is the core feature screen.

LAYOUT STRUCTURE:

1. Authenticated Navigation (same as Dashboard)
- Rounded container
- Logo left
- Links: Dashboard, History, Pricing
- Language toggle
- User avatar
- Consistent styling

2. Page Header Section

Large serif heading:
"New Optimization"

Subtext (muted):
"Tailor your resume for a specific remote tech role."

Right aligned small link:
"View Optimization Guide"

Keep spacing elegant and breathable.

3. Main Input Section (Two-Column Layout)

Use a wide centered container.

LEFT SIDE — Resume Input Card

Rounded large card.
Soft beige surface (#E8E1D9).

Small serif title:
"Your Resume"

Large journal-style text area.
- Rounded
- Spacious padding
- Comfortable writing experience
- Placeholder text:
  "Paste your resume content here..."

Below textarea:
Small muted helper text:
"Tip: Include measurable achievements and technologies used."

RIGHT SIDE — Job Description Input Card

Rounded large card.
Same styling as resume card.

Small serif title:
"Remote Job Description"

Large journal-style text area.
Placeholder:
  "Paste the job description here..."

Below textarea:
Muted helper text:
"Include full description for better keyword analysis."

4. Action Section (Below Both Columns)

Centered.

Primary Button:
"Analyze & Optimize"

Large.
Rounded.
Muted dark tone.
Same style as landing CTA.

Below button:
Small muted text:
"You have 3 free optimizations remaining."

Optional subtle loading state placeholder area (minimal).

5. Visual Balance

Keep the page airy.
Large spacing between sections.
No clutter.
No sidebars.
No heavy UI noise.

This screen must feel:
Focused.
Calm.
Intentional.
Like writing thoughtfully at a desk.

Generate a complete Optimize Page layout fully consistent with the established editorial SaaS design system.
```
