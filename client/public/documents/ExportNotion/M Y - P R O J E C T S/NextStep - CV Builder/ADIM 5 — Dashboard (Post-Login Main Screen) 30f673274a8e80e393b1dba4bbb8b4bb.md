# ADIM 5 — Dashboard (Post-Login Main Screen)

Bu ekran artık “SaaS core” ekranı.

Ama blog estetiğini bozmadan.

Amaç:

- Kullanıcıyı hemen aksiyona sokmak
- Kredi durumunu göstermek
- Geçmiş optimizasyonları göstermek
- Ana CTA: “New Optimization”

Aşağıdaki promptu direkt Stitch’e at:

---

```
Create the Dashboard Page for:

"Remote Tech Jobs Resume Optimizer"

IMPORTANT:
Strictly follow the previously generated Design System and Landing UI.
Maintain the exact same warm neutral palette, serif headline style, spacing logic, rounded containers, and calm editorial aesthetic.

Do NOT introduce new colors.
Do NOT use pure white.
Do NOT use dark mode.
Do NOT use bright accent colors.
Preserve the soft beige background (#F3EFEA) and soft surface cards (#E8E1D9).

This is the first screen users see after logging in.

LAYOUT STRUCTURE:

1. Top Navigation (Authenticated Version)
- Rounded nav container
- Logo on left
- Links: Dashboard, History, Pricing
- Language toggle (EN / TR)
- User avatar on right (minimal circle)
- Soft hover states
- Same style as landing navigation

2. Welcome Section (Top Area)

Large serif heading:
"Your Workspace"

Subtext:
"Optimize your resume for remote opportunities."

Right side:
Primary Button:
"New Optimization"

Rounded.
Muted dark tone.
Consistent with landing CTA style.

3. Credit Status Card

Medium rounded card.
Soft beige surface.
Title (serif small heading):
"Usage Overview"

Inside:
- Remaining credits (large serif number)
- Small muted explanation text
Example:
"3 free optimizations remaining"

Small subtle link:
"Upgrade Plan"

Keep layout calm and minimal.

4. Recent Activity Section

Section title (serif):
"Recent Optimizations"

Below:
3-4 soft rounded cards.

Each card includes:
- Job Title
- Match Score (large serif percentage, e.g. 78%)
- Small muted tags (React, Node.js, Remote)
- Date
- Small subtle "View Details" link

Cards must feel elegant and editorial.
No heavy borders.
Soft shadows only.

5. Quick Stats Section (Optional Right Column or Below)

Two small cards:
- Average Match Score
- Remote Readiness Average

Large serif numbers.
Minimal visual indicators.
Not gamified.

STYLE RULES:

- Large vertical spacing between sections
- Generous padding inside cards
- No sharp corners
- No blue highlights
- No SaaS neon UI
- Maintain thoughtful, crafted atmosphere

This dashboard must feel:
Calm.
Professional.
Organized.
Crafted for serious remote developers.

Generate a complete dashboard layout strictly consistent with the established design system.
```
