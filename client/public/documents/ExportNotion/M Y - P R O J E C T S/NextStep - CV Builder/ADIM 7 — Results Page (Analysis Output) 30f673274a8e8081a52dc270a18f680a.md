# ADIM 7 — Results Page (Analysis Output)

Burası ürünün “wow” anı.

Ama dikkat:

Gamified değil.

Neon değil.

Startup bağırması yok.

Yine editorial.

Yine warm beige.

Yine serif score.

Bu sayfa şunları gösterecek:

- Overall Match Score
- Remote Readiness Score
- Missing Keywords
- AI Suggestions
- Improved Resume Version

Aşağıdaki promptu direkt Stitch’e gönder:

---

```
Create the Results Page for:

"Remote Tech Jobs Resume Optimizer"

IMPORTANT:
Strictly follow the existing Design System and all previous screens (Landing, Dashboard, Optimize).
Preserve:

- Warm beige background (#F3EFEA)
- Soft surface cards (#E8E1D9)
- Serif headlines
- Sans-serif body text
- Large rounded corners
- Subtle shadows
- Generous spacing
- Calm editorial aesthetic

Do NOT introduce new colors.
Do NOT gamify the score.
Do NOT use bright greens or reds.
Do NOT use gradients.
Do NOT use pure white or pure black.

This page displays the AI analysis results after optimization.

LAYOUT STRUCTURE:

1. Authenticated Navigation
Same as Dashboard and Optimize.
Fully consistent styling.

2. Page Header Section

Large serif headline:
"Optimization Results"

Subtext:
"Your resume tailored for this remote opportunity."

Right side subtle button:
"Start New Optimization"

3. Score Overview Section (Top Highlight Area)

Centered wide rounded card.

Inside:

Left:
Large serif percentage (e.g. 82%)
Label:
"Overall Match"

Below:
Muted short explanation:
"Your resume aligns well with this role."

Right:
Two minimal sub-metrics:

Remote Readiness:
Large serif number or text (e.g. High or 90%)

Keyword Match:
Percentage (e.g. 76%)

Keep layout calm and refined.
No circular neon charts.
Minimal progress bars in muted tone only.

4. Missing Keywords Section

Serif section title:
"Missing Keywords"

Below:
Soft rounded tag pills.
Muted beige background.
Subtle spacing.

Example:
REST API
CI/CD
Unit Testing
Async Communication

Short helper text:
"Consider incorporating these naturally into your experience."

5. AI Suggestions Section

Serif section title:
"Improvement Suggestions"

Each suggestion inside soft rounded card blocks.
Minimal icon.
Short actionable feedback.

Example:
"Quantify your impact in the Stripe integration section."
"Highlight cross-functional collaboration in remote settings."

6. Optimized Resume Preview Section

Serif section title:
"Optimized Resume Version"

Large rounded card.
Journal-style text area but read-only.
Comfortable line height.
Generous padding.

Top-right small subtle buttons:
"Copy"
"Download"

Neutral style.
No bright colors.

7. Bottom Action Section

Centered.
Primary Button:
"Save to History"

Secondary subtle link:
"Edit & Re-analyze"

STYLE RULES:

- Large vertical spacing between sections
- No clutter
- No excessive UI elements
- Maintain premium editorial feel
- Elegant typography hierarchy
- Calm neutral palette

This results page must feel:
Insightful.
Refined.
Professional.
Crafted for serious remote developers.

Generate a complete results page layout strictly consistent with the established design system.
```

---

Bu ekran tasarım olarak en güçlü ekran olacak.
