# Tasarım

Stitch gibi tasarım üreten araçlarda iyi sonuç almak için prompt’un **çok net ve yapısal olması** gerekiyor. Yani:

- ürün ne
- kim kullanacak
- hangi sayfalar var
- stil nasıl
- renkler
- UI bileşenleri

hepsi belirtilmeli.

Aşağıdaki prompt’u **direkt copy-paste kullanabilirsin** 👇

---

Design a clean and modern web application UI for an **Apartment Management System** called **“Cumhuriyet Apartmanı”**.

The design language should be **minimalist, elegant, and similar to Apple’s website style**. Use lots of white space, modern typography, soft shadows, and a very clean layout.

The color palette should mainly use **neutral gray tones** with white backgrounds. Avoid bright colors. The design should feel calm, professional, and simple.

Primary colors:

- #111111
- #333333
- #666666
- #f5f5f5
- #ffffff

The website is **Turkish only**.

The application should include the following pages and UI components:

---

Landing Page

A modern landing page with a large hero section.

Hero section should include:

- Title: “Cumhuriyet Apartmanı”
- Clean modern typography
- Minimal background
- Elegant layout

Below the hero section include a **timeline section** that shows the history of the apartment.

Timeline example:

- 2024 — Apartment built
- 2025 — Maintenance improvements
- 2026 — Current financial status

Each year should show:

- total income
- total expenses
- major maintenance activities

The timeline should be visually represented as a **horizontal or vertical timeline line**.

---

Before / After Section

A section that visually shows improvements made to the apartment.

Examples:

- garden improvements
- entrance renovation
- common area upgrades

Use side-by-side image comparison cards.

---

Finance Transparency Section

Residents should be able to see the **income and expense records** of the building.

Design a clean table UI for:

- expense title
- date
- amount
- invoice preview button

Users should be able to click to view uploaded invoices.

---

Meeting Notes Section

A section that displays apartment meeting records.

Each meeting card should include:

- meeting date
- meeting time
- number of apartments that attended
- meeting notes
- decisions made

Use modern card components.

---

Admin Dashboard (Manager Panel)

This panel is only accessible via login.

Dashboard sections should include:

Aidat Management (Monthly Fees)

- apartment list
- payment status
- mark as paid / unpaid

Income / Expense Management

- add expense
- add invoice
- upload PDF or image
- expense list

Meeting Management

- create meeting
- add meeting notes
- track attendance

Apartment List

Show all 18 apartments with owner names.

---

Design Style

- Inspired by Apple website design
- Minimal UI
- Rounded cards
- Soft shadows
- Clean typography
- Large spacing
- Smooth layout

Avoid clutter.

The interface must look **modern, premium, and very simple**.

---

Footer

At the bottom center of the page include an animated text:

“Kutluhan Gül tarafından hazırlanmıştır”

Use a subtle animation or fade effect.—
