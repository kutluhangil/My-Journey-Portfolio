# PROJEYİ BİLGİSAYARINIZA ÇEKME TALİMATI

Arkadaşlar, hepimiz aynı şekilde ilerleyelim  diye adımları net yazıyorum.

![:one:](https://a.slack-edge.com/production-standard-emoji-assets/14.0/apple-medium/0031-fe0f-20e3.png)

VS Code’u açın

- Başka bir proje **açık olmasın**

![:two:](https://a.slack-edge.com/production-standard-emoji-assets/14.0/apple-medium/0032-fe0f-20e3.png)

Klasör açın

- **File → Open Folder**
- **Desktop**’ı (ya da çalışmak istediğiniz ana klasörü) seçin

![:three:](https://a.slack-edge.com/production-standard-emoji-assets/14.0/apple-medium/0033-fe0f-20e3.png)

VS Code içinden terminal açın

- **Terminal → New Terminal**
- Terminal yolu Desktop’ı göstermeli

![:four:](https://a.slack-edge.com/production-standard-emoji-assets/14.0/apple-medium/0034-fe0f-20e3.png)

Repo’yu clone edin

Terminale şunu yazın:

```

git clone https://github.com/january-javaScript-project/cinemania.git

```

![:five:](https://a.slack-edge.com/production-standard-emoji-assets/14.0/apple-medium/0035-fe0f-20e3.png)

Proje klasörünü açın

- **File → Open Folder**

**cinemania** klasörünü seçin

- Tekrar **Terminal → New Terminal**

> Terminalin yolu şuna benzemeli:
> 

```

.../cinemania>

```

![:six:](https://a.slack-edge.com/production-standard-emoji-assets/14.0/apple-medium/0036-fe0f-20e3.png)

Güncel kodu alın (zorunlu)

```

git checkout main
git pull origin main

```

![:seven:](https://a.slack-edge.com/production-standard-emoji-assets/14.0/apple-medium/0037-fe0f-20e3.png)
