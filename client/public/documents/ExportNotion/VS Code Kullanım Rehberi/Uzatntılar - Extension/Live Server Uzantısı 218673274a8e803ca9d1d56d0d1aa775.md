# Live Server Uzantısı

Bir tane daha kritik uzantı kaldı, bu da kod yazarken çok faydalı olacak..

Geliştirme sırasında projeyi manuel olarak tarayıcıda açmak pratik olmayabilir, çünkü bir dizi sınırlama vardır. Bunun yerine, özel web sunucuları kullanılır.

Geliştirme için Web Sunucusu:

- Doğrudan bilgisayarınızda başlar.
- Gerçek bir web sunucusunu taklit eder.
- Kodunuzdaki değişikliklerde tarayıcı sekmesini otomatik olarak yeniden yükler gibi ek işlevler sunar.

1. Web sunucusu bağlantısı için uzantı eklemek için,

- Arama çubuğuna live server yazın.
- Tam adı **Live Server** olan uzantıya tıklayın.
- **Install** butonuna tıklayın.

```
Live Server uzantısı bir kez kurulur ve tüm projeler için etkin olur.

```

2. Kurulumdan sonra,

- Uzantı sekmesini kapatın,
- Aktif projeyi **index.html** aç,

Durum çubuğunda **Go Live** simgesini göreceksiniz.

```
EğerGo Live simgesi görünmüyorsa, editörü yeniden başlatmanız ve projeyi tekrar açmanız gerekebilir.

```

3. Web sunucusunu başlatmak için **Go Live** simgesine tıklayın.

4. Kodu üzerindeki değişikliklerin sunucuda nasıl yansıdığını görün.

5. Web sunucuyu durdurmak için **Port: ...** simgesine tıklayın ve tekrar **Go Live** simgesine dönmesini bekleyin.

Sunucu durduruldu.

```
Editörü kapatmadan önce, başlatılmış olan web sunucuyu kapatmayı unutmayın.
Bunu yapmazsanız, port (web sayfasının başlatıldığı adres) meşgul olacak ve onu serbest bırakmak için bilgisayarı yeniden başlatmanız gerekecek.
```
