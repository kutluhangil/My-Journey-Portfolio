# HTML CSS Support ve Path Intellisense Uzantısı

VS Code’un yetenekleri, varsayılan düzenleyicide sunulan işlevsellikleriyle sınırlı değildir. VS Code uzantıları; tema değiştirme, kod kalite Kontrolü ekleme, otomatik Biçimlendirme gibi daha spesifik özelliklerle destek eklemenize olanak tanır. Tüm bu uzantılar geliştirme sürecini kolaylaştırır. Bugün VS Code’a birkaç faydalı uzantı yükleyeceğiz.

1. Uzantı panelini açmak için **Uzantılar** (kare simgeli olan). En üstte arama paneli, en altta sonuçlar panelini göreceksiniz.

2. HTML CSS Support uzantısını ekleyelim, bu size işaretleme sürecinizi hızlandırmaya ve hataları önlemeye yardımcı olacaktır. Bunun için:

- Arama paneline html css support yazın,
- Listeden gerekli uzantıya tıklayın,
- **Install** butonuna tıklayın.

Bir uzantıyı tek sefer yüklemeniz yeterlidir. Yüklediğiniz uzantı, gelecekteki tüm projelerde aktif olacaktır.

```
Bazı uzantıların yüklenmesi, VS Code'un yeniden başlatılmasını gerektirebilir. Bu durumda, genellikle Install butonunun yanında bir yeniden yükleme seçeneği sunan bir mesaj görüntülenir.

```

3. Her uzantının, özelliklerini ve kullanım talimatlarını açıklayan bir belgesi bulunmaktadır.

HTML CSS Support uzantısının belgelerini inceleyerek, fonksiyonları ve araçları hakkında bilgi edinebilirsiniz.

![](https://s3.eu-north-1.amazonaws.com/lms.goit.files/7afce0f8-5931-4911-b5f4-f85f9f187f0eUntitled%20%2846%29.png)

4. **HTML CSS Support** uzantısının ne yaptığına bir göz atalım.

Her defasında bir sınıf veya özellik adını yazmaya başladığınızda, hızlı giriş ve hatalardan kaçınmak için açılır listede olası seçenekleri önerir.

5. Şimdi **Path Intellisense** uzantısını ekleyelim. Bu, işaretleme sürecinizi hızlandırmaya ve hatalardan kaçınmaya yardımcı olacaktır. Bunun için:

- Hala **Uzantılar** bölümünde olduğunuzdan emin olun — yeşil oku kontrol edin.
- Arama paneline path intellisense yazın,
- Listeden gerekli uzantıya tıklayın,
- **Install** düğmesine tıklayın.

Aşağıda, uzantının işlevselliğine dair açıklamaları görebilirsiniz.

6. **Path Intellisense** uzantısının nasıl çalıştığını öğrenelim.

Bu uzantı, projenizdeki dostaların adlarını ve yolunu hatırlar ve bu bilgileri otomatik tamamlamada önerir — videodaki ./css kısmından sonraki her şey.

Projede birçok ek dosta olduğunda bu özellik zaman kazandırır ve geliştiricinin verimliliğini artırır.

Tebrikler, HTML CSS Support ve Path Intellisense uzantıları başarıyla yüklendi!
