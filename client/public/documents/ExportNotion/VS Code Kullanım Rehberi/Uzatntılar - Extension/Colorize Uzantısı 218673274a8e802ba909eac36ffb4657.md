# **Colorize Uzantısı**

Hadi şimdi, görsel çalışmayı kolaylaştıran uzantıları ekleyelim!

1. Hala **Uzantılar** bölümünde olduğunuzdan emin olun.

![](https://s3.eu-north-1.amazonaws.com/lms.goit.files/5dbaf6f5-ba39-4cf5-bde8-b33c18913ce5Untitled%20%2849%29.png)

2. **Colorize** uzantısını ekleyelim. Bunun için:

- Arama çubuğuna colorize yazın.
- **Colorize** listede görünüyorsa, tıklayın — eğer birden fazla sürüm görüyorsanız, **kamikillerto** adlı yazarın sürümünü seçin.
- **Install** butonuna tıklayın.

```
Colorize extension hızlıca CSS renklerini projenizde görselleştirir. Bu uzantı ayrıca stillerin her biri için renkleri bulur ve uygun renk kullanarak bir arka plan oluşturur. Nasıl çalıştığını uzantının açıklamasında görebilirsiniz.

```

Tebrikler, colorize uzantısı başarıyla yüklendi!
