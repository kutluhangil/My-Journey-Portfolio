# Auto Close Tag - Rename Tag - Highlight Matching Tag

Şu anda zaten iki yardımcı uzantınız var, ancak bu, VS Code'da etkili çalışma için yeterli değil. Geliştiriciler genellikle etiketlerle, yani hipertext işaretleme dilinin öğeleriyle yoğun bir şekilde çalışırlar. Bu nedenle, etiketleri doğru kullanmaya yardımcı olacak ve hızlı hataları bulmaya yardımcı olacak uzantılar ekleyelim.

1. Hala **Uzantılar** bölümünde olduğunuzdan emin olun.

![](https://s3.eu-north-1.amazonaws.com/lms.goit.files/117ba48c-ff44-41f8-b17a-e1d7a76b5cf1Untitled%20%2848%29.png)

2. **Auto Close Tag** uzantısını ekleyelim. Bunun için:

- Arama çubuğuna auto close tag yazın,
- Altındaki listeden **Auto Close Tag**’e tıklayın,
- **Install** düğmesine basın.

```
Eşleşen birkaç etiket var — bunlar, düzgün çalışma için hem bir açılış hem de kapanış etiketi gerektirenlerdir. Tabii ki, kod yazarken kapanış etiketini unutmak kolay olabilir.Auto Close Tag uzantısı, yazarken otomatik olarak kapanış etiketini ekleyecektir. Nasıl çalıştığını uzantının açıklamasında görebilirsiniz.

```

3. **Auto Rename Tag** uzantısını ekleyelim. Bunun için:

- Arama çubuğuna auto rename tag yazın,
- Altındaki listeden **Auto Rename Tag**’e tıklayın,
- **Install** butonuna tıklayın.

```
Auto Rename Tag uzantısı, bir etikete yapılan değişikliklerde eşleşen etikette otomatik olarak aynı değişiklikleri yapar. Nasıl çalıştığını uzantının açıklamasında görebilirsiniz.

```

4. **Highlight Matching Tag** uzantısını ekleyelim. Bunun için:

- Arama çubuğuna highlight matching tag yazın,
- Altındaki listeden **Highlight Matching Tag**’e tıklayın,
- **Install** butonuna tıklayın.

```
Highlight Matching Tag uzantısı, ilgili açılış ve/veya kapanış etiketlerini vurgular. Ayrıca, etiketin yolunu durum çubuğunda gösterir. Nasıl çalıştığını uzantının açıklamasında görebilirsiniz.

```

Tebrikler, etiketlerle çalışmayı kolaylaştırmak için uzantılar başarıyla yüklendi!
