# **Gremlins tracker for Visual Studio Code Uzantısı**

Kod içinde çeşitli hataları bulmaya yardımcı olan bir uzantı olduğunu biliyor musunuz? Böyle bir uzantı kullanmak ister misiniz?

1. Hala **Uzantılar** bölümünde olduğunuzdan emin olun.

![](https://s3.eu-north-1.amazonaws.com/lms.goit.files/b8f9f5e5-867e-421b-bd5d-8149563db876Untitled%20%2850%29.png)

2. **Gremlins tracker for Visual Studio Code** uzantısını ekleyelim. Bunun için:

- Arama çubuğuna gremlins yazın.
- Altındaki listeden **Gremlins tracker for Visual Studio Code**’u seçin.
- **Install** butonuna tıklayın.

```
Gremlins tracker for Visual Studio Code uzantısı, potansiyel sorunlu karakterleri gösterir - görünmeyen veya tehlikeli karakterleri, örneğin Ukrayna ve İngilizce "c" harfleri gibi, neredeyse aynı görünen karakterleri. Yanlış tire tipi (kısa, uzun, tire), basılı tırnaklar ve benzerleri de buna dahildir.

```
