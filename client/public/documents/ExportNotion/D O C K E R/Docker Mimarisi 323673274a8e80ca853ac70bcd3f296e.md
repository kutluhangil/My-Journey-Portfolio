# Docker Mimarisi

Docker, client-server mimarisi kullanır. Docker client, Docker daemon ile iletişim kurar; daemon, Docker container’larının oluşturulması, çalıştırılması ve dağıtılması gibi işlemleri gerçekleştirir. Docker client ve daemon aynı sistemde çalışabilir ya da bir client, uzak bir daemon’a bağlanabilir. Docker client ve daemon, UNIX socket’leri veya ağ arayüzü üzerinden REST API aracılığıyla iletişim kurar. Bir diğer Docker client aracı da **Docker Compose**’tur; bu araç, birden fazla container’dan oluşan uygulamalarla çalışmanızı sağlar.
