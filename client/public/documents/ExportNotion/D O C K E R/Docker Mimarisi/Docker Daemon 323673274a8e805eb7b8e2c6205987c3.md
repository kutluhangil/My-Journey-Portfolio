# Docker Daemon

Docker daemon (**`dockerd`**), Docker API isteklerini dinler ve image, container, network ve volume gibi Docker nesnelerini yönetir. Bir daemon, diğer daemon’larla iletişim kurarak Docker servislerini de yönetebilir.

---

## **1️⃣ Docker Daemon nedir?**

**Docker Daemon**, Docker’ın arka planda çalışan ana servisidir.

Görevleri:

- Docker komutlarını dinler
- Container’ları yönetir
- Image’ları yönetir
- Network’leri yönetir
- Volume’ları yönetir

Yani terminalde bir komut yazdığında aslında **Docker CLI → Docker Daemon’a istek gönderir**.

---

## **2️⃣ Docker nasıl çalışır? (Basit akış)**

Docker mimarisi 3 ana parçadan oluşur:

1️⃣ **Docker CLI**

2️⃣ **Docker Daemon (dockerd)**

3️⃣ **Docker Objects (container, image vb.)**

Akış şöyle olur:

```
Terminal (docker run nginx)
        ↓
Docker CLI
        ↓
Docker API
        ↓
Docker Daemon (dockerd)
        ↓
Container oluşturulur
```

Örneğin:

```
docker run nginx
```

Bu komut şunları yapar:

1️⃣ CLI komutu alır

2️⃣ Docker API üzerinden daemon’a gönderir

3️⃣ Daemon image kontrol eder

4️⃣ Yoksa indirir

5️⃣ Container oluşturur

6️⃣ Container’ı başlatır

---

## **3️⃣ Docker Daemon hangi şeyleri yönetir?**

### **📦 Image**

Container oluşturmak için kullanılan template.

Örnek:

```
docker pull node
```

---

### **📦 Container**

Çalışan uygulama.

Örnek:

```
docker run node
```

---

### **🌐 Network**

Container’ların birbirleriyle iletişimi.

Örnek:

```
docker network create my-network
```

---

### **💾 Volume**

Kalıcı veri saklama.

Örnek:

```
docker volume create my-volume
```

---

## **4️⃣ Docker Daemon aslında bir servis**

Linux veya Mac’te şu şekilde çalışır:

```
dockerd
```

Terminalde kontrol edebilirsin:

```
docker info
```

veya Linux’ta:

```
systemctl status docker
```

---

## **5️⃣ Docker Daemon neden önemli?**

Çünkü **Docker CLI tek başına hiçbir şey yapamaz.**

CLI sadece komut gönderir.

Asıl işi yapan:

```
Docker Daemon
```

---

## **6️⃣ Birden fazla daemon olabilir mi?**

Evet.

Metindeki şu cümle bunu anlatıyor:

> Bir daemon, diğer daemon’larla iletişim kurarak Docker servislerini de yönetebilir.
> 

Bu özellikle:

- **Docker Swarm**
- **Kubernetes**
- **Cluster sistemleri**

için kullanılır.

Yani birden fazla Docker host birlikte çalışabilir.

---

## **7️⃣ Gerçek hayat örneği**

Şunu yazdığında:

```
docker run -p 3000:3000 my-app
```

arkada şunlar olur:

Docker daemon:

1️⃣ image kontrol eder

2️⃣ container oluşturur

3️⃣ network bağlar

4️⃣ port map eder

5️⃣ container çalıştırır
