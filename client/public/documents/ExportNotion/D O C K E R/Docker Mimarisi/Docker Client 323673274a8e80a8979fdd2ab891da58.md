# Docker Client

Docker client (**`docker`**), Docker kullanıcılarının Docker ile etkileşim kurmasının birincil yoludur. **`docker run`** gibi komutlar kullandığınızda, client bu komutları **`dockerd`**’a gönderir ve daemon bunları yürütür. **`docker`** komutu Docker API’yi kullanır ve birden fazla daemon ile iletişim kurabilir.

---

## **1️⃣ Docker Client nedir?**

**Docker Client**, Docker kullanıcılarının Docker sistemi ile etkileşim kurmasını sağlayan komut satırı aracıdır.

Terminalde kullandığın şu komut aslında Docker Client’tır:

```
docker
```

Örneğin:

```
docker run nginx
docker build .
docker ps
docker pull node
```

Bu komutların hepsi **Docker Client tarafından gönderilir**.

---

## **2️⃣ Docker Client ne yapar?**

Docker Client’ın görevi:

- Kullanıcıdan komut almak
- Komutu Docker API formatına çevirmek
- Docker Daemon’a göndermek
- Daemon’dan gelen sonucu kullanıcıya göstermek

Yani Client **kendisi container çalıştırmaz**.

Sadece komutu **daemon’a iletir**.

---

## **3️⃣ Docker Client → Docker Daemon iletişimi**

Docker Client ile Docker Daemon arasında iletişim **Docker API** üzerinden gerçekleşir.

Akış şu şekildedir:

```
User (Terminal)
      ↓
Docker Client (docker command)
      ↓
Docker API
      ↓
Docker Daemon (dockerd)
      ↓
Container / Image / Network işlemleri
```

---

### **Örnek**

Terminalde şu komutu yazdın:

```
docker run nginx
```

Arka planda olanlar:

1️⃣ Docker Client komutu alır

2️⃣ Docker API ile daemon’a gönderir

3️⃣ Daemon nginx image’ını kontrol eder

4️⃣ Yoksa Docker Hub’dan indirir

5️⃣ Container oluşturur

6️⃣ Container’ı çalıştırır

Sonuç tekrar Client’a gönderilir ve terminalde gösterilir.

---

## **4️⃣ Docker Client hangi komutları çalıştırır?**

Docker Client üzerinden kullanılan bazı temel komutlar:

### **Container komutları**

```
docker run
docker start
docker stop
docker rm
docker ps
```

---

### **Image komutları**

```
docker pull
docker push
docker build
docker images
```

---

### **Network komutları**

```
docker network ls
docker network create
```

---

### **Volume komutları**

```
docker volume create
docker volume ls
```

---

## **5️⃣ Docker Client birden fazla daemon ile çalışabilir**

Metinde şu cümle geçiyor:

> docker komutu Docker API’yi kullanır ve birden fazla daemon ile iletişim kurabilir
> 

Bu şu anlama gelir:

Docker Client farklı Docker host’larına bağlanabilir.

Örneğin:

```
Local Docker Daemon
Remote Docker Daemon
Cloud Docker Daemon
```

Örnek kullanım:

```
docker -H tcp://192.168.1.10:2375 ps
```

Bu komut **uzaktaki Docker daemon’a bağlanır**.

---

## **6️⃣ Docker Client aslında bir CLI tool**

Docker Client bir **CLI (Command Line Interface)** aracıdır.

Yani:

```
docker
docker-compose
docker buildx
```

bunların hepsi Docker Client araçlarıdır.

---

## **7️⃣ Docker Client neden önemlidir?**

Çünkü kullanıcı Docker ile **doğrudan daemon üzerinden değil client üzerinden iletişim kurar**.

Client:

- kullanıcı ile sistem arasında köprü görevi görür
- komutları API çağrılarına çevirir
- çıktıyı kullanıcıya gösterir

---

## **8️⃣ Gerçek hayattan basit bir benzetme**

Docker sistemini bir **restoran** gibi düşün.

👨‍🍳 **Docker Daemon → aşçı**

🧑‍💻 **Docker Client → garson**

🍔 **Container → yemek**

Akış:

```
Sen → garsona sipariş verirsin
Garson → aşçıya iletir
Aşçı → yemeği hazırlar
Garson → sana getirir
```

Yani kullanıcı **aşçı ile değil garson ile konuşur**.
