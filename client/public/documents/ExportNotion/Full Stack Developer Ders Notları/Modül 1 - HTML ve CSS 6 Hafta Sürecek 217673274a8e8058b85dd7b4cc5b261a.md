# Modül 1 - HTML ve CSS 6 Hafta Sürecek

Created: June 19, 2025 10:12 PM
Class: H T M L - C S S

*Modül 1: HTML Temelleri*

*✅ HTML'in yapısını ve temel etiketlerini öğreneceğiz.*

*✅ Başlıklar, paragraflar, listeler, bağlantılar, görseller ve diğer temel HTML öğelerini kullanabileceğiz.*

*✅ Web sayfalarının nasıl oluşturulduğunu ve tarayıcıda nasıl görüntülendiğini anlayacağız.*

*Modül 2: CSS Temelleri*

*✅ CSS ile web sayfalarını nasıl stillendireceğimizi öğreneceğiz.*

*✅ Yazı tipleri, renkler, arka planlar ve kenarlıklar gibi görsel unsurları nasıl kontrol edeceğimizi anlayacağız.*

*✅ CSS seçicilerini ve stil kurallarını etkili bir şekilde kullanabileceğiz.*

*Modül 3: Kutu Modeli ve Flexbox*

*✅ HTML öğelerinin kutu modeli içinde nasıl davrandığını öğreneceğiz.*

*✅ Öğelerin kenar boşlukları (margin), dolgu (padding) ve çerçeve (border) gibi özelliklerini kullanabileceğiz.*

*✅ Flexbox ile sayfa düzenlerini daha esnek ve duyarlı hale getirebileceğiz.*

*Modül 4: CSS Efektleri ve Animasyonlar*

*✅ Gölgelendirme, degradeler ve geçiş efektleri gibi görsel iyileştirmeler yapabileceğiz.*

*✅ CSS ile basit animasyonlar ve geçiş efektleri oluşturabileceğiz.*

*✅ Hover efektleri ve buton animasyonlarıyla kullanıcı deneyimini artırabileceğiz.*

*Modül 5: Formlar ve Veri Görselleştirme*

*✅ HTML form elemanlarını (input, checkbox, radio button, textarea, select vb.) kullanarak etkileşimli formlar oluşturabileceğiz.*

*✅ Form validasyonu yaparak kullanıcı hatalarını önleyebileceğiz.*

*✅ Tabloları kullanarak verileri düzenli ve anlaşılır bir şekilde gösterebileceğiz.*

*Modül 6: Responsive Tasarım*

*✅ Mobil uyumlu (responsive) web siteleri tasarlayabileceğiz.*

*✅ Media queries kullanarak farklı ekran boyutlarına uyum sağlayan tasarımlar oluşturabileceğiz.*

*✅ Flexbox ve diğer CSS teknikleriyle duyarlı sayfa düzenleri oluşturabileceğiz.*

*📌 **Sonuç:***

*Bu kursu tamamladığımızda, modern web sayfaları oluşturmak için HTML ve CSS'in temel ve ileri düzey özelliklerini kullanabileceğiz. Mobil uyumlu, erişilebilir ve estetik web siteleri tasarlayarak öğrendiklerimizi projelerimize uygulayabileceğiz. 🚀*
