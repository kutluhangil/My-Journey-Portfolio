# Tool Overview

The **Time Series Tool UI** allows you to annotate audio by creating timestamp intervals directly on the spectrogram.

- [x]  **Draw boxes** on the spectrogram to mark intervals.
    - [x]  Use the **Questions panel** to apply labels and answer follow-up questions.
    - [x]  For accuracy, use **zoom and scrub functions** (see Hot Keys for shortcuts).
        
        ![Screenshot 2026-01-09 .jpg](Tool%20Overview/Screenshot_2026-01-09_.jpg)
        

To navigate the tool refer to the Hot Keys section below.

Time Series Tool Hot Keys

|  | **Hotkey** | **Function** |
| --- | --- | --- |
| 1 | spacebar | Toggle play and pause |
| 2 | Left Click | Add, select, and modify annotations |
| 3 | Right Click | Pan the chart |
| 4 | Shift + drag | Move the playhead (scrub) |
| 5 | Scroll on mouse | Zoom in / out of the chart |
| 6 | r | Reset zoom level |
| 7 | a | Annotate at current mouse position |
| 8 | esc | Deselect annotation |
| 9 | delete / backspace | Delete selected annotation |
| 10 | alt + click | Place an annotation that overlaps another |
| 11 | left / right arrow | Jump to the beginning / end of the audio clip |
| 12 | up / down arrow | Select the next / previous timestamp |
| 13 | q / w | Decrease / Increase the playback rate |
