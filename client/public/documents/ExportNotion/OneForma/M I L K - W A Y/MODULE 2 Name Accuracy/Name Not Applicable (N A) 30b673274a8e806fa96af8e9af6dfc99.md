# Name Not Applicable (N/A)

![](https://my.oneforma.com/blobweb/Recruiter/courses/1229/course/assets/OgUI2O/stock-image.jpg)

The N/A rating should be used for all address type results, including residential addresses, streets, localities, and so on.

Unlike Business/POI type results, address type results do not actually have a result name. Instead, the first line of address type results appears as the result title because this field is meant to present the most relevant part of the address information.

![](https://my.oneforma.com/blobweb/Recruiter/courses/1229/course/assets/Picture1.jpg)

Since address results do not have a name, their Name Accuracy cannot be evaluated. Therefore the N/A rating should be selected.
