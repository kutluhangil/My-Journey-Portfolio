# **Let's understand how to report issues related to street components.**

## **Street Number**

If the result address has an incorrect or missing street number, rate Address Accuracy as **Incorrect** – Street Number.

**Street Number ExtensionsAddress Range**

Some markets use a street number extension system. Street number extensions are part of the street number, not a further breakdown of it like building or unit numbers. If a street number extension is incorrect or missing from a POI address it should be treated as an incorrect/missing street number.
