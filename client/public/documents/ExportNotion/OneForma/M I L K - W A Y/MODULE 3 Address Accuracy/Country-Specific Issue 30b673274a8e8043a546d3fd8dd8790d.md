# Country-Specific Issue

The variety of address formats and distinctive country-specific issues is broad. In general, use the checkbox for ***Country Specific Issue*** when there is an address problem that is not covered by the available checkboxes. This includes things like instances when an address also requires a sub-locality or municipality in addition to locality and state, but those components are either missing or incorrect. See your Country Specific guidelines for more information.

## **Country-Specific Issue Vs. Correct with Formatting Issue**

Any additional components beyond the regular address format for a country are rated:

- **Correct  –** with formatting issue if correct
- **Incorrect –** Country Specific Issue if very unusual or wrong
