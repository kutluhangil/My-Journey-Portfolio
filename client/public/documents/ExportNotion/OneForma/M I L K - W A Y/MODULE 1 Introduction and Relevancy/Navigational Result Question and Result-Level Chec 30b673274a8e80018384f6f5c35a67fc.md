# Navigational Result Question and Result-Level Checkboxes

**Query-Level “Navigational Result” Question**

You will answer one question for each query 'Is there a navigational result for this query?'

This means are there any real results results that would completely satisfy the user's intent.

Even if presented with a query that has no results, you must still answer this question and submit your answer

| Query-level question | Explanation | Notes |
| --- | --- | --- |
| Is there a navigational result for this query? | Are there any results in the real world that can completely satisfy the user intent? | You will only need to answer this question once for each query. |

A result that would completely satisfy a user is when we can tell from their query there is an **exact** place they looking for, for example:

**Query** [Holiday Inn London - Bloomsbury, Coram Street, London]

*Is there a navigational result for this query*? Yes - a side search shows there is a hotel of this name, on this street in London - the user is looking for somewhere that exists and an exact match would be possible.

___________________________________________________

**Query** [Holiday Inn London]

*Is there a navigational result for this query*? No - side search shows there are lots of Holiday Inn hotels in London and the user has not specified they are looking for an exact one with the information they have given in their query.

**Result-Level Rating Checkboxes**

For each result, you will be presented with two high-level questions. These will allow you to highlight any problems at the result level.

| High-level question | Explanation | Notes |
| --- | --- | --- |
| Result name/ title is in unexpected language or script | Result is not in the language of the query, the test locale, or the result region (the expected languages) or is in a mix of expected and unexpected languages (unless it is an official company, chain, or brand name). | If you check this box, your rating for this result will be complete (all other questions will be unavailable). |
| 
 
Business/POI is closed or does not exist | 
 
Research shows that the business is closed or that no such business exists at the address listed in the result. | If you check this box, you will rate only the relevance of the result as if it did exist. All other questions will become unavailable, and your rating will be complete.
Use thorough research and your best judgement to determine whether the result is closed, has never existed, or the result component(s) are incorrect.See Unclear Results for further guidance. |
