# Introduction: Pin Accuracy

![](https://my.oneforma.com/blobweb/Recruiter/courses/1229/course/assets/c56N6e/stock-image.png)

For each result returned, you will find a pin on the map. Rate the accuracy of each pin’s placement using this scale:

- **Perfect**
- **Approximate**
- **Next Door**
- **Wrong**
- **Can’t Verify**

The location represented by the pin should reflect the result. Pin ratings should be evaluated individually and not influenced by address or other data. A pin can be correct when other rating components are rated wrong.
