# Vercel'e Dağıtım

**Vercel**'de dağıtım yaptıktan sonra yönlendirme ile çalışan uygulamanın doğru çalışması için proje kök dizinine **`vercel.json`** yapılandırma dosyası eklenmelidir.

**Vercel**'de dağıtım yaptıktan sonra yönlendirme ile çalışan uygulamanın doğru çalışması için proje kök dizinine **`vercel.json`** yapılandırma dosyası eklenmelidir.

![](https://s3.eu-north-1.amazonaws.com/lms.goit.files/bd5691e4-67ca-49eb-bbed-c51d25d2a903Screenshot%202024-02-04%20at%2015.36.20.png)

**`vercel.json`** dosyasının içeriği aşağıdaki gibi görünmelidir.

```
{
  "rewrites":  [
    {"source": "/(.*)", "destination": "/"}
  ]
}
```

Bu dosya, projenin ilk ayarları sırasında veya ilk dağıtımdan önce oluşturulabilir. **`vercel.json`** dosyasını ekledikten sonra, dosyayı GitHub deposuna göndermek için bir Git komutu kullanmalısınız. Bu işlem, Vercel'in projeyi derlemesine ve yapılandırma dosyasını kullanarak dağıtım sürecini tamamlamasına olanak tanır.

# **Bu yapılandırmanın amacı nedir?**

Vercel sunucusu, varsayılan olarak web uygulamanızın her bir rotası için belirli bir HTML dosyasını bulmaya çalışır. Örneğin:

- **`my-app.com`** - hosting **`index.html`** dosyasını döndürmeye çalışır.
- **`my-app.com/about`** - hosting **`about.html`** dosyasını döndürmeye çalışır.
- **`my-app.com/profile`** - hosting **`profile.html`** dosyasını döndürmeye çalışır ve devam eder.

Ancak, React uygulamamızda yalnızca **`index.html`** dosyası bulunur. URL değişikliklerinde aynı **`index.html`** dosyası kullanılarak farklı bileşenler render edilir.

Herhangi bir rotaya geçildiğinde sunucunun her zaman **`index.html`** dosyasını döndürmesini sağlamamız gerekiyor. Ardından, React Router kontrolü devralarak mevcut URL için sayfa bileşenlerini görüntülemeye başlayabilir.

İşte **`vercel.json`** dosyasının amacı budur: Vercel'e, uygulamanızın Tek Sayfa Uygulaması (SPA) olduğunu ve tüm yönlendirmelerde **`index.html`** dosyasının döndürülmesi gerektiğini bildirir.
