# Değer Türleri

`get()` metodu, sorgu dizesinde belirtilen parametre değerine bakılmaksızın her zaman bir dize döndürecektir. Örneğin, `?name=hoodie&maxPrice=500&inStock=true`şeklindeki bir sorgu dizesi için, aşağıdaki parametre değerlerini alırız.

```
const [searchParams] = useSearchParams();

const name = searchParams.get("name");
console.log(name, typeof name);// "hoodie", string

const maxPrice = searchParams.get("maxPrice");
console.log(maxPrice, typeof maxPrice);// "500", string

const inStock = searchParams.get("inStock");
console.log(inStock, typeof inStock);// "true", string
```

Eğer parametreler sayılarsa veya daha önce sayılar olmuşlarsa, doğru türde bir değer elde etmek için tür dönüştürme yapılması gerekir. Bu, `Number(value)` ve `Boolean(value)` yerleşik sınıfları ile gerçekleştirilebilir.
