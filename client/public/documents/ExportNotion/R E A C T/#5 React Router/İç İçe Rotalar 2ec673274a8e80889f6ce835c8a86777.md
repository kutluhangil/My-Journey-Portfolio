# İç İçe Rotalar

İç içe rotalar, bir ana sayfa bileşeninin altındaki alt bileşenlerin hangi URL'ler altında gösterileceğini tanımlamamızı sağlar. Bu yapı, belirli bir rotanın (örneğin `/about`) altındaki daha spesifik rotalar (örneğin `/about/mission`, `/about/team`, `/about/reviews`) aracılığıyla, ilgili bileşenlerin içerik hiyerarşisini kurmamıza olanak tanır.

Örneğin, `/about/mission`, `/about/team` ve `/about/reviews` gibi URL'lerde, "Hakkımızda" sayfasının altında şirketin misyonunu anlatan makaleleri, ekip bilgilerini veya kullanıcı yorumlarını gösteren alt bileşenler görüntülemek istiyoruz.

```
// ❌ Yanlış
<Route path="/about" element={<About />} />
<Route path="/about/mission" element={<Mission />} />
<Route path="/about/team" element={<Team />} />
<Route path="/about/reviews" element={<Reviews />} />
```

Bu şekilde rotalar tanımlandığında, dört bağımsız sayfa elde ederiz. `/about`adresinde sadece bilgi sayfası görüntülenirken, `/about/team` adresinde yalnızca çalışanlar galerisi görüntülenir. Ancak ihtiyacımız olan şey, ana sayfa bileşeni ile birlikte ilgili alt bileşenlerin de aynı sayfa içinde yer almasıdır. Bunun için iç içe rotaları kullanmamız gereklidir.

```
// ✅ Doğru
<Route path="/about" element={<About />}>
  <Route path="mission" element={<Mission />} />
  <Route path="team" element={<Team />} />
  <Route path="reviews" element={<Reviews />} />
</Route>
```

Bu yapıdaki birkaç önemli noktaya dikkat edin:

- Alt yönlendirmeleri, **üst** `<Route>` bileşeninin içerisine tanımladık. Bu, alt rotaların **ana** bileşenin içinde bir yerde render edileceğini belirtir.
- Alt rotaların `path` prop'u, **üst** rotaya göre belirlenir. Örneğin, `path="mission"`tanımlaması, tam yol olan `path="/about/mission"` yerine göreceli bir yol tanımlamaktır.
- Göreceli yollar, baştaki `/` işareti olmadan yazılır; yani `path="mission"`, `path="/mission"` değil. Eğer bir eğik çizgi eklersek, bu durumda ayrı bir yönlendirme olan `/mission` oluşturur ve yönlendirme mantığını bozmuş oluruz.

Uygulamamızın yönlendirme tam konfigürasyonu bu şekilde görünecektir.

**App.jsx**

```
import { Routes, Route, Link } from "react-router-dom";
import Home from "path/to/pages/Home";
import About from "path/to/pages/About";
import Products from "path/to/pages/Products";
import NotFound from "path/to/pages/NotFound";
import ProductDetails from "path/to/pages/ProductDetails";
import Mission from "path/to/components/Mission";
import Team from "path/to/components/Team";
import Reviews from "path/to/components/Reviews";

export const App = () => {
  return (
    <div>
      <nav>
        <Link to="/">Home</Link>
        <Link to="/about">About</Link>
        <Link to="/products">Products</Link>
      </nav>
      <Routes>
        <Route path="/" element={<Home />} />
        <Route path="/about" element={<About />}>
          <Route path="mission" element={<Mission />} />
          <Route path="team" element={<Team />} />
          <Route path="reviews" element={<Reviews />} />
        </Route>
        <Route path="/products" element={<Products />} />
        <Route path="/products/:productId" element={<ProductDetails />} />
        <Route path="*" element={<NotFound />} />
      </Routes>
    </div>
  );
};
```

Son olarak, iç içe rotaların render edileceği noktayı ana yönlendirme bileşeninde belirtmek gerekir. Bunun için React Router'da `<Outlet>` bileşeni kullanılır.

**src/pages/About.jsx**

```
import { Link, Outlet } from "react-router-dom";

export const About = () => {
  return (
    <div>
      <h1>About page</h1>
      <ul>
        <li>
          <Link to="mission">Read about our mission</Link>
        </li>
        <li>
          <Link to="team">Get to know the team</Link>
        </li>
        <li>
          <Link to="reviews">Go through the reviews</Link>
        </li>
      </ul>
      <Outlet />
    </div>
  );
};
```

Eğer tarayıcı adres çubuğundaki geçerli URL, gömülü rotanın `path` özelliği ile eşleşiyorsa, `<Outlet>` bu bileşeni render eder, aksi takdirde `null` render eder ve üst bileşenin şemasını etkilemez.

```
💡 RELATİVE LİNKS (GÖRECELİ BAĞLANTILAR)
<Link> bileşeninin to özelliğinin değerine dikkat edin. Tıpkı gömülü rotanın path özelliği gibi, gömülü bağlantıların to özelliği de geçerli URL'ye göre belirtilir. <About> bileşeni /about adresinde görüntülenir, bu nedenle to="mission" olan bir bağlantı /about/mission adresine gidecektir. Eğer başka bir sayfaya bağlantı vermek gerekiyorsa, tam yolu belirtin; örneğin to="/products".
```
