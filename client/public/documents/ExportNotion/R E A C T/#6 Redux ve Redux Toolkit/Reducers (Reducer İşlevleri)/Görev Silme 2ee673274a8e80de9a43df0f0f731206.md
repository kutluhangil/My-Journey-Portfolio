# Görev Silme

Ana reducer'a diğer tüm eylemleri işlemek için kod ekleyelim. Silme işleminde `payload` ile görev kimliğine erişebiliriz. Bu görevi çıkarmak için, `Array.filter()`metodunu kullanarak yeni bir dizi oluşturacağız. Gönderilen eylemin türünün `"tasks/deleteTask"` olup olmadığını kontrol edip, yeni durum nesnesini döndüreceğiz.

```
// src/redux/store.js

const rootReducer = (state = initialState, action) => {
  switch (action.type) {
		// Önceki kod case "tasks/addTask"

    case 'tasks/deleteTask':
      return {
        ...state,
        tasks: {
          items: state.tasks.items.filter((task) => task.id !== action.payload),
        },
      };

    default:
      return state;
  }
};
```
