# Durum Değişikliği

Durum değişikliğinde görev kimliğine `payload` özelliğinden erişimimiz olduğundan, `completed` özelliğinin değerini değiştirilmiş bir yeni dizi oluşturmak için `Array.map()`metodunu kullanacağız. Gönderilen eylemin türünün `"tasks/toggleCompleted"`dizesine karşılık gelip gelmediğini kontrol edelim ve yeni durum nesnesini döndürelim.

```
// src/redux/store.js

const rootReducer = (state = initialState, action) => {
  switch (action.type) {
      // Önceki kod case "tasks/addTask"

     // Önceki kod case "tasks/deleteTask"

    case 'tasks/toggleCompleted':
      return {
        ...state,
        tasks: {
          items: state.tasks.items.map((task) => {
            if (task.id !== action.payload) {
              return task;
            }
            return {
              ...task,
              completed: !task.completed,
            };
          }),
        },
      };

    default:
      return state;
  }
};
```
