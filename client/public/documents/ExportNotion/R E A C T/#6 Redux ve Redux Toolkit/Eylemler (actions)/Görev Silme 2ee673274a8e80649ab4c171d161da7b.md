# Görev Silme

`Task` bileşeninde silme butonuna tıklandığında, görev kimliğini geçerek görev silme eylemi göndermek gerekmektedir. Bu veri, görev nesnesinin diziden silinmesi için yeterli olacaktır.

```
// src/components/Task/Task.jsx

// 1. Hook içe aktarıyoruz
import { useDispatch } from "react-redux";
// 2. Eylem fabrikasını içe aktar
import { deleteTask } from "../../redux/actions";

export const Task = ({ task }) => {
  // 3. Eylem gönderme fonksiyonuna olan referansı al
  const dispatch = useDispatch();

  // 4. Eylem fabrikasını çağır ve görev kimliğini geçir
  // 5. Sonucu gönder — görev silme eylemi
  const handleDelete = () => {
	  dispatch(deleteTask(task.id))
  };

  return (
    <div>
      <input type="checkbox" />
      <p>{task.text}</p>
      <button type="button" onClick={handleDelete}>
        Delete
      </button>
    </div>
  );
};
```

Silme butonuna tıklandığında, Redux DevTools’a gönderilen görev silme eylemi eklenir. Üzerine tıklayıp detaylı bilgi görüntülenebilir.
