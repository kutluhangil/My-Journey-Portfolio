# Görev Sayacı

`TaskCounter` bileşeninin Redux durumunun `items` özelliğinden bir görevler dizisine ihtiyacı var, bu nedenle seçici fonksiyonu `state => state.tasks.items` şeklinde olacaktır. Bu veriler üzerinden aktif ve tamamlanmış görevlerin sayısını hesaplayabiliriz.

```
// src/components/TaskCounter/TaskCounter.jsx

// 1. Hook içe aktarıyoruz
import { useSelector } from 'react-redux';

export const TaskCounter = () => {
	// 2. Redux durumundan görevler dizisini alıyoruz
  const tasks = useSelector((state) => state.tasks.items);

	// 3. Redux durumundan türetilmiş verileri alıyoruz
  const count = tasks.reduce(
    (acc, task) => {
      if (task.completed) {
        acc.completed += 1;
      } else {
        acc.active += 1;
      }
      return acc;
    },
    { active: 0, completed: 0 }
  );

  return (
    <div>
      <p>Active: {count.active}</p>
      <p>Completed: {count.completed}</p>
    </div>
  );
};
```
