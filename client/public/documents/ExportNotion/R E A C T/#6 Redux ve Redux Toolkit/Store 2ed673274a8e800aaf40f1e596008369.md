# Store

Store, uygulamanın global durumunu barındıran bir nesnedir ve bu duruma erişim gibi onunla etkileşim kurmak için birkaç yöntem sunar. Uygulamada yalnızca bir store bulunabilir.

Store'u oluşturmak için [**`configureStore(options)`**](https://redux-toolkit.js.org/api/configureStore) fonksiyonu kullanılmaktadır ve bu fonksiyon yeni bir store nesnesi döndürür. `configureStore` fonksiyonu, store oluşturma sürecini kolaylaştıran parametreler içeren bir nesneyi argüman olarak alır.

```
// src/redux/store.js

import { configureStore } from "@reduxjs/toolkit";

export const store = configureStore({});
```

Store'a mutlaka bir `reducer` özelliği eklenmelidir; bu özellik, Redux durumunu değiştiren mantığı içeren bir fonksiyondur. Bu tür fonksiyonlara reducer denir ve ilerleyen bölümlerde reducer'ların işleyişini daha detaylı inceleyeceğiz.

```
// src/redux/store.js

import { configureStore } from "@reduxjs/toolkit";

// Şu anda yalnızca alınan Redux durumunu
// geri döndüren bir reducer kullanıyoruz
const rootReducer = (state, action) => {
  return state;
};

export const store = configureStore({
  reducer: rootReducer,
});
```

Başlangıçta durumun varsayılan değerini, reducer fonksiyonundaki `state`parametresine varsayılan olarak ekleyelim.

```
// src/redux/store.js

import { configureStore } from "@reduxjs/toolkit";

// 1. Redux durumunun başlangıç değerini tanımlıyoruz
const initialState = {
  tasks: {
	  items: [
	    { id: 0, text: "Learn HTML and CSS", completed: true },
	    { id: 1, text: "Get good at JavaScript", completed: true },
	    { id: 2, text: "Master React", completed: false },
	    { id: 3, text: "Discover Redux", completed: false },
	    { id: 4, text: "Build amazing apps", completed: false },
	  ]
  },
  filters: {
    status: "all",
  },
};

// 2. Redux durumunun başlangıç değerini geçiriyoruz
const rootReducer = (state = initialState, action) => {
  return state;
};

export const store = configureStore({
  reducer: rootReducer,
});
```

Store oluşturulduktan sonra, React bileşenleri ile store'u bağlamak gerekir. Böylece bileşenler duruma ve store'a erişebilir. Bunun için, React Redux kütüphanesinde bulunan [**Provider**](https://react-redux.js.org/api/provider) bileşeni kullanılır. Bu bileşen, store'u `store` prop'u aracılığıyla alır.

```
// src/main.jsx

import React from 'react';
import ReactDOM from 'react-dom/client';
import App from './components/App';
// 1. Provider'ı içe aktarıyoruz
import { Provider } from 'react-redux'
// 2. Daha önce oluşturulan store'u içe aktarıyoruz
import { store } from "./redux/store";

ReactDOM.createRoot(document.getElementById('root')).render(
  <React.StrictMode>
	  <Provider store={store}>
	    <App />
	  </Provider>
  </React.StrictMode>
);
```

**`Uygulamadaki herhangi bir bileşenin store'u kullanabilmesi için, Provider ile bileşen ağacını sarmalıyoruz.`**
