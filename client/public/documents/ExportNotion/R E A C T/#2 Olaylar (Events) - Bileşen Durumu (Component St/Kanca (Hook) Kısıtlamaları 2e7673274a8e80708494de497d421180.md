# Kanca (Hook) Kısıtlamaları

React'te **hook**’lar yalnızca bileşen fonksiyonlarının en üst düzeyinde çağrılabilir. Bu, hook'ların doğrudan bileşen fonksiyonunun gövdesinde bulunması gerektiği, döngüler, koşullar, iç içe fonksiyonlar vb. içinde olmaması gerektiği anlamına gelir. Bu kısıtlama, bileşen mantığını sadeleştirir ve kodun daha öngörülebilir ve okunabilir olmasını sağlar.

```
const App = () => {
	// ❌ Hata verecek
	if (isLoggedIn) {
		const [username, setUsername] = useState("");
	}

	// ❌ Hata verecek
	for (let i = 0; i < 10; i++) {
		const [value, setValue] = useState(0);
	}

	// ...
};

// ✅ Bu doğru
const App = () => {
	const [username, setUsername] = useState("");
	const [value, setValue] = useState(0);
};
```

`Hook'ları yalnızca bileşen fonksiyonunun en üst seviyesinde çağırmalısınız. Tıpkı modülleri dosyanın en üstünde import ettiğiniz gibi, hook'ları da bileşen fonksiyonunun en üst düzeyinde kullanmalısınız.`
