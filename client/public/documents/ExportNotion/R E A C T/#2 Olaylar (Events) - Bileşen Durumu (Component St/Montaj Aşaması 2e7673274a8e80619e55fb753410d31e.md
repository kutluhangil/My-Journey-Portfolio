# Montaj Aşaması

Eğer `useEffect` hook’unun ikinci parametresi olarak **boş bir dizi** (`[]`) verirseniz, bu etki yalnızca **bir kez**, bileşenin **montaj aşamasında** gerçekleşir ve bir daha çalışmaz:

```
useEffect(() => {
	// ...
}, [])
```

Aşağıdaki örnekte, konsola yazılan mesajın yalnızca bir kez göründüğünü fark edeceksiniz. `clicks` durumundaki değişiklikler ve bileşen güncellemeleri, bu etkiyi yeniden tetiklemez:

```
import { useState, useEffect } from "react";

const App = () => {
  const [clicks, setClicks] = useState(0);

  useEffect(() => {
    console.log("You can see me only once!");
  }, []);

  return (
    <button onClick={() => setClicks(clicks + 1)}>
      You clicked {clicks} times
    </button>
  );
};
```

Bu etki yalnızca **bir kez**, bileşen DOM’a eklendikten hemen sonra çalışır. Montaj aşamasında tetiklenen etkiler, kullanıcı etkileşimlerinden bağımsız olarak bazı işlemleri başlatmak için kullanılır. Örnek kullanım alanları:

- Başlangıç verilerini almak için HTTP istekleri gönderme
- Sayfaya olay dinleyicileri (event listeners) ekleme
- Zamanlayıcıları başlatma
- Yerel depolamadan veri okuma
