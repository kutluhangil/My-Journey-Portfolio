# Durum Yönetimi

Bir bileşende ihtiyacınız kadar durum değişkeni kullanabilirsiniz. Her biri için ayrı bir `useState` çağrısı yapmalısınız:

```
const [a, setA] = useState();
const [b, setB] = useState();
const [c, setC] = useState();
```

Aşağıdaki örnekte, `App` bileşenine metin paragrafının görüntülenmesini kontrol edecek bir durum değişkeni olan `isOpen` ekleyeceğiz:

```
const App = () => {
  const [clicks, setClicks] = useState(0);
  const [isOpen, setIsOpen] = useState(false);

  const handleClick = () => {
    setClicks(clicks + 1);
  };

  const handleToggle = () => {
    setIsOpen(!isOpen);
  };

  return (
    <>
      <button onClick={handleClick}>Current: {clicks}</button>
      <button onClick={handleToggle}>{isOpen ? "Hide" : "Show"}</button>
      {isOpen && <p>Now you can see me!</div>}
    </>
  );
};
```

Bu örnekte `clicks` ve `isOpen` durumları birbirinden bağımsızdır ve kendi güncelleme fonksiyonları olan `setClicks` ve `setIsOpen` ile yönetilir. Kullanıcı butonlara tıkladıkça her bir durum değişkeni kendi değerine göre güncellenir ve bileşenin yeniden render edilmesi sağlanır.

Bu yapı sayesinde bileşenin durumu ve davranışları, kullanıcı etkileşimlerine bağlı olarak dinamik biçimde değişebilir.
