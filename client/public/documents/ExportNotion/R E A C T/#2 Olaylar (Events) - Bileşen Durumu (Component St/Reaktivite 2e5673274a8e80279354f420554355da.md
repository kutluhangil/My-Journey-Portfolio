# Reaktivite

Bir butona tıkladığınızda tıklama sayısını göstermek için basit bir değişken kullanma örneğini inceleyelim.

Butona her tıkladığınızda değişkenin değeri değişmeli ve yeni değer arayüzde görüntülenmelidir. Ancak bu, beklediğiniz gibi çalışmayacaktır deneyebilirsiniz!

```
const App = () => {
	let clicks = 0;

  const handleClick = () => {
    clicks = clicks + 1;
  };

	return <button onClick={handleClick}>Current: {clicks}</button>
};
```

Olay işleyici `handleClick`, yerel değişken `clicks`’i günceller. Ancak, aşağıdaki iki durum nedeniyle bu değişiklikler arayüzde görünmez:

1. Yerel değişkenler, yeniden render işlemleri arasında saklanmaz. React bu bileşeni ikinci kez render ettiğinde, her şeyi sıfırdan başlatır; yerel değişkenlerdeki değişiklikleri dikkate almaz.
2. Yerel değişkenlerdeki değişiklikler, yeniden render tetiklemez. React, bileşenin güncellenmesi gerektiğini fark etmez.

Bir bileşeni yeni verilerle güncellemek için iki adım gerekir:

- Verileri render işlemleri arasında saklamak
- React’in bileşeni yeni verilerle yeniden render etmesini sağlamak

Bu iki adımı sağlamak için **durum (state)** kullanılmalıdır.

İlk olarak, bir durum değişkeni tanımlamak için bileşenin en üstünde `useState`fonksiyonunu React'ten içe aktaralım:

```
import { useState } from 'react';

const App = () => {
	let clicks = 0;

  const handleClick = () => {
    clicks = clicks + 1;
  };

	return <button onClick={handleClick}>Current: {clicks}</button>
};
```

Sonrasında, `clicks` değişkenini durum olarak tanımlayalım:

```
import { useState } from 'react';

const App = () => {
	// let clicks = 0;
	const [ clicks, setClicks ] = useState(0);

  const handleClick = () => {
    clicks = clicks + 1;
  };

	return <button onClick={handleClick}>Current: {clicks}</button>
};
```

Burada `[clicks, setClicks]` ifadesi, `useState` fonksiyonundan dönen diziyi iki ayrı değişkene ayırmayı (dekompozisyon) ifade eder. Bu dizi her zaman tam olarak iki eleman içerir:

- `clicks`: durumu tutan değişken
- `setClicks`: durumu güncellemek için kullanılan fonksiyon

`handleClick` fonksiyonu içinde artık doğrudan `clicks` değişkenini değiştirmek yerine `setClicks` fonksiyonu kullanılır.

```
import { useState } from 'react';

const App = () => {
	const [ clicks, setClicks ] = useState(0);

  const handleClick = () => {
    // clicks = clicks + 1;
		setClicks(clicks + 1);
  };

	return <button onClick={handleClick}>Current: {clicks}</button>
};
```

Sonuç olarak, butona her tıklanışta `clicks` değeri güncellenir, bu da bileşenin yeniden render edilmesini sağlar ve arayüzde güncel değer görüntülenir.
