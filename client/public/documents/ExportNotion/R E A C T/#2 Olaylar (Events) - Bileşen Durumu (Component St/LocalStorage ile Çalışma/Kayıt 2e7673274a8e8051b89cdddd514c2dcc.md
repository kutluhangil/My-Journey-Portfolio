# Kayıt

Sayfa yeniden yüklendiğinde tıklama sayısını korumak için **etki (effect)**kullanabiliriz. `clicks` durumundaki her değişiklik, bileşenin yeniden render edilmesine neden olur ve bu değişiklikleri yerel depolamaya kaydedebiliriz:

```
const App = () => {
  const [clicks, setClicks] = useState(0);

  useEffect(() => {
    console.log(`Clicks changed - ${clicks}`);
  }, [clicks]);

  return (
    <div>
      <button onClick={() => setClicks(clicks + 1)}>
        You clicked {clicks} times
      </button>
      <button onClick={() => setClicks(0)}>Reset</button>
    </div>
  );
};
```

Şimdi etkide, yerel depolama için kayıt kodunu ekleyelim. Anahtar olarak `"saved-clicks"` gibi anlamlı bir ifade kullanacağız ve değeri `clicks` durumundan alacağız:

```
const App = () => {
  const [clicks, setClicks] = useState(0);

  useEffect(() => {
    window.localStorage.setItem("saved-clicks", clicks);
  }, [clicks]);

  return (
    <div>
      <button onClick={() => setClicks(clicks + 1)}>
        You clicked {clicks} times
      </button>
      <button onClick={() => setClicks(0)}>Reset</button>
    </div>
  );
};
```

`Eğer karmaşık veri türleriyle (örneğin nesne veya dizi) çalışıyorsanız, değeri saklamadan önce JSON.stringify ile dizeye dönüştürmeyi unutmayın:`

`window.localStorage.setItem("key", JSON.stringify({}));`
