# Okuma

Yerel depolamadan değer okumak için bir `useEffect` kullanmamıza gerek yoktur. Çünkü `useEffect`, bileşen monte edildikten **sonra** çalışır. Bizim ihtiyacımız olan ise, değeri **senkron** bir şekilde hemen okumaktır. Bunu `useState`’in başlangıç değeri olarak bir fonksiyon kullanarak yapabiliriz:

`const [] = useState(0);`

Ayrıca, **`useState`** için bir fonksiyon kullanarak başka bir yazım şekli de vardır.

```
const [] = useState(() => {
	return 0;
});
```

Bu yöntemle, başlangıç değerinin yerine, bir başlangıç değeri döndüren bir fonksiyonun referansı da verilebilir. Bu iki yazım şekli, durumun başlangıç değeri **`0`**olacak şekilde aynı şekilde çalışır.

Ancak bu yöntemle, yerel depolamadan okuma gibi ek işlemler gerçekleştirmek de mümkündür.

```
const [clicks, setClicks] = useState(() => {
	// Anahtar ile değeri okuyoruz
  const savedClicks = window.localStorage.getItem("saved-clicks");

	// Eğer burada bir değer varsa, bunu
  // durumun başlangıç değeri olarak döndürüyoruz
  if (savedClicks !== null) {
    return savedClicks;
  }

	// Aksi takdirde varsayılan bir değer döndürüyoruz
  return 0;
});
```

**`Karmaşık veri türleriyle çalışıyorsanız, yerel depolamadan okunan veriyi JSON.parse ile ayrıştırmayı unutmayın. Aksi takdirde string olarak kalır:`**

```
const [obj, setObj] = useState(() => {
	// Anahtar ile değeri okuyoruz
  const savedObject = window.localStorage.getItem("key");

	// Eğer burada bir değer varsa, ayrıştırıyor ve
	// bunu durumun başlangıç değeri olarak döndürüyoruz
  if (savedObject !== null) {
    return JSON.parse(savedObject);
  }

	// Aksi takdirde varsayılan bir değer döndürüyoruz
  return {};
});
```

Aşağıda, `clicks` durumunu yerel depolamada saklayan tam örnek yer almaktadır:

```
const App = () => {
  const [clicks, setClicks] = useState(() => {
    const savedClicks = window.localStorage.getItem("saved-clicks");
    if (savedClicks !== null) {
      return savedClicks;
    }
    return 0;
  });

  useEffect(() => {
    window.localStorage.setItem("saved-clicks", clicks);
  }, [clicks]);

  return (
    <div>
      <button onClick={() => setClicks(clicks + 1)}>
        You clicked {clicks} times
      </button>
      <button onClick={() => setClicks(0)}>Reset</button>
    </div>
  );
};
```
