# useState Hook'u

`useState` fonksiyonu, React uygulamalarında durum yönetimini sağlamak için kullanılan bir **hook** (kanca) olarak tanımlanır. React, bu kancaları bileşenlerin belirli durumları yönetmesini ve bu durumların değişimini takip etmesini sağlamak amacıyla sunar.

![](https://s3.eu-north-1.amazonaws.com/lms.goit.files/1c70b794-866e-40e6-a65f-79acb04f25d0image%20%2831%29.jpg)

Hook'lar, React'in sunduğu özel fonksiyonlardır ve uygulamanızın çeşitli yeteneklerine erişmenizi sağlar. Durum yönetimi bu yeteneklerden yalnızca biridir; ilerleyen bölümlerde diğer hook'larla da tanışacaksınız.

Bir hook'u kullanabilmek için bileşen dosyanıza React kütüphanesinden içe aktarmanız gerekir:

`import { useState } from 'react';`

`useState` fonksiyonunu çağırdığınızda, React’e bu bileşenin belirli bir durumu (state) hatırlamasını istediğinizi belirtirsiniz. Örneğin, kullanıcı tıklama sayısını takip etmek için `clicks` durumunu hatırlamak isteyebiliriz:

`const [clicks, setClicks] = useState(0);`

`useState` fonksiyonu tek bir argüman alır: durum değişkeninin **başlangıç değeri**. Bu örnekte, başlangıç değeri `0` olarak verilmiştir.

Bileşen her yeniden render edildiğinde, `useState` iki değerden oluşan bir dizi döner:

- **Durum Değişkeni (`clicks`)**
- **Durum Güncelleme Fonksiyonu (`setClicks`)**: Bu fonksiyon, durumu güncelleyerek bileşenin yeniden render edilmesini sağlar.

Örnek kullanım:

```
import { useState } from 'react';

const App = () => {
	const [clicks, setClicks] = useState(0);

  const handleClick = () => {
		setClicks(clicks + 1);
  };

	return <button onClick={handleClick}>Current: {clicks}</button>
};
```

**`Not:** Bu yapıdaki değişken isimlerini istediğiniz gibi adlandırabilirsiniz, örneğin [something, setSomething]. Ancak yaygın konvansiyonlara uymak, projeler arası kodun okunabilirliğini artırır.`

useState Kancasının Çalışma Mantığı:

`const [clicks, setClicks] = useState(0);`

**İlk Render:** Bileşen ilk kez render edildiğinde, `useState(0)` ifadesi `clicks` için başlangıç değeri olarak `0` döner. React, bu değeri hatırlar.

**Durum Güncelleme:** Kullanıcı butona tıkladığında `setClicks(clicks + 1)`fonksiyonu çalışır. İlk durumda `clicks = 0` olduğu için bu ifade `setClicks(1)`anlamına gelir. React’e `clicks` değerinin `1` olduğu bildirilir ve yeni bir render işlemi başlatılır.

**İkinci Render:** React bileşeni yeniden render eder. Kodda yine `useState(0)` yazsa da React önceki durumu (1) hatırladığı için bu kez `[1, setClicks]` döner.

**Devam Eden Güncellemeler:** Kullanıcı her tıkladığında bu süreç tekrar eder. React her defasında yeni durumu hatırlar ve arayüzü günceller.
