# Durum İzolasyonu

Durum (state), bir bileşenin örneğine özeldir. Aynı bileşeni birden fazla kez render ettiğinizde, her kopya kendi bağımsız durumunu tutar. Yani bir örneğin durumu değiştiğinde diğer örnekler bundan etkilenmez.

Aşağıda, tıklama sayısını takip eden bir `ClickCounter` bileşeni oluşturacağız. Bu bileşen, butona her tıklamada kendi durumunu günceller:

```
const ClickCounter = () => {
	const [clicks, setClicks] = useState(0);

	const handleClick = () => {
    setClicks(clicks + 1);
  };

	return <button onClick={handleClick}>Current: {clicks}</button>
};
```

Şimdi bu bileşeni `App` içinde iki kez kullanalım:

```
const App = () => {
  return (
    <>
			<ClickCounter />
			<ClickCounter />
    </>
  );
};
```

Her iki butona da tıkladığınızda, tıklama sayılarının birbirinden bağımsız şekilde arttığını göreceksiniz. Çünkü her `ClickCounter` bileşeni kendi durumunu saklar ve günceller.

[https://stackblitz.com/edit/vitejs-vite-w9rhfhjr?file=src%2FApp.jsx](https://stackblitz.com/edit/vitejs-vite-w9rhfhjr?file=src%2FApp.jsx)

Bu tür izolasyon, durumu sıradan değişkenlerden ayırır. Her `ClickCounter` bileşeni yalnızca kendi durumuna sahiptir.

```
Ayrıca, App bileşeni ClickCounter bileşeninin durumunu bilmez. Props’un aksine, durum tamamen bileşene özgüdür ve üst bileşen tarafından kontrol edilemez. Bu sayede bileşenleri uygulamaya eklemek veya uygulamadan kaldırmak, diğer bileşenleri etkilemeden gerçekleşebilir.
```
