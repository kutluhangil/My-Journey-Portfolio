# Güncelleme Aşaması

Eğer bir etki, bir durum, prop veya bileşenin içinde tanımlanan herhangi bir değişkeni kullanıyorsa, bunları etki bağımlılıkları olarak belirtmek zorunludur. Örneğin, aşağıdaki etki hatalı bir şekilde yazılmıştır:

```
import { useState, useEffect } from "react";

const App = () => {
  const [clicks, setClicks] = useState(0);

	// ❌ Etki hatalı yazılmış!
  useEffect(() => {
    console.log("Clicks updated: ", clicks);
  }, []);

  return (
    <button onClick={() => setClicks(clicks + 1)}>
      You clicked {clicks} times
    </button>
  );
};
```

Bu etki yalnızca bir kez, bileşen monte edildikten sonra tetiklenecek; bu, `clicks`durumu her güncellendiğinde gerçekleşmeyecektir. Ayrıca kod editöründe, bağımlılıklar dizisinde bir alt çizgi göreceksiniz; üzerine geldiğinizde hata mesajı ve talimatlar çıkacaktır.

React ile oluşturulmuş bir Vite projesinde **ESLint** linter’ı yapılandırılmıştır. Bu kurallardan biri `react-hooks/exhaustive-deps` olarak adlandırılır ve etkilerin bağımlılık dizisinde kullanılan tüm dış değişkenlerin (state, props vb.) eksiksiz şekilde yazılmasını zorunlu kılar.

```
Eğer VSCode editörünüzde bir alt çizgi görünmüyorsa, ESLint uzantısını yükleyin ve editörü yeniden başlatın. Ek bir ayar yapmanıza gerek yoktur.
Bir etki yazdıysanız ve linter bağımlılık listesinde sorunlar belirtiyorsa – bu etki kesinlikle kararsız ve öngörülemez çalışacaktır. Gerekli tüm bağımlılıkları etkiye eklemeyi unutmayın.

```

Yukarıdaki etkide `clicks` durumu kullanılmakta, ancak bağımlılık dizisi boş bırakılmıştır; bu hatalıdır. `clicks` değişkenini bağımlılık dizisine eklemeliyiz:

```
import { useState, useEffect } from "react";

const App = () => {
  const [clicks, setClicks] = useState(0);

	// ✅ Bağımlılıklar doğru şekilde belirtildi
  useEffect(() => {
    console.log("Clicks updated: ", clicks);
  }, [clicks]);

  return (
    <button onClick={() => setClicks(clicks + 1)}>
      You clicked {clicks} times
    </button>
  );
};
```

`Bağımlılık dizisi ile kullanılan bir etkinin özelliği, bu etkinin bileşen monte edildikten sonra bir kez çalışması ve ardından her bağımlılık güncellendiğinde yeniden çalışmasıdır; bu da tamamen normaldir.`
