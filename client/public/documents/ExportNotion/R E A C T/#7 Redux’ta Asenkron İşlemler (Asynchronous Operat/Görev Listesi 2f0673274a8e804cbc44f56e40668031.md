# Görev Listesi

`TaskList` bileşeninde, mevcut filtreleme koşuluna uyan görevlerin listesini hesaplayan bir kod bulunuyor. Bu hesaplama işlemi, aslında bir seçici tarafından yapılabilir ve bu şekilde bileşenin filtrelenmiş görev listesini hesaplama mantığı gizlenmiş olur.

```
// src/components/TaskList/TaskList.jsx

import { useSelector } from "react-redux";
import { selectTasks, selectStatusFilter } from "redux/selectors";
import { statusFilters } from "redux/constants";

const getVisibleTasks = (tasks, statusFilter) => {
  switch (statusFilter) {
    case statusFilters.active:
      return tasks.filter(task => !task.completed);
    case statusFilters.completed:
      return tasks.filter(task => task.completed);
    default:
      return tasks;
  }
};

export const TaskList = () => {
  const tasks = useSelector(selectTasks);
  const statusFilter = useSelector(selectStatusFilter);
  const visibleTasks = getVisibleTasks(tasks, statusFilter);

  // JSX biçimlendirme oluşturucu
};
```

`selectVisibleTasks` seçicisini oluşturalım ve filtrelenmiş görev listesini hesaplama mantığını bu seçiciye taşıyalım.

```
// src/redux/selectors.js

import { statusFilters } from "./constants";

export const selectTasks = state => state.tasks.items;
export const selectIsLoading = state => state.tasks.isLoading;
export const selectError = state => state.tasks.error;
export const selectStatusFilter = state => state.filters.status;

export const selectVisibleTasks = state => {
  // Використовуємо інші селектори
  const tasks = selectTasks(state);
  const statusFilter = selectStatusFilter(state);

  switch (statusFilter) {
    case statusFilters.active:
      return tasks.filter(task => !task.completed);
    case statusFilters.completed:
      return tasks.filter(task => task.completed);
    default:
      return tasks;
  }
};
```

Burada, `selectVisibleTasks` seçicisinde başka seçiciler olan `selectTasks` ve `selectStatusFilter` kullanılarak durumun gerekli parçalarını alıyoruz ve daha fazla hesaplama yapıyoruz.

Durumdan sadece bir parçayı döndüren seçicilere **"basit"** seçiciler, hesaplamalar yaparak değer döndürenlere ise **"bileşik"** seçiciler diyoruz.

Şimdi, `TaskList` bileşenindeki kod daha basit hale gelecek, çünkü tüm hesaplama mantığını bir seçiciye taşıdık. Bileşen, yalnızca seçiciyi çağıracak ve elde edilen değeri kullanacaktır.

```

import { selectVisibleTasks } from "redux/selectors";
```
