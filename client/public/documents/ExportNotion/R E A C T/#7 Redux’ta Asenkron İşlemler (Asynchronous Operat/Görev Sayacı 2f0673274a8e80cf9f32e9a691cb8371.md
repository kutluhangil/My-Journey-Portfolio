# Görev Sayacı

`TaskCounter` bileşeninde de aktif ve tamamlanmış görevlerin sayısını hesaplayan bir kod var.

```
// src/components/TaskCounter/TaskCounter.jsx

import { useSelector } from "react-redux";
import { selectTasks } from "redux/selectors";

export const TaskCounter = () => {
  const tasks = useSelector(selectTasks);

  const count = tasks.reduce(
    (acc, task) => {
      if (task.completed) {
        acc.completed += 1;
      } else {
        acc.active += 1;
      }
      return acc;
    },
    { active: 0, completed: 0 }
  );

  // JSX biçimlendirme oluşturucu
};
```

Buradaki hesaplama mantığını da bir seçiciye taşıyıp, `selectTaskCount` adında bileşik bir seçici oluşturacağız. Bu seçici, basit `selectTasks` seçicisini kullanarak görevler listesini alacak ve hesaplamayı yaparak sonucu döndürecek.

```
// src/redux/selectors.js

// Diğer seçiciler

export const selectTasks = state => state.tasks.items;

export const selectTaskCount = state => {
  const tasks = selectTasks(state);

  return tasks.reduce(
    (count, task) => {
      if (task.completed) {
        count.completed += 1;
      } else {
        count.active += 1;
      }
      return count;
    },
    { active: 0, completed: 0 }
  );
};
```

Bu değişiklikle, `TaskCounter` bileşeninin kodu daha basit hale gelecek, çünkü hesaplama mantığını bir seçiciye taşıdık. Bileşen, sadece seçiciyi çağırıp elde edilen değeri kullanacak.
