# JSX - UI Tanımı

Her bileşen, React'in tarayıcıda renderladığı HTML yapısını içeren kendi şablonuna sahiptir. React, bu yapıyı temsil etmek için JSX (JavaScript Söz Dizimi Genişletmesi) adı verilen bir sözdizimi uzantısını kullanır.

**`Product`** bileşenine ürünün görüntüleme yapısını ekleyelim.

```
// src/components/Product.jsx

export const Product = () => {
  return (
    <div>
      <h2>Tacos</h2>
			<img src="<https://images.pexels.com/photos/461198/pexels-photo-461198.jpeg?dpr=2&h=480&w=640>" alt="Tacos With Lime" width="640" />
			<p>Price: 999 credits</p>
    </div>
  );
};
```

JSX sözdizimi, HTML'ye çok benzer, ancak dikkate alınması gereken bazı özelliklere sahiptir.

Eğer bir etiket boş veya kendiliğinden kapanan (self-closing) bir etiket ise, kesinlikle **`/>`** ile kapatılmalıdır.

```
<img src="" alt="" />
<input type="text" />
```

Bileşenin render edilmesi sırasında JSX sözdizimi kullanılır, bu nedenle bileşen etiketini kapatma parantezinden önce ters eğik çizgi (**`/`**) ile kapatmayı unutmayın.

```
<App />
<Product />
```

Bazı niteliklerin, HTML ile karşılaştırıldığında farklı adları vardır; örneğin, **`label`**etiketinin **`for`** niteliği JSX'te **`htmlFor`** olarak adlandırılır. React'ı öğrenirken nitelik adlarındaki tüm özellikleri gözden geçireceğiz.

```
<label htmlFor="login">
  <input id="login" />
</label>

```

Herhangi iki veya daha fazla bitişik etiketin ortak bir kapsayıcısı olmalıdır; diğer bir deyişle, bir bileşenden bu tür bir biçim döndürmek mümkün değildir, aksi takdirde hata meydana gelir.

```
// src/components/Product.jsx

export const Product = () => {
  return (
      <h2>Tacos</h2>
		  <img src="<https://images.pexels.com/photos/461198/pexels-photo-461198.jpeg?dpr=2&h=480&w=640>" alt="Tacos With Lime" width="640" />
      <p>Price: 999 credits</p>
  );
};
```

Bu nedenle JSX’te, her bileşen yalnızca bir kapsayıcı öğe döndürmelidir.

```
// src/components/Product.jsx

export const Product = () => {
  return (
    <div>
      <h2>Tacos</h2>
			<img src="<https://images.pexels.com/photos/461198/pexels-photo-461198.jpeg?dpr=2&h=480&w=640>" alt="Tacos With Lime" width="640" />
      <p>Price: 999 credits</p>
    </div>
  );
};
```

Eğer gereksiz bir sarmalayıcı etiket düzenlemede gerekli değilse, **fragmentler**kullanılır. Sözdizimi, isimsiz bir etiket gibi görünmektedir.

```
Aslında, React "boş"<></> etiketi yerine yerleşikFragment bileşenini ekler. Bu yerleşik bileşen, render sırasında içeriğini yerleştirerek açılır.

```

JSX içinde geçerli herhangi bir ifadeyi süslü parantezler içinde kullanabilirsiniz. Diğer her şey metin olarak kabul edilir. Fiyat değerini **`price`** değişkenine alalım ve bu değişkenin değerini JSX içinde kullanarak yerleştirelim.

```
// src/components/Product.jsx

export const Product = () => {
	const price = 999;

  return (
    <>
      <h2>Tacos</h2>
			<img src="<https://images.pexels.com/photos/461198/pexels-photo-461198.jpeg?dpr=2&h=480&w=640>" alt="Tacos With Lime" width="640" />
      <p>Price: {price} credits</p>
    </>
  );
};
```

Özniteliklerin değerleri, eğer sıradan bir dize ise çift tırnak içerisinde; eğer değer bir dizeden farklıysa veya bir değişkende bulunuyorsa süslü parantezler içerisinde belirtilir.

```
// src/components/Product.jsx

export const Product = () => {
	const price = 999;
	const imgUrl = "<https://images.pexels.com/photos/461198/pexels-photo-461198.jpeg?dpr=2&h=480&w=640>";

  return (
    <>
      <h2>Tacos</h2>
			<img src={imgUrl} alt="Tacos With Lime" width="640" />
      <p>Price: {price} credits</p>
    </>
  );
};
```
