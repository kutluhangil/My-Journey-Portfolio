# Vite Ayarları

Proje, varsayılan olarak üretim ortamında küçültülmüş ve obfuscate edilmiş (karıştırılmış) bir kod ile gelir. Bu, performans optimizasyonu sağlasa da, ödev değerlendirmesi sırasında mentörlerin kodu gözden geçirmesini zorlaştırabilir.

Bu durumu kolaylaştırmak için **Source Map** özelliğini etkinleştirebilirsiniz. Source Map, derlenmiş kodu, kaynak kodu ile eşleştirerek geliştirici araçlarında orijinal kodu görmenizi sağlar.

Bu ayarı etkinleştirmek için, projenizin kök dizinindeki **`vite.config.js`** dosyasına aşağıdaki kodu ekleyin:

```
import { defineConfig } from "vite";
import react from "@vitejs/plugin-react";

// <https://vitejs.dev/config/>
export default defineConfig({
  plugins: [react()],
  build: {
    sourcemap: true,
  },
});
```
