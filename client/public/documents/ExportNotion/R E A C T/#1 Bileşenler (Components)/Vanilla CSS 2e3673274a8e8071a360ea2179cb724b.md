# Vanilla CSS

Bileşen tasarımı, stil sayfasına taşınabilir. Bu durumda, her bileşenin stilleri ayrı bir `.css` uzantılı CSS dosyasında tanımlanır. Dosya adı, bileşenin ismi ve uzantısından oluşur. Örneğin, `Alert` bileşeni için stil dosyası `Alert.css` olarak adlandırılacaktır.

```
/* src/components/Alert.css */

.alert {
  margin: 8px;
  padding: 12px 16px;
  border-radius: 4px;
  background-color: gray;
  color: white;
}
```

```
Stil dosyası içerisinde herhangi bir geçerli CSS kodu yazılabilir. İyi bir uygulama olarak, bu dosyada yalnızca ilgili bileşenin HTML yapısına yönelik CSS tanımlamaları yapılması önerilir.

```

Bileşenin stilleri, bileşen dosyasına import edilerek kullanıma hazır hale getirilir. Bu sayede, stil dosyasında tanımlanmış CSS sınıfları React bileşeninde uygulanabilir. React'te HTML'de kullanılan `class` özelliği, JSX içerisinde `className` olarak adlandırılır ve bir öğeye birden fazla sınıf atanabilir.

```
// src/components/Alert.jsx

import "./Alert.css";

const Alert = ({ children }) => {
  return <p className="alert">{children}</p>;
};
```

Vite gibi modern araçlar, proje derleme sürecinde CSS dosyalarını küçültür ve tarayıcı uyumluluğu için [Autoprefixer](https://github.com/postcss/autoprefixer) ile otomatik olarak vendor prefix'lerini ekler. Ayrıca, eski tarayıcıların desteklenmesi gereken durumlarda polyfill’ler aracılığıyla modern CSS özellikleri kullanılabilir hale gelir. Bu sayede geliştiriciler, tarayıcı uyumluluğu konusunda endişe duymadan çalışabilir.
