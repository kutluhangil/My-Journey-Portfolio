# Bileşenler

Kullanıcı arayüzü, butonlar, metin ve görseller gibi küçük unsurlardan oluşur. React, bu unsurları yeniden kullanılabilir bileşenler halinde birleştirmenize olanak tanır; bu bileşenler, React uygulamalarının temel yapı taşlarını oluşturur ve arayüz, bağımsız parçalara ayrılır. Herhangi bir arayüz (tasarım) bileşenlere bölünebilir.

![](https://s3.eu-north-1.amazonaws.com/lms.goit.files/17b2fcc2-34df-4978-9602-21d138809299image%20-%202024-09-23T154302.468.png)

React uygulaması, bileşenlerden oluşan bir ağaç olarak düşünülebilir. En üst seviyede kök bileşen yer alır ve onun içinde istediğimiz sayıda diğer bileşen bulunur. Her bileşen, hangi HTML'nin DOM'da render edilmesini istediğimizi gösteren bir yapıyı döndürmelidir.

```
Uygulamamızda kök bileşen App'dir. Diğer bileşenleri bu bileşene yerleştireceğiz.

```

# **Bileşen Tanımı**

Bir bileşen, props adı verilen bir nesne alır ve React öğeleri (HTML yapısı) döndürür.

![](https://s3.eu-north-1.amazonaws.com/lms.goit.files/668325a5-c31d-461a-a962-48a46de4690bScreenshot%202023-12-06%20at%2018.29.32.png)

Şu anda hiçbir **`props`** almayan **`Product`** bileşenini ele alalım, bu bileşen bir ürün kartı şeması döndürüyor.

```
const Product = () => {
  return (
    <div>
      <h2>Cookies</h2>
			<p>Price: 999 credits</p>
    </div>
  );
};
```

**`App.jsx`** dosyasının içeriğini aşağıdaki kodla değiştirin. İşte **`App`** bileşeni, üç **`Product`** bileşenini gösteriyor. Web sayfasının nasıl değiştiğine göz atın.

```
// src/App.jsx

const Product = () => {
  return (
    <div>
      <h2>Cookies</h2>
			<p>Price: 999 credits</p>
    </div>
  );
};

export default function App() {
  return (
    <div>
      <h1>Products</h1>

      <Product />
      <Product />
      <Product />
    </div>
  );
}
```

`Bileşen adı mutlaka büyük harfle başlamalıdır. Küçük harfle başlayan bileşen adları HTML elemanları için ayrılmıştır. Eğer bir bileşeni **product** yerine **Product** olarak adlandırmaya çalışırsanız, React render aşamasında bunu göz ardı eder ve **<product></product>** etiketini render eder.`
