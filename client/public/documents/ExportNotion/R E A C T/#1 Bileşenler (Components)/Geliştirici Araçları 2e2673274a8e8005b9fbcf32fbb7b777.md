# Geliştirici Araçları

**React Geliştirici Araçları** — geliştiricilerin React uygulamalarını izlemelerine, analiz etmelerine ve hata ayıklamalarına yardımcı olan kapsamlı bir araç setidir.. Bu araçlar, bileşenlerin nasıl çalıştığını anlamalarına yardımcı olur ve olası sorunların çözümüne yönelik araçlar sunar.

```
📖 React Geliştirici Araçları Dokümantasyonu

```

Tarayıcınıza bir uzantı yükledikten sonra, uygulamanızı `npm` komutuyla başlattığınızda web sayfasında bileşenler ağacını, durumlarını ve özelliklerini görüntüleyebilirsiniz.

- [Chrome için](https://chrome.google.com/webstore/detail/react-developer-tools/fmkadmapgofadopljbjfkapdkoienihi?hl=en)
- [Firefox için](https://addons.mozilla.org/en-US/firefox/addon/react-devtools/)
- [Edge için](https://microsoftedge.microsoft.com/addons/detail/react-developer-tools/gpphkfbcpidddadnkolkpfckpihlkkil)
