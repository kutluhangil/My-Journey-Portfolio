# Kontrolsüz Form

Eğer form alanlarının değerleri yalnızca formun gönderildiği anda gerekli ise, bu tür formlar **kontrolsüz formlar** olarak adlandırılır. Kontrolsüz formlarda, elemanların değerlerine formun interaktif öğelerine referanslar tutan **`elements`** özelliği ile erişiriz.

```
const LoginForm = () => {

  const handleSubmit = (evt) => {
    evt.preventDefault();

    const form = evt.target;
    const { login, password } = form.elements;

		// DOM Elemanlarına Referanslar
    console.log(login, password);

		// Alanların Değerleri
		console.log(login.value, password.value)

		// Form gönderildikten sonra alanların değerlerini sıfırlıyoruz
		form.reset();
  };

  return (
    <form onSubmit={handleSubmit}>
      <input type="text" name="login" />
      <input type="password" name="password" />
      <button type="submit">Login</button>
    </form>
  );
};
```

- **`elements`** özelliği, form elemanlarını **`name`** nitelikleriyle eşleştirerek erişilebilir hale getirir.
- Her bir özellik, form alanının DOM elemanına bir referans sağlar.
- Alanların değerlerine erişmek için **`value`** özelliğini kullanırız.
- Form gönderildikten sonra, alanların değerlerini sıfırlamak için formun yerleşik **`reset`** metodunu kullanabiliriz. Bu yöntem, formu ilk haline geri döndürür.
