# useId hook’u

React’teki `useId` hook’u, form alanları için benzersiz kimlikler (ID’ler) oluşturmayı sağlar. Bu kimlikler özellikle erişilebilirlik öznitelikleri açısından faydalıdır ve her form alanına özgü bir ID sağlayarak form elemanlarının doğru şekilde etiketlenmesini mümkün kılar.

```
import { useId } from 'react';

const MyComponent = () => {
	const id = useId();
};
```

`useId` hook’u şu şekilde çalışır:

- Herhangi bir parametre almaz.
- Kullanıldığı her bileşen için benzersiz bir kimlik dizesi döner.
- React’te `htmlFor` olarak temsil edilen `label` etiketinin `for` HTML özniteliği, alan ve label arasındaki bağlantıyı sağlamak için yardımcı teknolojilere yardımcı olur.

```
import { useId } from "react";

const MyComponent = () => {
  const id = useId();

  return (
    <div>
      <label htmlFor={id}>Text field label</label>
      <input type="text" id={id} />
    </div>
  );
};
```

```
Not:useId, yalnızca form alanları için benzersiz kimlikler oluşturmak amacıyla tasarlanmıştır. Liste anahtarları (keys) oluşturmak için kullanılmamalıdır.

```

Her form alanı için gerekli sayıda kimlik oluşturabilirsiniz. Her kimlik ayrı bir değişkende saklanır:

```
const LoginForm = () => {
  const loginId = useId();
  const passwordId = useId();

  return (
    <form>
      <label htmlFor={loginId}>Login</label>
      <input type="text" name="login" id={loginId} />

      <label htmlFor={passwordId}>Password</label>
      <input type="password" name="password" id={passwordId} />

      <button type="submit">Login</button>
    </form>
  );
};
```

**Benzersiz kimlikler neden bu kadar önemlidir?**

Örneğin, aynı sayfada birden fazla form bileşeni olduğunu düşünelim:

- **Benzersizlik:** Bir HTML belgesinde `id` değerlerinin benzersiz olması gerekir. Aksi takdirde kimlikler geçersiz hale gelir ve tarayıcılar form alanlarını doğru şekilde işleyemez.
- **Odaklanma Sorunları:** Aynı kimliğe sahip birden fazla form alanı varsa, form elemanlarına odaklanma (focus) işlemi düzgün çalışmaz. Tarayıcı, `label`üzerine tıklandığında hangi alanın odaklanması gerektiğini bilemez.

İşte bu nedenle `useId` hook’u vardır; belirli bir bileşende yapılan her `useId` çağrısı, benzersiz bir kimlik dizesi döndürür.
