# select elemanı

`select` etiketi, bir dizi `option` elemanı içerir ve her `option` elemanının bir `value`özniteliği olmalıdır. Bu öznitelik, kullanıcının yaptığı seçimi belirtir.

```
const LangSwitcher = () => {
  const selectId = useId();

  return (
    <div>
      <label htmlFor={selectId}>Choose language</label>
      <select id={selectId}>
        <option value="en">English</option>
        <option value="uk">Ukrainian</option>
        <option value="pl">Polish</option>
      </select>
    </div>
  );
};
```

Eğer `select` bir formun dışında kullanılıyorsa, onu **kontrollü bir eleman** olarak ele alırız:

- Seçili değeri durum (state) içinde saklarız.
- Bu değeri `value` özniteliği olarak geçiririz.
- `onChange` olayında durumu güncelleriz.

```
const LangSwitcher = () => {
  const selectId = useId();
  const [lang, setLang] = useState("uk");

  return (
    <div>
      <label htmlFor={selectId}>Choose language</label>
      <select
        id={selectId}
        value={lang}
        onChange={(evt) => setLang(evt.target.value)}
      >
        <option value="uk">Ukrainian</option>
        <option value="en">English</option>
        <option value="pl">Polish</option>
      </select>
    </div>
  );
};
```

```
Eğer bir select elemanını kontrolsüz bir form içinde kullanıyorsak:
-Önce name özniteliğini ekleriz.
-Form gönderildiğinde, seçilen değere evt.target.elements.selectName.value ile erişiriz.
-Buradaki selectName, name özniteliğine verdiğimiz isimdir.

```

Şimdi, `LangSwitcher` bileşenini kullanarak `App` bileşeninde seçilen dili gösteren bir arayüz oluşturalım:

```
const App = () => {
  return (
    <>
      <p>Selected language: </p>
      <LangSwitcher />
    </>
  );
};
```

Ancak burada bir sorun ortaya çıkar: `LangSwitcher` bileşeni durumu kendi içinde sakladığı için, `App` bileşeninden seçilen dile erişemeyiz.

Bu sorunu çözmek için React’in **state lifting (durum yükseltme)** desenini kullanarak durumu `App` bileşenine taşımalıyız:

```
const App = () => {
  const [lang, setLang] = useState("uk");

  return (
    <>
      <p>Selected language: {lang}</p>
      <LangSwitcher />
    </>
  );
};
```

Bu durumda, `LangSwitcher` bileşeni artık çalışmaz çünkü durum `App` bileşeninde yönetilmektedir ve `LangSwitcher` bu duruma erişemez.

Bu problemi çözmek için, `LangSwitcher` bileşenine durumu (`value`) ve durumu değiştirecek fonksiyonu (`onSelect`) prop olarak geçmeliyiz:

```
const App = () => {
  const [lang, setLang] = useState("uk");

  return (
    <>
      <p>Selected language: {lang}</p>
      <LangSwitcher value={lang} onSelect={setLang} />
    </>
  );
};
```

Son olarak, `LangSwitcher` bileşenini bu `value` ve `onSelect` prop'larını kullanacak şekilde yeniden yapılandıralım:

```
const LangSwitcher = ({ value, onSelect }) => {
  const selectId = useId();

  return (
    <div>
      <label htmlFor={selectId}>Choose language</label>
      <select
        id={selectId}
        value={value}
        onChange={(evt) => onSelect(evt.target.value)}
      >
        <option value="uk">Ukrainian</option>
        <option value="en">English</option>
        <option value="pl">Polish</option>
      </select>
    </div>
  );
};
```
