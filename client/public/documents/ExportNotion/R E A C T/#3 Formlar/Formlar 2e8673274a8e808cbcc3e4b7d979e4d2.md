# Formlar

Formlar, kullanıcıdan veri toplamak için kullanılan temel araçlardır. Bu örnekte, kullanıcı adı ve parola alanlarına sahip bir **`LoginForm`** bileşeni oluşturalım:

```
const LoginForm = () => {
  return (
    <form>
      <input type="text" name="login" />
      <input type="password" name="password" />
      <button type="submit">Log in</button>
    </form>
  );
};
```

Formun gönderim işlemini işlemek için, form etiketine **`onSubmit`** özelliği ekleyip, bir geri çağırma fonksiyonu (callback function) tanımlayabiliriz:

```
const LoginForm = () => {

  const handleSubmit = (evt) => {
    evt.preventDefault();
    console.log(evt);
  };

  return (
    <form onSubmit={handleSubmit}>
      <input type="text" name="login" />
      <input type="password" name="password" />
      <button type="submit">Login</button>
    </form>
  );
};
```

**`handleSubmit`** fonksiyonu, form gönderildiğinde tetiklenen bir geri çağırma fonksiyonudur. Bu fonksiyon, form gönderme olayını tek bir argüman olarak alır ve **`event.preventDefault()`** yöntemiyle tarayıcıda formun varsayılan gönderim davranışını engelleriz.
