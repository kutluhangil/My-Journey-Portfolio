# Radio Buttons

Seçim butonları (radio buttons), bir grupta yalnızca tek bir seçeneğin seçilmesine izin veren bir form elemanıdır. Bu nedenle, `select` elemanına bir alternatiftir. Radio butonları, birden fazla seçenek arasından yalnızca birinin seçilmesini sağlar.

```
const App = () => {
  return (
    <>
      <h1>Select coffee size</h1>
      <label>
        <input type="radio" name="coffeeSize" value="sm" />
        Small
      </label>
      <label>
        <input type="radio" name="coffeeSize" value="md" />
        Medium
      </label>
      <label>
        <input type="radio" name="coffeeSize" value="lg" />
        Large
      </label>
    </>
  );
};
```

- Radio butonlarını gruplamak için **`name`** özniteliğine aynı değeri atarız.
- Her seçeneğin değeri **`value`** özniteliğinde saklanır.

Seçilen değer durum (state) içinde saklanır.

```
const App = () => {
  const [coffeeSize, setCoffeeSize] = useState("sm");

	// Kodun geri kalanı
};
```

Bir seçeneğin seçili olup olmadığını kontrol etmek için, **`checked`** özniteliğine **`true`**ya da **`false`** değeri geçilir. Bu, durumun (state) değeri ile ilgili radio butonunun **`value`** özniteliğini karşılaştırarak yapılır.

```
const App = () => {
  const [coffeeSize, setCoffeeSize] = useState("sm");

  return (
    <>
      <h1>Select coffee size</h1>
      <label>
        <input
          type="radio"
          name="coffeeSize"
          value="sm"
          checked={coffeeSize === "sm"}
        />
        Small
      </label>
      <label>
        <input
          type="radio"
          name="coffeeSize"
          value="md"
          checked={coffeeSize === "md"}
        />
        Medium
      </label>
      <label>
        <input
          type="radio"
          name="coffeeSize"
          value="lg"
          checked={coffeeSize === "lg"}
        />
        Large
      </label>
    </>
  );
};
```

Bu noktada, geliştirici araçlarında tanıdık bir uyarı alabiliriz. Radio butonları kontrol edilen (controlled) elemanlardır, yani değeri durum (state) içinde saklanır, ancak bir seçenek seçildiğinde durumu değiştirmek için **`onChange`** özniteliğini eklememiz gerekir.

![](https://s3.eu-north-1.amazonaws.com/lms.goit.files/1d41a214-ec58-4a30-852e-c1d739835f85Screenshot%202023-12-18%20at%2015.11.46.png)

Grup içindeki her radyo butonuna, içinde seçilen değeri bileşenin durumuna kaydedeceğimiz bir fonksiyonun atanacağı **`onChange`** özniteliğini ekleyelim.

```
const App = () => {
  const [coffeeSize, setCoffeeSize] = useState("sm");

  const handleSizeChange = (evt) => {
    setCoffeeSize(evt.target.value);
  };

  return (
    <>
      <h1>Select coffee size</h1>
      <label>
        <input
          type="radio"
          name="coffeeSize"
          value="sm"
          checked={coffeeSize === "sm"}
          onChange={handleSizeChange}
        />
        Small
      </label>
      <label>
        <input
          type="radio"
          name="coffeeSize"
          value="md"
          checked={coffeeSize === "md"}
          onChange={handleSizeChange}
        />
        Medium
      </label>
      <label>
        <input
          type="radio"
          name="coffeeSize"
          value="lg"
          checked={coffeeSize === "lg"}
          onChange={handleSizeChange}
        />
        Large
      </label>
    </>
  );
};
```
