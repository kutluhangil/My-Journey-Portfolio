# useRef Hook’u

Referanslar, DOM öğelerine veya React bileşenlerine doğrudan erişim sağlar. DOM yöntemlerine ve element özelliklerine erişim gerektiğinde kullanılır. İşte bazı kullanım senaryoları:

- Olay sırasında bir elementin odaklanması, metin seçimi
- Medya içeriğinin kontrolü
- DOM kütüphaneleriyle entegrasyon
- Element boyutları, kaydırma değeri gibi doğrudan DOM özelliklerine erişim
