# useMemo Hook’u

Memoization, programların performansını artırmak için kullanılan bir tekniktir. Bu teknik, bir fonksiyonun sonuçlarını önbelleğe alarak, aynı giriş verileriyle yapılan tekrar çağrılarda hesaplamayı yeniden yapmadan, kaydedilmiş sonucu döndürür.

**Memoize edilmiş** bir fonksiyon, belirli bir argüman kümesine karşılık gelen hesaplamaları "hatırlar" ve aynı değerlerle çağrıldığında önbellekteki sonucu geri döndürür.

Bazı bileşenlerde pahalı ve senkron hesaplamalar yapılması gerekebilir. **`useMemo`**hook’u, memoization kullanarak bu hesaplamaların önbelleğe alınmasını ve yeniden hesaplanmasını sağlar.

`import { useMemo } from "react";`

**useMemo** Hook’unun Argümanları:

- Anonim Fonksiyon: Hatırlanacak değeri döndüren anonim fonksiyondur.
- **Bağımlılıklar Dizisi:** Dizideki herhangi bir değer değiştiğinde, ilk argüman olarak verilen fonksiyon tekrar çalıştırılır.

```
const memoizedValue = useMemo(() => {
  return a + b;
}, [a, b]);
```

`useMemo` Hook’unun Çalışma Mantığı:

- İlk render sırasında bileşen fonksiyonu çağrılır, sonucu kaydeder ve bu değer hook tarafından döndürülür.
- Sonraki render’larda bağımlılıklar değişmedikçe, hook fonksiyonu tekrar çağırmaz ve kaydedilen değeri geri döndürür.
- Bağımlılıklardan biri değişirse, fonksiyon yeniden çağrılır ve yeni değer kaydedilir.

Aşağıdaki örnek, bir dizeler dizisini ve arama sorgusunun değerini durumda saklar.

```
const App = () => {
  const [planets, setPlanets] = useState(["Earth", "Mars", "Jupiter", "Venus"]);
  const [query, setQuery] = useState("");

  const filteredPlanets = planets.filter(planet => planet.includes(query));

  return (
    <ul>
      {filteredPlanets.map(planet => (
        <li key={planet}>{planet}</li>
      ))}
    </ul>
  );
};
```

Planets veya query değeri her değiştiğinde, bileşen yeniden render edilir ve `filteredPlanets` yeniden hesaplanır. Bu normal bir durumdur ve memoization gerektirmez.

Şimdi `App` bileşeninin gezegenler üzerinde hiçbir etkisi olmayan ek bir `clicks`durumu içerdiğini düşünün.

```
const App = () => {
  const [planets, setPlanets] = useState(["Earth", "Mars", "Jupiter", "Venus"]);
  const [query, setQuery] = useState("");
  const [clicks, setClicks] = useState(0);

  const filteredPlanets = planets.filter(planet => planet.includes(query));

  return (
    <>
      <button onClick={() => setClicks(clicks + 1)}>
        Number of clicks: {clicks}
      </button>
      <ul>
        {filteredPlanets.map(planet => (
          <li key={planet}>{planet}</li>
        ))}
      </ul>
    </>
  );
};
```

Ancak, bileşene **`clicks`** adlı başka bir durum eklendiğinde, her tıklamada bileşen yeniden render edilir ve **`filteredPlanets`** tekrar hesaplanır, oysa **`planets`** ve **`query`** değişmemiştir! `filter` metodu her seferinde yeni bir dizi döndürdüğü için, React bunu yeni veri olarak algılar ve gezegenler listesi yeniden render edilir. Bu durumda, **`filteredPlanets`** hesaplamasını memoize etmek mantıklıdır.

```
import { useMemo } from "react";

const App = () => {
  const [planets, setPlanets] = useState(["Earth", "Mars", "Jupiter", "Venus"]);
  const [query, setQuery] = useState("");
  const [clicks, setClicks] = useState(0);

  const filteredPlanets = useMemo(
    () => planets.filter(planet => planet.includes(query)),
    [planets, query]
  );

  return (
    <>
      <button onClick={() => setClicks(clicks + 1)}>
        Number of clicks: {clicks}
      </button>
      <ul>
        {filteredPlanets.map(planet => (
          <li key={planet}>{planet}</li>
        ))}
      </ul>
    </>
  );
};
```

Bu durum, özellikle uzun for döngüleri gibi **maliyetli işlemler** için de geçerlidir. Karmaşık hesaplamalar kullanıcı arayüzünün performansını etkileyebilir ve **`useMemo`**bu durumlarda performansı iyileştirebilir.

Ancak, her hesaplamayı memoize etmeye gerek yoktur. Çünkü memoization işleminin kendisi de belli bir kaynak kullanır. Basit işlemlerin yeniden hesaplanması, bunları memoize etmekten daha verimli olabilir. **`useMemo`** kullanırken dikkatli olun, özellikle diziler ve pahalı hesaplamalar için uygundur.

---

## **🔹 useMemo nedir?**

> useMemo, pahalı (masraflı) hesaplamaların sonucunu hatırlamak için kullanılır.
> 

Yani:

- Aynı hesaplamayı
- Aynı verilerle
- **tekrar tekrar yapmayı engeller**

---

## **🔹 Mantığı (en basit haliyle)**

React’ta:

- **Her state değiştiğinde** bileşen yeniden render edilir
- Render olunca **tüm hesaplamalar tekrar çalışır**

👉 useMemo der ki:

> “Bu hesaplamayı
> 
> 
> **sadece gerekli olduğunda**
> 

---

## **🔹 Ne zaman sorun çıkar?**

Şu durumda 👇

- Bileşende:
    - Filtreleme
    - Map / filter
    - Uzun döngüler
    - Büyük diziler
- VE
- Alakasız bir state (örneğin clicks) değişiyor

➡️ Hesaplama **gereksiz yere tekrar çalışır**

---

## **🔹 useMemo ne yapar?**

```
const value = useMemo(() => {
  return expensiveCalculation();
}, [dependencies]);
```

- İlk render:
    - Hesaplar
    - Sonucu kaydeder
- Sonraki render’lar:
    - **Bağımlılıklar değişmediyse**
    - Eski sonucu geri verir
- Bağımlılık değişirse:
    - Yeniden hesaplar

---

## **🔹 Senin örnekte neyi çözüyor?**

```
const filteredPlanets = useMemo(
  () => planets.filter(p => p.includes(query)),
  [planets, query]
);
```

- clicks artınca:
    
    ❌ yeniden filter çalışmaz
    
- planets veya query değişince:
    
    ✅ yeniden hesaplanır
    

---

## **🔹 Ne işe yarıyor? (tek cümle)**

> Gereksiz hesaplamaları engelleyerek performansı artırır.
> 

---

## **🔹 Ne zaman KULLANMA?**

❌ Şunlar için gerekmez:

- Küçük diziler
- Basit hesaplamalar
- Erken optimizasyon

> useMemo = **ilaç** Her baş ağrısında içilmez 😄
> 

---

## **🔹 Ne zaman KULLAN?**

✅ Şunlar varsa:

- Büyük listeler
- Ağır filter / map işlemleri
- Performans problemi hissediyorsan
- React DevTools “wasted renders” gösteriyorsa
