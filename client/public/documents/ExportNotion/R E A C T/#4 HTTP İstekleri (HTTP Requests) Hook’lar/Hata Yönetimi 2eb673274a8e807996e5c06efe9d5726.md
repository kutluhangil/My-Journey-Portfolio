# Hata Yönetimi

HTTP istekleri her zaman başarılı sonuçlanmayabilir. Bu nedenle bir sorun oluştuğunda kullanıcıyı bilgilendirmek oldukça önemlidir. İlk olarak, hataları yönetmek için `error` adında bir durum (state) değişkeni ekleyelim:

```
const App = () => {
  const [articles, setArticles] = useState([]);
  const [loading, setLoading] = useState(false);
  const [error, setError] = useState(false);

	/* Kodun geri kalanı */
};
```

Hataları ele almak için `try...catch` yapısını kullanacağız. `catch` bloğu, bir hata meydana geldiğinde çalışır ve HTTP isteği başarısız olduğunda devreye girer:

```
const App = () => {
  const [articles, setArticles] = useState([]);
  const [loading, setLoading] = useState(false);
  const [error, setError] = useState(false);

  useEffect(() => {
    async function fetchArticles() {
      try {
        setLoading(true);
        const response = await axios.get(
          "<https://hn.algolia.com/api/v1/search?query=react>"
        );
        setArticles(response.data.hits);
      } catch (error) {
				// Hata durumunu true olarak ayarlayın
        setError(true);
      } finally {
        setLoading(false);
      }
    }

    fetchArticles();
  }, []);

	/* Kodun geri kalanı */
};
```

Artık `JSX` içinde `error` durumunu kullanarak kullanıcıya anlamlı bir hata mesajı gösterebiliriz:

```
const App = () => {

  /* Kodun geri kalanı */

	return (
    <div>
      <h1>Latest articles</h1>
      {loading && <p style={{ fontSize: 20 }}>Loading data, please wait...</p>}
      {error && (
        <p>Whoops, something went wrong! Please try reloading this page!</p>
      )}
      {articles.length > 0 && <ArticleList items={articles} />}
    </div>
  );
};
```

Kodun hata yönetimini test etmek için bilinçli bir şekilde HTTP isteğinde hata oluşturabilirsiniz. Bunun en basit yolu, istek yapılan URL’yi geçersiz hale getirmektir. Örneğin, `/search` yolunun sonuna `1` ekleyerek şu şekilde bozabilirsiniz:

`"<https://hn.algolia.com/api/v1/search1?query=react>"`

Bu şekilde URL geçersiz hale gelir ve sunucu bir hata döndürür. Uygulamayı tarayıcıda yeniden yüklediğinizde hata durumunu test etmiş olursunuz.
