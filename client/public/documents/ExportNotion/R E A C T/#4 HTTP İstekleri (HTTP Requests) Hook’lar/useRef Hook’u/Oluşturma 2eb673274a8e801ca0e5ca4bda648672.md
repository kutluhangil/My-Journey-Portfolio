# Oluşturma

Referanslar, `useRef()` hook’u kullanılarak oluşturulur ve React bileşenlerine `ref`(reference’ın kısaltması) özelliği ile bağlanır. Bu, DOM elementine bir referans saklamayı sağlar:

```
import { useRef } from "react";

const App = () => {
  const btnRef = useRef();

  return <button ref={btnRef}>Button with ref</button>;
};
```
