# X + Y seçici

Seçilen öğeleri stilize etmek için `:checked` sözde sınıfı kullanılabilir.

Bunu yapmak için `X + Y` seçicisini kullanmanız gerekir. Bu seçici, yalnızca HTML işaretlemesinde `X` öğesinin hemen ardından gelen `Y` öğesini seçer.

`ul + p {
 background-color: yellow;
}`

Bu CSS kuralında, yalnızca numaralandırılmamış listeden sonra gelen metin paragrafını seçeceğiz.

`X+Y` seçicisini ve `:checked` sözde veri kümesini birleştirerek, onay kutusu etiketini seçtiğinizde metnin renginin değişmesini sağlayabilirsiniz.

Bunu yapmak için, `label` etiketi onay kutusundan sonra işaretlemede olmalıdır.

`<input type="checkbox" name="hobby" value="music" id="music" />
<label for="music">Music</label>
input[type="checkbox"]:checked + label {
  color: blue;`

# **Form kod parçacığını okuyun**

HTML belgesi

`<form>
  <p>I find the HTML/CSS course:</b>
    <input type="checkbox" class="form-input" name="emotions" value="fantastic" id="fantastic">
    <label class="form-label" for="fantastic">Absolutely fantastic</label>

    <input type="checkbox" class="form-input" name="ratio" value="useful" id="useful">
    <label class="form-label" for="useful">Really useful</label>
 
    <input type="checkbox" class="form-input" name="difficulties" value="challenging" id="challenging">
    <label class="form-label" for="challenging">Quite challenging</label>

  <button type="submit">Submit</button>
</form>`

CSS dosyası

`input[type="radio"]:checked + label {
  color: blue;
}`

Evet, bu sorunun cevabı aslında çok net:

**CSS kodu radio için yazılmış ama HTML’deki input’lar checkbox.**

---

### **📌 Sorunun Özeti**

### **HTML:**

Senin formundaki input’lar şöyle:

```
<input type="checkbox" ... />
```

Ama CSS’te bu input’ları hedefleyen kod şu şekilde yazılmış:

```
input[type="radio"]:checked + label {
  color: blue;
}
```

🔴 **Problem:** CSS seçici sadece radio tipindeki seçili input’ları hedefliyor, ama senin kullandığın input’lar checkbox. Bu nedenle stil hiç uygulanmıyor.

---

### **✅ Çözüm 1: CSS Seçiciyi Doğru Girdiye Göre Düzenle**

HTML’deki input türü checkbox olduğu için CSS’ini şöyle düzeltmelisin:

```
input[type="checkbox"]:checked + label {
  color: blue;
}
```

---

### **⚠️ Ama Hâlâ Çalışmayabilir! Neden?**

Seçiciyi doğru yazsan bile, bu CSS şunu yapmaya çalışır:

> checked olan bir checkbox’tan
> 
> 
> **hemen sonra gelen bir label**
> 

Fakat senin HTML yapında **label, input’tan sonra geliyor ama araya boşluk giriyor ve HTML’de “komşu kardeş” (+) durumu bozuluyor.**

---

### **🧪 Mevcut HTML’de Yapı:**

```
<input ... id="fantastic">
<label for="fantastic">Absolutely fantastic</label>
```

> Burada label, input’ın
> 
> 
> **kardeşi değil**
> 

> Yani + label seçicisi bu durumda çalışmaz.
> 

---

### **✅ Çözüm 2: HTML Yapısını Değiştir (Label’ı Input’tan Sonra “Kardeş” Yap)**

Eğer + label kullanmak istiyorsan, HTML şu şekilde olmalı:

```
<input type="checkbox" id="fantastic" />
<label for="fantastic">Absolutely fantastic</label>
```

Ve **araya boşluk (boş satır, br, div, vs.) girmemeli.** Çünkü + seçici sadece **doğrudan bitişik kardeşleri** seçebilir.

---

### **💡 Alternatif ve Daha Güvenli Yaklaşım:**

for ve id ile bağlı olan etiketlerde görsel stil vermek istiyorsan, :has() gibi modern CSS özelliklerini ya da JavaScript kullanman gerekebilir çünkü klasik CSS bu bağlantıyı görsel olarak algılayamaz.

---

### **🧾 Kısa Özet**

| **Hata Nerede?** | **Açıklama** |
| --- | --- |
| ❌ type="radio" kullanılmış | Ama input’lar type="checkbox" |
| ❌ + label seçici kullanılmış | Ama label, input’a bitişik değil; for ile bağlı |
| ✅ Doğru CSS | input[type="checkbox"]:checked + label { ... } |
| ✅ Doğru yapı | input ve label **bitişik** ve **doğrudan kardeş** olmalı |
