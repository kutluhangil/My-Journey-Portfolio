# Disabled özniteliği

`disabled` niteliği, etkileşimli bir öğeyi devre dışı bırakmanıza olanak tanır. Bu tür öğeler odak etkisi almaz ve fare tıklamalarını dikkate almaz.

`<button type="button">Active button</button>
<button type="button" disabled>Disabled button</button>`

Bir özniteliğin değeri yoksa, bu öznitelik boolean (mantıksal) olarak adlandırılır. Bir ışık anahtarı gibi düşünülür: iki durumu vardır - açık veya kapalı. Boolean öznitelikler için de durum aynıdır: öznitelik varsa "açık", öznitelik yoksa "kapalı" olarak kabul edilir.

`button:disabled {
  background-color: lightgray;
  cursor: not-allowed;
}`

Etkin olmayan bir öğeyi biçimlendirmek için bir sözde sınıf vardır: `disabled`, `disabled` niteliği ile öğeye uygulanır.

## **disabled (devre dışı) özniteliği ve CSS ile biçimlendirme**

---

### **disabled nedir?**

HTML’de disabled özniteliği, bir öğeyi **devre dışı bırakmak** (kullanılamaz hale getirmek) için kullanılır.

```
<button type="button" disabled>Disabled button</button>
```

➡️ Bu düğmeye **tıklanamaz**, **odaklanılamaz** ve **kullanıcı etkileşimi alamaz**.

---

### **💡 Not: disabled bir boolean (mantıksal) özniteliktir.**

Yani bu öznitelik:

- **Varsa → öğe devre dışı (kapalı)** kabul edilir.
- **Yoksa → öğe etkin (açık)** kabul edilir.

```
<button disabled> // bu yeterlidir ✅
```

### **CSS ile devre dışı öğeleri nasıl biçimlendiririz?**

CSS’te :disabled adı verilen bir **pseudo-class** vardır. Bu, disabled özniteliği olan öğeleri hedef alır.

```
button:disabled {
  background-color: lightgray;
  cursor: not-allowed;
}
```

### **Bu ne işe yarar?**

- Devre dışı (disabled) olan butonun **arkaplanını gri yapar.**
- Mouse üstüne gelince imleç, **yasak işareti (🚫)** olur.

---

### **3. Ne zaman kullanılır?**

- Formdaki tüm alanlar doldurulana kadar “Gönder” butonunu **devre dışı bırakmak** için.
- Bu davranış genellikle **JavaScript** ile kontrol edilir.

**Örnek kullanım senaryosu:**

```
<input type="text" id="name" />
<button type="submit" disabled>Submit</button>
```

JavaScript ile name input doldurulunca butonu aktif hale getirirsin.

---

## **📌 Özet Not**

| **Özellik** | **Açıklama** |
| --- | --- |
| disabled | HTML öğesini devre dışı bırakır |
| Boolean öznitelik | Sadece var/yok durumu vardır (disabled varsa → çalışmaz) |
| :disabled CSS seçici | Devre dışı öğeleri CSS ile biçimlendirmek için kullanılır |
| Kullanım alanı | Öğe tıklanmasın, girilemesin diye geçici olarak devre dışı bırakılır |
| JS ile birlikte | Alanlar boşsa butonu devre dışı bırakmak gibi kontroller yapılır |

Devre dışı olan bir “Gönder” butonunu JavaScript ile nasıl etkinleştiririz? Göstereyim mi?

Harika! Aşağıda sana hem **HTML**, hem **CSS**, hem de **JavaScript** içeren, tamamen çalışan bir örnek hazırladım.

Bu örnekte:

- Kullanıcı adını yazmadan “Submit” butonuna basamazsın.
- Alan doldurulunca buton otomatik olarak aktif olur.

---

## **✅ HTML + CSS + JavaScript Örneği**

### **🔧 HTML:**

```
<form class="order-form">
  <label>
    Name:
    <input type="text" id="username" />
  </label>

  <button type="submit" id="submitBtn" disabled>Submit</button>
</form>
```

### **🎨 CSS:**

```
.order-form {
  display: flex;
  flex-direction: column;
  gap: 12px;
  max-width: 300px;
}

button:disabled {
  background-color: lightgray;
  cursor: not-allowed;
}
```

### **🧠 JavaScript:**

```
<script>
  const input = document.getElementById("username");
  const button = document.getElementById("submitBtn");

  input.addEventListener("input", () => {
    if (input.value.trim() !== "") {
      button.disabled = false;  // Alan doluysa buton etkin
    } else {
      button.disabled = true;   // Alan boşsa buton devre dışı
    }
  });
</script>
```
