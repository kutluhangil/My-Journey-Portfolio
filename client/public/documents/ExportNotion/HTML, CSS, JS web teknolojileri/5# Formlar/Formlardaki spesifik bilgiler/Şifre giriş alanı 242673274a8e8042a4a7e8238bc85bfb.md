# Şifre giriş alanı

`password` türü için, kullanıcı tarafından girilen parola değeri, güvenlik nedeniyle görsel olarak işaretçilerle değiştirilecektir.

`<form>
	<label>
	  Email
	  <input type="email" name="email" />
	</label>
	<label>
	  Password
	  <input type="password" name="pwd" minlength="5" maxlength="12" />
	</label>
  <button type="submit">Register</button>
</form>`

`minLength` ve `maxLength` nitelikleri isteğe bağlıdır. Alana girilebilecek karakter sayısını sınırlamanıza izin verirler.

Bir oturum açma formu oluşturun. `Password` etiketinden sonra `user_pwd` adında bir şifre alanı ekleyin.

- HTML düzenleyicisinde bir `<form>` açılış etiketi olmalıdır.
- HTML düzenleyicide bir `</form>` kapanış etiketi olmalıdır.
- `form` etiketi içinde ikinci bir `label` etiketi olmalıdır.
- İkinci `label` etiketi `Password` metnini içermelidir.
- İkinci `label` etiketi içinde bir `input` etiketi olmalıdır.
- İkinci `input` etiketi `type=password` özniteliğine sahip olmalıdır.
- İkinci `input` etiketi `name=user_pwd` özniteliğine sahip olmalıdır.

`<form class="login-form">
<label>
Email
<input type="email" name="user_email" />
</label>
<label>
Password
<input type="password" name="user_pwd"/>
</label>
<button type="submit">Log In</button>
</form>`
