# textarea elemanı

`textarea` elemanı, çok satırlı bir metin alanı oluşturarak büyük miktarda metin girmek için kullanılır. Bu tür alanlar, aşağıdaki gibi çeşitli amaçlarla kullanılabilir:

- geri bildirim
- Yorum
- sosyal ağlarda yayınlayın
- sipariş detaylarının netleştirilmesi vb.

`<textarea name="" rows="" cols="" placeholder=""></textarea>`

`textarea` öğesi aşağıdaki niteliklere sahiptir:

- `rows` - satır sayısını (yükseklik) ayarlar
- `cols` - sütun sayısını (genişlik) ayarlar

Pratikte, yalnızca `rows` belirtilir ve öğenin genişliği CSS aracılığıyla kontrol edilir.

![Screen Shot 2025-07-31 at 23.05.16 PM.png](textarea%20eleman%C4%B1/Screen_Shot_2025-07-31_at_23.05.16_PM.png)

Varsayılan olarak, `textarea` öğesi yatay ve dikey olarak uzatılabilir. Kullanıcı tarafından yeniden boyutlandırma olasılığını kontrol etmek için CSS `resize` özelliğine sahiptir.

`resize: both | horizontal | vertical | none`

Örnek: 

Açıklama girmek için forma bir `textarea` öğesi ekleyerek kullanıcıların açıklama girmesini sağlayın.

- Bu `textarea` elemanı `form-label` sınıfına sahip bir etikete çevrelenmelidir.
- Etiketin metni `Description` olmalıdır
- `textarea` öğesi `form-input` sınıfına sahip olmalıdır.
- `textarea` öğesinin `name` niteliğ `description` olmalıdır.
- `textarea` öğesinin `placeholder` metni `Please provide a detailed issue description` şeklinde olmalıdır.
- `textarea` öğesi beş satırdan oluşmalıdır
- Formda üç adet `label` öğesi bulunmalıdır.
- Tüm etiketler `form-label` sınıfına sahip olmalıdır.
- Üçüncü `label` içindeki metin `Description` olmalıdır.
- Üçüncü `label` `textarea` öğesi içermelidir.
- `textarea`, `form-input` değerine sahip `class` niteliğine sahip olmalıdır.
- `textarea`, `description` değerine sahip bir `name` özniteliğine sahip olmalıdır.
- `textarea`, `Please provide a detailed issue description` değerine sahip bir `placeholder` özniteliğine sahip olmalıdır.
- `textarea` öğesinin `rows` niteliği `5` olmalıdır.

Aşağıda, talep ettiğin tüm kurallara uygun şekilde güncellenmiş <form> yapısını bulabilirsin. Üçüncü <label> etiketi içinde belirtilen textarea alanı da doğru şekilde eklendi:

```
<form class="form" name="issue_report_form" autocomplete="off">
  <label class="form-label">
    Your name
    <input
      class="form-input"
      type="text"
      name="username"
      placeholder="Andrew Berger"
      autofocus
    />
  </label>

  <label class="form-label">
    Topic
    <input
      class="form-input"
      type="text"
      name="topic"
      placeholder="Short issue summary"
    />
  </label>

  <label class="form-label">
    Description
    <textarea
      class="form-input"
      name="description"
      placeholder="Please provide a detailed issue description"
      rows="5"
    ></textarea>
  </label>

  <button class="form-button" type="submit">Submit an issue</button>
</form>
```

Bu yapı ile:

- Formda toplam 3 adet label etiketi var ve her biri form-label sınıfına sahip.
- Üçüncü label öğesi içinde Description metni bulunuyor.
- textarea öğesi form-input sınıfını, description isim özniteliğini, Please provide a detailed issue description değerinde placeholder’ı ve rows="5" satır sayısını içeriyor.
