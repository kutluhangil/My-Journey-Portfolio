# Form elemanı

Bir `form` elemanı, bir HTML belgesinin, kullanıcının bir web sunucusuna bilgi göndermesine olanak tanıyan etkileşimli denetimler içeren bir bölümüdür.

Semantik olarak, ilgili öğeleri bir arada gruplandıran bir kapsayıcıdır. Örneğin, bir çevrimiçi mağazanın geri bildirim, kayıt ve ödeme formları; bu arayüz bileşenlerinin her biri, bir form tarafından gruplandırılmış etkileşimli öğelerden oluşur.

`<form name="feedback_form" autocomplete="off" novalidate>
	*<!-- Form elemanı -->*</form>`

`Form` öğesinin zorunlu bir niteliği yoktur. İşte örnekteki bazı yararlı isteğe bağlı olanlar.

- `name` - geçerli web sayfasında benzersiz olan formun adı. Her durumda İngilizce alfabe karakterleri, sayılar, alt çizgiler ve tire işaretleri içerebilir. Formla çalışırken hem sunucuda hem de istemcide kullanılır.
- `autocomplete` - tarayıcının tüm form öğelerinin değerlerini otomatik olarak doldurup dolduramayacağını belirler. Sadece iki değeri vardır: `off` ve `on`.
- `novalidate` - bayrak niteliğidir, değeri yoktur. Tarayıcıya, formu gönderirken girilen verilerin geçerliliğini kontrol etmemesini söyler. Öznitelik belirtilmezse, tarayıcının yerleşik doğrulaması gerçekleştirilir.

HTML düzenleyicisinde, form öğesi için aşağıdaki işaretlemeyi ekleyin ve belirtilen özellikleri ayarlayın:

- Sınıf `form`
- İsim `issue_report_form`
- Otomatik tamamlama alanlarını devre dışı bırakın(autocomplete="off")

CSS düzenleyicisinde, form sınıfı için bir seçici içeren kural ekleyin ve aşağıdaki özellikleri ayarlayın:

- Maksimum genişlik `300px`
- Form bir esnek(flex) kapsayıcıdır
- Ana eksen yönü: column (yukarıdan aşağıya doğru)
- Elemanlar arasındaki boşluk: `12px`
- Kenarlık: 1px solid #212121
- Tüm kenarlarda dolgu (padding): 8px
- HTML düzenleyicisi `<form>` açılış etiketi bulunmalıdır.
- HTML düzenleyicisi `</form>` kapanış etiketi bulunmalıdır.
- `form` etiketi class="form" niteliğine sahip olmalıdır.
- `form` etiketi, `name= issue_report_form` niteliğine sahip olmalıdır.
- `form` etiketi, `autocomplete=off` niteliğine sahip olmalıdır..
- CSS düzenleyicisinde `.form` seçicisine sahip bir kural bulunmalıdır.
- `.form` seçicisine sahip CSS kuralının `display:flex` özelliği olmalıdır.
- `.form` seçicisine sahip CSS kuralının `flex-direction:colum` özelliği olmalıdır.
- `.form` seçicisine sahip CSS kuralının `gap:12px` özelliği olmalıdır.
- `.form` seçicisine sahip CSS kuralının `padding` özelliği `8px` değerine sahip olmalıdır.
- `.form` seçicisine sahip CSS kuralının `border:1px solid #212121` değerine sahip olmalıdır.
- `.form` seçicisine sahip CSS kuralının `max-width:300px` özelliği olmalıdır.

**HTML kodu:** 

`<form class="form" name="issue_report_form" autocomplete="off">
<!-- Form elemanları buraya gelecek -->
</form>`

**CSS kodu:**

- `{
box-sizing: border-box;
}`

`body {
font-family: sans-serif;
line-height: 1.5;
color: #212121;
}`

`input,
textarea,
button {
font-family: inherit;
line-height: inherit;
}`

`.form {
max-width: 300px;
display: flex;
flex-direction: column;
gap: 12px;
border: 1px solid #212121;
padding: 8px;
}`
