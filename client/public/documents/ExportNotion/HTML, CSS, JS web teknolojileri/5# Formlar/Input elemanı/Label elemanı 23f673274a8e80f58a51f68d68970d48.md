# Label elemanı

*Kullanıcıya bir giriş alanı vermek yeterli değildir. Neyin girilmesi gerektiğini açıkça tanımlamak da önemlidir.*

`label` elemanı bir açıklamayı (etiket) etkileşimli bir form elemanı ile ilişkilendirir. Metin ve eleman sadece görsel olarak değil, aynı zamanda mantıksal olarak da birbirine bağlıdır. Örneğin, kullanıcı odağı bağlantılı öğeye koyduğunda ekran okuyucu etiket metnini duyuracaktır. Etikete tıkladığınızda, bağlantılı öğe otomatik olarak odaklanacaktır.

Form elemanı bir `label` içinde yuvalanmışsa, bağlantı tarayıcı tarafından otomatik olarak oluşturulur. Örneğin "Username" metnine tıklamak odağı giriş alanına getirecektir.

`<form>
  <label>
    Username
    <input type="text" name="username" />
  </label>
  <button type="submit">Submit feedback</button>
</form>`

Form öğesi bir `label` ile iç içe geçmemişse, bunları açık bir şekilde bağlamanız gerekir:

- öğenin `id` niteliği ve
- öğenin `for` niteliği

`<form>
  <label for="username">Username</label>
  <input type="text" name="username" id="username" />
  <button type="submit">Submit feedback</button>
</form>`

![](https://s3.eu-north-1.amazonaws.com/lms.goit.files/93fbe38b-1fa9-4cb9-9a19-8aeda3f33e35image%20%2854%29.png)

Metin alanlarını, her birine uygun bir metin açıklaması eklenmiş `form-label` sınıfına sahip `label` etiketleriyle çevreleyin.`name="username"` olan alan için etiket metni `Your name` olmalıdır.`name="topic"` olan alan için etiket metni `Topic` olmalıdır.

CSS düzenleyicide, `form-label` sınıfında bir seçici içeren bir kural ekleyin ve aşağıdaki özellikleri ayarlayın:

- Etiket bir flex-container olmalıdır.
- Etiketler dikey olarak düzenlenmelidir.
- HTML düzenleyicisi `<form>` açılış etiketine sahip olmalıdır.
- HTML düzenleyicisi `</form>` kapanış etiketine sahip olmalıdır.
- Formun içinde bir `button` öğesi bulunmalıdır.
- Form içinde iki adet `input` öğesi bulunmalıdır.
- Form içinde iki adet `label` öğesi bulunmalıdır.
- `input` elemanları `label` etiketlerinin içine yerleştirilmelidir.
- Etiketler, `form-label` değerine sahip `class` niteliğine sahip olmalıdır.
- `name="username"` alanının iç içe geçtiği etiketin metni `Your name` şeklinde olmalıdır.
- `name="topic"` alanının iç içe geçtiği etiketin metni `Topic`şeklinde olmalıdır.
- Etiketlerin metni, metin alanlarının işaretlemesinden önce gelmelidir.
- CSS düzenleyicide, `.form-label` seçicisine sahip bir kural bulunmalıdır.
- `.form-label` seçicisine sahip CSS kuralının `flex` değerine sahip bir `display` özelliği bulunmalıdır.
- `.form-label` seçicisine sahip CSS kuralının `flex-direction`özelliği `column` değerine sahip olmalıdır.

## **🎯 Senden ne isteniyor?**

1. Her bir <input> elemanını, **etiket (label)** içine alacaksın.
2. Bu etiketlere class="form-label" vereceksin.
3. Etiketin içinde önce açıklama metni yazılacak, sonra input gelecek:
    - Your name → username için
    - Topic → topic için

Yani input’ları doğrudan kullanmak yerine, onların etrafına bir label kutusu oluşturuyorsun.

---

## **🎓 Neden böyle yapılıyor?**

Çünkü <label> kullanıcı deneyimini geliştirir:

- Kullanıcı label’a tıkladığında ilgili input’a odaklanır.
- Ekran okuyucular (engelli kullanıcılar için) bu şekilde formu daha iyi okur.
- Aynı zamanda CSS ile label ve input’u birlikte daha rahat biçimlendirebilirsin.

---

## **💡 Nasıl başlanır?**

Senin eski kodun şu şekildeydi:

```
<input class="form-input" type="text" name="username" />
<input class="form-input" type="text" name="topic" />
```

Ama artık **her input’u bir label içine alacaksın**. Etiketin içine önce açıklama metnini, sonra input’u koyacaksın.

---

## **✅ Doğru HTML Kodu:**

```
<form class="form" name="issue_report_form" autocomplete="off">
  <label class="form-label">
    Your name
    <input class="form-input" type="text" name="username" />
  </label>
  <label class="form-label">
    Topic
    <input class="form-input" type="text" name="topic" />
  </label>
  <button class="form-button" type="submit">Submit an issue</button>
</form>
```

---

### **Açıklaması:**

### **label Etiketi Ne Yapıyor?**

```
<label class="form-label">Your name ...</label>
```

Bu satır, input’un açıklamasını içeriyor. Bu metin kullanıcıya gösteriliyor.

### **input Etikete Nasıl Yerleştirilir?**

```
<label class="form-label">
  Your name
  <input class="form-input" type="text" name="username" />
</label>
```

Burada input, label’ın **içine yerleştirildi**. Böylece label ile input bir bütün oldu.

---

## **Bonus: CSS Kodun (Sen zaten yapmıştın ama tamam olsun)**

```
.form-label {
  display: flex;
  flex-direction: column;
}
```

Bu stil sayesinde:

- Label içindeki metin (örneğin “Your name”) üstte,
- Input kutusu altta gözükür.

## **✅ Sonuç**

Bu şekilde:

- Her input bir label içinde
- label açıklamaları doğru
- class="form-label" kullanıldı
- CSS doğru tanımlandı
- Tüm input’lar butonun **önünde**
