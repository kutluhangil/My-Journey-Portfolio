# İnput Elemanları - Ö Z E T

## **:focus-within Nedir?**

- :focus-within, bir HTML öğesi **veya onun içindeki herhangi bir alt öğe** odaklandığında (focus olduğunda) tetiklenen bir **durum (pseudo-class)** seçicisidir.
- Bu sayede, örneğin .form-label bir label içindeyken, içindeki input odaklandığında label’a CSS uygulanabilir.

📌 Örnek:

```
.form-label:focus-within {
  color: #009688;
}
```

🧠 **Not**: label:focus çalışmaz çünkü label’a tıklamak input’a odaklanır ama label kendisi focus olmaz. Bu yüzden :focus-within gerekir.

---

## **transition ile Renk Değişimi**

- transition özelliği sayesinde CSS’deki bir özellik değişimi **animasyonlu olarak** gerçekleşir.
- Burada istenen şey: .form-label’ın yazı rengi değişirken bu **yumuşak bir geçiş** ile olsun.

📌 Örnek:

```
.form-label {
  transition: color 150ms ease-in-out;
}
```

Bu demek oluyor ki:

- **color** özelliği değiştiğinde,
- Bu değişim **150 milisaniye** sürecek,
- Geçiş süreci ise ease-in-out olacak, yani başlangıç ve bitişi yavaş, ortası daha hızlı bir geçiş sağlayacak.

---

## **color Özelliği**

- color bir HTML öğesinin **metin rengini** belirler.
- :focus-within ile birlikte color değiştirerek kullanıcıya görsel bir ipucu verilmiş olur.

---

## **Uygulama için Gerekli CSS Kuralları**

Aşağıdaki 3 CSS kuralı mutlaka tanımlanmış olmalı:

### **.form-label:focus-within**

Bu seçici ile içindeki input odaklandığında renk değiştirilecek.

```
.form-label:focus-within {
  color: #009688;
}
```

### **.form-label**

Bu temel sınıfa geçiş (transition) tanımı eklenmeli ki değişim yumuşak olsun.

```
.form-label {
  display: flex;
  flex-direction: column;
  transition: color 150ms ease-in-out;
}
```

### **HTML Yapısı Doğru Olmalı**

input etiketi mutlaka .form-label sınıfının **içinde** olmalı.

```
<form class="form">
  <label class="form-label">
    Your name
    <input class="form-input" type="text" name="username" />
  </label>
</form>
```

## **🔧 Örnek Tam Kod (HTML + CSS)**

### **HTML:**

```
<form class="form">
  <label class="form-label">
    Your name
    <input class="form-input" type="text" name="username" />
  </label>
  <label class="form-label">
    Topic
    <input class="form-input" type="text" name="topic" />
  </label>
  <button class="form-button" type="submit">Submit an issue</button>
</form>
```

### **CSS:**

```
* {
  box-sizing: border-box;
}

body {
  font-family: sans-serif;
  line-height: 1.5;
  color: #212121;
}

input,
textarea,
button {
  font-family: inherit;
  line-height: inherit;
}

.form {
  display: flex;
  flex-direction: column;
  gap: 12px;
  padding: 8px;
  border: 1px solid #212121;
  max-width: 300px;
}

.form-button {
  align-self: flex-start;
}

.form-input {
  padding: 4px;
  color: #212121;
  border: 1px solid #212121;
  border-radius: 4px;
}

.form-input::placeholder {
  color: #616161;
}

.form-label {
  display: flex;
  flex-direction: column;
  transition: color 150ms ease-in-out;
}

.form-label:focus-within {
  color: #009688;
}
```

## **📊 Özet Tablo**

| **CSS Kuralı** | **Ne işe yarar?** | **Örnek** |
| --- | --- | --- |
| .form-label | Temel label yapısını ve geçiş efektini tanımlar | transition: color 150ms ease-in-out; |
| .form-label:focus-within | İçindeki input odaklandığında rengin değişmesini sağlar | color: #009688; |
| transition: color ... | Renk değişiminin animasyonla gerçekleşmesini sağlar | transition: color 150ms ease-in-out; |
| color: #009688 | Yazı rengini yeşil tonuna değiştirir | .form-label:focus-within içinde kullanılır |
| :focus-within | Bir öğenin içine focus olursa çalışır (label içindeki input gibi) | .form-label:focus-within |
