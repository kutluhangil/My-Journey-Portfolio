# Placeholder özniteliği

`Placeholder` özelliği, bir form alanına girilmesi gereken veriler hakkında bir metin ipucu sağlar. Bu ipucu, `input` öğesi boş olduğunda görünür ve kullanıcı metin girdiğinde kaybolur.

`Placeholder` özelliği, metin girişi olan herhangi bir form öğesinde kullanılabilir. Bu metin, `label` etiketinin yerini almaz ancak girilmesi gereken veriler hakkında bir örnek sağlar.

`<form>
  <label>
    Username
    <input type="text" name="username" placeholder="Jacob Mercer" />
  </label>
  <button type="submit">Submit feedback</button>
</form>`
