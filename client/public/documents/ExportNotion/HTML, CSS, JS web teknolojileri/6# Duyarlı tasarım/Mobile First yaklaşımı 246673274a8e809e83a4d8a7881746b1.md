# Mobile First yaklaşımı

*Görevdeki adımları gerçekleştirme sıranız önemlidir.*

*Bir web sayfası geliştirmeye nereden başlamalı: mobil cihazlar için mi yoksa masaüstü bilgisayarlar için mi uyarlamalı? Düzenin uyarlanacağı birden fazla cihazınız varsa, hangi cihazla başlamanız gerektiğini anlamak önemlidir.*

*Modern bir standart, bir web sitesi oluşturmaya mobil sürümden başlamanızı gerektiren Mobile First yaklaşımıdır. Bu yaklaşımın avantajlarını öğrenelim.*
