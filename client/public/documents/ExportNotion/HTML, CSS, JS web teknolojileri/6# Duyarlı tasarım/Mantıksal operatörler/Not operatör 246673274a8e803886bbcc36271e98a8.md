# Not operatör

`Not` operatörü bir olumsuzlama yapmanıza, yani bir medya talebini iptal etmenize olanak tanır. `Not` anahtar sözcüğü medya talebinin başına eklenir ve tüm talebe uygulanır. Çok nadiren kullanılır.

Yazdırma dışında her yerde stillerin kullanılması gereken bir koşul yazalım.

`@media not print {
  */* ... */*
}`

`not` operatörünü kullanırken, ortam türü belirtilmelidir.

Ortam türünü belirtmezseniz, varsayılan olarak `all` olarak ayarlanacaktır. Böylece, kelimenin tam anlamıyla "tüm ortamlar için geçerli değil" olarak okunacak `not all` ifadesi görünecek ve ortam isteği hiçbir zaman yürütülmeyecektir.

`*/* Asla çalışmaz */*
@media not (max-width: 500px) {
  */* ... */*
}`

Aşağıdaki medya sorgusu yalnızca ekransız bir cihazda açıldığında ve görünüm genişliği `500px`ten büyük olduğunda çalıştırılacaktır.

`@media not screen and (max-width: 500px) {
  body {
    background-color: tomato;
  }
}`

```
Not! Yukarıdaki örnekte,not mantıksal işleciscreen and (max-width: 500px) ifadesindeki her iki koşula da uygulanır. Bu, aklınızda bulundurmanız gereken bir sözdizimi özelliğidir.

```

Bu durumda, kodu okumayı kolaylaştırmak için, olumsuzlama ve **`max-width`,** yerine sadece `min-width` kullanmak daha iyidir.

`@media (min-width: 500px) {
  body {
    background-color: tomato;
  }
}`

### **“not” operatörü ne yapar?**

**“not”** kelimesi, **“tam tersini yap!”** demektir.

Mesela:

```
@media not print {
  /* Bu kurallar yazıcı dışında HER yerde geçerli olacak */
}
```

Yani diyor ki:

> “Eğer yazıcı değilse, bu kıyafetleri giy.”
> 

---

### **💥 Ama dikkat: “not” her yerde çalışmaz!**

Eğer ortam türü (örneğin screen, print, vs.) **belirtilmezse**, işler **karışır**.

Şuna bakalım:

```
@media not (max-width: 500px) {
  /* ... */
}
```

Bu, aslında demek istiyor ki:

> “500px’den küçük olduğunda değilse uygula” gibi gözükür…
> 

Ama **yanlış çalışır** çünkü:

- Ortam türü yazılmadığı için, tarayıcı bunu not all and (max-width: 500px) gibi anlar.
- Bu da “her yerde değil VE genişlik 500px’den küçük” gibi saçma bir duruma dönüşür.
- Yani bu **asla çalışmaz**.

---

### **Doğru kullanım örneği:**

```
@media not screen and (max-width: 500px) {
  body {
    background-color: tomato;
  }
}
```

Bu ne diyor?

> “Eğer cihaz bir ekran değilse
> 
> 
> **VEYA**
> 

---

### **Daha kolay yolu?**

Bu tür **kafa karıştıran “not”** yerine, işimizi şöyle sade yapabiliriz:

```
@media (min-width: 500px) {
  body {
    background-color: tomato;
  }
}
```

Bu ne diyor?

> “Eğer ekran 500px ve üzerindeyse, arka plan kırmızı olsun.”
> 

Aynı işi yapıyor, ama çok daha **temiz ve anlaşılır**.

---

### **🔑 Özet gibi özet:**

| **Ne?** | **Ne işe yarar?** | **Ne zaman kullanmalı?** |
| --- | --- | --- |
| not | Koşulu tersine çevirir | Çok nadir kullanılır, kafa karıştırabilir |
| Ortam türü (örneğin screen) | Zorunludur, yoksa çalışmaz | Her zaman yazılmalı |
| Alternatif | min-width gibi sade kurallar | Genelde en iyi ve temiz çözümdür |
