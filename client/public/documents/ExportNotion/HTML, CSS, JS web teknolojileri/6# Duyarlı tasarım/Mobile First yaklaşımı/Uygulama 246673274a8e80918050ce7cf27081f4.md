# Uygulama

Teknik olarak uygulama oldukça basittir:

- Mobil stiller, medya sorgularının dışındaki temel stillerdir.
- Her kesme noktası için, gerekli temel stilleri geçersiz kılan bir medya sorgusu eklenir.
- Ardından önceki aralıktaki stiller veya yeni stiller eklenir.

Aşağıdaki diyagram, iki pivot noktası olan bir sayfa için medya sorgularının ve stillerin yapısını göstermektedir: `768px` ve `1024px`.

![](https://s3.eu-north-1.amazonaws.com/lms.goit.files/e3771241-dacd-4ac8-935a-a2fa10973f9bGroup%202155.png)

İlk olarak, mobil cihazlar için temel stillerin ve stillerin bir sürümünü oluşturursunuz. Daha geniş ekranlar için tüm stiller, ilgili medya sorgularının içinde kapatılır. HTML biçimlendirmesi değiştirilmez.

Mobile First yaklaşımında, stiller küçükten büyüğe doğru yazıldığından, medya sorguları çoğu durumda `min-width` medya işlevini kullanır.

`selector {
  */* Temel stiller */*
}

@media (min-width: tablet genişliği) {
  selector {
    */* Tablet stilleri */*
  }
}

@media (min-width: masaüstü genişliği) {
  selector {
    */* Masaüstü stilleri */*
  }
}`

Bu düzenin avantajları:

- Temiz kod, çünkü arayüz öğelerini konumlandırmamıza yardımcı olması için belge akışını ve blok modelini kullanıyoruz.
- Dar ekranlardan geniş ekranlara stillerin kalıtımı.
- Konumlandırma stillerinin minimum düzeyde geçersiz kılınması.

CSS düzenleyicide, öğenin stilini `toast` sınıfıyla ekleyin.

Temel öğe stilleri:

- `inline-flex` görüntülenmelidir.
- Dolgu : `8px`
- Arka plan rengi : `#2196f3`
- Metin rengi : `#fff`
- Öğe gölgesi : `2px 2px 4px 0px rgba(0, 0, 0, 0.7)`
- Çerçeve yarıçapı : `4px`

Görüntü alanının genişliği `600px`ten büyük olduğunda öğe stilleri:

- Dolgu : `12px`
- Yazı tipi boyutu : `18px`

Görüntü alanının genişliği `1200px`'den büyük olduğunda öğe stilleri:

- Dolgu : `16px`
- Yazı tipi boyutu : `20px`
- Kodda medya sorgularının dışında bir `.toast` seçicisi ile bir kural bulunmalıdır.
- `.toast` seçicisine sahip kuralın `display` özelliği `inline-flex` değerine sahip olmalıdır.
- `.toast` seçicisine sahip kuralın `8px` değerinde bir `padding` özelliği olmalıdır.
- `.toast` seçicisine sahip kuralın `background-color` özelliği `#2196f3` değerine sahip olmaldıır.
- `.toast` seçicisine sahip kuralın `color` özelliği `#fff` değerine sahip olmalıdır.
- `.toast` seçicisine sahip kuralın `box-shadow` özelliği `2px 2px 4px 0px rgba(0, 0, 0.7)` değerini almalıdır.
- `.toast` seçicisine sahip kuralın `border-radius` özelliği `4px` değerinde olmalıdır.
- Kodda iki medya sorgusu bulunmalıdır.
- Kod, ekran genişliği `600px`den büyük olduğunda çalıştırılan bir medya sorgusuna sahip olmalıdır.
- Ekran genişliği `600px`den büyükse, `toast` sınıfına sahip öğenin dolgu değeri `12px` olmalıdır.
- Ekran genişliği `600px`den büyükse, `toast` sınıfına sahip öğenin yazı tipi boyutu `18px` değerinde olmalıdır.
- Kod, ekran genişliği `1200px`den büyük olduğunda çalıştırılan bir medya sorgusuna sahip olmalıdır.
- Ekran genişliği `1200px`den büyükse, `toast` sınıfına sahip öğenin dolgu değeri `16px` değerini almalıdır.
- Ekran genişliği `1200px`den büyükse, `toast` sınıfına sahip öğenin yazı tipi boyutu `20px` değerini almalıdır.

---

### **🔴 Hatalar:**

1. **box-shadow satırının sonunda ; eksik**:

```
box-shadow: 2px 2px 4px 0px rgb(0, 0, 0, 0.7)
```

1. Bu satırın sonuna ; konmalı.
2. **border-radius yanlış yazılmış**:
    
    Şu anda border-radius; 4px; olarak yazmışsın. Doğru kullanım:
    

```
border-radius: 4px;
```

1. 
2. **Medya sorgularında .tost yerine .toast yazılmalı**:
    
    Ana sınıf .toast ama media query içinde .tost olarak yazmışsın. Bu nedenle stiller uygulanmaz.
    

---

### **✅ Düzeltilmiş CSS Kodu:**

```
* {
  box-sizing: border-box;
}

body {
  font-family: sans-serif;
  line-height: 1.5;
}

.toast {
  display: inline-flex;
  padding: 8px;
  background-color: #2196f3;
  color: #fff;
  box-shadow: 2px 2px 4px 0px rgba(0, 0, 0, 0.7);
  border-radius: 4px;
}

@media (min-width: 600px) {
  .toast {
    padding: 12px;
    font-size: 18px;
  }
}

@media (min-width: 1200px) {
  .toast {
    padding: 16px;
    font-size: 20px;
  }
}
```

---

### **✅ Bu haliyle:**

- .toast sınıfı temel stilleri içerir.
- 600px üzeri ekranlarda padding ve font-size güncellenir.
- 1200px üzeri ekranlarda yine güncellenir.
- Tüm sözdizimi hataları düzeltilmiştir.
