# Menzil stilleri

Çoğu durumda `min-width` işlevini kullanmak ve stilleri eklemek ya da geçersiz kılmak yeterlidir. Ancak, `max-width` medya fonksiyonunu kullanmanın kodu daha temiz ve okunabilir okunabilir hale getirebilir.

Durumu analiz edelim:

1. Bir mobil cihazda (`767px` kadar), öğeye bir kenarlık eklemeniz gerekir.
2. Bir tablet için (`768px` ile `1023px` arasında), elemanın bir gölgesi olmalıdır.
3. Masaüstü cihazlar için (`1024px` sonra), öğenin gölgesi olmamalıdır.

![](https://s3.eu-north-1.amazonaws.com/lms.goit.files/e74cd800-ace5-4a2a-8d5a-6203a7f17b25Screenshot%202023-05-22%20at%2014.31.26.png)

# **Kötü çözüm**

Sadece `min-width` kullanmak, çerçeve stillerinin `768px` kesme noktasında sıfırlanmasına neden olur. Ayrıca, `1024px` kesme noktasında gölge stillerini sıfırlar.

En iyi çözüm değil.

`*/* ❌ KÖTÜ */*.box {
	border: 1px solid black;
}

@media (min-width: 768px) {
  .box {
    border: none;
		box-shadow: 2px 2px 4px 2px black;
  }
}

@media (min-width: 1024px) {
  .box {
		box-shadow: none;
  }
}`

# **İyi çözüm**

Bu gibi durumlarda, belirli görünüm alanı aralıklarında belirli stilleri kapatmak daha iyidir.

![](https://s3.eu-north-1.amazonaws.com/lms.goit.files/da274a01-7822-4981-8e09-92d82c33757dGroup%202156.png)

Bu sorunu çözmek için `max-width` medya fonksiyonunu kullanıyoruz.

`*/* ✅ İYİ */*@media (max-width: 767px) {
  .box {
    border: 1px solid black;
  }
}

@media (min-width: 768px) and (max-width: 1023px) {
  .box {
    box-shadow: 2px 2px 4px 2px black;
  }
}`

Canlı bir örnekte sonuç alanının genişliği nasıl değiştirilir?

[Bağlantıyı](https://codepen.io/goit-academy/full/MWKJWem) takip edin. Ardından, goit sayfası örneğinde gösterildiği gibi duyarlı düzen için geliştirici araçlarını kullanın:

- geliştirici araçlarını açın (Windows ve Linux için **Ctrl + Shift + I**, macOS için **cmd + Shift + I**).
- Toggle device araç çubuğunu etkinleştirmek için `1` simgesine tıklayın (yukarıdaki şemaya bakın). Bu moddan çıkmak için `1` simgesine tekrar tıklayın.
- Görüntü alanının genişliğini basitçe esneterek değiştirin. Bunu yapmak için `2` kontrolünü kullanın. Etki, tarayıcı penceresinin gerilmesi veya sıkıştırılması ve böylece görüntü alanının genişliğinin değiştirilmesi gibidir.

Örnek: 

CSS düzenleyicide, öğenin stilini `toast` sınıfı ile tamamlayın. Gerekli medya sorgularını ekleyin.

- `toast` öğesinin `2px 2px 4px 0px rgba(0, 0, 0, 0.7)` gölgesine sahip olması gerekir; bu gölge, ekran genişliği `600px` veya daha fazla olduğunda kaybolmalıdır..
- `toast` öğesinin kenarlığı `2px solid #212121` olmalıdır, ancak yalnızca ekran genişliği `800px` ila `1000px` aralığında.
- Kodda medya sorgularının dışında bir `.toast` seçicisi ile bir kural bulunmalıdır.
- Kod, ekran genişliği `600px`den büyük olduğunda çalıştırılan bir medya sorgusuna sahip olmalıdır.
- Ekran genişliği `600px`den büyük olduğunda, `toast` sınıfına sahip öğenin dolgu değeri `12px` olmalıdır.
- Ekran genişliği `600px`den büyükse, `toast` sınıfına sahip öğenin yazı tipi boyutu `18px` değerini almalıdır.
- Kod, ekran genişliği `1200px`den büyük olduğunda çalıştırılan bir medya sorgusuna sahip olmalıdır.
- Ekran genişliği `1200px`den büyükse, `toast` sınıfına sahip öğenin dolgu değeri `16px`olmalıdır.
- Ekran genişliği `1200px`den büyükse, `toast` sınıfına sahip öğenin yazı tipi boyutu `20px` değerini almalıdır.
- Kod, ekran genişliği `599px`den az olduğunda çalıştırılan bir medya sorgusuna sahip olmalıdır.
- Ekran genişliği `599px`den az olduğunda, `toast` sınıfına sahip öğenin `2px 2px 4px 0px rgba(0, 0, 0, 0.7)` gölgesi olmalıdır.
- Kod, ekran genişliği `800px` ile `1000px` arasında olduğunda çalıştırılan bir medya sorgusuna sahip olmalıdır.
- Ekran genişliği `800px` ile `1000px` arasında olduğunda, `toast` sınıfına sahip öğenin kenarlığı `2px solid #212121` değerinde olmalıdır.
