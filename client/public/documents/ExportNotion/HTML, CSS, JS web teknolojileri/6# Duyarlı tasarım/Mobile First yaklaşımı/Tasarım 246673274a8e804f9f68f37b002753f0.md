# Tasarım

Modern web sayfalarının tasarımı öncelikle mobil cihazlara odaklanmaktadır.

**Mobile First** yaklaşımı, önce mobil sürümün, ardından tablet sürümünün ve daha sonra da masaüstü sürümünün - küçükten büyüğe doğru - tasarlandığı anlamına gelir.

![](https://s3.eu-north-1.amazonaws.com/lms.goit.files/3d861921-a96a-48d9-a1e1-4edaaf0ed5a5image-_1_.jpg)

**Mobile First** yaklaşımının avantajları.

- **Tek bir web sitesi** - tüm cihazlar için tek bir proje. Gerekli geliştirici sayısını azaltır.
- **Kullanıcı dostu** - kullanıcılar sayfadaki en önemli bilgileri ilk önce alır.
- **Yükleme hızı** - mobil cihazlarda indirilen ve görüntülenen kaynak sayısı daha az olabilir. Bu nedenle sayfa daha hızlı yüklenebilir.
- **Arama Motoru Sıralamaları** - Google gibi arama motorları, mobil cihazlar için optimize edilmiş web sitelerine öncelik verir.
