# Adaptif şebeke

Satır sayısı ve satır başına öğe sayısı görüntü alanının genişliğine bağlı olarak değiştiğinde uyarlanabilir bir öğe ızgarası oluşturma tekniğini düşünün.

![](https://s3.eu-north-1.amazonaws.com/lms.goit.files/c93d58d3-a4e4-4613-a289-6fe92ef74983Screenshot%202023-05-21%20at%2022.23.14.png)

Aşağıdaki HTML işaretlemesini kullanalım ve `div.element`i `div.container` içine `768px` ve `1024px` iki kesme noktası ile resme (düzene) göre yerleştirelim.

`<div class="container">
  <div class="element">1</div>
  <div class="element">2</div>
  <div class="element">3</div>
  <div class="element">4</div>
  <div class="element">5</div>
  <div class="element">6</div>
</div>`

# **Temel stiller**

Mobil cihazlar için, yani medya sorgusu olmadan, temel stilleri ve stilleri yazalım.

Konteynerin sadece genişliğini ayarlamak, ortalamak ve öğeler arasındaki boşluğu düzenlemek için temel stilleri yazıyoruz. Hiçbir öğe stili yoktur.

`.container {
  display: flex;
  flex-direction: column;
  gap: 5px;
  max-width: 1170px;
  min-width: 320px;
  maring: 0 auto;
}`

```
Kapsayıcının minimum ve maksimum genişliği düzen tarafından belirlenir - sayfa içeriğinin mobil ve masaüstü sürümlerinin genişliğidir.

```

# **İlk kırılma noktası**

İlk kesme noktası `768px`de, öğeleri yatay olarak yerleştirmeniz gerekir, böylece her bir satıra iki öğe sığar. Bunu yapmak için ana eksenin yönünü değiştirin ve kutuyu çok satırlı hale getirin. Öğeler için boyutu, ızgara oluşturma tekniğinden zaten bildiğimiz formüle göre ayarlıyoruz.

`@media (min-width: 768px) {
  .container {
    flex-direction: row;
    flex-wrap: wrap;
    gap: 10px;
  }

  .element {
    flex-basis: calc((100% - 10px) / 2);
  }
}`

```
Değişengap dikkat edin. Bu, elemanlar arasındaki boşlukların kırılmanın farklı noktalarında değişebileceğini göstermek için bilerek yapılmıştır. Tüm bunlar tasarıma bağlıdır, bu nedenle özellik değerlerinin farklı cihazlarda değişip değişmediğini kontrol etmek için dikkatli olmanız gerekir.

```

# **İkinci kesme noktası**

Son adım, `1024px` kesme noktası için boşluk, öğe sayısı ve boyutunu düzenle eşleşecek şekilde değiştirmektir.

`@media screen and (min-width: 1024px) {
  .container {
    gap: 15px;
  }

  .element {
    flex-basis: calc((100% - 30px) / 3);
  }
}`

### **Konu Ne?**

Ekran boyutuna göre değişen bir **flexbox tabanlı düzen** oluşturulmak isteniyor. Bu düzende:

- Mobilde (dar ekran): Tüm öğeler alt alta yerleşiyor (tek sütun).
- Tablet boyutunda (768px ve üzeri): Her satırda 2 öğe olacak şekilde yan yana diziliyor.
- Masaüstü boyutunda (1024px ve üzeri): Her satırda 3 öğe olacak şekilde yan yana diziliyor.

6 tane kutu (element) bir kapsayıcıya (.container) yerleştirilmiş.

### **CSS Tarafı ve Dikkat Etmen Gerekenler**

### **Temel Stiller (Mobil İçin)**

```
.container {
  display: flex;
  flex-direction: column;
  gap: 5px;
  max-width: 1170px;
  min-width: 320px;
  maring: 0 auto; /* DİKKAT: maring → yazım hatası! margin olmalı */
}
```

- **Mobil ekran** için tüm öğeler **alt alta sıralanıyor.**
- gap: 5px → kutular arası boşluk.
- margin: 0 auto → kapsayıcıyı ortalamak için (ama yanlış yazılmış!).

**⚠️ DİKKAT**: maring yazılmış, doğrusu margin.

---

### **İlk Kırılma Noktası (768px ve üstü - tabletler)**

```
@media (min-width: 768px) {
  .container {
    flex-direction: row;
    flex-wrap: wrap;
    gap: 10px;
  }

  .element {
    flex-basis: calc((100% - 10px) / 2);
  }
}
```

- Artık yatay yerleşim başlıyor (flex-direction: row).
- flex-wrap: wrap → kutular satıra sığmazsa alt satıra geçer.
- Her kutu **yarım satır kadar** yer kaplar: (100% - 10px) / 2 → 2 kutu yan yana olacak şekilde hesaplanmış.
- gap: 10px → boşluk artırıldı.

---

### **İkinci Kırılma Noktası (1024px ve üstü - masaüstü)**

```
@media screen and (min-width: 1024px) {
  .container {
    gap: 15px;
  }

  .element {
    flex-basis: calc((100% - 30px) / 3);
  }
}
```

- Artık her satıra **3 kutu** sığdırılacak.
- flex-basis: calc((100% - 30px) / 3) → 3 öğe için genişlik hesaplanıyor.
- Gap artık 15px, bu yüzden toplam 2 aralık: 15px * 2 = 30px

---

### **NELERE DİKKAT ETMELİSİN?**

| **Dikkat Noktası** | **Açıklama** |
| --- | --- |
| ✅ **Flexbox yönü** | Mobilde column, büyük ekranlarda row. |
| ✅ **Gap değeri değişiyor** | Farklı ekran genişliklerinde gap değişiyor → dikkat! |
| ✅ **flex-basis hesaplamaları** | calc((100% - toplam boşluk) / öğe sayısı) formülünü iyi öğren. |
| ⚠️ **Yazım hataları** | maring: 0 auto; → Hatalı, margin olmalı. |
| ✅ **Medya sorguları sıralı olmalı** | Küçükten büyüğe doğru sıralanmalı (mobile-first yaklaşımı). |

### **🧠 Kısa Özetle:**

Bu örnek sana **duyarlı tasarım**ın temelini öğretiyor:

- Farklı ekran boyutlarına uygun yerleşim.
- flex + media queries + calc() kullanımı.
- Mobil öncelikli (mobile-first) yaklaşım.

CSS düzenleyicide, bildirilen kuralların kodunu tamamlayın ve aşağıdaki kriterleri karşılayacak şekilde yenilerini ekleyin:

- `card-set` sınıfına sahip bir öğenin maksimum genişliği `960px`'dir.
- `card-set` sınıfına sahip bir öğenin minimum genişliği `320px`'dir
- `card-set` sınıfına sahip öğe yatay olarak ortalanır.
- Varsayılan olarak, `item` sınıfının öğeleri `card-set` içinde dikey olarak yer alır ve aralarında `4px` boşluk bulunur.
- Ekran genişliği `600px` veya daha fazla olduğunda, `item` öğeleri satır başına üç öğe olacak şekilde yatay olarak düzenlenir ve öğeler arasında `8px` boşluk olmalıdır.
- Ekran genişliği `900px` ve üzerinde olduğunda, `item` öğeleri yatay olarak dört öğe bir satır olacak şekilde düzenlenir ve öğeler arasında `12px`boşluk olmalıdır.
- Kodda medya sorguları dışında `.card-set` seçicisiyle bir kural bulunmalıdır.
- `.card-set`seçicisiyle ilişkilendirilmiş kuralda, `max-width` özelliği `960px`değerine sahip olmalıdır.
- `.card set` seçicisiyle ilişkilendirilmiş kuralda `min-width` özelliği, `320px`değerine sahip olmalıdır.
- `.card-set` seçicisiyle ilişkilendirilmiş kuralda `0 auto` değerine sahip `margin` özelliği bulunmalıdır.
- `.card-set` seçicisiyle ilişkilendirilmiş kuralda `display` özelliği `flex`değeriyle bir gelmektedir.
- `.card-set` seçicisiyle ilişkilendirilmiş kuralda `flex-direction` özelliği `column` değeri ile bulunmalıdır.
- `.card-set` seçicisine sahip kuralda `gap` özelliği `4px` değerine sahip olmalıdır.
- Kodda iki medya sorgusu bulunmalıdır.
- Kod, ekran genişliği `600px`den büyük olduğunda çalıştırılan bir medya sorgusuna sahip olmalıdır.
- Ekran genişliği `600px`'den fazla olduğunda, `item` öğesi arasında `8px`boşluk bulunmalıdır.
- Ekran genişliği `600px`den büyükse, `item` öğeleri satır başına üç öğe olacak şekilde yatay olarak düzenlenmelidir.
- Kodda, ekran genişliği `900px`'den fazla olduğunda gerçekleştirilen medya sorgusu bulunmalıdır.
- GEkran genişliği `900px`'den büyükse, `item` öğesi arasında `12px` boşluk bulunmalıdır.
- Ekran genişliği `900px`den büyük olduğunda, `item` öğeleri satır başına dört öğe olacak şekilde yatay olarak düzenlenmeliri.

## **✅ Görev Kriterlerinin Kontrolü ve Kodun Analizi**

---

### **1. card-set sınıfının max-width = 960px olması**

**Kodundaki satır:**

```
.card-set {
    max-width: 960px;
    ...
}
```

**✔ Doğru!** Bu özellik doğru şekilde tanımlanmış.

---

### **2. card-set sınıfının min-width = 320px olması**

**Kodundaki satır:**

```
.card-set {
    ...
    min-width: 320px;
    ...
}
```

**✔ Doğru!** Kriter karşılanıyor.

---

### **3. card-set sınıfı ortalanmalı (margin: 0 auto)**

**Kodundaki satır:**

```
.card-set {
    ...
    margin: 0 auto;
    ...
}
```

**✔ Doğru!** Ortalamak için kullanılır ve doğru yazılmış.

---

### **4. card-set → display: flex,**

### **flex-direction: column**

**Kodundaki satır:**

```
.card-set {
    ...
    display: flex;
    flex-direction: column;
    ...
}
```

**✔ Doğru!** Öğeler dikey sıralanacak şekilde ayarlanmış.

---

### **5. card-set için gap: 4px**

**Kodundaki satır:**

```
.card-set {
    ...
    gap: 4px;
}
```

**✔ Doğru!** Varsayılan boşluk sağlanmış.

---

### **6. .item öğeleri arasında boşluk için gap yanlış yerde tanımlanmış**

**Kodundaki hata:**

```
@media (min-width: 600px) {
    .item {
        gap: 8px; /* ❌ "item" bir flex container değil, "gap" burada işe yaramaz */
    }
}
```

**❌ Hatalı!**

→ gap özelliği **.card-set** gibi flex ya da grid içeren kapsayıcılara uygulanmalı.

→ .item bir çocuk öğe, gap burada geçersiz.

**✅ Doğrusu:**

```
@media (min-width: 600px) {
    .card-set {
        flex-direction: row;
        flex-wrap: wrap;
        gap: 8px;
    }

    .item {
        flex: 0 0 calc((100% - 16px) / 3); /* 3 item, 2 boşluk arası (2 x 8px) */
    }
}
```

---

### **7. .container adında bir sınıf tanımlamışsın ama görevde yok**

**Kodundaki satır:**

```
@media (min-width: 600px) {
    .container {
        display: flex;
        flex-wrap: wrap;
    }
}
```

**❌ Hatalı!**

→ Görevde container diye bir sınıf hiç yok. Bu kurallar card-set üzerinde uygulanmalı.

---

### **8. @media (min-width: 600px) içinde .item stil bloğu dışında bir tane daha var**

**Kodundaki satırlar:**

```
@media (min-width: 600px) {
    .item { ... }
}

@media (min-width: 600px) {
    .container { ... }
}
```

**❌ Hatalı!**

→ **Aynı medya sorgusu birleştirilmeli**, dağınık olmamalı. Ayrıca yanlış sınıfa (.container) yazılmış.

---

### **9. .item için flex değeri dışarıda yazılmış**

**Kodundaki satır:**

```
.item {
    flex: 0 0 33.33%;
    box-sizing: border-box;
  }
}
```

**❌ Hatalı!**

→ Bu blok yanlış kapanmış, fazladan süslü parantez var.

→ Bu stil sadece büyük ekranlar için geçerli olmalı, ama globalde tanımlanmış.

---

### **10. @media (min-width: 900px) kuralı mevcut**

**Kodundaki satır:**

```
@media (min-width: 900px) {
    .item {
        gap: 12px;
        flex: 0 0 25%;
        ...
    }
}
```

**⚠️ Kısmen doğru ama:**

- gap: 12px yine yanlış yerde.
- gap özelliği .card-set’e yazılmalı.
- Ayrıca 900px’de card-set’in gap değeri 12px olmalı.

## **🧹 Tüm Hataları Düzelten Doğru CSS**

Aşağıda tüm kuralları karşılayan, temiz ve doğru bir CSS yapısı veriyorum:

```
* {
  box-sizing: border-box;
}

body {
  font-family: sans-serif;
  line-height: 1.5;
  background-color: #edf2f7;
}

.card-set {
  max-width: 960px;
  min-width: 320px;
  margin: 0 auto;
  padding: 0;
  list-style: none;
  display: flex;
  flex-direction: column;
  gap: 4px;
}

.item {
  padding: 4px;
  text-align: center;
  background-color: #fff;
  border-radius: 4px;
  border: 1px solid #212121;
}

/* Ekran genişliği 600px ve üzeri */
@media (min-width: 600px) {
  .card-set {
    flex-direction: row;
    flex-wrap: wrap;
    gap: 8px;
  }

  .item {
    flex: 0 0 calc((100% - 16px) / 3); /* 3 item, 2 boşluk x 8px */
  }
}

/* Ekran genişliği 900px ve üzeri */
@media (min-width: 900px) {
  .card-set {
    gap: 12px;
  }

  .item {
    flex: 0 0 calc((100% - 36px) / 4); /* 4 item, 3 boşluk x 12px */
  }
}
```
