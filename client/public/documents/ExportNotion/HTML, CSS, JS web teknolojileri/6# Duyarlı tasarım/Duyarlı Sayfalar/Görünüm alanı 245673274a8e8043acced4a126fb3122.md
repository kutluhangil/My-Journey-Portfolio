# Görünüm alanı

**Görünüm alanı (viewport)**, bir web sayfasının adres çubuğu, yer imleri çubuğu veya diğer tarayıcı hizmetlerini içermeyen görünür, dikdörtgen bir alanı ifade eder.

![](https://s3.eu-north-1.amazonaws.com/lms.goit.files/a7d67a5e-7f60-4a77-9a74-0e2c7f4c5ca1Screenshot%202024-06-28%20at%2013.35.22.png)

Mobil tarayıcılar, web sayfalarını bir **düzen görünüm alanında** (layout viewport) görüntüler. Düzen görünüm alanının genişliği, cihaz üreticisine bağlı olarak değişir. Çoğu zaman, varsayılan sanal görünüm alanının genişliği `980px` olarak ayarlanmıştır.

**Fiziksel görünüm alanı** **(visual viewport)** cihazın fiziksel ekranının genişliğine eşit bir değerdir. Mobil cihazlarda, fiziksel görüntü alanının boyutu varsayılan olarak sanal görüntü alanıyla eşleşmez. Sanal görüntü alanı, cihazın fiziksel ekranından daha geniş olabilir.

Sorunun özeti şudur:

Mobil tarayıcı, bir web sayfası açtığında cihaza görüntü alanının genişliğini sorar. Varsayılan olarak, tarayıcı fiziksel görünüm alanının değil, sanal görünüm alanının (980px) boyutuyla yanıt verir. Bu durum, web sitesinin fiziksel ekranda yanlış görüntülenmesine neden olabilir.

![](https://s3.eu-north-1.amazonaws.com/lms.goit.files/bfab74ec-c7ff-4cbe-ba9c-bf3512a35da4image%20%283%29.jpg)

Mobil uyumlu duyarlı CSS kuralları, mobil tarayıcılarda doğrudan uygulanmaz veya geçersiz kılınır. Örneğin, bir web sayfası 400 piksel genişliğinde bir ekranda açıldığında, 800 piksel genişlik için tasarlanmış duyarlı CSS kuralları uygulanır. Bu durum, mobil stillerin geçersiz kılınmasına ve sayfanın telefonda açıldığında bile tabletler için bir varyantının görüntülenmesine neden olabilir.

Farklı cihazlarda görüntülenmek üzere uyarlanmış sayfalar, `<head>` bölümünde `viewport` meta etiketini içermelidir. Tarayıcıya görüntü alanının boyutunu ve ölçeğini nasıl kontrol edeceğini söyler.

`<head>
  *<!-- Diğer meta etiketler -->*<meta name="viewport" content="width=device-width, initial-scale=1.0" />
  <title>Viewport meta etiketi duyarlı sayfalar için önemlidir</title>
</head>`

- `width=device-width` - görünüm alanının genişliğini cihaz ekranının fiziksel genişliğine (device-width) eşit olacak şekilde ayarlar.
- `initial-scale=1.0` - CSS pikselleri ile cihazın donanım pikselleri arasındaki oranı (ölçek) 1:1 olarak ayarlar.

![](https://s3.eu-north-1.amazonaws.com/lms.goit.files/113b9fb0-8a5d-4898-b689-460336878301image%20%284%29.jpg)

Mobil cihazlarda görünüm alanını özelleştirmek için HTML düzenleyicisine `viewport`meta etiketini ekleyiniz.

- Kodun içinde açılış `head` etiketi bulunmalıdır.
- Kod, `head` kapanış etiketine sahip olmalıdır.
- `head` etiketi içinde iki adet `meta` etiketi olmalıdır.
- İlk `meta` etiketi `utf-8` değerine sahip bir `charset` özelliğine sahip olmalıdır.
- İkinci `meta` etiketi `viewport` değerine sahip bir `name` özelliğine sahip olmalıdır.
- İkinci `meta` etiketi, `width=device-width, initial-scale=1.0` değerine sahip `content`özelliğine sahip olmalıdır.
- `meta` etiketleri `title` etiketinden önce yerleştirilmalidir

---

```
<!DOCTYPE html>
<html lang="en">
  <head>
    <meta charset="utf-8" />
    <meta name="viewport" content="width=device-width, initial-scale=1.0" />
    <title>Planet Fatness is the place for beginners and pros!</title>
  </head>
  <body></body>
</html>
```

---

Bu haliyle tüm kriterleri karşılamış oluyorsunuz:

✅ head etiketi var

✅ head içinde 2 adet meta etiketi var

✅ İlki charset="utf-8"

✅ İkincisi name="viewport" ve doğru content değeri

✅ meta etiketleri title etiketinden önce

✅ Etiketler düzgün kapatılmış
