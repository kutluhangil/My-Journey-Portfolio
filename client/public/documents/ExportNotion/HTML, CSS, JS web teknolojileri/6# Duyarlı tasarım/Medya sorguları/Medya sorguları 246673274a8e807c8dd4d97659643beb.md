# Medya sorguları

Medya sorguları, masaüstü veya akıllı telefon gibi her ekranda eşit derecede iyi görünen modern duyarlı web sayfaları oluşturmayı mümkün kılan bir araçtır.

Medya sorgularıyla çalışmak, belirli bir CSS kuralını uygulamaktan ibarettir. Belirli bir CSS kuralının seçimi ve kullanımı aşağıdaki faktörlere bağlıdır

- tarayıcı penceresinin boyutu (görüntüleme alanı, viewport)
- tarayıcı ayarları
- cihaz yetenekleri

![](https://s3.eu-north-1.amazonaws.com/lms.goit.files/a37719e2-18ca-4d18-ac83-744e8a841235image%20%2855%29.png)

Stilleri uygulamak için algoritma aşağıdaki gibidir:

1. Geliştirici, bir dizi medya sorgusu ve bunların içindeki CSS kurallarını tanımlar.
2. Tarayıcı, görüntü alanının boyutundaki değişikliği izler.
3. Tarayıcı, medya sorgularından geçerli görüntü alanı boyutuna uyan CSS kurallarını uygular.

Başka bir deyişle, medya sorguları aşağıdaki gibi tanımlanabilecek talimatlardır: "Sayfa X görüntü alanı genişliğinde açıldığında metin renginin kırmızı, Y görüntü alanı genişliğinde açıldığında ise yeşil olmasını istiyorum".

Görüntü alanı genişliğinin yanı sıra odaklanabileceğimiz birçok başka kriter vardır. Bunlar ekran çözünürlüğü, cihaz oryantasyonu, işletim sistemi ayarları vb. bulunur.
