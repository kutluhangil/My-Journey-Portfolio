# Stilleri geçersiz kılma

Bu yaklaşım, geçerli medya sorgusu için daha önce tanımlanmış olan stilleri yeniden kullanarak, her bir medya sorgusunun yalnızca geçerli olduğu genişlik aralığında geçerli olacak şekilde katmanlı bir stil yapısı oluşturmanıza olanak tanır. Böylece, daha önce tanımlanmış stiller bozulmadan ve gereksiz tekrarlar yapılmadan, sadece gerekli olan kurallar uygulanır.

`*/* Temel stil */*body {
  background-color: #fff;
}

*/* 900 piksel ve daha geniş alanlarda arka plan rengini geçersiz kılın */*@media (min-width: 900px) {
  body {
    background-color: #388e3c;
  }
}`

### **Ne anlatılıyor bu kodda?**

Bu örnek, bir web sayfasının **arka plan rengini** ekrana göre değiştirmek için yazılmış. Yani, **ekran küçükse başka renk**, **ekran genişse başka renk** görünsün istiyor.

---

### **Önce temel fikir:**

CSS’de “medya sorgusu” dediğimiz şey, ekrana göre **farklı stiller uygulamak** anlamına gelir. Mesela:

- Telefon gibi **küçük ekranlarda** bir şey göster,
- Bilgisayar gibi **büyük ekranlarda** başka bir şey göster.

---

### **Örnekte ne yapılıyor?**

```
/* Temel stil */
body {
  background-color: #fff;  /* Yani ekran beyaz */
}
```

Bu satır, **herkes için** geçerli. Sayfa açıldığında arka plan rengi **beyaz** olacak.

Ama sonrasında şöyle bir şey yazıyor:

```
@media (min-width: 900px) {
  body {
    background-color: #388e3c;
  }
}
```

Bu ne demek?

> Eğer ekran
> 
> 
> **900 pikselden genişse**
> 
> **yeşile çevir**
> 

Yani:

- 📱 **Telefon gibi küçük ekranlarda:** Arka plan **beyaz**.
- 💻 **Bilgisayar gibi büyük ekranlarda:** Arka plan **yeşil**.

---

### **“Stilleri geçersiz kılma” kısmı ne demek?**

Bu sadece şu anlama geliyor:

> Önce herkes için bir kural koy (beyaz yap),
> 

> sonra sadece büyük ekranlar için
> 
> 
> **o kuralın üstüne**
> 

> Eski kuralı tamamen silme, sadece gerektiğinde
> 
> 
> **üstüne yaz**
> 

Böylece:

- Tekrar tekrar her şeyi yazmana gerek kalmaz,
- Kodun daha temiz olur,
- Sayfa daha iyi görünür.

---

### **Özetle:**

Bu kod diyor ki:

> “Sayfam beyaz başlasın. Ama biri büyük ekranla gelirse, orada yeşil gösteririm.”
> 

Ve bunu yaparken eski ayarı silmeden, **üstüne yazıyor** sadece.

---

Kuralın tamamı değil, yalnızca aynı özellikler geçersiz kılınır.

Bu, geçerli medya sorgusu için de uygun olan öncekileri çoğaltmadan katmanlı bir stil pastası yapmanıza olanak tanır.

`*/* Temel stiller */*body {
  color: #2a2a2a;
  background-color: #fff;
  font-size: 16px;
  line-height: 1.5;
  font-family: sans-serif;
}

*/* 600 piksel ve üzerinde arka plan rengini, metin boyutunu ve rengini değiştireceğiz */*@media (min-width: 600px) {
  body {
    background-color: #2196f3;
    font-size: 20px;
    color: #fff;
  }
}

*/* 900 piksel ve üzerinde arka plan rengini değiştireceğiz. */*@media (min-width: 900px) {
  body {
    background-color: #4caf50;
  }
}`

Görüntü alanının genişliği 900 pikselden fazla olduğunda geliştirici araçları `<body>` öğesinin stilleri gibi görünecektir.

Aşağıdaki canlı örnekte, arka plan rengi, metin boyutu ve rengi, 600 ve 900 piksel kesme noktalarına sahip medya sorgularında belirtilen görüntü alanının genişliğine bağlı olarak değişecektir.

# **Farklı ekran genişlikleri için rengin değiştiğini nasıl kontrol edebilirim?**

1. Bu [bağlantı](https://codepen.io/goit-academy/pen/PoZGxeG) adresindeki canlı örnek sayfasına gidin.

2. Geliştirici araçlarını açın

Bunu yapmak için:

- Sayfada herhangi bir yere sağ tıklayın.
- Açılan menüden **İncele** seçeneğini tıklayın.

3. Geliştirici araçlarında

- **Elementler** sekmesinin sol tarafındaki iki ekran simgesine tıklayın.
- Sonuç alanını görüntüleyen bir pencere görünür. Kenarlığa tıklayarak pencerenin genişliğini ayarlayabilirsiniz.
- Ekran genişliğini değiştirmek için bu pencerenin kenarını sürükleyin. Böylece, farklı ekran boyutlarını simüle edebilirsiniz.

Arka plan ve metin renklerinin yanı sıra penceredeki metnin boyutu da pencerenin genişliğine bağlı olarak değişmelidir.

Örnek olarak: “

```
/* Base styles */
body {
  color: #2a2a2a;
  background-color: #fff;
  font-size: 16px;
  line-height: 1.5;
  font-family: sans-serif;
}

/* From 600px and wider, override the background, font and color. */
@media (min-width: 600px) {
  body {
    background-color: #2196f3;
    font-size: 20px;
    color: #fff;
  }
}

/* From 900px and wider, override the background. */
@media (min-width: 900px) {
  body {
    background-color: #4caf50;
  }
}
```

Örnek:

Ekran genişliği `600px` olduğunda:

- Dolgu(padding) : `12px`
- Yazı tipi(font) : `16px`
- Arka plan rengi : `yellow`

Ekran genişliği `900px` büyük olduğunda:

- Dolgu(padding) : `20px`
- Arka plan rengi : `teal`
- Metin rengi : `white`
- Kodda medya sorgularının dışında bir `.card` sınıfına ait bir CSS kuralı bulunmalıdır.
- Kodda `min-width` özelliğini kullanan iki medya sorgusu bulunmalıdır.
- Kod, ekran genişliği `600px` veya daha fazla olduğunda çalışacak bir medya sorgusu içermelidir.
- Ekran genişliği `600px`den büyükse, `.card` öğesinin dolgu(padding) değeri `12px`olmalıdır.
- Ekran genişliği `600px` olduğunda, `.card` öğesinin metin boyutu `16px` değerini almalıdır.
- Ekran genişliği `600px` olduğunda, `.card` öğesinin arka planı `yellow` değerini almalıdır.
- Kod, ekran genişliği `900px` veya daha fazla olduğunda çalışacak bir medya sorgusu içermelidir.
- Ekran genişliği `900px`den büyükse, `.card` öğesinin dolgu değeri `20px` olmalıdır.
- Ekran genişliği `900px` olduğunda, `.card` öğesinin arka plan rengi `teal` olmalıdır.
- Ekran genişliği `900px` olduğunda, `.card` öğesinin metin rengi `white` değerini almalıdır.

---

### **💡 Sorun ne?**

Senin yazdığın CSS kodunda medya sorguları içinde **.body** sınıfını değiştirmeye çalışmışsın ama **.card** sınıfını değiştirmek gerekiyordu.

---

### **🛠️ Kodunun bu kısmı hatalı:**

```
@media (min-width: 600px) {
    .body {
        padding: 12px;
        font-size: 16px;
        background-color: yellow;
    }
}
```

Burada **.body** diye bir şey yazıyorsun. Ama aslında stil vermek istediğin şey **.card** idi.

---

---

### **✅ Doğrusu nasıl olmalıydı?**

```
.card {
  border: 2px solid darkorchid;
  padding: 8px;
  max-width: 320px;
  border-radius: 4px;
  font-size: 20px;
  font-family: sans-serif;
  color: black;
}

/* 600px ve üstü için değişiklikler */
@media (min-width: 600px) {
  .card {
    padding: 12px;
    font-size: 16px;
    background-color: yellow;
  }
}

/* 900px ve üstü için değişiklikler */
@media (min-width: 900px) {
  .card {
    padding: 20px;
    background-color: teal;
    color: white;
  }
}
```

---

### **📦 Özet:**

- .card adlı öğeyi değiştirmek istiyorduk ama yanlışlıkla .body öğesini değiştirmişiz.
- Bu yüzden medya sorgularında yazdığın stil değişiklikleri çalışmadı.
- Medya sorgularında .card yazarsan hepsi çalışır 🎯
