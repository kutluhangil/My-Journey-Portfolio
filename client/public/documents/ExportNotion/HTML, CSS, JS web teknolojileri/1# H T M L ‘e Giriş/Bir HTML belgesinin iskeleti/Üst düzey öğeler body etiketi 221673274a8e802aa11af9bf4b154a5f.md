# Üst düzey öğeler: <body> etiketi

`<body>` etiketi, gelecekteki web sayfasının tüm içeriğini içerir. Sayfada görüntülenmesi gereken her şey bu etiketin içine yerleştirilmelidir.

`<!DOCTYPE html>
<html lang="en">
  <head>
    <meta charset="utf-8" />
    <meta name="description" content="Learning the basics of HTML for beginners" />
    <title>HTML is simple!</title>
  </head>
  <body>
    *<!-- İçerik-->*</body>
</html>`

ÖNEMLİ: <body> etiketi <html> etiketi içinde yer alması gerekmektedir.
