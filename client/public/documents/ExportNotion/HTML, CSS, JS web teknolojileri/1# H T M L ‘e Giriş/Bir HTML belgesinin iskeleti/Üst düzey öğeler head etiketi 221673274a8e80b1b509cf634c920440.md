# Üst düzey öğeler: <head> etiketi

`<head>` etiketi, sayfa hakkında hizmet bilgilerini saklamak için kullanılır. Bu bilgiler, sayfanın başlığı, karakter kodlaması, açıklama gibi çeşitli verileri içerir:

- başlık : Sayfanın tarayıcı sekmesinde görünen başlık.
- kodlama : Sayfanın hangi karakter setini kullandığını belirten bilgi.
- açıklama : Arama motorları ve sosyal medya platformları için kullanılan kısa açıklamalar.

Bu bilgiler tarayıcı penceresinde doğrudan görüntülenmez, bunun yerine, tarayıcının sayfayı nasıl işlemesi gerektiğine dair talimatlar sağlar.

`<!DOCTYPE html>
<html lang="en">
  <head>
    *<!-- Servis bilgileri -->*</head>
</html>`
