# Doküman başlık etiketleri: içerik açıklama meta name description

`<meta>` etiketinin çok yaygın bir diğer işlevi de arama motorlarına bilgi sağlamaktır. Arama motorları bir sayfayı içeriğine göre indeksler. `<meta>` etiketi, bir sayfanın içeriğini arama motorlarına iletmek için nitelikler kullanır:

- `name="description"` . Bu nitelik, bu etiketteki meta bilgi türünün sayfa içeriğinin bir açıklaması olduğunu tanımlar.
- `content="..."` , burada değer sayfa içeriğinin kısa bir açıklamasıdır.

`<!DOCTYPE html>
<html lang="en">
  <head>
    <meta charset="utf-8" />
    <meta name="description" content="Learning the basics of HTML for beginners" />
    <title>HTML is simple!</title>
  </head>
</html>`

`name` ve `content` nitelikleri bir tür + değer olarak eşleştirilir.

İçeriğin kısa bir açıklaması, arama motorlarının sayfayı daha iyi indekslemesine yardımcı olur.

Sayfa içeriği hakkında meta bilgileri ekleyin. Aşağıdaki `Planet Fatness description meta tag content` metnini kullanın.

- Kod `meta` etiketini içermelidir.
- `meta` etiketi `head` etiketinin içinde yer almalıdır.
- `meta` etiketi `name` niteliğine sahip olmalıdır.
- `name` özniteliğinin değeri `description` olmalıdır.
- `meta` etiketi `content` niteliğine sahip olmalıdır.
- `content` niteliğinin değeri `Planet Fatness description meta tag content`olmalıdır.
