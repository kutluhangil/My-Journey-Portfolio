# Bir belge türü bildirme

`<!DOCTYPE>` bir etiket değil, zorunlu bir belge türü bildirimidir. Tarayıcıya belgenin hangi HTML sürümünde yazıldığını belirtmek için kullanılır.

Tarayıcı doküman tipine göre HTML sürümünü belirler ve sayfayı doğru şekilde görüntüler. Belge türü bildirimi, tarayıcının bir HTML belgesini işlerken gördüğü ilk şey olmalıdır.

`*<!-- Belgenin HTML Living Standard spesifikasyonuna göre yazıldığını gösterir -->*<!DOCTYPE html>`

```
HTML'in geçmişte farklı sürümleri vardı. En son sürüm HTML5'tir. ArtıkHTML Living Standard, sürümleri terk edilen tek HTML spesifikasyonudur, sadece güncellenmiştir. HTML5 hakkında konuştuğumuzda, "modern HTML" veya HTML Yaşam Standardı ile aynı anlama gelir; sadece daha kısa bir terimdir.
```
