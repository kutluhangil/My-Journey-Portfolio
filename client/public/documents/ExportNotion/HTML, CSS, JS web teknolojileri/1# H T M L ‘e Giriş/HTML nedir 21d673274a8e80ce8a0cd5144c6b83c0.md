# HTML nedir?

**Hypertext Markup Language**, web belgelerini işaretlemek için kullanılan bir dildir. Metinsel bilgileri yapılandırmak (işaretlemek), resim eklemek, tablolar, formlar, listeler vb. oluşturmak için bir dizi kural içerir.

**HTML belgesi** — uzantısı `.html` olan bir metin dosyasıdır.

HTML kullanılarak işaretlenmiş bir belge bir tarayıcı tarafından yorumlanır. Bu yorumlama sonucunda, kullanıcılar kaynak kodunu değil, bu kodun işlenmesiyle oluşturulan web sayfasını görürler.

![](https://s3.eu-north-1.amazonaws.com/lms.goit.files/4a203917-6867-4039-bc4b-1f86ead11c73Untitled%20%281%29.jpeg)

HTML'nin popülerliği ve web sayfaları için temel olarak kullanılması, standartların oluşturulması, sürdürülmesi ve geliştirilmesi ihtiyacını doğurmuştur. Bu şu anda [HTML Living Standard](https://html.spec.whatwg.org/multipage/) spesifikasyonu üzerinde çalışan [Web Hypertext Application Technology Working Group WHATWG)](https://whatwg.org/) tarafından yapılmaktadır.

```
Şu anda tarayıcınızda görüntülenen bir HTML belgesinin içeriğini görüyorsunuz. Bu etkileşimli uzun okuma HTML işaretlenmiş bir sayfadır.
```
