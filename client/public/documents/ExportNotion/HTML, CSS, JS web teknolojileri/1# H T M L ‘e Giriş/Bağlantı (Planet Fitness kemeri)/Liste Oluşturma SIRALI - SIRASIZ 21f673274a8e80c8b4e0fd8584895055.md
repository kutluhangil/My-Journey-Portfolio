# Liste Oluşturma SIRALI - SIRASIZ

**✅ 1.**

---

## **Sırasız Liste (Unordered List)**

Kare veya yuvarlak madde işaretleriyle gösterilir.

### **🔧 HTML Kodu:**

```
<ul>
  <li>Apples</li>
  <li>Bananas</li>
  <li>Cherries</li>
</ul>
```

### **💡 Ekranda Görüntüsü:**

- Apples
- Bananas
- Cherries

---

## **✅ 2.**

## **Sıralı Liste (Ordered List)**

Numaralandırılmış liste şeklindedir (1, 2, 3…).

### **🔧 HTML Kodu:**

```
<ol>
  <li>Wake up</li>
  <li>Exercise</li>
  <li>Have breakfast</li>
</ol>
```

### **💡 Ekranda Görüntüsü:**

1. Wake up
2. Exercise
3. Have breakfast

---

## **🔹 Bonus: Liste İçinde Liste (İç içe liste)**

```
<ol>
  <li>Breakfast
    <ul>
      <li>Eggs</li>
      <li>Toast</li>
      <li>Tea</li>
    </ul>
  </li>
  <li>Lunch</li>
</ol>
```
