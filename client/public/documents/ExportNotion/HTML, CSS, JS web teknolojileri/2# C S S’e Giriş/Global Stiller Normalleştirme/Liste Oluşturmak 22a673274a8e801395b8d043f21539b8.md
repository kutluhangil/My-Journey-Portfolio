# Liste Oluşturmak

Varsayılan olarak, liste öğeleri liste türüne bağlı olarak madde işaretleri veya sayılarla vurgulanır. Çoğu durumda, özellikle madde işaretli listeler için bu işaretleyiciler tasarımda kullanılmaz.

`list-style-type` özelliği liste madde işaretinin türünü tanımlar. İşaretleyici gösterimini kaldırmak için `none` olarak ayarlayın.

`body {
  font-family: 'Helvetica Neue', 'Roboto', 'Verdana', sans-serif;
	color: #2a2a2a;
	background-color: #fafafa;
}

h1, h2, h3, h4, h5, h6 {
	font-family: 'Tahoma';
}

ul, ol {
	list-style-type: none;
}`

---

### **🔍 Genel Bakış:**

Aşağıdaki kod parçası bir web sayfasında yazı tipi, metin rengi, arka plan rengi ve **liste görünümleri** gibi bazı temel görsel özellikleri belirliyor.

---

### **💡 Kodun Satır Satır Anlamı:**

```
body {
  font-family: 'Helvetica Neue', 'Roboto', 'Verdana', sans-serif;
  color: #2a2a2a;
  background-color: #fafafa;
}
```

- **body** etiketi için geçerli:
    - Yazı tipi sıralaması: 'Helvetica Neue' öncelikli, o yoksa 'Roboto', sonra 'Verdana', en son tarayıcıda ne varsa (sans-serif).
    - Metin rengi: **#2a2a2a** (çok koyu gri).
    - Arka plan rengi: **#fafafa** (neredeyse beyaz, açık gri ton).

---

```
h1, h2, h3, h4, h5, h6 {
  font-family: 'Tahoma';
}
```

- Tüm başlık etiketlerinin (h1–h6) yazı tipi **‘Tahoma’** olacak.

---

```
ul, ol {
  list-style-type: none;
}
```

### **🎯 Bu Satır Ne İşe Yarar?**

- ul: Unordered list → yani **madde işaretli liste**
- ol: Ordered list → yani **numaralı liste**

Bu kodla deniyor ki:

👉 “Bu listelerde **madde işareti** veya **sayı** gösterme.”

Yani **liste işaretlerini gizle**!

### **Örneğin:**

```
<ul>
  <li>Bir</li>
  <li>İki</li>
</ul>
```

Normalde böyle görünür:

- Bir
- İki

Ama bu CSS sayesinde bu hale gelir:

Bir

İki

(Yani madde işaretleri yok.)

---

### **👇 Neden Bu Yapılır?**

Tasarım açısından bazı projelerde liste işaretleri **rahatsız edici** veya **gereksiz** olabilir. Geliştirici, işaretleri kaldırır ve yerine özel ikonlar, görseller ya da özel stiller kullanabilir.

---

### **Özetle:**

Bu kod parçası, modern ve sade bir tasarım için:

- Yazı tiplerini ayarlıyor.
- Metin ve arka plan renklerini belirliyor.
- **Liste işaretlerini gizliyor** (list-style-type: none; ile).
