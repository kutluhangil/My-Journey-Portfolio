# Satır Aralığı

Bir belgedeki metinlerin çoğu genellikle aynı satır aralığına sahip olur. Bu nedenle, `line-height` özelliğinin değerini global stillerde ayarlamak, tüm sayfa boyunca tutarlı bir görünüm sağlar. `line-height` özelliği miras alınır, böylece genel ayarları `body` etiketi gibi üst seviyede belirtebiliriz ve yalnızca ihtiyaç duyulan yerlerde bu değeri geçersiz kılabiliriz.

`body {
  font-family: 'Helvetica Neue', 'Roboto', 'Verdana', sans-serif;
	color: #2a2a2a;
	background-color: #fafafa;
	line-height: 1.5;
}`

Belge metninin `body` etiketindeki ana satır aralığını `1.5` olarak ayarlayın.

- Stil sayfasında `body` seçicisine sahip bir CSS kuralı bulunmalıdır.
- `body` seçicisine sahip CSS kuralının `line-height` özelliği `1.5`değerinde olmalıdır.
