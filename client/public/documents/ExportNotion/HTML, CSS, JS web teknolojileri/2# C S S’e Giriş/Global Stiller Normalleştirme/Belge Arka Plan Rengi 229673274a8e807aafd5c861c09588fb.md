# Belge Arka Plan Rengi

Varsayılan olarak, sayfanın tamamı `#ffffff` beyaz arka plan rengine sahiptir, ancak tasarımda birkaç ton bile farklılık gösterebilir. Bu nedenle, her durumda, tüm belge için bir renk ayarlamanız gerekir.

`body {
  font-family: 'Helvetica Neue', 'Roboto', 'Verdana', sans-serif;
	color: #2a2a2a;
	background-color: #fafafa;
}`

Belge arka plan rengini `body` etiketinde `#fafafa` olarak ayarlayın

- Stil sayfasında `body` seçicisine sahip bir CSS kuralı bulunmalıdır.
- `body` seçicisine sahip CSS kuralının `background-color` özelliği `#fafafa` değerine sahip olmalıdır.
