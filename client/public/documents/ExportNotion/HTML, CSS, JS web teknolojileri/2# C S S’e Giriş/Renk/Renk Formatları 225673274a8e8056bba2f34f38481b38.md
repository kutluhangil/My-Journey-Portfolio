# **RGB**

Üç temel renk vardır: `kırmızı`, `yeşil` ve `mavi`. Bunları farklı oranlarda birleştirerek başka herhangi bir renk elde edebilirsiniz.

![](https://s3.eu-north-1.amazonaws.com/lms.goit.files/658ec640-4cc0-41e8-8316-9714479e2594%D0%9C02%D0%9202S03.jpg)

Bu formatta tek bir rengin değerini ayarlamak için, üç ana rengin her birinin oranını belirleyen ve ardından istenen rengi üretmek için bunları birleştiren `rgb()` işlevini kullanırsınız.

`rgb(kırmızı, yeşil, mavi)`

Her parametre bir rengin yoğunluğunu 0 (renk yok) ile 255 (maksimum) arasında bir tam sayı olarak tanımlar. Bu, bir RGB rengini belirtmenin temel yoludur.

Örneğin, `rgb (255, 0, 0)` kırmızı olarak görüntülenir. Çünkü kırmızı parametresi maksimum değere (255) ve diğer parametreler 0'a ayarlanmıştır.

`*/* Saf kırmızı renk: 255 kırmızı, 0 yeşil, 0 mavi */*p {
  color: rgb(255, 0, 0);
}`

Ya da `%0` ile `%100` arasında bir yüzde.

`*/* Saf kırmızı renk: 100 kırmızı, %0 yeşil, %0 mavi */*p {
  color: rgb(100%, 0%, 0%);
}`

```
Tüm renkler tasarımcı tarafından düzene dahil edildiğinden, RGB değerlerinin kombinasyonlarını ezberlemeye gerek yoktur. Ayrıca, bu ana renk formatı değildir.
```

header {
background-color: #f5f5f5;
}

a {
color: #212121;
}
