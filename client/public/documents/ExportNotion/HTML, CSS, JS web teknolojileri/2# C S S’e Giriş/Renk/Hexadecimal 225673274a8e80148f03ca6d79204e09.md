# Hexadecimal

Rengin bu tanımı, onaltılık bir sayının temsiline dayanmaktadır. Üç ana rengin her birinin oranı iki karakterle tanımlanır ve rengin yoğunluğunu belirler.

![](https://s3.eu-north-1.amazonaws.com/lms.goit.files/59020827-af5b-4331-95b2-0778dbd496d1%D0%9C02%D0%9202S04.jpg)

Bu sayı sisteminde `0`'dan `9`'a kadar bir dizi rakam ve `A`'dan `F`'ye kadar küçük veya büyük harfli Latin harfleri kullanılır. Küçük harfleri yazmak daha kolaydır. Büyük harfin okunması daha kolaydır. Harfler arasında başka önemli bir fark yoktur.

- `00` — en küçük renk oranı;
- `ff` — en büyük renk oranına sahiptir.

`*/* Saf kırmızı renk: ff (%100) kırmızı, 00 (%0) yeşil, 00 (%0) mavi */*p {
  color: #ff0000;
}

*/* Saf yeşil renk: 00 (%0) kırmızı, ff (%100) yeşil, 00 (%0) mavi */*p {
  color: #00ff00;
}

*/* Saf mavi renk: 00 (%0) siyah, 00 (%0) yeşil, ff (%100) mavi */*p {
  color: #0000ff;
}`

