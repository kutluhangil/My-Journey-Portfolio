# Öğe Arka Plan Rengi

`background-color` özelliği bir öğenin arka plan rengini belirler. Varsayılan olarak, çoğu öğenin arka plan rengi şeffaftır. Bu değer `transparent`'tir.

`p {
  background-color: tomato;
  color: white;
}`

Elementin arka planı, dikdörtgen kutunun tamamını kaplar.

![](https://s3.eu-north-1.amazonaws.com/lms.goit.files/c0619136-585d-47cf-ac3f-de3785f81aa3Frame%2047892.png)

Satır içi öğelerde, kutunun genişliği öğenin içeriğine bağlı olarak değişir. Blok öğelerde ise genişlik, tüm satırın genişliğine eşittir (Blok ve satır içi öğeler bölümüne bakınız Modül 1).

`header` etiketi için stil sayfasına arka plan rengini `whitesmoke` olarak değiştiren bir kural ekleyin.

- Stil sayfasında `a` seçicisine sahip bir CSS kuralı bulunmalıdır.
- `a` seçicisine sahip CSS kuralının `color` değeri `black` olmalıdır.
- Stil sayfasında `header` seçicisine sahip bir CSS kuralı bulunmalıdır.
- `header` seçicisine sahip CSS kuralının `background-color` özelliği `whitesmoke` değerine sahip olmalıdır.

a {
color: black;
}
header {
background-color: whitesmoke;
}

Stil dosyasındaki renk değerini RGB olarak değiştirin. `whitesmoke`yerine `245, 245, 245` rengini, `black` yerine `0, 0, 0` rengini kullanın.

- Stil sayfasında `a` seçicisine sahip bir CSS kuralı bulunmalıdır.
- `a` seçicisine sahip CSS kuralının `color` değeri `rgb(0, 0, 0)`olmalıdır.
- Stil sayfasında `header` seçicisine sahip bir CSS kuralı bulnmalıdır.
- `header` seçicisine sahip CSS kuralının `background-color` özelliği `rgb(245, 245, 245)` değerine sahip olmalıdır.

header {
background-color: rgb(245, 245, 245);
}

a {
color: rgb(0, 0, 0);
}
