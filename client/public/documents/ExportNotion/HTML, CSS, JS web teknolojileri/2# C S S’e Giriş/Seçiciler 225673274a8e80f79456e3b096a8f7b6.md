*Sayfada birçok paragraf var. Ve bunlardan yalnızca birinde metni kırmızı renkle vurgulamanız gerekiyor. Paragrafı başka bir öğeyle değiştirdiğinizde tipik bir görev elde edersiniz — tek tek öğeleri şekillendirmek. Ayrıca, değişiklik yapmak için çok fazla zaman harcamamak için ölçeklendirmenin rahatlığını da göz önünde bulundurmanız gerekir.*

# **Eleman Türüne Göre Seçici (X)**

Tek bir öğeyi veya bir öğe grubunu seçmek için çeşitli seçicileri kullanabilirsiniz.

![](https://s3.eu-north-1.amazonaws.com/lms.goit.files/09cd8855-cf80-4baa-b110-2592f6b27193Untitled%20%2824%29.jpeg)

Eleman seçici, CSS kuralının hangi tür elemana uygulanacağını belirler: yukarıdaki diyagramda gösterildiği gibi tüm paragraflara veya tüm birinci seviye başlıklara, tüm bağlantılara vb.

Öğe Seçici, tek bir paragraf gibi bir sayfadaki tek tek öğeleri stilize etmek için yeterince spesifik değildir. Bu nedenle, bu seçici genellikle bir sayfadaki aynı türden tüm etiketleri stilize etmek için kullanılır; örneğin, bir belgedeki tüm bağlantılardan alt çizgiyi kaldırmak istiyorsanız.

`*/* Sayfadaki tüm paragraflar için geçerlidir */*p {
  color: tomato;
}

*/* Sayfadaki tüm bağlantılar için geçerlidir */*a {
  color: tomato;
}`

h1 {
color: #f44336;
}

h2 {
color: #3f51b5;
}

h3 {
color: #4caf50;
}

a {
color: #ffc107;
}
