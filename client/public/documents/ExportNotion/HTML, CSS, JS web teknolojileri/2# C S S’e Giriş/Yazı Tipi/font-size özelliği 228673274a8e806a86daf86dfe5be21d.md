# font-size özelliği

`font-size` özelliği, öğenin yazı tipi boyutunu mutlak veya göreli birimler olarak ayarlar. Şimdilik, sadece mutlak birimlere odaklanalım ve `px` (piksel) birimini kullanarak başlayalım.

`<p class="text">
  Lorem, ipsum dolor sit amet consectetur adipisicing elit. Obcaecati commodi,
  veritatis nihil alias iste odit similique sit eius optio veniam, impedit
  cumque fuga facere labore quo id necessitatibus quaerat rerum.
</p>`

Varsayılan olarak, tarayıcının stil sayfasında ayarlanan paragraf yazı tipi boyutu `16 px`. olarak ayarlanmıştır.

`.text {
  font-size: 20px;
}`

Sayfa öğelerinin yazı tipi boyutunu ayarlayın. Mevcut CSS kurallarının kodunu tamamlayın ve gerekirse yenilerini oluşturun. Class ve descendant seçicilerini kullanın.

- `h1` başlığının metni `24px` olmalıdır
- `h2` başlıklarının metni `20px` olmalıdır
- `h3` başlıklarının metni `16px` olmalıdır
- Kulüpler bölümündeki bağlantıların metni `14px` olmalıdır
- Stil sayfasında `.page-title` seçicisine sahip bir CSS kuralı bulunmalıdır.
- `.page-title` seçicisine sahip CSS kuralının `font-size` ödeğeri `24px` olmalıdır.
- Stil sayfasında `.section-title` seçicisine sahip bir CSS kuralı bulunmalıdır.
- `.section-title` seçicisine sahip CSS kuralının `font-size` değeri `20px` olmalıdır.
- Stil sayfasında `.club-list .title` seçicisine sahip bir CSS kuralı bulunmalıdır.
- `.club-list .title` seçicisine sahip CSS kuralının `font-size`değeri `16px` olmalıdır.
- Stil sayfasında `.club-list .link` seçicisine sahip bir CSS kuralı bulunmalıdır.
- `.club-list .link` seçicisine sahip CSS kuralının `font-size` değeri `14px` olmalıdır.
