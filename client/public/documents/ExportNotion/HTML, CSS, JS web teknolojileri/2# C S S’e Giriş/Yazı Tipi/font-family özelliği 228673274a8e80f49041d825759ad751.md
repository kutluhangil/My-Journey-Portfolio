# font-family özelliği

**Yazı Tipi (Font) —** Belirli bir stildeki tipografik harfler, sayılar ve özel karakterler kümesidir.

Yazı tipleri birkaç ana gruba (aileye) ayrılır:

- serif yazı tipleri;
- sans-serif yazı tipleri;
- monospace;
- dekoratif;
- el yazısı, vs.

MacOS, Linux ve Windows, her aileden bir dizi standart yazı tipiyle birlikte gelir. Varsayılan olarak, başka bir yazı tipi belirtilmezse, tarayıcı serif ailesinden `Times New Roman`'ı kullanır.

Bir öğenin metninin hangi yazı tipinde görüntülendiğini geliştirici araçlarında `Computed` sekmesinde görebilirsiniz.

![](https://s3.eu-north-1.amazonaws.com/lms.goit.files/e5969b27-6ed0-4a50-a3ef-60acf403350eimage.png)

`font-family` özelliği, öğenin metninin yazı tipini belirtir. Virgüllerle ayırarak, tarayıcının kullanıcının sisteminde bulmaya ve uygulamaya çalışacağı rastgele sayıda yazı tipi listeleyebilirsiniz. Tarayıcı fontları soldan sağa doğru arayacak ve bulduğu ilk fontu uygulayacaktır.

`p {
  font-family: 'Helvetica Neue', 'Roboto', 'Verdana', 'Tahoma', sans-serif;
}`

Listelenen yazı tiplerinden hiçbirinin bulunamaması durumunda, yazı tipi ailesi her zaman listenin sonunda belirtilir. Bu durumda, kullanıcının sisteminde mevcut olan bu aileden standart yazı tipi kullanılır.

Birinci seviye başlığı için yazı tipini `Georgia` olarak ayarlayın. Kullanıcının `Georgia` yazı tipine sahip olmaması durumunda sans serif yazı tipi ailesini belirtmeyi unutmayın.

- Stil sayfasında `.page-title` seçicisine sahip bir CSS kuralı bulunmalıdır.
- `.page-title` seçicisine sahip CSS kuralının `font-family` özelliği `Georgia`, serif` değerine sahip olmalıdır.

.page-title {
font-family: Georgia, serif;
}
