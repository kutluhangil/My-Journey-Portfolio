# line-height özelliği

`line-height` özelliği, metnin satır aralığını yani satır yüksekliğini ayarlar. Varsayılan olarak, satırlar arasındaki mesafe yazı tipine ve boyutuna bağlıdır ve tarayıcı tarafından otomatik olarak belirlenir.

`line-height: normal | sayı | uzunluk | yüzde | initial | inherit`

Değerler, mutlak veya göreli birimler ve bir çarpan olarak belirlenebilir. Çarpan olarak ayarlamak en iyi yöntemdir, çünkü bu durumda satır aralığı, metnin geçerli yazı tipi boyutundan hesaplanır.

`<p class="text">
  Lorem, ipsum dolor sit amet consectetur adipisicing elit. Obcaecati commodi,
  veritatis nihil alias iste odit similique sit eius optio veniam, impedit
  cumque fuga facere labore quo id necessitatibus quaerat rerum.Obcaecati
  commodi, veritatis nihil alias iste odit similique sit eius optio veniam,
  impedit cumque fuga facere labore quo id necessitatibus quaerat rerum.
</p>`

Örneğin, düzendeki yazı tipi boyutu `16px` ve dolgu `24px` ise, `24`'ü `16`'ya bölerek `1,5` çarpanı elde edin.

`.text {
  font-size: 16px;
  line-height: 1.5;
}`

```
Bir çarpanın kullanılması, metin boyutunu değiştirdiğinizde satır aralığının eşit olarak ölçeklenmesini sağlar.
```

Tüm başlıklar için satır aralığını `1.333` olarak, `section-text` sınıfına sahip metinler için ise `1.5` olarak ayarlayın. Mevcut CSS kurallarını kullanın ve gerektiğinde yeni kurallar ekleyin.

- Stil sayfasında `.page-title` seçicisine sahip bir CSS kuralı bulunmalıdır.
- `.page-title` seçicisine sahip CSS kuralının `line-height` değeri `1.333` olmalıdır.
- Stil sayfasında `.section-title` seçicisine sahip bir CSS kuralı bulunmalıdır.
- `.section-title` seçicisine sahip CSS kuralının `line-height`özelliği `1.333` değerinde olmalıdır.
- Stil sayfasında `.club-list .title` seçicisine sahip bir CSS kuralı bulunmalıdır.
- `.club-list .title` seçicisine sahip CSS kuralının `line-height`özelliği değeri `1.333` olmalıdır.
- Stil sayfasında `.section-text` seçicisine sahip bir CSS kuralı bulunmalıdır.
- `.section-text` seçicisine sahip CSS kuralının `line-height` özelliği `1,5` olmalıdır.
