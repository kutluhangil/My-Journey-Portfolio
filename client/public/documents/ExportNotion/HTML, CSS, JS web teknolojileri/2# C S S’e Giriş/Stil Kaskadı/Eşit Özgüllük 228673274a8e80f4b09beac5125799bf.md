# Eşit Özgüllük

Özgünlük aynı ise, CSS kodunda daha altta bulunan kural, yani çakışan kurallar sıralamasında sonuncu olan uygulanır.

`*/* Aynı özgüllüğe sahip üç öğe seçici */*a {
  color: teal;
}

a {
  color: brown;
}

*/* Bu kural aşağıdadır, bu nedenle tüm bağlantılar turuncu renktedir */*a {
  color: orange;
}`
