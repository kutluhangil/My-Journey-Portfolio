# Özgüllükten Kaçınma

Eğer seçici `A > B > C > X > Y` gibi görünüyorsa, bunu düşünmelisiniz. CSS seçimlerindeki özgüllüğü basit ve etkili tutmak, özgüllükle ilgili sorunları azaltabilir. Seçiciniz ne kadar karmaşık olursa, özgüllük sorunları o kadar fazla olabilir. Sınıf seçicilerini kullanarak bu sorunları minimize edebilir ve HTML işaretlemenizin okunabilirliğini artırabilirsiniz.

# **1. Bir sınıfı yalnızca ortak bir bloğa atama**

İlk yaklaşım, ortak bir üst bloğa sınıf atamak ve alt öğeleri bu sınıfa göre biçimlendirmektir.

`<div class="post">
  <h1>Lorem ipsum dolor sit amet</h1>
  <p>
    Lorem, ipsum dolor sit amet consectetur adipisicing elit. Obcaecati commodi,
    veritatis nihil alias iste odit similique sit eius optio veniam, impedit
    cumque fuga facere labore quo id necessitatibus quaerat rerum.
  </p>
  <a href="">Читати далі...</a>
</div>`

Bu CSS kodu, biçimlendirme basit olduğunda etkili çalışır.

Ancak, ayrı bir sınıfı olan bir bloğun (örneğin, `.post`) biçimlendirmesinin karmaşıklığı arttıkça, etiket seçiciye göre (yani, `.post > h1`, `.post > link`) uygun biçimlendirme imkansız hale gelir. Örneğin, yazı yalnızca bir değil 5 bağlantı içeriyorsa, bir noktada bir bağlantı seçemezsiniz veya seçici çok karmaşık olur.

`.post {
  */* Makale stilleri */*
}

.post > h1 {
  */* Başlık stilleri */*
}

.post > p {
  */* Metin stilleri */*
}

.post > a {
  */* Referans stilleri */*
}

.post > a:hover {
  */* Hover referans stilleri */*
}`

# **2. Üst blok ve içindeki etiketler için tanımlayıcı sınıflar**

İkinci yaklaşım — ana bloğa ve içindeki etiketlere açıklayıcı sınıflar eklemektir.

`<div class="post">
  <h1 class="title">Lorem ipsum dolor sit amet</h1>
  <p class="text">
    Lorem, ipsum dolor sit amet consectetur adipisicing elit. Obcaecati commodi,
    veritatis nihil alias iste odit similique sit eius optio veniam, impedit
    cumque fuga facere labore quo id necessitatibus quaerat rerum.
  </p>
  <a class="link" href="">Читать дальше...</a>
</div>`

Bu tür CSS kodu iyi ölçeklenebilir ve bakımı yapılabilir.

Bu, iyi CSS yazmak için başlangıç noktasıdır. Ancak, biçimlendirmenin karmaşıklığı arttıkça, özgüllükle ilgili bazı küçük sorunlarla karşılaşabilirsiniz.

`.post {
  */* Makale stilleri */*
}

.post > .title {
  */* Başlık stilleri */*
}

.post > .text {
  */* Metin stilleri */*
}

.post > .link {
  */* Referans stilleri */*
}

.post > .link:hover {
  */* Hover referans stilleri */*
}`

# **Her etiket için özel sınıflar**

Üçüncü yaklaşım, "üst ad - alt ad" ilkesine göre üst bloğa ve içindeki her etikete çok özel sınıflar atamaktır.

`<div class="post">
  <h1 class="post-title">Lorem ipsum dolor sit amet</h1>
  <p class="post-text">
    Lorem, ipsum dolor sit amet consectetur adipisicing elit. Obcaecati commodi,
    veritatis nihil alias iste odit similique sit eius optio veniam, impedit
    cumque fuga facere labore quo id necessitatibus quaerat rerum.
  </p>
  <a href="" class="post-link">Devamını oku...</a>
</div>`

Bu yaklaşım basit sınıf seçicileri kullanır, bu nedenle özgüllük hakkında düşünmeye gerek yoktur. Bu tür CSS kodu iyi ölçeklenebilir ve bakımı yapılabilir. Geliştirme sürecinde, stilleri yazarken bu yaklaşımın varyasyonları kullanılır.

`.post {
  */* Makale stilleri */*
}

.post-title {
  */* Başlık stilleri */*
}

.post-text {
  */* Metin stilleri */*
}

.post-link {
  */* Hover referans stilleri*/*
}

.post-link:hover {
  */* Hover referans stilleri */*
}`

```
Tek bir yaklaşımı seçmekle sınırlı kalmamalısınız. Üç yaklaşımı da duruma göre birlikte kullanarak daha etkili bir stil uygulaması gerçekleştirebilirsiniz.
```
