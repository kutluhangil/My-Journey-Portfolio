# HARİCİ Stil Sayfası

**Harici CSS kodu** (external stylesheet), diğer sayfalarda kolayca ölçeklenebilir, bakımı yapılabilir ve tekrar kullanılabilir. Bu, stilleri eklemenin standart yoludur. Bir projede, `.css` uzantılı ayrı bir stil sayfası dosyası oluşturulur ve HTML belgesine bağlanır.

`<!DOCTYPE html>
<html lang="en">
  <head>
    <meta charset="UTF-8" />
    <title>CSS is amazing!</title>
		<link rel="stylesheet" href="./css/styles.css" />
  </head>
  <body></body>
</html>`

- **`index.html`** dosyasının hemen yanında **`css`** adında bir klasör oluşturulur ve içine **`styles.css`** adında bir stil dosyası oluşturulur.
- **`index.html`** dosyasının **`<head>`** etiketi içinde, daha önce oluşturulan **`styles.css`** dosyası **`<link>`** etiketi kullanılarak eklenir.
- **`href`** özniteliği, HTML belgesinden stil dosyasına mutlak yolunu belirtir.
- **`rel`** özniteliği eklenen belgenin türünü belirtir, bu da **`stylesheet`** (stil tablosu) olarak belirtilir.

```
Her birine<link> etiketi ekleyerek istediğiniz kadar CSS dosyası ekleyebilirsiniz.
```
