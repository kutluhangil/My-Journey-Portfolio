# Örnekler

---

## **🎯 Ne İsteniyor?**

Senin bir HTML dosyan var. Bununla birlikte **harici bir CSS dosyası (ayrı bir stil dosyası)** oluşturmanı ve onu HTML dosyasına **bağlamanı** istiyorlar.

Ayrıca bu CSS dosyasının içinde, **h1 etiketi için turuncu (orange)**, **p etiketi için cam göbeği (cyan)** renk kuralı yazmanı bekliyorlar.

---

## **✅ Yapman Gerekenler (Adım Adım)**

### **🔹 1. Adım: CSS dosyasını oluştur**

- Proje klasörünün içinde **css adında bir klasör** oluştur.
- Bu klasörün içine **styles.css** adında bir dosya oluştur.

📁 Klasör yapısı şöyle görünecek:

```
proje-klasörü/
│
├── index.html
└── css/
    └── styles.css
```

---

### **🔹 2. Adım: HTML dosyasını düzenle (index.html)**

Şimdi sana verilen HTML dosyasına, <head> içine bir <link> etiketi ekleyeceğiz.

### **🔧 Değişiklik Yapılacak Yer:**

```
<head>
  <meta charset="utf-8" />
  <meta
    name="description"
    content="Planet Fatness description meta tag content"
  />
  <title>Planet Fatness is the place for beginners and pros!</title>

  <!-- Stil dosyasını buraya bağlıyoruz -->
  <link rel="stylesheet" href="./css/styles.css" />
</head>
```

### **🔍 Bu ne işe yarıyor?**

> rel="stylesheet" → bu bir stil dosyasıdır diyor.
> 

> href="./css/styles.css" → dosyanın yerini gösteriyor (css klasörü içindeki styles.css dosyasını)
> 

---

### **🔹 3. Adım: CSS dosyasına kuralları yaz**

Şimdi styles.css dosyasının içine şu kuralları ekle:

```
h1 {
  color: orange;
}

p {
  color: cyan;
}
```

---

## **🧩 Sonuç: Her şey bir araya gelince**

### **✅ index.html dosyan böyle olacak:**

```
<!DOCTYPE html>
<html lang="en">
  <head>
    <meta charset="utf-8" />
    <meta
      name="description"
      content="Planet Fatness description meta tag content"
    />
    <title>Planet Fatness is the place for beginners and pros!</title>

    <link rel="stylesheet" href="./css/styles.css" />
  </head>

  <body>
    <h1>Planet Fatness</h1>
    <p>
      Healthy food is delicious. Doing sport is enjoyable. You just need to
      start - people said. Nonsense! - I thought. To me, a 19-year-old guy,
      overweight and depressed, who ate tons of junk food to seize the stress,
      those healthy-life-gurus sounded like aliens coming from another planet.
      On their planet, it must have sounded right. On my planet, eating pizza
      was OK and jogging was exhausting. 12 years later, after I shed almost 100
      pounds and completely changed my diet, I still believe we WERE on
      different planets. The thing is that once I escaped.
    </p>
  </body>
</html>
```

---

### **✅ styles.css dosyan böyle olacak:**

```
h1 {
  color: orange;
}

p {
  color: cyan;
}
```

## **🎉 Ne Kazandın?**

- HTML içinde hiçbir style="..." yazmadın ❌
- <style> etiketi de kullanmadın ❌
- Tüm stiller ayrı bir dosyada duruyor ✔️
- Kodun **düzenli**, **temiz** ve **profesyonelce** oldu ✔️
