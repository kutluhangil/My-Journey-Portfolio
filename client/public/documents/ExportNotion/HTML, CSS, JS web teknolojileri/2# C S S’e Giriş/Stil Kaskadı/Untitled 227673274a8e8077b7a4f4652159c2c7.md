**Yerleşik stilleri hatırlıyor musunuz?**

Etikette doğrudan `style` niteliğinde belirtilenler. Satır içi stiller ilk sıraya bir tane ekler ve bu nedenle en yüksek özgüllüğe sahiptir.

`*<!-- Bu tarzın özgünlüğü - 1 0 0 0 -->*<p style="color: green;">
  Lorem, ipsum dolor sit amet consectetur adipisicing elit. Obcaecati commodi,
  veritatis nihil alias iste odit similique sit eius optio veniam, impedit
  cumque fuga facere labore quo id necessitatibus quaerat rerum.
</p>`

Yerleşik stiller neredeyse hiç kullanılmaz çünkü:

- CSS aracılığıyla geçersiz kılınamaz;
- ölçeklendirilmesi zor.
