# 4. Dereceden Seçiciler

1. dereceden seçiciler şunlardır:
- eleman türüne göre seçiciler **(X)**;
- Sözde öğe seçiciler (sözde öğe kavramı kursun ilerleyen bölümlerinde ele alınacaktır).

Bu seçiciler en düşük spesifikliğe sahiptir, bu da onların daha spesifik seçicilerle olan çatışmalarda genellikle kaybedeceği anlamına gelir.

![](https://s3.eu-north-1.amazonaws.com/lms.goit.files/92772b7f-32a9-48e3-a7d8-84d636b1881eUntitled%20%2826%29.jpeg)

Her öğe ve sözde öğe seçici dördüncü sıraya bir ekler.

`<section>
  <h1>Lorem ipsum dolor sit amet</h1>
  <p>
    Lorem, ipsum dolor sit amet consectetur adipisicing elit. Obcaecati commodi,
    veritatis nihil alias iste odit similique sit eius optio veniam, impedit
    cumque fuga facere labore quo id necessitatibus quaerat rerum.
  </p>
</section>`

Paragraf metninin rengi turuncu olacaktır çünkü:

- ilk kural etiket türüne göre bir seçici içerir, bu nedenle özgüllüğü 0001'dir;
- ikinci kural iki öğeli bir alt seçici içerir, özgüllüğü 0002'dir;
- İkinci kural daha spesifiktir.

`*/* Özgüllük - 0 0 0 1 */*p {
  color: green;
}

*/* ✅ Özgüllük - 0 0 0 2 */*section > p {
  color: orange;
}`
