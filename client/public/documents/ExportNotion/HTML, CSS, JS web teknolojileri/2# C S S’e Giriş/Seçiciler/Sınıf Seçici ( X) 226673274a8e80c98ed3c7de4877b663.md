# Sınıf Seçici (.X)

Modern web geliştirmede en yaygın kullanılan seçicidir. `class` niteliği ile birlikte kullanılır. `class` seçicisi, `id` seçicisinden farklı olarak, sınıf adlarının benzersiz olmasını gerektirmez ve birden fazla öğeyi seçmek için kullanılabilir.

Sınıf adının özellikleri:

- sadece İngilizce olarak ayarlanmıştır;
- mutlaka bu öğeyi tanımlayan bir isimdir.

Sınıf adları oluştururken aşağıdaki kaynaklardan yararlanabilirsiniz:

- referans kitabı;
- bir terimler sözlüğü;
- kısaltmalar.

`<h2 class="title">Merhaba, ben Mango.</h2>
<p class="text">
  Kişisel sayfama hoş geldiniz. Burada görebilirsiniz
  <a class="link" href="">projeleri</a>.
</p>

<h2>Bu başlık şekillendirilmeyecek</h2>
<p>Bu metin şekillendirilmeyecek<p>
<a href="">Bu bağlantı şekillendirilmeyecek</a>`

CSS, aynı `class` niteliğine sahip bir veya daha fazla öğenin stilini belirlemek için sınıf seçicilerini kullanır. Bir sınıf seçicisi, sınıf adının önüne gelen bir `.` noktası içerir.

`/* Başlık sınıfına sahip tüm etiketler için geçerlidir */
.title {
  color: skyblue;
}

/* Metin sınıfına sahip tüm etiketler için geçerlidir */
.text {
  color: brown;
}

/* Bağlantı sınıfına sahip tüm etiketler için geçerlidir */
.link {
	color: tomato;
}`

```
Sınıf adında yalnızca küçük harfler ve tire işaretleri kullanılır. Örneğin,list,list-item,logo-image vb.Alt çizgilist_item,büyük harfListItem veyasayı listitem27 kötü biçim olarak kabul edilir.
```

HTML kodunda, elementlere `class` özniteliği ekledik: başlık `header`, `h1`, `h2`, paragraf `p` etiketlerine bölümlerde, altbilgi `footer` ve paragraf `p` altbilgide.

Diğer etiketler için, bir sınıf seçici ve aşağıdaki özellikleri içeren kurallar ekleyin:

- Başlıkta arka plan rengi `#bdbdbd` olmalıdır.
- Sınıfı `section-text` olan öğelerdeki metin rengi `#ff5722` olarak değiştirilmelidir.
- Altbilginin arka plan rengi `#212121` olmalıdır.
- Altbilgideki metin rengi `#ffffff` olmalıdır.
- Sayfa başlığı metin rengi `#f44336` olmalıdır.
- Bölüm başlıkları metin rengi `#3f51b5` olmalıdır.
- Stil sayfasında `.page-header` seçicisine sahip bir CSS kuralı bulunmalıdır.
- `.page-header` seçicisine sahip CSS kuralının `background-color`özelliği `#bdbdbd` değerine sahip olmalıdır.
- Stil sayfasında `.page-title` seçicisine sahip bir CSS kuralı bulunmalıdır.
- `.page-title` seçicisine sahip CSS kuralının `color` özelliği `#f44336`değerine sahip olmalıdır.
- Stil sayfasında `.section-title` seçicisine sahip bir CSS kuralı bulunmalıdır.
- `.section-title` seçicisine sahip CSS kuralının `color` özelliği `#3f51b5` değerine sahip olmalıdır.
- Stil sayfasında `.section-text` seçicisine sahip bir CSS kuralı bulunmalıdır.
- `.section-text` seçicisine sahip CSS kuralının `color` özelliği `#ff5722` değerine sahip olmalıdır.
- Stil sayfasında `.page-footer` seçicisine sahip bir CSS kuralı bulunmalıdır.
- `.page-footer` seçicisine sahip CSS kuralının `background-color`özelliği `#212121` değerine sahip olmalıdır.
- Stil sayfasında `.copyright-text` seçicisine sahip bir CSS kuralı bulunmalıdır.
- `.copyright-text` seçicisine sahip CSS kuralının `color` özelliği vardır `#ffffff` değerine sahip olmalıdır.
