# Pseudo-class:focus

Etkileşimli bir öğeye (bağlantı, düğme, form alanı) fare ile tıkladığınızda veya klavye (`tab` tuşu) ile sayfada gezindiğinizde odaklanıldığında etkinleştirilir.

`<ul class="social-links">
  <li><a class="link" href="<https://twitter.com>">Twitter</a></li>
  <li><a class="link" href="<https://www.instagram.com>">Instagram</a></li>
  <li><a class="link" href="<https://www.facebook.com>">Facebook</a></li>
</ul>`

Bağlantıya bir temel stil ve odaklanma stili ekleyelim ekleyin.

`.social-links .link {
  color: teal;
}

.social-links .link:focus {
  color: orange;
}`

Hem `:hover` hem de `:focus` durumlarını hesaba katmak için her iki durumu da aynı anda stilize etmeniz gerekir. Bu, seçicileri virgülle ayırarak yapılır.

`.social-links .link {
  color: teal;
}

*/* Aynı kural için iki veya daha fazla seçici virgülle ayrılır */*.social-links .link:hover,
.social-links .link:focus {
  color: orange;
}`
