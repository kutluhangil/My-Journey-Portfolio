# Pseudo sınıf : hover

Pseudo-class`:hover`, fare imleci bir öğenin üzerine geldiğinde örneğin bir bağlantının veya başka bir öğenin üzerine geldiğinizde etkinleştirilir.

`<p>
  Etiketlerle ilgili harika bir kopya sayfası şu adreste bulunabilir
  <a class="link" href="<https://htmlreference.io>">bağlantıda</a>.
</p>`

Bağlantıya şu stilleri ekleyin:

- temel stil;
- hover stili.

`.link {
  color: teal;
}

.link:hover {
  color: tomato;
}`

Pseudo sınıflar, bağlamsal olanlar da dahil olmak üzere herhangi bir seçiciye uygulanabilir.

`<ul class="social-links">
  <li><a class="link" href="<https://twitter.com>">Twitter</a></li>
  <li><a class="link" href="<https://www.instagram.com>">Instagram</a></li>
  <li><a class="link" href="<https://www.facebook.com>">Facebook</a></li>
</ul>`

Listedeki bağlantıya ekleyin:

- temel stil;
- hover stili.

`.social-links .link {
  color: teal;
}

.social-links .link:hover {
  color: tomato;
}`

Bu seçici "`social-links` sınıfına sahip bir öğenin içinde bulunan link sınıfına sahip öğelerin üzerine gelindiğinde" şeklinde okunur. Yani, seçiciler sağdan sola doğru okunur.

```
pseudo-class:hover bağlantılara uygulanmak zorunda değildir, bu nedenle belgenin diğer öğelerine de ekleyebilirsiniz. Her şey web sayfasının tasarımına bağlıdır.
```

Bağlantılar üzerine gelindiğinde renk değiştirmelidir:

- `page-nav` içindeki bağlantıların rengi `#18ffff` olarak değiştirilmelidir.
- `club-list` içindeki bağlantıların rengi `#f57f17` olarak değiştirilmelidir.
- Stil sayfasında `.page-nav .link:hover` seçicisine sahip bir CSS kuralı bulunmalıdır.
- `.page-nav .link:hover` seçicisine sahip CSS kuralının `color`özelliği `#18ffff` değerine sahip olmalıdır.
- Stil sayfasında `.club-list .link:hover` seçicisine sahip bir CSS kuralı bulunmalıdır.
- `.club-list .link:hover` seçicisine sahip CSS kuralının `color`özelliği `#f57f17` değerine sahip olmalıdır.
