# Metin Biçimlendirme

*Web sayfaları ne içindir?*

*Kısacası — belirli bilgileri bulmak için. Çoğu zaman, bu bilgiler metin biçimindedir. Bu nedenle, metinlerin okunması kolay olmalı ve sitenin diğer unsurlarıyla iyi bir şekilde birleştirilmelidir.*

*Harf aralığı, satır aralığı, hizalama, alt çizgi - tüm bunlar metnin algılanışını etkiler. Ve tüm bunlar yapacağınız mizanpajlarda yer alacaktır.*
