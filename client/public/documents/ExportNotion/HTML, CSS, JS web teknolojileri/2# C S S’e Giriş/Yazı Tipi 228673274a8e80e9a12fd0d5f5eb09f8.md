# Yazı Tipi

*Bir web sitesinde Times New Roman kullanmak bir onur nişanıdır, ve Open Sans — web tasarımının modern klasiğidir.*

*"Bu benim işim değil, yazı tiplerini web tasarımcısı seçsin," diye düşünebilirsiniz. Ancak, bir web tasarımcısının belirlediği her şeyin geliştirici tarafından kodda uygulanması gerektiğini unutmayın.*

*Bu yüzden, yazı tipleri hakkında bilgi sahibi olmanız önemlidir. Yazı tipleri, boyutları, kalınlıkları ve diğer estetik özellikleriyle tanışın.*
