# CSS nedir?

**CSS (Cascading Style Sheets, basamaklı stil şablonları)** — öğelerin görünümünü tanımlamak ve değiştirmek için kullanılan bir dildir.

- HTML, bir belgenin içeriğinin yapısını ve anlamını tanımlamak için kullanılır;
- CSS — HTML işaretleme öğelerinin tasarımı ve konumlandırılması için.

# **Söz Dizimi**

CSS kod bloğuna kural adı verilir ve bir seçici ile küme parantezleri içindeki bir grup bildirimden oluşur.

![](https://s3.eu-north-1.amazonaws.com/lms.goit.files/38b883a1-b7e1-4b9f-b1bb-31b6ae5416a1Frame%2047858.png)

- **Seçici** — tarayıcıya bu kuraldaki stilleri hangi biçimlendirme öğelerine uygulayacağını söyler.
- Her **bildirim** bir çiftten oluşur: `özellik: değer;.`
- Bir **özellik** ve **değeri** iki nokta üst üste ve bir boşlukla ayrılır `:`. Öğenin stilleriyle tam olarak ne yapmak istediğinizi açıklarlar.
- **Değerinden** sonra noktalı virgül eklediğinizden emin olun;. Bir kural istediğiniz kadar özellik içerebilir.

`seçici {
  özellik: değer;
  özellik: değer;
  özellik: değer;
}`

```
Kural içindeki özelliklerin sırası önemli değildir.
```
