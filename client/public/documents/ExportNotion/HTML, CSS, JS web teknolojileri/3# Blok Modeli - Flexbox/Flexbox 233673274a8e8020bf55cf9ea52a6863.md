# Flexbox

*Gökdelen inşaatı ve yerleşim planının ortak noktası nedir?*

*Zorlu görevler özel aletler gerektirir. Yüksek binalar yüksek kaldırma kapasitesine sahip özel vinçler gerektirir.*

*Karmaşık düzenler özel teknolojiler gerektirir. Örneğin, esnek kapsayıcılar oluşturmanıza olanak tanıyan ve sayfadaki öğelerin görüntülenmesinin verimli bir şekilde düzenlenmesini sağlayan Flexbox. Flexbox ile gerçekten harika şeyler yapabilirsiniz. Ancak tek bir şartla... Eğer flex-container kullanım kurallarını biliyorsanız! Ve bunu yapmak için eksenler hakkında bilgi sahibi olmanız gerekir.*
