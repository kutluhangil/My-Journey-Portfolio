# Gap özelliği

Bir önceki adımda, `display: flex;` özelliğini kullanmıştık. Şimdi yatay olarak bir satır halinde düzenlenmişlerdir. Ayrıca, birbirlerine yakın olduklarından aralarında boşluk görünmüyor.

![](https://s3.eu-north-1.amazonaws.com/lms.goit.files/27c064de-55db-4e09-94c6-ea58fa9f9598Untitled%20-%202024-04-25T112550.213.png)

Flex öğeleri arasındaki boşluğu ayarlamak için flex konteynerinin `gap` özelliğini kullanın. Bizim tasarımımızda bu `8px` olacaktır. Bir eleman koleksiyonu için, `gap` özelliği dış dolguyu geçersiz kılar, böylece her eleman için ayrı ayrı ayarlamak zorunda kalmazsınız.

Şimdi `gap` özelliğini `.menu` sınıfına ekleyerek, öğeler arasında 8px boşluk oluşturalım:

`.menu {
  display: flex;
	gap: 8px;
}`

- `Gap` özelliğinin öğelerin görüntülenmesini nasıl etkilediğini görmek için **Result** öğesine tıklayın.
- **CSS** sekmesine tıklayın ve `gap` özelliğinin eklendiği kod parçacığını bulun.
