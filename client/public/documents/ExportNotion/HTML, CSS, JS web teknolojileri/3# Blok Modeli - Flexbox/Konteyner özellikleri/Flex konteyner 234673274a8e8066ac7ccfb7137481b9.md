# Flex konteyner

Bir flex-container (bundan sonra sadece bir konteyner), içindeki öğelerin sırasını değiştirmenize olanak tanıyan bir grup öğenin ana öğesidir. Kontrol eden konteyner özellikleridir:

- eksenlerin yönü,
- çok satırlı ve
- Bir satırdaki öğelerin konumlandırılması.
