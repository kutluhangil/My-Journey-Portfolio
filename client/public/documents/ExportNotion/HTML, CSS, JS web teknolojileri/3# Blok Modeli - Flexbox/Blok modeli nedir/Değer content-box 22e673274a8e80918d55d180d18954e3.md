# Değer content-box

Bu tür blok modeli tarayıcının varsayılan stil sayfasında kullanılır.`width` ve `height` özellikleri, elemanın toplam boyutunu değil, yalnızca içerik alanının genişliğini ve yüksekliğini belirler.

![](https://s3.eu-north-1.amazonaws.com/lms.goit.files/a2536d41-a23c-4808-a41e-154aaae49c9bFrame%2047920%20%281%29%20%281%29.png)

`Content-box` değerine sahip bir bloğun son genişliğini ve yüksekliğini hesaplamak için kullanılan formüller.

`Genişlik = width + padding-left + padding-right + border-left + border-right

Yükseklik = height + padding-top + padding-bottom + border-top + border-bottom`

Elemanı `width` 150px, `padding` 30px ve `border` 5px olarak ayarlayarak toplam 220px genişlik elde ederiz.

`*/* Nihai blok genişliği = 150px + 30px + 30px + 5px + 5px */*.box {
  width: 150px;
  height: 150px;
  border: 5px solid #f44336;
  padding: 30px;
  margin: 100px;
  background-color: #ffeb3b;
}`

Geliştirici araçlarında, `Elements > Computed` sekmesi bu elemanın geometrisini gösterir.
