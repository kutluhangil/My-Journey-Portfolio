# padding veya margin ?

**`Padding`** (dolgu) kullanıldığında, elemanlar dolgusuz bir kenarlıkla sınırlandırılır. Öğenin kenarlığı veya arka plan rengi yoksa, dolgunun etkilerini görsel olarak belirlemek zor olabilir; bu durumda geliştirici araçlarını kullanmak gerekebilir.

![](https://s3.eu-north-1.amazonaws.com/lms.goit.files/b5fba697-7e54-4868-b9be-6443d3b3d2c6Frame%2048398.png)

`Padding` ile `Margin` birbirine karıştırmamak çok önemlidir. Aralarındaki fark şudur:

Dolgu ile kenar boşluğunu karıştırmamak çok önemlidir. Aralarındaki fark şudur:

- `Padding` özelliği içeriği eleman sınırından ayırır. Bu, elemanın iç kısmındaki boşluktur.
- `Margin` özelliği bitişik elemanlar arasında boşluklar oluşturur. Bu, elemanın dış kısmındaki boşluktur.
- 

```
Not: Nerede dolgu, nerede kenar boşluğu kullanmanız gerektiğini hatırlamakta zorlanıyorsanız, tüm öğeler için arka plan rengi belirlemek faydalı olabilir. Bu yöntem, sadece içerik ve dolgu için görsel olarak belirgin olur; kenar boşlukları için değil. Düzen tamamlandıktan sonra, arka plan rengini CSS kurallarınızdan kaldırabilirsiniz.
```
