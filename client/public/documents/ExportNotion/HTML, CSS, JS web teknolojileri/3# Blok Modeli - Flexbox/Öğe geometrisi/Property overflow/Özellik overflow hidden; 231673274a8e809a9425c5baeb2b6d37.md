# Özellik overflow: hidden;

Karşıt değer `hidden`dır. Bu durumda, elemanın ötesine geçen herhangi bir içerik görünmez. Bu davranış, belirli dekoratif efektler için kullanışlıdır.

- `Overflow` özelliğinin `hidden` olarak ayarlandığında tarayıcıda nasıl göründüğünü görmek için **Result** sekmesine tıklayın.
- **CSS** sekmesine tıklayın ve `overflow:hidden` özelliğinin tanımlandığı sınıfı bulun.

```
Bu durumda, taşan içeriğin erişilemez olduğunu ve kullanıcıdan gizlendiğini unutmayın. Bu yüzden metin blokları için asla sabit bir yükseklik ayarlamayız.
```
