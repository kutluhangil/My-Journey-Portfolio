# Özellik overflow: visible;

Eğer `overflow` özelliğini belirtmezseniz, varsayılan değer `visible` olarak ayarlanır. Böylece, blok taştığında, içerik bloğun dışında görüntülenir.

- Varsayılan `overflow` özelliğinin tarayıcıda nasıl göründüğünü görmek için **Result** sekmesine tıklayın. Örnekte, elemanın sınırı kırmızı bir çerçeve ile işaretlenmiştir.

Yukarıdaki örnekte, elemanın dışına taşan metni göreceksiniz. Ancak bu metin, bitişikteki öğeyi etkilemez.

```
Yani, bloktan taşan görünür içerik komşu elemanların geometrisini etkilemez.
```
