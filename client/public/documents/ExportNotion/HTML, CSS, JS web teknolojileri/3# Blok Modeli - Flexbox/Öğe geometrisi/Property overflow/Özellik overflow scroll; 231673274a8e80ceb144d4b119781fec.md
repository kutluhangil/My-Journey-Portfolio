# Özellik overflow: scroll;

`scroll` olarak ayarlandığında, bloktan taşan içerik gizlenecektir. Gizli içeriği görüntülemek için kaydırma çubukları görünecektir.

- Kaydırma çubuklarının tarayıcıda nasıl görüntülendiğini görmek için **Result** sekmesine tıklayın.

```
Yalnızca bir kaydırma çubuğu gerekli olmasına rağmen her iki kaydırma çubuğunun da (yatay ve dikey) gösterildiğine dikkat edin.
```
