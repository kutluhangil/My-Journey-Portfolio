# Özellik border

`Border` özelliği, öğenin kenarlığının genişliğini, stilini ve rengini kontrol eder.

![](https://s3.eu-north-1.amazonaws.com/lms.goit.files/e2db8bf7-930a-45bf-9711-3185b66ece20Frame%2048403.png)

`border: genişlik stil rengi;`

- **Genişlik:** Çerçevenin genişliği piksel cinsinden tanımlanır.
- **Stil:** Olası değerler arasında `solid`, `dashed`, ve `dotted` gibi değerler bulunur.
- **Renk:** Herhangi bir renk formatında belirtilebilir, genellikle HEX formatı kullanılır.

`.box {
  width: 200px;
  height: 200px;
  border: 5px solid orangered;
}`

Aşağıdaki canlı kod örneğine bakalım.

- **HTML** sekmesinde sayfa düzenini inceleyin.
- **CSS** sekmesinde, öğenin alan özelliklerinin değerlerini görüntüleyin.
- **Result** sekmesinde, öğenin tarayıcıda nasıl görüntülendiğini görüntüleyin.

`border: 2px dashed #212121` gibi

## **✅ border özelliği neyi kapsar?**

Bir HTML öğesine şu şekilde bir border tanımlanabilir:

`border: 2px solid red;`

Bu tanımda 3 bileşen vardır:

1. **Genişlik (2px)** – Kenarlığın kalınlığı
2. **Stil (solid)** – Kenarlığın tipi: düz çizgi, kesikli çizgi vs.
3. **Renk (red)** – Kenarlığın rengi
