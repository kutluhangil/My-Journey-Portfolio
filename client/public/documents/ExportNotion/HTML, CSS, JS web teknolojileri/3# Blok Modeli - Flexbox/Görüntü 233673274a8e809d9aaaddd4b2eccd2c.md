# Görüntü

Görsel olarak harika sayfaları nasıl oluşturursunuz?

İlk olarak, esnek görüntüler oluşturun. Bu tür görüntüler otomatik olarak kapsayıcının genişliğine uyum sağlar ve kalite kaybı yaşamaz 📐🖼️ Müşteriler bu tür görüntüleri gerçekten beğenir.

İkinci olarak, orijinal oranları koruyarak veya esneterek görüntüyü kapsayıcıya farklı şekillerde yerleştirmek önemlidir. Bu özellik, özellikle çevrimiçi mağaza sayfaları gibi çok sayıda görsel içeren sayfalar oluştururken çok faydalıdır.
