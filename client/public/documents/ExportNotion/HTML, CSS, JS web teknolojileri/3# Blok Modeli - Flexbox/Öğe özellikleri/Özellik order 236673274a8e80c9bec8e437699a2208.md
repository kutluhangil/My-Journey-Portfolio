# Özellik order

Varsayılan olarak, öğeler HTML dosyasında belirtildikleri sırayla yerleştirilir. `order` özelliğini kullanarak, ana eksen (main axis) boyunca öğelerin sırasını **görsel olarak** değiştirebilirsiniz. Bu durumda, HTML kodunda hiçbir şey değişmeyecektir. Varsayılan olarak, tüm öğeler `0` değerine sahiptir.

`order: pozisyon;`

Bu özellik nadiren kullanılır çünkü öğelerin görsel sırası ile tarayıcı ve yardımcı teknolojiler tarafından nasıl görüldükleri arasındaki bağlantıyı koparır. Ancak bu özelliği bilmeye değer. Gelecekte bir sorunu çözmek için buna ihtiyacınız olabilir.
