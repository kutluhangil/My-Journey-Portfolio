# Özellik flex-basis

`flex-basis` özelliği, flex **container içindeki bir flex** öğesinin başlangıç boyutunu tanımlar.

**Başlangıç boyutu**, `flex-grow` ve `flex-shrink` özellikleri uygulanmadan önceki boyuttur. Bu özellikler öğelerin birbirine göre boyutlarını etkiler. Bu konuları daha sonra ele alacağız.

```
flex-basis özelliğinin değeri herhangi bir geçerli değer olabilir:px veya%. flex elemanları için bu özellikwidth özelliği ile aynı işleve sahiptir. Ancak pratikte, yawidth ya daflex-basis kullanılır.

```

`flex-basis: auto | değer`

- Hem `flex-basis` hem de `width` özellikleri uygulanmışsa, `width' özelliği göz ardı edilir.
- `flex-basis` özelliği bir elemanın yüksekliğini tanımlayabilir, ancak genişliğini tanımlayamaz. Bu, ana eksenin yönü dikey olduğunda gerçekleşir.
- `min-width` ve `max-width` özellikleri, `flex-basis` özelliği uygulanmış olsa bile bir öğe için boyut sınırlayıcıları olarak çalışır.
- `flex-basis` özelliği elemanın son boyutu değil, `flex-grow` ve `flex-shrink` özellikleri tarafından kontrol edilen boş alan ayrılmadan önceki boyuttur.

### **flex-basis Nedir?**

flex-basis, bir **flex öğesinin başlangıç boyutunu** belirler. Yani, flex container içindeki bir öğenin **ilk boyutu ne olsun?** sorusuna cevap verir.

Bu başlangıç boyutu, öğeye boşluk eklenmeden (flex-grow) veya küçültülmeden (flex-shrink) **önceki halidir.**

---

### **📌 Kısaca farkı ne?**

- width: Normalde bir kutunun genişliğini belirtir.
- flex-basis: Flex konteyner içinde **flex düzenlemesi yapılırken başlangıç genişliğini** (veya ana eksene göre yüksekliğini) belirtir.

**Not:** flex-basis varsa, width değeri yok sayılır.

---

### **🔧 Kullanım Şekli**

```
.item {
  flex-basis: 200px;
}
```

Bu, .item class’ına sahip öğenin flex container içinde **başlangıçta 200px genişliğinde** (veya dikey eksende ise yüksekliğinde) olmasını söyler.

---

### **🎯 Neye göre genişlik, neye göre yükseklik?**

- Eğer flex-direction: row (yani öğeler yatay diziliyorsa):
    
    ➤ flex-basis → **genişliği** belirler.
    
- Eğer flex-direction: column (yani öğeler dikey diziliyorsa):
    
    ➤ flex-basis → **yüksekliği** belirler.
    

---

### **❗️ Dikkat Edilmesi Gerekenler**

- flex-basis bir px, % gibi değer alabilir.
- flex-basis: auto kullanılırsa, öğenin width ya da height değeri dikkate alınır.
- Hem width hem flex-basis yazarsan, **sadece flex-basis geçerli olur.**
- min-width ve max-width gibi sınırlayıcılar, flex-basis olsa da hala çalışır.

---

### **🧠 Örnek**

```
.container {
  display: flex;
}

.item {
  flex-basis: 100px;
  flex-grow: 1;
  flex-shrink: 1;
}
```

Bu durumda:

- .item öğesi başlangıçta 100px olur.
- Daha sonra kalan alan varsa flex-grow devreye girip genişletir.
- Alan daralırsa flex-shrink ile küçülür.
