# Flex elemanlar

Flex elemanları bir flex konteynerinin alt öğeleridir, ilk yuvalama seviyesinin elemanlarıdır.

Flexbox modelinde, flex öğeleri (bundan sonra sadece öğeler olarak anılacaktır):

- artık standart belge akışını takip etmez;
- türlerini (blok, satır, vb.) kaybeder ve
- konumlandırılmış Flexbox modelinin kurallarını takip edin.
