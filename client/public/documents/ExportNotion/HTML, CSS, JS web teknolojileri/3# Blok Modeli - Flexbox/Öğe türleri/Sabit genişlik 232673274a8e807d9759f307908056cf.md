# Sabit genişlik

Blok öğelerinin genişliği açıkça belirtilmiş olsa bile, bu öğeler birbirlerinin altına dikey olarak konumlandırılmaya devam edecektir. Satırdaki tüm boş alan, varsayılan olarak öğenin otomatik sağ kenar boşluğu (`margin-right`) tarafından kaplanır.

- Blokların sayfada nasıl göründüğünü görmek için **Result** sekmesine tıklayın.
- Eleman özelliklerinin değerlerini incelemek için **CSS** sekmesine tıklayın. Blokların genişliğinin sayfadaki konumlarını nasıl etkilediğini karşılaştırın.

```
Bir öğenin kenar boşluğu, sayfada görsel olarak öne çıkmadığından geliştirici araçları kullanılarak görüntülenmelidir.
```
