# Blok elemanları

Blok elemanları görsel olarak birbirini yukarıdan aşağıya takip eden dikdörtgen alanlar olarak temsil edilebilir.

![](https://s3.eu-north-1.amazonaws.com/lms.goit.files/36fcca87-b185-43e7-bf52-11d251fc5837Untitled%20%2835%29.jpeg)

- Bu elemanlar `display: block` özelliği ile tanımlanır.
- Kapsayıcı öğenin içindeki satırın tüm genişliğini kaplarlar.
- `height` özelliği belirtilmediyse, içeriklerine bağlı olarak belirlenir.
- Her zaman yeni bir satırda başlarlar, bu nedenle birkaç bitişik blok elemanı dikey olarak üst üste yerleştirilir.
- Öğenin boyutlarını ve yerleşimini belirlemek için genişlik, yükseklik, dolgular (padding), kenarlıklar (border) ve kenar boşlukları (margin) gibi çeşitli CSS özellikleri atanabilir.

```
Çoğu HTML öğesi blok elemandır. Örneğin:<h1>,<p>,<section>,<ul>,<li>,<div>,<header> vb.
```

### **HTML Öğeleri ve display Özellikleri Tablosu**

| **Öğenin Türü** | display **Değeri** | **Davranışı** | **Örnek HTML Öğeleri** |
| --- | --- | --- | --- |
| **Blok (block)** | display: block | Yeni satırdan başlar, tüm satırı kaplar. Genişlik/yükseklik verilebilir. | <div>, <p>, <h1>, <section> |
| **Satır içi (inline)** | display: inline | Satır içinde kalır, yan yana gelir. Genişlik/yükseklik verilemez. | <a>, <span>, <img> |
| **Satır içi blok (inline-block)** | display: inline-block | Satır içinde kalır **ama** genişlik/yükseklik verilebilir. | Butonlar, ikonlar, menü öğeleri (CSS ile yapılır) |
| **Hiç görünmesin** | display: none | Öğeyi tamamen gizler. Sayfada yer kaplamaz. | (CSS ile uygulanır) |

---

### **💡 Ek Bilgiler:**

- **Blok öğeler** her zaman alt alta yerleşir.
- **Satır içi öğeler** metin gibi yan yana dizilir.
- display: inline-block hem satır düzeni sağlar **hem de** boyutlandırma esnekliği sunar.
- display: none → Öğeyi tamamen gizler (görünmez ve boşluk bırakmaz).
