# Öğe geometrisi

*Okuldaki geometri derslerinden zevk aldın mı?*

*Sinüsler ve kosinüsler değil. Ama çocuklar farklı geometrik şekiller oluşturmayı öğrendiklerinde: dikdörtgenler, kareler, daireler. Umarım onları sevmişsinizdir, çünkü şimdi bu şekillerin nasıl yapıldığını öğreneceğiz.*

*Bu konuda ilgilenmezseniz bile, şekillerle tanışmak oldukça eğlenceli olabilir.*
