# Çift ve tek öğeler

Pseudo-class `:nth-child(an + b)`, belirli bir matematiksel formül kullanarak bir grup içindeki öğeleri seçmenizi sağlar. Bu formül, öğelerin konumlarına göre seçim yapmanıza olanak tanır.

- `a` - döngünün periyodu. Rastgele bir sayı.
- `n` - döngünün sayacı. Sıfırdan başlar ve her iterasyonda bir artırılır.
- `b` - ofset. Rastgele bir sayıdır.

Örneğin, `a = 2` ve `b = 1` ise, o zaman `an + b = 2n +1`. Bu formül tüm tek elemanları seçecektir.

`*# n = 0'da*2 * 0 + 1 = 1

*# n = 1'da*2 * 1 + 1 = 3

*# n = 2'da*2 * 2 + 1 = 5

*# Ve böylece n = 3, n = 4 için ...*`

Pratikte, bu sözde sınıf bir koleksiyonun tüm çift veya tek öğelerini seçmek için kullanılır. Örneğin, bir tablonun satırlarını diğer her satırda farklı renklerde yapmak için.

On öğeden oluşan bir liste için bir işaretleme oluşturalım ve bunların arka plan rengini değiştirelim.

`<ul class="list">
  <li class="list-item">1</li>
  <li class="list-item">2</li>
  <li class="list-item">3</li>
  <li class="list-item">4</li>
  <li class="list-item">5</li>
  <li class="list-item">6</li>
  <li class="list-item">7</li>
  <li class="list-item">8</li>
  <li class="list-item">9</li>
  <li class="list-item">10</li>
</ul>`

Tüm eşleştirilmiş öğeleri seçmek için `2n` formülünü veya diğer adı olan ve ayrılmış bir sözcük olan `even` değerini kullanabilirsiniz.

`.list-item:nth-child(2n) {
  background-color: orange;
}

/* Benzer şekilde, takma ad kullanarak */
.list-item:nth-child(even) {
  background-color: orange;
}`

![](https://s3.eu-north-1.amazonaws.com/lms.goit.files/9d22e96a-eca7-434d-ad1e-e2076f966fecFrame%2048275.png)

Tek elemanları seçmek için `2n + 1` formülünü veya diğer adı olan ayrılmış bir kelime olan `odd` değerini kullanabilirsiniz.

`.list-item:nth-child(2n + 1) {
  background-color: orange;
}

/* Benzer şekilde, takma ad kullanarak */
.list-item:nth-child(odd) {
  background-color: orange;
}`

### **🔧 CSS Tarafı:**

```
.list-item:nth-child(odd) {
  background-color: orange;
}
```

Bu, listenin 1., 3., 5…. gibi **tek** sıradaki öğelerini turuncuya boyar.

```
.list-item:nth-child(even) {
  background-color: lightblue;
}
```

Bu da **çift** sıradakileri mavi yapar.

---

### **🎉 Sonuç:**

- :nth-child() sayesinde sıraya göre stiller verebiliriz.
- odd ve even sayesinde bir tablo ya da liste daha okunabilir ve düzenli görünür.
- Bu yöntem sadece listelerde değil, tablo satırlarında, kartlarda, sütunlarda da kullanılır.
