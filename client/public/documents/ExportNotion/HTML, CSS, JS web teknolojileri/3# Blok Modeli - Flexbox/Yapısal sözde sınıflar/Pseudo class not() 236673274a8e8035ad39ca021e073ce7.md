# Pseudo class :not()

`:not()` pseudo-class'ı, belirli bir kritere uymayan tüm öğeleri seçmenize olanak tanır.

Bu kriter, parantez içinde belirtilen basit bir seçici şeklinde tanımlanır. Basit bir seçici; evrensel seçici, tür seçici, kimlik belirteci, nitelik seçici, sınıf veya başka bir pseudo-class olabilir.

`:not(selector)`

Bu sözde sınıf, ilk veya son öğenin kenar boşluğunu temizleme sorununu farklı bir şekilde çözmek için kullanılabilir.

Bir kuralda tüm öğeler için kenar boşluğunu ayarlamak ve daha sonra başka bir kuralda belirli bir öğe için sıfırlamak yerine, tek bir kuralda belirli bir öğe hariç tüm öğeler için kenar boşluğunu ayarlayabilirsiniz.

`.list-item:not(:last-child) {
  margin-bottom: 20px;
}`

Şöyle okunur:

Bu, şu şekilde yorumlanır: `list-item` sınıfına sahip ve koleksiyondaki son öğe olmayan tüm öğelere stilleri uygula. Yani, bu seçici son öğe dışındaki tüm öğeler için geçerlidir.

---

### **Pseudo-class :not() nedir?**

:not() = *“Şu **hariç** hepsi” demek.*

Yani bu CSS özelliğiyle bir grup elemanı seçebilirsin ama belirttiğin bir tanesini **hariç tutarsın**.

---

### **🎯 Gerçek Hayattan Örnek:**

Diyelim ki sınıfta 4 çocuk var: Ali, Ayşe, Can ve Zeynep. Hepsine çikolata vereceksin **ama Can’a vermek istemiyorsun.**

Bu durumda şöyle diyorsun:

> “Herkese çikolata ver, sadece
> 
> 
> **Can hariç!**
> 

> Yani: :not(Can)
> 

---

### **🎨 CSS Örneğiyle Açalım:**

```
.list-item:not(:last-child) {
  margin-bottom: 20px;
}
```

Bu ne demek?

- list-item sınıfına sahip olan öğelere bak.
- Ama **sonuncu olanı hariç tut!**
- Geriye kalan her öğeye margin-bottom: 20px; uygula.

---

### **🤔 Neden Böyle Yapıyoruz?**

Diyelim ki bir liste var ve her elemanın arasında boşluk olsun istiyorsun.

Ama **sonuncudan sonra boşluk olmasın**, çünkü bu hoş durmaz.

**Klasik Yöntem:**

```
.list-item {
  margin-bottom: 20px;
}

.list-item:last-child {
  margin-bottom: 0;
}
```

**:not() ile Kısa Yolu:**

```
.list-item:not(:last-child) {
  margin-bottom: 20px;
}
```

Bu yöntem daha kısa, daha temiz ve fazladan yazmayı önler.

---

### **🧠 Kısaca Akılda Kalsın Diye:**

- :not() = “Ama bu **değil**.”
- Liste yaparken :not(:last-child) = “Sonuncu hariç hepsine boşluk bırak.”

### **Amaç:**

Liste öğelerinin arasına boşluk bırakmak ama sonuncu öğeden sonra boşluk **bırakmamak**.

---

### **💻 HTML Kodu:**

```
<ul class="list">
  <li class="list-item">🍎 Elma</li>
  <li class="list-item">🍌 Muz</li>
  <li class="list-item">🍓 Çilek</li>
</ul>
```

---

### **🎨 CSS Kodu:**

```
.list-item:not(:last-child) {
  margin-bottom: 20px;
}
```

---

### **🖼️ Görsel Açıklama:**

Bu CSS ne yapar?

- Elma ile Muz arasında **20px boşluk bırakır.**
- Muz ile Çilek arasında da **20px boşluk bırakır.**
- Ama Çilek’ten sonra **boşluk bırakmaz**, çünkü :last-child olan öğe hariç tutulmuştur.

---

### **🔍 Sonuç:**

Bu yöntem sayesinde liste görsel olarak daha düzenli görünür. Son öğeden sonra gereksiz boşluk kalmaz.
