# 3# Blok Modeli - Flexbox

# **Modül 3 Hedefler:**

- Blok modelinin ne olduğunu ve nasıl kullanıldığını anlamak
- Bir öğenin geometrisini nasıl özelleştireceğinizi öğrenmek
- Farklı öğelerin kenar boşluklarının (margin ve padding) nasıl etkileşime girdiğini anlamak
- Flexbox teknolojisinin temel kavramları hakkında bilgi edinmek
- Flex container ve flex öğelerinin özelliklerini nasıl yapılandıracağınızı öğrenin
- `:first-child`, `:last-child`, `:not()` ve `:nth-child(an + b)` sözde sınıflarını kullanarak tek tek öğeleri özelleştirin.

Bu modülde birçok canlı kod örneği bulacaksınız.

Ve bu sadece bu koda bir resim gibi bakma meselesi değil. Bu çok daha havalı bir araç.

**Bu nedir?** HTML, CSS ve JavaScript ile çalışabileceğiniz bir sanal alan. Yani, HTML biçimlendirmesini, CSS dosyasını ve tüm bunların tarayıcıda görüntülenmesini aynı anda görebilirsiniz.
