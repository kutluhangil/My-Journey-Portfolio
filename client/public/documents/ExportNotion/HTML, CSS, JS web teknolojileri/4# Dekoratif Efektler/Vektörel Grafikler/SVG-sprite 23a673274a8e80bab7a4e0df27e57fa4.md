# SVG-sprite

SVG-sprite — vektör grafikleri ile çalışırken çoğu durumda kullanılan bir tekniktir.

- Tüm vektör simgeleri tek bir dosyada toplanır.
- Sprite dosyası tarayıcı tarafından önbelleğe alınır ve tekrar ziyaret ettiğinizde indirilmez.
- CSS kullanarak sprite simgelerinin rengini ve diğer özelliklerini değiştirebilirsiniz.
