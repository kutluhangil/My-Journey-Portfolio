# transition-delay özelliği

`transition-delay` özelliği, geçiş animasyonunun hangi gecikmeden sonra başlayacağını tanımlar. Varsayılan değer `0s`'dir.

`transition-delay: değer;`

Örnekte, gecikme `500ms` olarak ayarlanmıştır. Fare imlecini karenin üzerine getirdiğinizde geçiş bu olaydan sadece yarım saniye sonra başlayacaktır.
