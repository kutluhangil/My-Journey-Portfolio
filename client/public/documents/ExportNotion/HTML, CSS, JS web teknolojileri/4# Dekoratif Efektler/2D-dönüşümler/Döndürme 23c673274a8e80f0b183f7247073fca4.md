# Döndürme

`rotate(açı)` fonksiyonu, öğeleri belirtilen açı kadar döndürür. Açı, derece (birim `deg`) cinsinden ifade edilir. Pozitif değerler öğeyi saat yönünde döndürürken, negatif değerler saat yönünün tersine döndürür.

`.box {
  transform: rotate(45deg);
}`

Değerler sadece derece olarak değil, aynı zamanda "tur" olarak da ifade edilebilir (birim `turn`). Örneğin, `rotate(0.5turn)` yarım turdur — `rotate(180deg)` ile benzerdir.

![Screen Shot 2025-07-26 at 13.24.36 PM.png](D%C3%B6nd%C3%BCrme/Screen_Shot_2025-07-26_at_13.24.36_PM.png)

CSS kodunu, fareyi liste öğesinin üzerine getirdiğinizde SVG ok simgesinin saat yönünde dönüp aşağıyı gösterecek şekilde değiştirin. Bir `ease-in-out` dağıtım işleviyle `150ms` süreli bir CSS geçişi ekleyerek simgenin dönüşünü canlandırın.

- Stil sayfasında `.icon` seçicisine sahip bir CSS kuralı bulunmalıdır.
- `.icon` seçicisine sahip CSS kuralının `transition` özelliği `transform 150ms ease-in-out` değerine sahip olmalıdır.
- Stil sayfasında `.pane:hover .icon` seçicisine sahip bir CSS kuralı bulunmalıdır.
- `.pane:hover .icon` seçicisine sahip CSS kuralının `transform` özelliği `rotate(90deg)`değerine sahip olmalıdır.

`.tabs {
display: flex;
flex-direction: column;
gap: 8px;
padding: 0;
margin: 0;
list-style: none;
font-family: sans-serif;
}`

`.pane {
display: inline-flex;
align-items: center;
gap: 16px;
padding: 4px 8px;
border: 1px solid #212121;
max-width: 440px;
cursor: pointer;
}`

`.icon {
transition: transform 150ms ease-in-out;
}`

`.pane:hover .icon {
transform: rotate(90deg)
}`
