# 2D-dönüşümler

*CSS geçişleri, CSS animasyonları ve şimdi de 2B dönüşümler. Aradaki farkı nasıl anlarsınız?*

*CSS geçişleri, CSS animasyonları ve 2D dönüşümler arasındaki farkı anlamak önemlidir. Geçişler ve animasyonlar, yapılandırılabilir durumların sayısıyla farklılık gösterirken, 2D dönüşümler tamamen farklı bir konudur. Dönüşümler "nasıl" değil, "hangi özelliklerin" değiştiği ile ilgilidir.*

2B dönüşümler öğeleri iki boyutlu boşlukta değiştirir ve CSS geçişleri ile CSS animasyonlarında kullanılabilir. Ayrıca tarayıcı dostudurlar!

## **🎯 Ne anlatılmak isteniyor?**

Bu metin, **CSS geçişleri (transitions)**, **CSS animasyonları (animations)** ve **2D dönüşümler (2D transforms)** arasındaki farkı anlatıyor. Hepsi görsel hareket ve değişiklik sağlasa da, **amaçları ve kullanım şekilleri farklı**.

---

### **🧩 Kavramların Anlamı:**

### **CSS Geçişleri (Transitions):**

- Bir öğenin özelliği değiştiğinde (örneğin color, opacity, width), bu değişimin **yumuşak bir şekilde** olmasını sağlar.
- Genellikle bir olayla (hover, focus) tetiklenir.
- **“Nasıl geçiş yapacağım?”** sorusuna yanıt verir.

### **CSS Animasyonları (Animations):**

- Bir öğe kendi kendine ya da olaylardan bağımsız olarak **belirli aşamalarda otomatik olarak** animasyon yapar.
- Keyframe’lerle çalışır. Yani animasyonun başı, ortası, sonu gibi **zaman çizelgesi** vardır.
- **“Ne zaman, ne kadar sürede ve nasıl değişim olacak?”** gibi daha detaylı kontrol sağlar.

### **2D Dönüşümler (2D Transforms):**

- Bir öğenin **konumunu, şeklini, yönünü veya boyutunu** iki boyutlu düzlemde değiştirir.
- Örneğin: döndürme (rotate()), ölçekleme (scale()), kaydırma (translate()), eğme (skew()).
- Tek başına kullanıldığında ani değişiklik yapar, ama **geçiş** veya **animasyon** ile birlikte kullanılırsa hareketli hale gelir.

### **✅ Sonuç:**

- **Geçiş ve animasyon**, bir değişimin **nasıl gerçekleşeceğini** tanımlar.
- **2D dönüşümler**, **hangi değişimin yapılacağını** (dönme, kayma, büyüme gibi) belirler.
- Genelde **birlikte kullanılırlar**. Örneğin:

```
.box {
  transform: rotate(0deg);
  transition: transform 0.5s ease;
}

.box:hover {
  transform: rotate(45deg);
}
```

Bu örnekte transform özelliğiyle dönüşüm sağlanır, transition ise o dönüşümün nasıl yapılacağını tanımlar.
