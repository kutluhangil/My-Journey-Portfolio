# IT İngilizcesinde sık göreceğiniz kelimeler

| Term / Phrase | Türkçe Karşılığı | Example Sentence |
| --- | --- | --- |
| deployment pipeline | yayına alma süreci | Let's check the deployment pipeline. |
| rollback | önceki sürüme dönmek | We had to rollback the last release. |
| production environment | canlı ortam | It works fine in production. |
| staging environment | test ortam | Test it in the staging environment first. |
| cross-team collaboration | ekipler arası iş birliği | This task needs cross-team collaboration. |
| stakeholder approval | paydaş onayı | We're waiting for stakeholder approval. |
| feature request | özellik talebi | There's a new feature request from the client. |
| root cause analysis | temel neden analizi | Let's do a root cause analysis. |
| configuration file | yapılandırma dosyası | I'll double-check the configuration file. |
| backlog refinement | görev listesi düzenleme | We have backlog refinement tomorrow. |
| continuous integration (CI) | sürekli entegrasyon | The build failed in CI. |
| code merge | kod birleştirme | I'll merge your branch into main. |
| release notes | sürüm notları | Please review the release notes. |
| API endpoint | API uç noktası | This API endpoint is returning an error. |
| temporary workaround | geçici çözüm | We implemented a temporary workaround. |
| system performance | sistem performansı | I'll monitor system performance today. |
| team alignment | ekip uyumu / öncelik birliği | Let's align on priorities. |
| project timeline | proje takvimi | We're running behind the project timeline. |
| escalation process | üst seviyeye iletilmesi süreci | Please follow the escalation process. |
| documentation review | dokümantasyon gözden geçirme | We need to review the documentation. |
