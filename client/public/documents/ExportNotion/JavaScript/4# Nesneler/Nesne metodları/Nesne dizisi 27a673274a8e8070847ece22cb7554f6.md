# Nesne dizisi

Bir nesnenin, kitap gibi bir varlığın özelliklerini gruplandırmanıza olanak sağladığını zaten biliyorsunuz.

Bu nedenle, çoğu zaman bir dizi nesne ile çalışacağız. Bunu yapmak için, `books` özelliğinde yalnızca dizeler değil, kitabın adını ve derecelendirmesini (ve gelecekte muhtemelen diğer özellikleri) içeren nesneleri saklayacağız.

```
const bookShelf = {
  books: [
		{ title: "The Last Kingdom", rating: 8 },
		{ title: "The Mist", rating: 6 }
	],
	getBooks() {
		return this.books;
	}
};
```

Şimdi `getBooks` yöntemi bir dizi nesne döndürecektir. `addBook` yöntemi ise parametre olarak bir dize değil, bir kitap nesnesi bekler ve bunu `books` özelliğindeki diziye ekler.

```
const bookShelf = {
  books: [
		{ title: "The Last Kingdom", rating: 8 },
		{ title: "The Mist", rating: 6 }
	],
  getBooks() {
    return this.books;
  },
  addBook(newBook) {
    this.books.push(newBook);
  }
};

bookShelf.addBook({ title: "Dream Guardian", rating: 9 });
```

`books` özelliğindeki bir dizi üzerinde döngü yaparken, bunun bir nesne dizisi olduğunu unutmayın.

Örneğin, kitapların ortalama puanını döndürecek bir `getAverageRating()` metodu ekleyelim. Bunu yapmak için:

- Nesnede yeni bir `getAverageRating` metodu tanımlayın.
- Toplam derecelendirmeyi saklamak için bir `totalRating` değişkeni tanımlayın.
- Kitap dizisi üzerinde `for...of` döngüsü ile `this.books` üzerinden yineleme yapın.
- Her yinelemede, kitabın `rating` değerini toplam puana ekleyin.
- Döngünün sonunda, toplam puanı kitap sayısına bölerek sonucu döndürün.

```
const bookShelf = {
  books: [
    { title: "The Last Kingdom", rating: 8 },
    { title: "The Mist", rating: 6 },
  ],
  getAverageRating() {
    let totalRating = 0;

    for (const book of this.books) {
      totalRating += book.rating;
    }

    return totalRating / this.books.length;
  },
};

bookShelf.getAverageRating();// 7
```

# **Görev**

Müşteri, her iksirin sadece isimle değil, aynı zamanda fiyatla da temsil edilmesini istiyor. Bu nedenle, şimdi `potions` özelliği `name` ve `price` özelliklerine sahip bir nesne dizisi depolayacaktır.

`potions` özelliğindeki tüm iksirlerin toplam fiyatını döndüren bir `getTotalPrice()` metodu ekleyin.

# **Testler**

- `atTheOldToad` değişkeni tanımlanır
- `atTheOldToad` değişkeninin değeri bir nesnedir
- `atTheOldToad.getPotions` özelliğinin değeri bir nesne metoddur
- Kaynak nesne için `atTheOldToad.getPotions()` metodu çağrıldığında `potions` özelliğinin geçerli değeri döndürülür
- `atTheOldToad.addPotion` özelliğinin değeri bir nesne metodudur.
- `atTheOldToad.addPotion({ name: "Invisibility", price: 620 })` metodu çağrıldıktan sonra, bu nesne `potions` dizisinin son öğesi olacaktır
- `atTheOldToad.addPotion({ name: "Power potion", price: 270 })` metodu çağrıldıktan sonra, bu nesne `potions` dizisinin son elemanı olacaktır
- `atTheOldToad.getTotalPrice` özelliğinin değeri bir nesne metodudur
- Kaynak nesne için `atTheOldToad.getTotalPrice()` metodu çağrıldığında, `potions` özelliğindeki tüm iksirlerin toplam fiyatı döndürülür

```jsx
const atTheOldToad = {
  potions: [
    { name: "Speed potion", price: 460 },
    { name: "Stone skin", price: 520 },
  ],
  getPotions() {
    return this.potions;
  },
  addPotion(newPotion) {
    this.potions.push(newPotion);
  },
  getTotalPrice() {
    let totalPrice = 0;
    for (const potion of this.potions) {
      totalPrice += potion.price;
    }
    return totalPrice;
  },
};
```
