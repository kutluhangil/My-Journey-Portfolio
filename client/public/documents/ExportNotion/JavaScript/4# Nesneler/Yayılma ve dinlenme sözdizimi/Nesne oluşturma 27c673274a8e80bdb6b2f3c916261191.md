# Nesne oluşturma

`spread` işlemi, rastgele sayıda nesnenin özelliklerini yeni bir nesneye dağıtmanıza olanak tanır.

```
const first = { propA: 5, propB: 10 };
const second = { propC: 15 };
const third = { ...first, ...second };
console.log(third); // { propA: 5, propB: 10, propC: 15 }
```

**Dağıtım sırası önemlidir.** Nesne özelliklerinin adları benzersizdir, bu nedenle `spread` ile birleştirilen nesnelerde aynı isimde özellikler varsa, sonraki nesnelerin özellikleri önceki olanların üzerine yazılır.

```
const first = { propA: 5, propB: 10, propC: 50 };
const second = { propC: 15, propD: 20 };

const third = { ...first, ...second };
console.log(third); // { propA: 5, propB: 10, propC: 15, propD: 20 }

const fourth = { ...second, ...first };
console.log(fourth); // { propA: 5, propB: 10, propC: 50, propD: 20 }
```

Bir örnekle açıklamak gerekirse: Eğer kutudaki elmaların üzerinde etiketler varsa, aynı kutuda aynı etikete sahip iki elma bulunamaz. Bu nedenle, aynı etikete sahip bir elma ikinci kez eklendiğinde, öncekini değiştirir.

Özellik eklerken `spread` operatörünü kullanarak, özellikleri istediğiniz sırayla yerleştirebilir ve üzerine yazma davranışını kontrol edebilirsiniz:

```
const first = { propA: 5, propB: 10, propC: 50 };
const second = { propC: 15 };

const third = { propB: 20, ...first, ...second };
console.log(third); // { propA: 5, propB: 10, propC: 15 }

const fourth = { ...first, ...second, propB: 20 };
console.log(fourth); // { propA: 5, propB: 20, propC: 15 }

const fifth = { ...first, propB: 20, ...second };
console.log(fifth); // { propA: 5, propB: 20, propC: 15 }
```

# **Görevler**

Yapıcıda, varsayılan ayarlara sahip yeni testler oluşturabilirsiniz. Varsayılan ayarlar `defaultSettings` değişkeninde saklanır.

Bir test oluştururken, ayarların tamamı veya bir kısmı geçersiz kılınabilir. Geçersiz kılınan ayarlar `overrideSettings` değişkenine kaydedilir.

Nihai test ayarlarını elde etmek için, varsayılan ayarları almanız ve geçersiz kılınan ayarları bunların üzerine uygulamanız gerekir. Kodu, `finalSettings` değişkeni nihai test ayarlarının bir nesnesini içerecek şekilde tamamlayın.

# **Testler**

- `defaultSettings` değişkeni tanımlanır
- `defaultSettings` değişkeninin değeri bir nesnedir
- `overrideSettings` değişkeni tanımlanır
- `overrideSettings` değişkeninin değeri bir nesnedir
- `finalSettings` değişkeni tanımlanır
- `finalSettings` değişkeninin değeri bir nesnedir
- `finalSettings.theme` özelliğinin değeri `light`tır.
- `finalSettings.public` özelliğinin değeri `false`dir.
- `finalSettings.withPassword` özelliğinin değeri `true`dur.
- `finalSettings.minNumberOfQuestions` özelliğinin değeri `10`dur.
- `finalSettings.timePerQuestion` özelliğinin değeri `30`dur.
- `finalSettings` değişkenine bir değer atamak için `...` sözdizimini kullanın

```
const defaultSettings = {
  theme: "light",
  public: true,
  withPassword: false,
  minNumberOfQuestions: 10,
  timePerQuestion: 60,
};
const overrideSettings = {
  public: false,
  withPassword: true,
  timePerQuestion: 30,
};

const finalSettings = { ...defaultSettings, ...overrideSettings };
```
