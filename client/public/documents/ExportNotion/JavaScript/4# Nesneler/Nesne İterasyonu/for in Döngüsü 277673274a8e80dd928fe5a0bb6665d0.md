# for...in Döngüsü

Diziler veya string'lerin aksine, nesneler doğrudan gezilebilir (iterable) yapılar değildir. Bu nedenle `for` veya `for...of` döngüleriyle dolaşılamazlar.

Nesnelerin anahtarları üzerinde gezinmek için özel olarak `for...in` döngüsü kullanılır. Bu döngü, verilen nesnenin **tüm anahtarları** üzerinde tek tek döner.

```
for (key in object) {
// talimatlar
}
```

`key` değişkeni yalnızca döngü gövdesinde geçerlidir.

Her yinelemede, bu değişkene nesnedeki bir özelliğin anahtar adı atanır.

Bu anahtarı kullanarak özelliğin değerine ulaşmak için köşeli parantez (`[]`) sözdizimi kullanılır.

```
const book = {
  title: "The Last Kingdom",
  author: "Bernard Cornwell",
  genres: ["historical prose", "adventure"],
  rating: 8.38,
};

for (const key in book) {
  console.log(key);// Anahtar
  console.log(book[key]);// Bu anahtara sahip özellik değeri
}
```

# **Görev**

`for...in` döngüsünü kullanarak `apartment` nesnesinin tüm anahtarlarını `keys` dizisine, tüm özellik değerlerini ise `values` dizisine kaydet.

# **Testler**

- `apartment` değişkeni tanımlanir
- `apartment` değişkeninin değeri bir nesnedir
- `keys` değişkeni tanımlanir
- `keys` değişkeninin değeri `["descr", "rating", "price"]` dizisidir
- `values` değişkeni tanımlanir
- `values` değişkeninin değeri `["Spacious apartment in the city center", 4, 2153]` dizisidir

```
const apartment = {
  descr: "Spacious apartment in the city center",
  rating: 4,
  price: 2153,
};
const keys = [];
const values = [];

for (const key in apartment) {
  keys.push(key);
  values.push(apartment[key]);
}
```
