# Kısa özellikler

Bazen bir nesne oluştururken, bir özelliğin değerini, o özellikle aynı ada sahip bir değişkenden veya fonksiyon parametresinden almak gerekir.

Aşağıdaki gibi bir sözdizimi kullanmak zahmetli olabilir çünkü hem özelliğin adını hem de aynı isimli değişkeni tekrar etmek gerekir: `name: name`, `age: age`.

```
const name = "Henry Sibola";
const age = 25;

const user = {
  name: name,
  age: age,
};

console.log(user.name); // "Henry Sibola"
console.log(user.age); // 25
```

**Kısaltılmış** özellik sözdizimi, bir değişken adını özellik adı ve değerini özellik değeri olarak kullanmanıza olanak tanıyarak bu sorunu çözer.

```
const name = "Henry Sibola";
const age = 25;

const user = {
  name,
  age,
};

console.log(user.name); // "Henry Sibola"
console.log(user.age); // 25
```

`name: name`, yerine `name` kullandık.

Ve `age: age`, yerine - `age`.

Yani, bir nesne tanımlanırken yalnızca özelliğin adını yazmak yeterlidir; değeri, aynı ada sahip değişkenden otomatik olarak alınır.

# **Görev**

Bir nesneyi, `name`, `price`, `image` ve `tags` özelliklerine sahip olacak ve aynı adlara sahip değişkenlerden değerler alacak şekilde tanımlamak için kodu tamamlayın. Kısa özellik sözdizimini kullandığınızdan emin olun.

# **Testler**

- `product` değişkeni bildirilir
- `product` değişkeninin değeri bir nesnedir
- İç içe `name` özelliğinin değeri `"Repair Droid"` dizesidir.
- İç içe `price` özelliğinin değeri `2500` sayısıdır
- İç içe `image` özelliğinin değeri `"<https://via.placeholder.com/640x480>"` dizesidir
- İç içe `tags` özelliğinin değeri `["on sale", "trending", "best buy"]` dizisidir.

```
const name = "Repair Droid";
const price = 2500;
const image = "<https://via.placeholder.com/640x480>";
const tags = ["on sale", "trending", "best buy"];

const product = {
  name,
  price,
  image,
  tags,
};
```
