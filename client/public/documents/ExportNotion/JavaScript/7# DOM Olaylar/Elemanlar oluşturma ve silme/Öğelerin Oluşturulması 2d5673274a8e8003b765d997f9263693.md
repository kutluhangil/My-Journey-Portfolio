# Öğelerin Oluşturulması

**DOM API** (Document Object Model Application Programming Interface) geniş bir işlevselliğe sahiptir. Bu API aracılığıyla şunlar yapılabilir:

- Var olan öğeleri **seçmek** veya **değiştirmek**
- Öğeleri **silmek**
- Yeni öğeler **oluşturmak** ve **dökümana (HTML'e)** eklemek

Yeni bir öğe nasıl oluşturulacağını inceleyelim:

`document.createElement(tagName)`

- `tagName` adında bir öğe oluşturur ve sonuç olarak onun nesnesine bir referans döndürür.
- `tagName`, oluşturulan öğenin türünü belirten bir **dizedir**.
- Öğe, **hafızada** oluşturulur; DOM'da henüz bulunmaz.

`const heading = document.createElement("h1");`

`heading` öğesini oluşturduktan sonra, bellekte bu nesnenin referansını alırız. Bu noktadan itibaren, bu nesnenin özelliklerine erişebilir ve onları DOM'a yerleştirmeden önce değiştirebiliriz:

**DOM API** (Document Object Model Application Programming Interface) geniş bir işlevselliğe sahiptir. Bu API aracılığıyla şunlar yapılabilir:

- Var olan öğeleri **seçmek** veya **değiştirmek**
- Öğeleri **silmek**
- Yeni öğeler **oluşturmak** ve **dökümana (HTML'e)** eklemek

Yeni bir öğe nasıl oluşturulacağını inceleyelim:

```

```

## **⚙️ Kısa ve Öz Teknik Mantık**

### **1️⃣ Eleman oluşturma**

```
const heading = document.createElement("h1");
```

- Bellekte yeni bir DOM elemanı oluşturur
- Henüz HTML içinde değildir

---

### **2️⃣ Özelliklerini ayarlama**

```
heading.classList.add("title");
heading.textContent = "This is a heading";
```

```
const image = document.createElement("img");
image.src = "https://picsum.photos/id/11/320/240";
image.alt = "Nature";
```

Bu aşamada:

- Eleman **tamamen hazır**
- Ama **hala DOM’a eklenmedi**
