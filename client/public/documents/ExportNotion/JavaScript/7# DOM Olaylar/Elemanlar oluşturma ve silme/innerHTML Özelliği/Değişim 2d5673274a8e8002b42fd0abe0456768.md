# Değişim

`innerHTML` özelliği hem **okunabilir** hem de **yazılabilir**.

Eğer HTML etiketleri içeren bir dize yazarsanız, tarayıcı bu dizeyi **ayrıştırarak geçerli HTML öğelerine dönüştürür** ve bunları DOM ağacına ekler.

```
Eğer innerHTML özelliğine boş bir dize atanırsa, öğenin içeriği temizlenir.
      Bu, tüm içeriği hızlı ve basit bir şekilde silmenin bir yoludur.

```

Tekrar eden (şablon) düzenleme, veri dizisinden oluşturulur.

Bu yöntem, bir diziyi döngüyle geçerek ve her bir öğe için HTML etiketleriyle bir satır oluşturarak çalışır. Son olarak, bu satır **öğenin `innerHTML` özelliğine atanır.** Eğer bunu `map()` yöntemiyle yaparsanız, unutmayın ki `map()` **bir dizi döndürür**. Dolayısıyla, DOM'a düzen eklemek için bu diziyi `join()` yöntemiyle **bir dizeye dönüştürmek** gerekmektedir.

`element.innerHTML` için yeni bir değer atandığında, `element` öğesinin tüm alt öğeleri **tamamen silinir** ve **yeniden oluşturulur**.

Eğer öğe önceden boş değilse, mevcut yapının yeniden oluşturulması **ek maliyetler**doğurur ve bu genellikle **verimsiz** bir yaklaşımdır.

```
element.innerHTML özelliğini yalnızca şu durumlarda kullanmanız önerilir:

 — Eğer elementboşsa,
 — element içeriğini tamamen değiştirmek gerekiyorsa.
```

---

## **innerHTML - okuma ve yazma**

### **🔹 Okuma örneği**

```
<div id="box">
  <p>Hello <strong>World</strong></p>
</div>
```

```
const box = document.querySelector("#box");
console.log(box.innerHTML);
```

📤 **Çıktı:**

```
<p>Hello <strong>World</strong></p>
```

👉 innerHTML, **etiketleriyle birlikte** içeriği string olarak döndürür.

---

## **innerHTML - ile yazma (HTML ayrıştırma)**

```
box.innerHTML = "<h2>Title</h2><p>New content</p>";
```

📌 Tarayıcı:

- String’i **HTML olarak parse eder**
- <h2> ve <p> gerçek DOM elemanlarına dönüşür
- Eski içerik **tamamen silinir**

---

## **innerHTML = "" → içeriği temizleme**

```
box.innerHTML = "";
```

✔️ #box içindeki **tüm çocuk elemanlar silinir**

✔️ Hızlı ve pratik bir temizleme yöntemidir

📄 Son durum:

```
<div id="box"></div>
```

---

## **Veri dizisinden şablon (tekrar eden) HTML oluşturma**

### **🎯 Amaç**

Bir dizi veriden HTML liste üretmek

### **🔹 Veri dizisi**

```
const fruits = ["Apple", "Banana", "Cherry"];
```

---

### **🔹 ❌ Yanlış kullanım (join yok)**

```
list.innerHTML = fruits.map(fruit => `<li>${fruit}</li>`);
```

📛 **Hata mantığı:**

- map() → **dizi döndürür**
- innerHTML → **string bekler**

---

### **Doğru kullanım (map + join)**

```
const list = document.querySelector("ul");

list.innerHTML = fruits
  .map(fruit => `<li>${fruit}</li>`)
  .join("");
```

📄 Oluşan HTML:

```
<ul>
  <li>Apple</li>
  <li>Banana</li>
  <li>Cherry</li>
</ul>
```

✔️ En yaygın innerHTML kullanım senaryosu

---

## **innerHTML - neden maliyetlidir?**

```
element.innerHTML = "<p>New content</p>";
```

🔴 Tarayıcının yaptığı işler:

1. Eski tüm çocukları **siler**
2. Yeni HTML’i **parse eder**
3. DOM’u **baştan oluşturur**
4. Olay dinleyiciler **kaybolur**

👉 Büyük DOM yapılarında **performans düşer**

---

## **6️⃣ ❗ Ne zaman kullanılmalı?**

### **✅ Kullanılması önerilir:**

✔️ Element **boşsa**

✔️ İçerik **tamamen değiştirilecekse**

✔️ İlk render (ilk çizim) yapılıyorsa

---

### **❌ Kullanılmaması önerilir:**

❌ Küçük bir parça değiştirilecekse

❌ Sık güncellenen içerik varsa

❌ Event listener’lar korunacaksa

➡️ Bu durumlarda createElement, append, textContent tercih edilir.

---

## **🧠 KISA ÖZET (Notluk)**

- innerHTML string ile çalışır
- HTML içeren string → gerçek DOM elemanları
- innerHTML = "" → tüm içerik silinir
- map() kullanırken → **join(””) şart**
- Her atamada DOM **tamamen yeniden oluşturulur**
- Performans maliyeti vardır
- Sadece:
    - Boş element
    - Tam içerik değişimi
        
        durumlarında kullan
