# Okuma

`innerHTML` özelliği, bir öğenin içeriğini — etiketler dahil — bir **dize** olarak saklar.

Döndürülen değer her zaman **geçerli bir HTML kodudur**.

---

## **🧩 HTML Örneği**

```
<div class="box">
  <p>Hello <strong>World</strong></p>
</div>
```

---

## **📖 JavaScript ile**

## **innerHTML okuma**

```
const box = document.querySelector(".box");

console.log(box.innerHTML);
```

### **🔍 Konsol çıktısı:**

```
<p>Hello <strong>World</strong></p>
```

---

## **🧠 Burada Ne Oldu?**

- innerHTML
    - **Etiketleriyle birlikte** içeriği okur
    - Sonuç **string (metin)** türündedir
- <p> ve <strong> etiketleri **korunur**
- Tarayıcı geçerli HTML olarak döndürür

---

## **🆚 Karşılaştırma (Hızlı)**

```
console.log(box.textContent);
```

📤 Çıktı:

```
Hello World
```

| **Özellik** | **Ne döndürür** |
| --- | --- |
| innerHTML | HTML + etiketler |
| textContent | Sadece düz metin |

---

## **📌 Kısa Not (Not Almalık)**

- innerHTML → **HTML’i string olarak okur**
- Etiketler kaybolmaz
- Dönen değer **her zaman geçerli HTML kodudur**
