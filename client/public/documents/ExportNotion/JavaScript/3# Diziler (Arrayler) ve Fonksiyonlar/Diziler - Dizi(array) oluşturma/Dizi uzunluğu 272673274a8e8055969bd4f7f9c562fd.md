# Dizi uzunluğu

Dizinin uzunluğu, yani eleman sayısı `length` özelliğinde saklanır. Bu, öğe eklediğinizde veya sildiğinizde otomatik olarak değişen dinamik bir değerdir.

`const planets = ['Earth', 'Mars', 'Venus'];
console.log(planets.length); *// 3*`

Bu örnekte, üç öğeli bir **`planets`** dizisine sahibiz. Dizi üç öğe içerdiğinden, **`planets.length`** ifadesi 3 değerini verecektir.

Bir dizinin uzunluğunu bilmek, o anda dizide kaç öğe olduğunu kontrol etmemiz gerektiğinde kullanışlıdır.

`const planets = ['Earth', 'Mars', 'Venus'];

if(planets.length >= 3) {
	console.log("3 or more elements");
} else {
	console.log("3 or less elements");
}`

- `getOrderQuantity(["apple", "peach", "pear", "banana"])` işlevi `4` sonucunu verir
- `getOrderQuantity(["apple", "banana"])` işlevi `2` sonucunu verir
- `getOrderQuantity(["apple", "banana", "pear"])` işlevi `3` sonucunu verir
- `getOrderQuantity([])` işlevi `0` sonucunu verir
