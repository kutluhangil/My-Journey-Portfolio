# concat() metodu

**`concat(arr1, arr2, ..., arrN)`** metodu iki veya daha fazla diziyi birleştirmek için kullanılır.

`const firstArray = ["Mercury", "Venus"];
const secondArray = ["Mars", "Jupiter"];
const result = firstArray.concat(secondArray);

console.log(result); // ["Mercury", "Venus", "Mars", "Jupiter"];`

Orijinal `firstArray` ve `secondArray` dizilerinin **concat()** çağrısından sonra değişmeden kaldığına dikkat edin. **`concat()`** metodu, birleştirilen dizilerin tüm öğelerini içeren yeni bir dizi oluşturur ve döndürür.

`const firstArray = ["Mercury", "Venus"];
const secondArray = ["Mars", "Jupiter"];
const result = firstArray.concat(secondArray);

console.log(firstArray); // ["Mercury", "Venus"];
console.log(secondArray); // ["Mars", "Jupiter"];
console.log(result); // ["Mercury", "Venus", "Mars", "Jupiter"];`

Metod bağımsız değişkenlerinin sırası, yeni dizideki öğelerin sırasını belirler.

`const firstArray = ["Mercury", "Venus"]*;*const secondArray = ["Mars", "Jupiter"]*;*const thirdArray = ["Saturn", "Neptune"]*;*

console.log(firstArray.concat(secondArray, thirdArray))*;* 
// ['Mercury', 'Venus', 'Mars', 'Jupiter', 'Saturn', 'Neptune']*;*

console.log(firstArray.concat(thirdArray, secondArray))*;* 
// ['Mercury', 'Venus', 'Saturn', 'Neptune', 'Mars', 'Jupiter', ]*;*`

# **Görev**

`allClients` değişkenini tanımlayın ve kodu, değeri `oldClients` ve `newClients` dizilerinin tüm öğelerinden oluşan bir diziye referans olacak şekilde değiştirin. Önce `oldClients` dizisinin elemanları, sonra da `newClients` dizisinin elemanları gitmelidir.

# **Testler**

- `OldClients` değişkeni tanımlanır
- `OldClients` değişkeninin değeri bir dizidir `["Mango", "Ajax", "Poly", "Kiwi"]`
- `newClients` değişkeni tanımlanır
- `newClients` değişkeninin değeri bir `["Peach", "Houston"]` dizisidir.
- `allClients` değişkeni tanımlanır
- `allClients` değişkeninin değeri bir dizidir `["Mango", "Ajax", "Poly", "Kiwi", "Peach", "Houston"]`
- Doğru argümanlarla `concat` metodu uygulandıktan sonra `allClients` değişkenine bir dizi atanır

`const oldClients = ["Mango", "Ajax", "Poly", "Kiwi"];
const newClients = ["Peach", "Houston"];`

`const oldClients = ["Mango", "Ajax", "Poly", "Kiwi"];
const newClients = ["Peach", "Houston"];

const allClients = oldClients.concat(newClients);`
