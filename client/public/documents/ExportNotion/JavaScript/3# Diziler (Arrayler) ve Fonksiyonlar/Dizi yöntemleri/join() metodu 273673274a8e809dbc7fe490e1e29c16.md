# join() metodu

`join(delimiter)` dizi metodu, bir dizinin elemanlarını bir dizede birleştirmenizi sağlar.

Elde edilen dizede, elemanlar `delimiter` içinde belirtilen karakter veya karakter grubu ile ayrılacaktır.

`join()` metodu kullanımına örnekler:

`const words = ["JavaScript", "is", "amazing"];
console.log(words.join("")); *// 'JavaScriptisamazing'*console.log(words.join(" ")); *// 'JavaScript is amazing'*console.log(words.join("-")); *// 'JavaScript-is-amazing'*`

Metodun sonucu daha sonra kullanılmak üzere bir değişkene kaydedilebilir.

Bir diziyi, elemanları arasında belirli sınırlayıcılar bulunan bir dizeye dönüştürmeniz gerektiğinde **`join()`** metodu kullanışlıdır. Örneğin, dizeleri snake_case'den (alt çizgi ile yılan gösterimi) kebab-case'e (tire gösterimi) dönüştüren bir fonksiyon yazmamız gerekir.

`function transformString(string) {
	const words = string.split("_");
	return words.join("-");
}

transformString("user_age"); *// "user-age"*
transformString("price_per_droid"); *// "price-per-droid"*`

### **join()m Nedir?**

- join() bir **dizi metodudur.**
- Dizideki tüm elemanları **tek bir string (yazı)** haline getirir.
- Elemanların arasına **ayırıcı (delimiter)** koyabilirsin.

👉 Eğer ayırıcı vermezsen, varsayılan olarak "," (virgül) kullanılır.

---

### **📌 Örnekler:**

```
const words = ["JavaScript", "is", "amazing"];

console.log(words.join(""));   // "JavaScriptisamazing"  (hiç boşluk yok)
console.log(words.join(" "));  // "JavaScript is amazing" (boşluk ile birleştirildi)
console.log(words.join("-"));  // "JavaScript-is-amazing" (tire ile birleştirildi)
```

---

### **📌 Günlük hayat örneği:**

Düşün ki elinde 3 kelime var:

👉 “JavaScript”, “is”, “amazing”

Bunları yan yana koymak istiyorsun. Ama aralarına **hangi işareti** koyacağını sen seçiyorsun:

- Hiçbir şey → "JavaScriptisamazing"
- Boşluk " " → "JavaScript is amazing"
- Tire "-" → "JavaScript-is-amazing"

### **split() + join()**

### **birlikte kullanımı**

Bazen elimizde **string** vardır, onu **parçalara ayırırız (split)**, sonra farklı şekilde birleştiririz (join).

Örnek:

```
function transformString(string) {
  const words = string.split("_");  // "_" gördüğü yerden böler
  return words.join("-");           // parçaları "-" ile birleştirir
}

console.log(transformString("user_age"));       // "user-age"
console.log(transformString("price_per_droid")) // "price-per-droid"
```

👉 Burada:

- "user_age" → ["user", "age"] (split("_"))
- sonra tekrar birleştirilir → "user-age" (join("-"))

---

✅ **Özet:**

- split() → String’i parçalar, dizi yapar.
- join() → Diziyi birleştirir, string yapar.
