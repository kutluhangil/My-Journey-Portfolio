# Varsayılan ayarlar

Fonksiyonlar, varsayılan değerlere sahip parametreler içerebilir. Bu parametreler, fonksiyon çağrılırken bir argüman sağlanmadığında devreye girer. Varsayılan değerler her türden veri olabilir.

Örneğin:

`function greet(username = "Guest") {
  console.log(`Hello, ${username}!`);
}

greet("Jacob"); *// "Hello, Jacob!"*
greet();        *// "Hello, Guest!"*`

Bu örnekte `greet` fonksiyonu, varsayılan değeri `"Guest"` olan bir `username` parametresi alır. Fonksiyon bir kullanıcı adıyla çağrılmazsa, `"Guest"` kullanılır. Argüman sağlanırsa, bu değer varsayılan değerin yerini alır.

Birden fazla parametre içeren bir fonksiyon örneği:

`function count(from, to, step = 1) {
  console.log(`from: ${from}, to: ${to}, step: ${step}`);

  for (let i = from; i <= to; i += step) {
  *// ...* 
  }
}

count(1, 15, 4); *// "from: 1, to: 15, step: 4"*count(1, 15); *// "from: 1, to: 15, step: 1"*`

---

### **📌 Nedir?**

Bazen bir fonksiyona **her zaman değer vermek istemeyiz**. İşte burada **varsayılan parametreler** devreye girer.

Fonksiyona değer **vermezsek**, onun yerine **önceden tanımladığımız varsayılan değer** kullanılır.

---

### **🔹 Örnek 1: Basit karşılama**

```
function greet(username = "Guest") {
  console.log(`Hello, ${username}!`);
}

greet("Jacob"); // Hello, Jacob!
greet();        // Hello, Guest!
```

✔ Burada:

- greet("Jacob") → username = "Jacob" oldu.
- greet() → hiçbir şey verilmedi, bu yüzden "Guest" kullanıldı.

---

### **🔹 Örnek 2: Birden fazla parametre**

```
function count(from, to, step = 1) {
  console.log(`from: ${from}, to: ${to}, step: ${step}`);

  for (let i = from; i <= to; i += step) {
    console.log(i);
  }
}

count(1, 15, 4);
// from: 1, to: 15, step: 4
// 1, 5, 9, 13

count(1, 15);
// from: 1, to: 15, step: 1
// 1, 2, 3, ... 15
```

✔ Burada:

- İlk çağrıda step = 4 verilmiş.
- İkinci çağrıda step verilmemiş, bu yüzden **otomatik olarak 1 kullanılmış**.

---

### **🎯 Basit benzetme**

Bir kafeye gittin, **kahve siparişi verdin ama şeker miktarı söylemedin**.

- Garson varsayılan olarak sana **1 şekerli kahve** getirir ☕.
- Eğer “2 şeker olsun” dersen, artık **senin söylediğin değer** geçerli olur.

# **Görev**

`calculateTax(amount, taxRate)` fonksiyonu iki parametre bildirir:

- `amount` - bir sayı, vergiyi hesaplamak istediğiniz tutar. Gerekli parametre.
- `taxRate` - bir sayı, vergi oranı. İsteğe bağlı bir parametredir. Varsayılan olarak değeri `0,2` olmalıdır.

Fonksiyon kodunu, tutarı vergi oranıyla çarpmanın sonucu olan vergi tutarını döndürecek şekilde tamamlayın.

# **Testler**

- `calculateTax(amount, taxRate)` fonksiyonu tanımlanır
- `calculateTax(100, 0.1)` fonksiyonuna yapılan bir çağrı `10` döndürür.
- `calculateTax(200, 0.1)` fonksiyonunun çağrılması `20` döndürür.
- `calculateTax(100, 0.2)` fonksiyonunun çağrılması `20` döndürür.
- `calculateTax(200, 0.2)` işlevi çağrıldığında `40` döndürülür
- `calculateTax(100, 0.3)` işlevi çağrıldığında `30` döndürülür
- `calculateTax(200, 0.3)` işlevi çağrıldığında `60` döndürülür
- `calculateTax(100)` fonksiyonunun çağrılması `20` döndürür
- `calculateTax(200)` fonksiyonunun çağrılması `40` değerini döndürür.

`function calculateTax(amount, taxRate) {}`

`function calculateTax(amount, taxRate = 0.2) {
  return amount * taxRate;
}`
