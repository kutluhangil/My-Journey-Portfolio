# includes() metodu

`includes()` dizi metodu, belirli bir elemanın dizide bulunup bulunmadığını kontrol etmek için kullanılır. Eleman dizide varsa `true`, yoksa `false` boolean değerini döndürür.

`includes()` metodunun sözdizimi aşağıdaki gibidir:

`array.includes(element)`

Burada:

- `array`, içinde eleman aranan kaynak dizidir
- `element` - kontrol edilecek eleman

`includes()` yönteminin kullanımına bir örnek:

`const planets = ["Earth", "Mars", "Venus"];

console.log(planets.includes("Earth")); *// true*console.log(planets.includes("Mars")); *// true*console.log(planets.includes("Venus")); *// true*console.log(planets.includes("Jupiter")); *// false*`

includes() metodu, koşulları kontrol etmek için dallanma yapılarıyla birlikte kullanılabilir. Örneğin, bir dizide belirli bir değerin varlığına bağlı olarak farklı işlemler gerçekleştirebilirsiniz.

`const fruits = ["apple", "banana", "orange"];

if (fruits.includes("banana")) {
  console.log("The array has an element banana");
} else {
  console.log("Array does not contain banana element");
}`

Yukarıdaki örnek, `fruits` dizisinde `"banana"` öğesinin varlığını kontrol eder ve duruma göre uygun mesajı yazdırır.

`"banana"` öğesinin dizide bulunup bulunmadığını kontrol etmek için `includes()` metodunu kullanıyoruz. Bu kontrol, `if` bloğu içinde `fruits.includes("banana")` şeklinde yapılır.

- `true` dönerse: `"banana"` dizide mevcuttur, `if` bloğu çalışır.
- `false` dönerse: `"banana"` dizide yoktur, `else` bloğu çalışır.

---

### **📌 Basitçe:**

- Bir **alışveriş sepetin** olduğunu düşün → ["apple", "banana", "orange"]
- Şimdi “**Sepette muz var mı?**” diye kontrol etmek istiyorsun.
- İşte includes("banana") bunu yapıyor.

---

### **📖 Örnek:**

```
const fruits = ["apple", "banana", "orange"];

console.log(fruits.includes("banana")); // true
console.log(fruits.includes("kiwi"));   // false
```

- "banana" sepette **var**, bu yüzden true döndürür ✅
- "kiwi" sepette **yok**, bu yüzden false döndürür ❌

---

### **🧩 if ile birlikte kullanım**

```
if (fruits.includes("banana")) {
  console.log("Yes! Banana is in the basket 🍌");
} else {
  console.log("Nope, no bananas here ❌");
}
```

- Eğer "banana" sepette varsa ilk mesaj çalışır.
- Eğer yoksa ikinci mesaj çıkar.

---

🔑 **Özet:**

includes() = “Bu dizide bu eleman var mı?” sorusunun cevabı.

- Varsa → true
- Yoksa → false

---

# **Görev**

Bu görevi çözmeden önce "ortak eleman" kavramını tanımlamak gerekir. Ortak elemanlar, her iki dizide de bulunan değerlerdir.

Örneğin, `[1, 3, 5]` ve `[0, 8, 5, 3]` dizilerinde `3` ve `5` ortak elemanlardır çünkü her iki dizide de bulunurlar. Buna karşılık `0`, `1` ve `8` yalnızca bir dizide yer alır.

`getCommonElements(array1, array2)` fonksiyonu, parametre olarak rastgele uzunlukta iki dizi alır (`array1` ve `array2`).

Fonksiyonun kodunu aşağıdaki adımlarla tamamlayın:

1. Ortak elemanları tutmak için boş bir dizi tanımlayın.
2. `array1` içindeki her eleman üzerinde bir `for` döngüsü ile yineleme yapın.
3. Döngü içinde, `includes()` metoduyla bu elemanın `array2` içinde bulunup bulunmadığını kontrol edin.
4. Eğer bulunuyorsa, bu elemanı ortak elemanlar dizisine ekleyin.
5. Sonuç olarak, ortak elemanları içeren diziyi döndürün.

# **Testler**

- `getCommonElements(array1, array2)` fomksiyonu tanımlanır
- `getCommonElements([1, 2, 3], [2, 4])` çağrısı `[2]` döndürür
- `getCommonElements([1, 2, 3], [2, 1, 17, 19])` çağrısı `[1, 2]` döndürür
- `getCommonElements([24, 12, 27, 3], [12, 8, 3, 36, 27])` çağrısı `[12, 27, 3]` döndürür
- `getCommonElements([10, 20, 30, 40], [4, 30, 17, 10, 40])` çağrısı `[10, 30, 40]` döndürür
- `getCommonElements([1, 2, 3], [10, 20, 30])` çağrısı `[]` döndürür
- İki rastgele diziyle `getCommonElements()` çağrıldığında doğru dizi döndürülür

`function getCommonElements(array1, array2) {}`

`function getCommonElements(array1, array2) {
  const commonElements = [];

  for (let i = 0; i < array1.length; i += 1) {
    const element = array1[i];

    if (array2.includes(element)) {
      commonElements.push(element);
    }
  }

  return commonElements;
}`
