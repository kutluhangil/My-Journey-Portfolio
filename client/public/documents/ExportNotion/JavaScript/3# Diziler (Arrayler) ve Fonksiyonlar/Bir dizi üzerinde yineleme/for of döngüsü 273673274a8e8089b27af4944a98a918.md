# for...of döngüsü

`for...of` döngüsü, bir dizi üzerinde yineleme yapmak için pratik bir yoldur. Sayaca ihtiyaç duyulmayan durumlarda, klasik `for` döngüsüne göre daha okunabilir bir alternatiftir.

`for...of` döngüsünün sözdizimi şu şekildedir:

`for (const element of array) {
  *// döngü gövdesi*
}`

Burada:

- `element`, her yinelemede dizideki mevcut öğeyi temsil eder.
- `array`, üzerinde yineleme yapılacak dizidir.

Bir dizi için **`for...of`** döngüsünün kullanımına bir örnek:

`const planets = ["Earth", "Mars", "Venus"];

for (const planet of planets) {
  console.log(planet);
}`

Bu örnekte, gezegen isimlerini içeren bir `planets` dizisi tanımlanmıştır.

Ardından `for...of` döngüsü ile dizideki her öğeye sırasıyla erişiyoruz. Her yinelemede `planet` değişkeni, dizinin o anki elemanını temsil eder. Döngü içinde `console.log()` ile bu değeri ekrana yazdırıyoruz.

Kod çalışmasının sonucu, **`planets`** dizisinin her bir öğesinin sıralı çıktısı olacaktır.

`for...of` döngüsü, daima dizinin ilk öğesinden son öğesine kadar sırasıyla ilerler. Belirli bir koşul sağlandığında döngüyü erken sonlandırmak istiyorsanız, `break` ifadesini kullanabilirsiniz.

### **for...of Döngüsü Nedir?**

Bir kutuda elmalar, muzlar ve armutlar var diyelim. 🍎🍌🍐

Sen sırayla her birini eline alıp bakmak istiyorsun. İşte for...of döngüsü tam olarak bunu yapıyor:

> “Kutunun içindeki her şeyi sırayla al,
> 
> 
> **bir değişkenin içine koy**
> 

---

### **📌 Sözdizimi:**

```
for (const element of array) {
  // element: şu anki kutudan çıkan şey
}
```

- **array** → kutu (üzerinde dolaşmak istediğimiz dizi)
- **element** → o an kutudan çıkan şey (yani dizi içindeki her eleman)

---

### **📌 Örnek:**

```
const planets = ["Earth", "Mars", "Venus"];

for (const planet of planets) {
  console.log(planet);
}
```

👉 Bu döngü şöyle çalışır:

1. İlk turda → planet = "Earth"
2. İkinci turda → planet = "Mars"
3. Üçüncü turda → planet = "Venus"

Ve konsola şunu yazar:

```
Earth
Mars
Venus
```

---

### **📌 Neden Kullanılır?**

- Klasik for döngüsünde sayacı (i) takip etmen gerekir:

```
for (let i = 0; i < planets.length; i++) {
  console.log(planets[i]);
}
```

- 
- Ama for...of ile sayaçla uğraşmazsın, **daha temiz ve okunaklıdır**.

---

### **📌 Bonus: Döngüyü Erken Bitirmek**

Eğer belli bir noktada durmak istiyorsan → break kullanabilirsin:

```
for (const planet of planets) {
  if (planet === "Mars") {
    break; // Mars'a gelince dur
  }
  console.log(planet);
}
// Çıktı: Earth
```

---

👉 Yani for...of döngüsü, bir dizi kutu gibi düşünüldüğünde **kutunun içindeki her şeyi tek tek çıkarıp bakmanın en kolay yolu**. 🚀

# **Görev**

`calculateTotalPrice(order)` fonksiyonunun kodunu `order` dizisindeki sayıların toplamını döndürecek şekilde tamamlayın. Dizi üzerinde yineleme yapmak için `for...of` döngüsünü kullanın.

# **Testler**

- `calculateTotalPrice(order)` fonksiyonu tanımlanır
- `calculateTotalPrice([12, 85, 37, 4])` fonksiyonu çağrıldığında `138` döndürülür.
- `calculateTotalPrice([164, 48, 291])` fonksiyonu çağrıldığında `503` döndürülür.
- `calculateTotalPrice([412, 371, 94, 63, 176])` fonksiyonu çağrıldığında `1116` döndürülür.
- `calculateTotalPrice([])` fonksiyonunun çağrılması `0` değerini döndürür.
- Rastgele bir sayı dizisi ile `calculateTotalPrice()` fonksiyonu çağrıldığında doğru miktar döndürülür
- 

`function calculateTotalPrice(order) *{}*`

`function calculateTotalPrice(order) {
  let total = 0;

  for (const orderItem of order) {
    total += orderItem;
  }

  return total;
}`
