# Return Değeri

`Async/await` döngülere dayanır, bu nedenle programın ana iş parçacığını engellemez. Aslında bu, bir fonksiyon içindeki döngülerle çalışmanın modern bir yoludur ve `then/catch` yapısına bir alternatiftir.

Asenkron bir fonksiyon her zaman bir Promise döndürür. Bu nedenle, fonksiyondan döndürülen herhangi bir değer Promise değeri olacaktır.

```
const foo = async () => {
	return 5;
};

foo().then(value => {
	console.log(value); // 5
});
```

Dönüş değeri için bir değer belirtmezseniz, `undefined` değerine sahip bir alan oluşturulur.

```
const foo = async () => {
	// Döndürülecek bir değer belirtmeyin
};

foo().then(value => {
	console.log(value); // undefined
});
```
