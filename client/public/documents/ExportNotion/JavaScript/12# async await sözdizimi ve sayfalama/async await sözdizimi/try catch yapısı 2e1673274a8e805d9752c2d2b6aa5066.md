# try...catch yapısı

`try...catch` yapısı — istisnaları ele almak için bir mekanizmadır. Hataların izleneceği bir `try` bloğu oluşturabilir ve bu hataları ele alabileceğiniz bir `catch`bloğu tanımlayabilirsiniz.

```
try {
  // Hataların oluşabileceği kod bloğu
} catch (error) {
  // try bloğunda oluşan hataları işlemek için kod bloğu
}
```

Bir `try` bloğunda bir hata (istisna) oluştuğunda, `try` bloğundaki kodun yürütülmesi durdurulur ve kontrol `catch` bloğuna aktarılır. Hata parametresi, genellikle hata hakkında hata mesajı gibi bilgiler içeren bir hata nesnesini temsil eder.

Bu mekanizma, hataları esnek bir şekilde ele almanıza ve uygun kararlar vermenize olanak tanır. Hatayı bir `catch` bloğunda ele alarak uygulamayı çalıştırmaya devam edebilir veya kullanıcıyı hata hakkında bilgilendirebilirsiniz.

Bir örnek verelim: bir sayıyı sıfıra bölmeye çalışıyoruz ve bu da bir hatayla sonuçlanıyor. `try...catch` kullanarak bu hatayı yakalayabilir ve bununla ilgili bir mesaj görüntüleyebilirsiniz.

```
console.log("Before try...catch");

try {
  const result = 10 / 0;
  console.log(result); // Bu satır bir hata nedeniyle yürütülmeyecektir
} catch (error) {
  // Hatayı ele alalım
  console.error(error.message);
}

console.log("After try...catch");
```
