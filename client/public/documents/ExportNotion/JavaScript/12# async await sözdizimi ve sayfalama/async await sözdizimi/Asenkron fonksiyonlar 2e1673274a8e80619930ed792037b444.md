# Asenkron fonksiyonlar

`async/await` sözdizimi — senkron kod gibi görünen asenkron kod yazmanın kullanışlı bir yoludur. Bu mekanizma ECMAScript 2017 (ES8) standardına eklenmiştir ve rahatlığı ve anlaşılırlığı nedeniyle geliştiriciler arasında çok popüler hale gelmiştir. Herhangi bir fonksiyon asenkron olabilir.

Asenkron bir fonksiyon tanımlamak için, `function` anahtar sözcüğünün önüne `async` ekleyin.

```
async function fetchData() {
	// ...
}
```

Bir fonksiyon ifadesinde, `function` anahtar sözcüğünden önce `async` sözcüğünü de eklersiniz.

```
const fetchData = async function() {
	// ...
}
```

Asenkron bir ok işlevi tanımlamak için, `async` anahtar sözcüğü parametre listesinden önce eklenir.

```
const fetchData = async () => {
	// ...
}
```

Bir nesnenin asenkron bir yöntemini tanımlamak için yöntem adının önüne `async`eklenir.

```
const user = {
  async getUsername() {
    // ...
  },
};
```

Asenkron bir sınıf yöntemi tanımlamak için, yöntem adından önce `async` de kullanırsınız.

```
class User{
  async getUsername() {
    // ...
  }
}
```
