# Hata işleme

Asenkron bir işlevin (promise) sonucu **harici kodda kullanılmazsa**, hatalar `try...catch` yapısı kullanılarak işlev gövdesinin kendisinde ele alınır. `catch`bloğundaki hata parametresinin değeri — isteğin reddedilmesi durumunda `await`'in oluşturacağı hatadır.

```
const fetchUsers = async () => {
	try {
		const response = await axios.get("<https://jsonplaceholder.typicode.com/users>");
		console.log(response.data);
	} catch(error) {
		console.log(error);
	}
};
```

Bir asenkron fonksiyonun (promise) sonucu harici kodda, yani diğer asenkron fonksiyonların dışında kullanılırsa, hatalar callback'in `catch()` yöntemi tarafından ele alınır. `catch()` yöntemindeki `error` parametresinin değeri — istek reddedilirse `await`'in oluşturacağı hatadır.

```
const fetchUsers = async () => {
	const response = await axios.get("<https://jsonplaceholder.typicode.com/users>");
	return response.data;
};

fetchUsers()
  .then(users => console.log(users))
  .catch(error => console.log(error));
```

Bir asenkron fonksiyonun sonucu başka bir asenkron fonksiyonda kullanılırsa, hatalar `try...catch` yapısı tarafından ele alınır. `catch` bloğundaki hata parametresinin değeri, istek reddedilirse `await`'in oluşturacağı hatayı temsil eder.

```
const fetchUsers = async () => {
	const response = await axios.get("<https://jsonplaceholder.typicode.com/users>");
	return response.data;
};

const doStuff = async () => {
  try {
    const users = await fetchUsers();
    console.log(users);
  } catch (error) {
    console.log(error);
  }
};

doStuff();
```
