# HTTP istekleri

Kodu daha okunabilir hale getirmek için HTTP istekleri ile çalışırken `async/await`sözdizimini kullanalım.

`fetchUsers` fonksiyonunu bu sözdizimini kullanarak yeniden yazalım.

```
const fetchUsers = () => {
	axios.get("<https://jsonplaceholder.typicode.com/users>")
	  .then(response => {
			console.log(response.data);
	  });
};
```

Asenkron hale getirmek için önce `async` anahtar sözcüğünü ekleyin.

```
const fetchUsers = async () => {
	// ...
};
```

Ardından `await` deyimini kullanarak `axios.get`'in tamamlanmasını bekler ve response nesnesini `response` değişkenine alırız.

```
const fetchUsers = async () => {
	const response = await axios.get("<https://jsonplaceholder.typicode.com/users>");
	console.log(response.data);
};
```

Bir HTTP isteğinin sonucunu harici kodda kullanmanız gerekiyorsa, değerini zaman uyumsuz işlevden döndürün ve `then` yönteminde işleyin.

```
const fetchUsers = async () => {
	const response = await axios.get("<https://jsonplaceholder.typicode.com/users>");
	return response.data;
};

fetchUsers()
	.then(users => console.log(users));
```
