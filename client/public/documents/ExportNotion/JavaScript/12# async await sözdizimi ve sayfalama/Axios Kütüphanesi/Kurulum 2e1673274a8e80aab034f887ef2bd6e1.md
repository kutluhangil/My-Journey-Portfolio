# Kurulum

[Axios](https://axios-http.com/) kütüphanesi — HTTP istekleriyle çalışırken birçok rutin görevi otomatikleştiren Promise tabanlı basit bir HTTP istemcisidir, yani şunları yapmanızı sağlar:

- tüm isteklere otomatik olarak eklenecek global ayarları saklar
- sorgu verilerini otomatik olarak JSON biçimine dönüştürme
- JSON biçiminden yanıt verilerini ayrıştırma
- 404 ve çok daha fazlası dahil olmak üzere tüm olası istek hatalarını ele alın.

Axios, standart Fetch API'sine uygun bir alternatiftir.

Axios'u bir kütüphane olarak yüklemek için NPM kullanın:

`npm install axios`

Kullanmak için, Axios'u kullanmayı planladığınız JavaScript dosyanıza varsayılan içe aktarmayı ekleyin.

`import axios from 'axios';`
