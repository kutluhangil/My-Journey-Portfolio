# Varsayılan üstbilgiler

Temel adrese ek olarak, gerekli standart istek başlıklarını da belirtebilirsiniz. Örneğin, her isteğe HTTP başlığı olarak dahil etmek istediğiniz benzersiz bir API anahtarınız varsa, bunu `axios.defaults.headers.common` özelliğine ekleyebilirsiniz.

```
import axios from "axios";

const myApiKey = "secret-api-key-for-every-request";

axios.defaults.headers.common["header-name"] = myApiKey;
```

`"header-name"` dizesi yerine, istediğiniz başlık adını bir dize olarak belirtin.

Başka bir deyişle, `axios.defaults.headers.common` nesnesine `"header-name"`anahtarıyla yeni bir özellik ekliyoruz. Axios daha sonra bu başlığı belirtilen değerle her isteğe otomatik olarak ekleyecektir.
