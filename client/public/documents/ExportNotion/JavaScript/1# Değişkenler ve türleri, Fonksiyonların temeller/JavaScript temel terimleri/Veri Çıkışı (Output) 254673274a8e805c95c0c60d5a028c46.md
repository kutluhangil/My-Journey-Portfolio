# Veri Çıkışı (Output)

Geliştirici, programın doğru şekilde çalışıp çalışmadığını belirli bir anda kontrol etmeli ve bilgiyi kodun belirli bir yerinde görüntülemelidir.

Bunun için tarayıcılardaki geliştirici araçlar içinde yer alan Console sekmesi kullanılır. Bu konsol, koddan gelen mesajların, çıktının veya hata bildirimlerinin anlık olarak görüntülenmesini sağlar.

![](https://s3.eu-north-1.amazonaws.com/lms.goit.files/7460e995-66d2-48ae-9ee9-a71bbedd8207Screenshot%202023-07-04%20at%2016.51.35.png)

Geliştirici araçlarının Console sekmesini açmak için aşağıdaki tuş kombinasyonlarını kullanabilirsiniz:

`Windows ve Linux için: Ctrl + Shift + J
MacOS için: Command + Option + J`
