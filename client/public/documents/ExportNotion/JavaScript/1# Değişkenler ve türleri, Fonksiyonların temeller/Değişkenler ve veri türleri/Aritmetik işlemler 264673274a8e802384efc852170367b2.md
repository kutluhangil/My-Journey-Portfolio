# Aritmetik işlemler

JavaScript, aritmetik hesaplamalar yapmanıza olanak tanıyan çeşitli matematiksel operatörlere sahiptir.

![](https://s3.eu-north-1.amazonaws.com/lms.goit.files/5029ebcd-75c0-4164-a40e-2730dfbcc132m01-b02-s09.jpg)

Bu operatörlerle çalışırken, **işlem sırası kurallarını** göz önünde bulundurmanız gerekir.

Bu kurallar, okulda cebir derslerinde öğrendiklerimize benzer:

İlk olarak **parantez içindeki işlemler**, ardından **kuvvet alma ve kökler**, daha sonra ise **çarpma ve bölme** gibi işlemler sırasıyla uygulanır.

İşlemlerin sonucu, ifadelerde daha fazla kullanılabilen veya değişkenlerde saklanabilen bir değerdir.

(`+`) operatörü iki sayıyı toplamak için kullanılır.

`const x = 8;
const y = 5;
console.log(x + y); *// 13*`

(`-`) operatörü bir sayıyı diğerinden çıkarmak için kullanılır.

`const x = 8*;*
const y = 5*;*
console.log(x - y)*; // 3*`

(`*`) operatörü iki sayıyı çarpmak için kullanılır.

`const x = 8*;*
const y = 5*;*
console.log(x * y)*; // 40*`

(`/`) operatörü bir sayıyı diğerine bölmek için kullanılır.

`const x = 8*;*
const y = 5*;*
console.log(x / y)*; // 1.6*`

(`%`) operatörü, bir sayının başka bir sayıya bölümünden kalanı verir.

`const x = 8*;*
const y = 5*;*
console.log(x % y)*; // 3*`

(`**`) operatörü, bir sayıyı ikinin kuvvetine yükseltmek için kullanılır.

`const x = 8*;*
const y = 5*;*
console.log(x ** y)*; // 32768*`
