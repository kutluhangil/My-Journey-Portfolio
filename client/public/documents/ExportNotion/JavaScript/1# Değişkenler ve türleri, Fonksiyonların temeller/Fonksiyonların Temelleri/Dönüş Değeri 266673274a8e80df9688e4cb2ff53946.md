# Dönüş Değeri

`return` operatörü, bir fonksiyonun gövdesinden bir değeri, fonksiyonun çağrıldığı yere **geri döndürmek** için kullanılır.

Yorumlayıcı (interpretör), `return` ifadesini gördüğünde fonksiyondan hemen çıkar (yürütmeyi durdurur) ve `return` ifadesinden sonra belirtilen değeri geri döndürür.

`function multiply(x, y, z) {
	const product = x * y * z;
  *// Çarpma işleminin sonucunu geri döndürüyoruz*return product;
}

*// Fonksiyonun çıktısını bir değişkene kaydedebilirsiniz*
const result = multiply(2, 3, 5);
console.log(result); *// 30*`

Fonksiyonun gövdesinde gereksiz bir değişken tanımlamaktan kaçınmak için, ifadenin sonucunu doğrudan `return` ile döndürebilirsiniz.

Bu sayede, sonucu saklamak için ayrı bir değişken oluşturmanıza gerek kalmaz.

`function multiply(x, y, z) {
  return x * y * z;
}

const result = multiply(2, 3, 5);
console.log(result); *// 30*`

Bir fonksiyonun gövdesinde `return` operatörü yoksa veya herhangi bir değeri döndürmüyorsa, fonksiyon özel bir değer olan `undefined` döndürür.

`function multiply(x, y, z) {
	const product = x * y * z;
}

const result = multiply(2, 3, 5);
console.log(result); *// undefined*`

`return` operatörü kullanıldığında, sonrasında gelen satırlardaki hiçbir talimat çalıştırılmaz. Çünkü fonksiyon, `return` ifadesine ulaşıldığında hemen sona erer.

`function multiply(x, y, z) {
  console.log('The code before return is executed as usual');

  return x * y * z;

  console.log('This code is never executed because it is after return');
}

console.log(multiply(2, 3, 5)); *// 3*`

---

### **1️⃣ Fonksiyon bir**

### **makine**

### **gibi düşün**

Fonksiyona bir şeyler (girdi → parametreler) verirsin.

O da sana bir şeyler **hesaplayıp geri verir** → işte bu geri verme işi return ile yapılır.

---

### **2️⃣ Örnek: Çarpma makinesi**

```
function multiply(x, y, z) {
  return x * y * z;
}

const result = multiply(2, 3, 5);
console.log(result); // 30
```

- multiply(2,3,5) çalışır → 2 * 3 * 5 = **30**
- return 30 → fonksiyon dışarıya **30** sonucunu verir.
- O yüzden result artık **30** oluyor.

---

### **3️⃣ Eğer**

### **return**

### **koymazsan**

```
function multiply(x, y, z) {
  const product = x * y * z;
}

const result = multiply(2, 3, 5);
console.log(result); // undefined
```

Burada return yok, o yüzden fonksiyon hiçbir şey geri vermez.

JavaScript otomatik olarak undefined döner.

---

### **4️⃣**

### **return**

### **sonrası kod çalışmaz**

```
function multiply(x, y, z) {
  console.log("return'den önce çalışır");

  return x * y * z;

  console.log("Burası asla çalışmaz");
}
```

- İlk console.log çalışır.
- return → fonksiyondan **çıkar**.
- return’den sonraki satırlar **görmezden gelinir**.

---

📌 Kısacası:

- return, fonksiyondan **cevabı dışarıya verir**.
- return varsa, o satırdan sonra fonksiyon biter.
- return yoksa → fonksiyonun sonucu undefined olur.

# **Görev**

`add` fonksiyonunun kodunu, üç parametre `a`, `b` ve `c` değerlerinin toplamını döndürecek şekilde tamamlayın.

# **Testler**

- Tanımlanan `add(a, b, c)` fonksiyonu.
- `add` fonksiyonunda bir `return` operatörü bulunmaktadır.
- `add(15, 27, 10)` çağrısı `52` değerini döndürür.
- `add(10, 20, 30)` çağrısı `60` değerini döndürür.
- `add(5, 10, 15)` çağrısı `30` değerini döndürür.
- Fonksiyon, rastgele ama geçerli argümanlarla çağrıldığında doğru değeri döndürür.

✅ Doğru çözüm:

```
function add(a, b, c) {
  return a + b + c;
}

// Testler
console.log(add(15, 27, 10)); // 52
console.log(add(10, 20, 30)); // 60
console.log(add(5, 10, 15));  // 30
```

---

🔎 Adım adım açıklama:

1. function add(a, b, c) → 3 parametreli bir fonksiyon tanımladık.
2. return a + b + c; → verilen 3 sayının toplamını dışarıya döndürür.
    - Burada console.log yok, sadece sonucu döndürür.
3. Fonksiyon çağrıldığında (add(15, 27, 10)), JavaScript toplamı hesaplar ve **52** değerini geri verir.
4. Biz de console.log(add(...)) yazarak ekrana bastırıyoruz.

---

📌 Farkı hatırla:

- console.log → sadece ekrana yazdırır.
- return → sonucu dışarıya verir, böylece başka yerde de kullanılabilir.
