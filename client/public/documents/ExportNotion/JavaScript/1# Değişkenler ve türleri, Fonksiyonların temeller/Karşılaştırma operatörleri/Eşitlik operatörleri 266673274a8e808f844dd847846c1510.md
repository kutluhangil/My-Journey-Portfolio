# Eşitlik operatörleri

JavaScript, değerleri karşılaştırmanıza ve eşit olup olmadıklarını belirlemenize olanak tanıyan **eşitlik operatörlerine** sahiptir.

**Esnek eşitlik operatörleri:**

- `==` (eşittir) operatörü: İki değeri eşitlik açısından karşılaştırır. İşlenen değerler eşitse `true`, değilse `false` döndürür.
- `!=` (eşit değildir) operatörü: İki değeri eşitsizlik açısından karşılaştırır. İşlenen değerler eşit değilse `true`, eşitse `false` döndürür.

`console.log(5 == 5); *// true*`

`console.log(5 == 3); *// false*`

`console.log(5 != 3); *// true*`

`console.log(5 != 5); *// false*`

# **Ama bir sorun var**

Eşitlik operatörleri, karşılaştırma bağlamına bağlı olarak değerleri farklı türlere **dönüştürebilir**. Bu durum beklenmedik sonuçlara yol açabileceğinden, birçok geliştirici bu operatörleri kullanmaktan kaçınmayı tercih eder.

`*// Bu kötüdür çünkü dizeleri ve boolean değerleri dolaylı olarak bir sayıya atar*`

`console.log(5 == "5"); *// true*`

`console.log(5 != "5"); *// false*`

`console.log(1 == true); *// true*`

`console.log(1 != true); *// false*`

Bu örneklere daha yakından bakalım.

`5 == "5"` ifadesi, biri sayı diğeri string olmasına rağmen `true` döndürür.

Bunun nedeni, `"5"` string’inin `5` sayısına dönüştürülmesi ve karşılaştırmanın `5 == 5` şeklinde gerçekleşmesidir.

Benzer şekilde, `1 == true` ifadesi de `true` döndürür; çünkü `true` boolean değeri, karşılaştırma sırasında `1` sayısına dönüştürülür.

Aşağıdaki resimde, eşitlik operatörleri kullanılarak değerlerin karşılaştırılmasına ilişkin bir tablo gösterilmektedir.

![](https://s3.eu-north-1.amazonaws.com/lms.goit.files/a81dd048-b72f-435c-a2ea-73868987d2dfm01-b04-s02.jpg)

Örtük (implicit) tür dönüşümü, özellikle acemi geliştiriciler için hatalara yol açabilir.

Bu tür sorunlardan kaçınmak için, tür dönüşümü yapmayan **kesin eşitlik operatörlerinin** kullanılması önerilir.

`===` operatörü (kesin eşitlik): İki değeri eşitlik açısından karşılaştırır.

Eğer değerler eşitse **ve** aynı veri türüne sahipse `true`, aksi takdirde `false` döndürür.

`!==` operatörü (kesin eşitsizlik): İki değeri eşitsizlik açısından karşılaştırır.

Değerler eşit **değilse** veya farklı veri türlerine sahipse `true`, aksi takdirde `false` döndürür.

`*// Tür dönüştürme yapılmadan sonuç hesaplanır*console.log(5 === 5); *// true*console.log(5 === "5"); *// false*console.log(5 !== "5"); *// true*console.log(5 !== 5); *// false*console.log(1 === true); *// false*console.log(1 !== true); *// true*`

Kesin olmayan operatörlerin aksine, `5 === "5"` ve `1 === true` ifadeleri `false` döndürür, çünkü işlenenler farklı türdedir.

Aşağıdaki görselde, kesin eşitlik operatörleri kullanılarak yapılan karşılaştırmaları gösteren bir tablo yer almaktadır. Bu tabloda, her bir değer yalnızca **kendisiyle** eşittir. Karşılaştırma yapılmadan önce hiçbir değer başka bir türe dönüştürülmez.

# **Görev**

`isValid` değişkenini tanımlayın ve `correctPassword` ile `userPassword`değişkenlerindeki parolaların eşitliğini kontrol etme sonucunu verin.

- Parolalar aynıysa (kesin eşitlikse), `isValid` değişkeninin değeri `true` olmalıdır.
- Parolalar eşleşmiyorsa, `isValid` değeri `false` olur.

Kesin eşitlik operatörünü (`===`) kullanın.

# **Testler**

- `correctPassword` değişkeni tanımlanır
- `userPassword` değişkeni tanımlanır
- `isValid` değişkeni tanımlanır
- Eğer `userPassword` değeri `mangodab3st` değerine eşitse, `isValid` değeri `false` olacaktır.
- Eğer `userPassword` değeri `kiwirul3z` ise, `isValid` değeri `false` olacaktır.
- Eğer `userPassword` değeri `jqueryismyjam` ise, `isValid` değeri `true` olacaktır.

---

### **1. Bizim doğru şifremiz (sistemde kayıtlı olan)**

```
const correctPassword = "jqueryismyjam";
```

---

### **2. Kullanıcının girdiği şifre**

```
const userPassword = "mangodab3st"; // örnek olarak bu
```

---

### **3. Karşılaştırma**

Katı eşitlik (===) kullanıyoruz. Çünkü:

- == tip dönüşümü yapar (örneğin "5" == 5 → true).
- === hem **değer hem tip** eşit olmalı der → daha güvenli ✅

```
const isValid = userPassword === correctPassword;
```

---

### **4. Çalışma mantığı**

- Eğer userPassword **aynen** "jqueryismyjam" ise → isValid = true
- Diğer tüm durumlarda → isValid = false

---

### **5. Test edelim**

```
const correctPassword = "jqueryismyjam";

let userPassword = "mangodab3st";
let isValid = userPassword === correctPassword;
console.log(isValid); // false

userPassword = "kiwirul3z";
isValid = userPassword === correctPassword;
console.log(isValid); // false

userPassword = "jqueryismyjam";
isValid = userPassword === correctPassword;
console.log(isValid); // true
```
