# Okuma

HTTP `GET` yöntemi mevcut verileri almak için kullanılır.

`fetch()` yöntemi, sunucuya bir gövde olmadan bir GET isteği göndermelidir. İsteği aldıktan sonra, arka uç bunu işleyecek ve yanıtta gerekli kaynakları döndürecektir.

# **Koleksiyonun tamamını alma**

Tüm gönderilerin bir dizisini alalım. Bunu yapmak için, arka uç belgelerinde açıklanan `/posts` kaynağına başvuruyoruz. `fetch()` yöntemi varsayılan olarak bir GET isteği yapar, bu nedenle istek seçeneklerini geçersiz kılmak gerekli değildir.

```
fetch("<https://jsonplaceholder.typicode.com/posts>")
  .then((response) => {
    if (!response.ok) {
      throw new Error(response.status);
    }
    return response.json();
  })
  .then((posts) => console.log(posts))
  .catch((error) => console.log(error));
```

# **Tek bir öğe alma**

Tek bir gönderiyi `/posts/:postId` kaynağına ekleyerek tanımlayıcıya (`id` özelliği) göre alalım.

Bu yolun son kısmı (`:postId`) dinamik parametre olarak adlandırılır ve belgelerde `/resource/:parameter` olarak tanımlanır. Dinamik parametreler başlangıçta iki nokta üst üste `:` ile ayırt edilir. Bu yalnızca bunun dinamik bir parametre olduğunu belirtmek için kullanılır, sorgu dizesinin kendisine dahil edilmez. Dinamik parametrelerin kullanımı kaynağın kendisini değiştirmez (tüm koleksiyonun yolu), ancak her bir öğesi için dinamik parametrenin değeri değişir.

```
// Change this number to fetch different post
const postId = 1;

fetch(`https://jsonplaceholder.typicode.com/posts/${postId}`)
  .then((response) => {
    if (!response.ok) {
      throw new Error(response.status);
    }
    return response.json();
  })
  .then(post => console.log(post))
  .catch(error => console.log(error));
```
