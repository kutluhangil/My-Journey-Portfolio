# Silme

`DELETE` yöntemi mevcut verileri silmek için kullanılır.

`fetch()` metodu sunucuya bir gövde olmadan bir DELETE isteği göndermelidir. Yol, hangi koleksiyonda ve hangi öğeyi silmek istediğimizi gösterir.

İsteği aldıktan sonra, arka uç bunu işleyecek, kaynağı koleksiyondan silecek ve yanıtta sonucun durumunu ve silinen öğeyi döndürecektir.

```
const postIdToDelete = 1;

fetch(`https://jsonplaceholder.typicode.com/posts/${postIdToDelete}`, {
  method: "DELETE",
})
  .then((response) => {
    if (!response.ok) {
      throw new Error(response.status);
    }
    return response.json();
  })
  .then((deletedPost) => console.log(deletedPost))
  .catch(error => console.log("Error:", error));

```
