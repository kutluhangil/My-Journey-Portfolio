# Oluşturma

Yeni bir kaynak eklemek için `POST` yöntemi kullanılır.

Sunucuya veri aktarmak için HTTP istek gövdesi kullanılır - isteğin sunucuya aktarılan verileri içeren kısmı.

İstemci herhangi bir ek veri olmadan basitçe bir istek gönderirse istek gövdesi boş olabilir. Ancak POST isteklerinde gövde form verileri, JSON nesneleri, dosyalar veya sunucunun işlemesi gereken diğer veriler gibi yararlı bilgiler içerir. `Content-Type`başlığı, istek gövdesindeki verilerin türünü belirtir ve sunucunun bunları doğru şekilde işlemesine yardımcı olur.

`fetch()` yöntemi sunucuya bir POST isteği göndermelidir; bu isteğin gövdesinde `title` ve `body` alanlarına sahip bir nesne bulunacaktır, tanımlayıcı arka uç tarafından otomatik olarak oluşturulacaktır. Bu isteğin sonucu, arka uç veritabanına eklenen bir nesne olacaktır.

```
const postToAdd = {
  title: "CRUD",
  body: "CRUD is awesome!",
};

const options = {
  method: "POST",
  body: JSON.stringify(postToAdd),
  headers: {
    "Content-Type": "application/json; charset=UTF-8",
  },
};

fetch("<https://jsonplaceholder.typicode.com/posts>", options)
  .then((response) => {
    if (!response.ok) {
      throw new Error(response.status);
    }
    return response.json();
  })
  .then(post => console.log(post))
  .catch(error => console.log(error));
```

Yukarıdaki örnekte biz:

- `posts` kaynağına erişerek bir gönderi oluşturmak için istekte bulunuyoruz, ancak `fetch()` yönteminin `options` yapılandırma nesnesinde HTTP yöntemini `POST` olarak değiştiriyoruz. Bu şekilde, arka uç mevcut bir kaynağı okumak yerine bu koleksiyonda yeni bir kaynak oluşturması gerektiğini bilir.
- HTTP protokolü her şeyi metin olarak ilettiği için istek gövdesi bir dize olmalıdır. Karmaşık veri türleri aktarılırken, `JSON.stringify()` yöntemi kullanılarak bir dizeye dönüştürülmelidir.
- Arka uca aktarılacak veri türünü belirten `Content-Type` başlığını belirtmeyi unutmayın.

Yanıt olarak, her şey yolunda giderse, yeni oluşturulan gönderinin bir JSON gösterimini alacağız, ancak `id` eklenmiş olarak. Tanımlayıcı her nesne için benzersiz olacaktır.

```
{
  "id": 101,
  "title": "CRUD",
  "body": "CRUD is awesome!"
}
```
