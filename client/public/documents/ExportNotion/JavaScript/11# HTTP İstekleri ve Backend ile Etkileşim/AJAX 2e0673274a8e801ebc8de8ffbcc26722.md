# **📌 AJAX Nedir?**

**AJAX (Asynchronous JavaScript and XML)**,

**sayfa yenilenmeden** sunucu ile veri alıp göndermemizi ve gelen veriye göre **arayüzü güncellememizi** sağlar.

📌 Günümüzde:

- XML **kullanılmaz**
- Veri formatı neredeyse her zaman **JSON**’dır
- İsim tarihi bir kalıntıdır

👉 AJAX = **fetch / axios / XMLHttpRequest ile yapılan tüm asenkron istekler**

---

## **🎯 AJAX Ne Sağlar?**

- Sayfa yenilenmez
- Daha hızlı ve akıcı kullanıcı deneyimi
- Kullanıcı işlem yaparken veri arka planda gelir

📌 Örnek:

- “Daha Fazla Yükle” butonu
- Form gönderimi
- Arama sonuçları
- Canlı listeleme

---

# **🔁 AJAX Akış Mantığı (EN ÖNEMLİ KISIM)**

1️⃣ Kullanıcı bir şey yapar

(buton tıklar, sayfa açılır, form gönderir)

2️⃣ JavaScript **fetch** ile HTTP isteği gönderir

3️⃣ Sunucu isteği alır, işler

4️⃣ Sunucu **JSON** veri döner

5️⃣ JavaScript bu veriyi alır

6️⃣ DOM güncellenir (arayüz değişir)

➡️ **Sayfa yenilenmez**

---

# **🧩 Basit AJAX Örneği (fetch)**

### **HTML**

```
<button class="btn">Fetch users</button>
<ul class="user-list"></ul>
```

---

### **JavaScript (AJAX isteği)**

```
const button = document.querySelector(".btn");

button.addEventListener("click", () => {
  fetch("https://jsonplaceholder.typicode.com/users")
    .then(response => response.json())
    .then(users => {
      console.log(users); // backend verisi
    })
    .catch(error => console.log(error));
});
```

📌 Bu bir **AJAX isteğidir**

📌 Sayfa yenilenmez

📌 Veri asenkron gelir

---

# **🖼 Arayüzü Güncelleme (DOM + AJAX)**

Veri geldikten sonra **HTML üretiriz** ve DOM’a ekleriz.

---

### **HTML Üretme Mantığı**

1. map() ile dizi dolaşılır
2. Her kullanıcı için HTML string döndürülür
3. join("") ile birleştirilir
4. insertAdjacentHTML ile eklenir

---

### **Tam Örnek**

```
const fetchUsersBtn = document.querySelector(".btn");
const userList = document.querySelector(".user-list");

fetchUsersBtn.addEventListener("click", () => {
  fetch("https://jsonplaceholder.typicode.com/users")
    .then(response => response.json())
    .then(users => {
      const markup = users
        .map(user => `
          <li>
            <p><b>Name:</b> ${user.name}</p>
            <p><b>Email:</b> ${user.email}</p>
            <p><b>Company:</b> ${user.company.name}</p>
          </li>
        `)
        .join("");

      userList.insertAdjacentHTML("beforeend", markup);
    })
    .catch(error => console.log(error));
});
```

# **🧠 Kodun Daha Temiz Hali (EN İYİ PRATİK)**

### **AJAX isteği ayrı fonksiyon**

```
function fetchUsers() {
  return fetch("https://jsonplaceholder.typicode.com/users")
    .then(res => res.json());
}
```

### **Render ayrı fonksiyon**

```
function renderUsers(users) {
  const markup = users.map(user => `
    <li>${user.name}</li>
  `).join("");

  userList.insertAdjacentHTML("beforeend", markup);
}
```

### **Event**

```
fetchUsersBtn.addEventListener("click", () => {
  fetchUsers()
    .then(renderUsers)
    .catch(console.log);
});
```

✔ Okunabilir

✔ Test edilebilir

✔ Profesyonel

# **⚠️ Yeni Başlayanların En Büyük HATASI**

❌ **Asenkron veriyi senkron kodda kullanmaya çalışmak**

---

### **❌ HATALI KOD**

```
let globalVariable;

fetch("https://jsonplaceholder.typicode.com/users")
  .then(res => res.json())
  .then(users => {
    globalVariable = users;
  });

console.log(globalVariable); // ❌ undefined
```

📌 Neden?

- fetch **asenkron**
- console.log **hemen çalışır**
- Veri henüz gelmemiştir

---

### **✅ DOĞRU YAKLAŞIM**

```
fetch("https://jsonplaceholder.typicode.com/users")
  .then(res => res.json())
  .then(users => {
    console.log(users); // ✅ veri burada
  });
```

📌 **Asenkron veriyi HER ZAMAN**

- .then
- catch
- veya async/await içinde kullan

---

# **🔎 Query Parameters (Sorgu Parametreleri) – AJAX’ta Kullanımı**

Query parametreleri:

- Filtreleme
- Sıralama
- Limit

---

### **📌 URL Yapısı**

```
?key=value&key=value
```

Başlangıç karakteri:

✅ **?**

---

### **Örnek**

```
fetch("https://jsonplaceholder.typicode.com/users?_limit=7&_sort=name")
```

✔ 7 kullanıcı

✔ Ada göre sıralı

---

# **🧰 URLSearchParams (Temiz Kullanım)**

### **Parametreleri nesneyle oluşturma**

```
const params = new URLSearchParams({
  _limit: 5,
  _sort: "name",
});

const url = `https://jsonplaceholder.typicode.com/users?${params}`;
```

📌 Çıktı:

```
_limit=5&_sort=name
```

📌 Avantaj:

- Temiz
- Okunabilir
- Kolay düzenlenir
