# **📌 CRUD Nedir? (Backend ile Veri İşlemleri)**

**CRUD**, backend (sunucu) üzerindeki verilerle yapılan **4 temel işlemi** ifade eder:

| **Harf** | **Anlamı** | **Ne yapar** |
| --- | --- | --- |
| C | Create | Veri oluşturur |
| R | Read | Veri okur |
| U | Update | Veri günceller |
| D | Delete | Veri siler |

Bu işlemler **HTTP metodları** ile yapılır.

---

## **🔹 CRUD ↔ HTTP Metodları**

| **İşlem** | **HTTP Metodu** | **Açıklama** |
| --- | --- | --- |
| Create | **POST** | Yeni veri ekler |
| Read | **GET** | Veri alır |
| Update | **PUT / PATCH** | Var olan veriyi günceller |
| Delete | **DELETE** | Veriyi siler |

# **🔍 READ – Veri Okuma (GET)**

## **✅ Tüm verileri almak**

```
fetch("https://jsonplaceholder.typicode.com/posts")
  .then(res => res.json())
  .then(posts => console.log(posts))
  .catch(error => console.log(error));
```

🔹 Ne olur?

- Tüm postlar (dizi halinde) gelir
- GET varsayılan metottur
- Gövde (body) yoktur

---

## **✅ Tek bir veri almak (ID ile)**

```
const postId = 1;

fetch(`https://jsonplaceholder.typicode.com/posts/${postId}`)
  .then(res => res.json())
  .then(post => console.log(post));
```

📌 URL mantığı:

```
/posts/1
```

> /posts/:id
>

## **❓ Soru (örnek)**

**15 ID’li kitabı almak için doğru URL hangisi?**

✅ **Doğru:**

# **✍️ CREATE – Veri Oluşturma (POST)**

Yeni veri eklemek için **POST** kullanılır.

### **📌 Önemli:**

- Veri **istek gövdesinde (body)** gönderilir
- JSON string olmalıdır
- Content-Type header zorunludur

---

## **✅ Örnek: Yeni post ekleme**

```
const newPost = {
  title: "CRUD",
  body: "CRUD is awesome!"
};

fetch("https://jsonplaceholder.typicode.com/posts", {
  method: "POST",
  headers: {
    "Content-Type": "application/json; charset=UTF-8",
  },
  body: JSON.stringify(newPost),
})
  .then(res => res.json())
  .then(data => console.log(data));
```

📌 Sonuç:

```
{
  "id": 101,
  "title": "CRUD",
  "body": "CRUD is awesome!"
}
```

➡️ id backend tarafından otomatik eklenir

---

## **❓ Soru**

**Yeni veri backend’e nereden gönderilir?**

✅ **Cevap:**

👉 **İstek gövdesinde (body)**

# **✏️ UPDATE – Veri Güncelleme (PUT / PATCH)**

## **PATCH vs PUT farkı**

| **Metot** | **Ne yapar** |
| --- | --- |
| PATCH | Sadece gönderilen alanları değiştirir |
| PUT | Tüm veriyi baştan yazar |

---

## **✅ Örnek: PATCH ile güncelleme**

```
const updatedPost = {
  body: "CRUD is really awesome!"
};

fetch("https://jsonplaceholder.typicode.com/posts/1", {
  method: "PATCH",
  headers: {
    "Content-Type": "application/json; charset=UTF-8",
  },
  body: JSON.stringify(updatedPost),
})
  .then(res => res.json())
  .then(data => console.log(data));
```

📌 Sadece body değişti

📌 Diğer alanlar aynen kaldı

# **🗑 DELETE – Veri Silme**

Silme işlemi için **DELETE** kullanılır.

- Body yok
- Sadece URL yeterli

---

## **✅ Örnek: Veri silme**

```
fetch("https://jsonplaceholder.typicode.com/posts/1", {
  method: "DELETE",
})
  .then(res => res.json())
  .then(data => console.log(data));
```

# **📊 CRUD – Özet Tablo (EN NET HALİ)**

| **İşlem** | **HTTP** | **URL Örneği** | **Body** | **Ne yapar** |
| --- | --- | --- | --- | --- |
| Read (All) | GET | /posts | ❌ | Tüm verileri alır |
| Read (One) | GET | /posts/1 | ❌ | Tek veri alır |
| Create | POST | /posts | ✅ | Yeni veri ekler |
| Update | PATCH | /posts/1 | ✅ | Veriyi günceller |
| Delete | DELETE | /posts/1 | ❌ | Veriyi siler |

---

# **🧠 KISA ÖZET (Sınavlık)**

- CRUD = Create, Read, Update, Delete
- GET → veri alır
- POST → veri ekler
- PATCH → kısmi güncelleme
- PUT → tamamen güncelleme
- DELETE → silme
- Veri **body** içinde JSON olarak gönderilir
- Content-Type: application/json unutulmaz
