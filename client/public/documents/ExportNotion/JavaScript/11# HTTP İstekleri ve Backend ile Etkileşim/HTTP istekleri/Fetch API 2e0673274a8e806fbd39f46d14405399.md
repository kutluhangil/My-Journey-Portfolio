# Fetch API

Fetch API, tarayıcıda yerleşik olarak bulunan ve `window` nesnesi aracılığıyla erişilebilen bir arayüzdür. Sunucudan kaynak göndermenize, almanıza ve işlemenize olanak tanıyan bir dizi özellik ve yöntem sağlar.

`fetch()` yöntemi, sunucuya istekte bulunmak için modern bir arayüz sağlar ve Promisler üzerine inşa edilmiştir.

`fetch(url, seçenekler)`

- `url` - arka uçta alınması, oluşturulması veya değiştirilmesi gereken verinin yolu. **Zorunlu argüman**.
- `options` - istek ayarlarının nesnesi: yöntem, başlıklar, gövde, vb. **Opsiyonel argüman**.

Bir [**JSONPlaceholder API**](https://jsonplaceholder.typicode.com/), çeşitli kaynaklar (kullanıcılar, ürünler, vb.) içeren bir web hizmetidir.

Aşağıdaki örnekte, bir kullanıcı koleksiyonu (`/users` kaynağı) almak için web hizmetimizi sorgulayacağız.

```
fetch("<https://jsonplaceholder.typicode.com/users>")
  .then(yanıt => {
    // Yanıt işleme
  })
  .then(veri => {
    // Veri işleme
  })
  .catch(hata => {
    // Hata işleme
  });
```

`fetch` yöntemi bir Promise döndürür, bu nedenle yanıtı işlemek için çağrısının sonucuna bir `then()` ve `catch()` yöntemleri zinciri ekleriz.

## **Fetch API nedir?**

**Fetch API**, tarayıcıda **sunucuya istek atmak** (veri almak / göndermek) için kullanılan **yerleşik (built-in)** bir JavaScript arayüzüdür.

Yani:

- Ekstra kütüphane kurmana gerek yok
- Tarayıcıda direkt kullanılır
- Promise tabanlıdır (asenkron çalışır)

---

## **fetch() ne yapar?**

```
fetch(url, options)
```

👉 Sunucuya bir **HTTP isteği** gönderir.

### **Parametreler**

### **1️⃣**

### **url**

### **(zorunlu)**

İstediğin kaynağın adresi (endpoint)

```
"https://jsonplaceholder.typicode.com/users"
```

### **2️⃣**

### **options**

### **(opsiyonel)**

İsteğin nasıl yapılacağını belirler:

- method (GET, POST, PUT, DELETE)
- headers
- body (gönderilecek veri)

Basit bir GET isteğinde gerekmez.

---

## **fetch neden Promise döndürür?**

Çünkü:

- Sunucudan veri almak **zaman alır**
- JavaScript donmasın diye bu işlem **asenkron** yapılır

👉 fetch() **hemen sonucu vermez**, bir **Promise** döndürür.

---

## **Temel kullanım mantığı**

```
fetch("https://jsonplaceholder.typicode.com/users")
  .then(response => {
    // Sunucudan gelen cevap (Response objesi)
  })
  .then(data => {
    // Gerçek veriler (JSON)
  })
  .catch(error => {
    // Hata olursa burası çalışır
  });
```

---

## **Akış mantığı (çok önemli)**

### **1️⃣ fetch isteği gönderilir**

```
fetch(url)
```

### **2️⃣ Sunucu cevap verir →**

### **Response**

```
.then(response => response.json())
```

- response **verinin kendisi değildir**
- JSON’a çevrilmesi gerekir

### **3️⃣ JSON verisi alınır**

```
.then(data => {
  console.log(data);
})
```

### **4️⃣ Hata varsa**

```
.catch(error => {
  console.log(error);
})
```

---

## **Gerçek ve net örnek**

```
fetch("https://jsonplaceholder.typicode.com/users")
  .then(response => response.json())
  .then(users => {
    console.log(users); // kullanıcılar dizisi
  })
  .catch(error => {
    console.error("Hata:", error);
  });
```
