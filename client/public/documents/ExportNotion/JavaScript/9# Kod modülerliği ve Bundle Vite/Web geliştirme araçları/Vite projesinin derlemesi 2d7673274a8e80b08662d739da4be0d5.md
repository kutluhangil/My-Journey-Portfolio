# Vite projesinin derlemesi

[Vite](https://vitejs.dev/) (Fransızca "hızlı" anlamına gelir, *"veet"* şeklinde telaffuz edilir) — JavaScript tabanlı web uygulamaları geliştirmek için kullanılan bir proje derleme aracıdır. Modern web standartlarının olanaklarını maksimum düzeyde kullanarak hızlı ve verimli web projeleri geliştirmeyi amaçlar.

**Vite'in Temel Özellikleri**

- **Hızlı geliştirme:**
- Vite, kod düzenlemesinden hemen sonra değişiklikleri anlık olarak görebilmenizi sağlayan hızlı yükleme ve yeniden yükleme hızıyla tanınır. Bu durum, geliştirme sürecini daha verimli hâle getirir.
- **Anında proje oluşturma:**
- Vite ile hazır şablonlar ve hızlı bağımlılık kurulumu sayesinde birkaç saniye içinde yeni bir proje oluşturabilirsiniz.
- **Geniş dil ve teknoloji yelpazesi:**
- Vite; JavaScript, TypeScript, CSS ve Vue.js, React, Svelte gibi çeşitli framework’leri destekler. İhtiyacınıza en uygun olanı seçebilirsiniz.
- **Modüler sistem:**
- Vite, modern ESM (ECMAScript Modules) sistemiyle çalışır ve modülleri yalnızca ihtiyaç duyulduğunda yükleyerek kaynakların verimli kullanımını sağlar.
- **Modülün Sıcak Değiştirilmesi (HMR):**
- Vite, kod değişikliklerinin sayfa yeniden yüklenmeden anında uygulanmasını sağlayan sıcak modül değiştirme (Hot Module Replacement) özelliğini destekler.
- **Eklenti sistemi:**
- Geliştirici, topluluk tarafından oluşturulmuş eklentileri projeye dahil edebilir veya kendi eklentilerini yazarak Vite’in işlevselliğini kolayca genişletebilir.
- **CSS ve CSS ön işleyicilerine yerleşik destek:**
- Vite, CSS dosyalarını otomatik işler ve SASS, LESS gibi CSS ön işleyicilerini destekler.

Vite, sunduğu hız ve kullanım kolaylığı sayesinde front-end geliştiriciler arasında giderek daha popüler hâle gelmektedir. Geliştiricilerin esas önemli konulara odaklanmasına olanak tanır ve etkili, modüler web uygulamaları geliştirmelerini sağlar.
