# Node.js

Web geliştirme için modern araçları kullanabilmek adına bilgisayarınızın işletim sistemine **Node.js** kurmanız gerekmektedir. Node.js, tarayıcı dışında JavaScript çalıştırma ortamı sağlayan, hafif ve verimli bir platformdur.

Node.js, başlangıçta uygulamalar için bir sunucu ortamı olarak geliştirilmiş olsa da, geliştiriciler zamanla yerel görevleri otomatikleştirmeye yardımcı olan araçlar oluşturmak için de kullanmaya başlamıştır. Bu durum, Node.js etrafında zengin bir araç ekosistemi oluşmasını sağlamış ve front-end geliştirme sürecini dönüştürmüştür.

**Kurulum**

En güncel kararlı sürümü (LTS) yüklemek için:

- [Resmi Node.js web sitesine](https://nodejs.org/) gidin.
- İşletim sisteminize uygun olan **LTS** kurulum paketini indirin (Windows, macOS veya Linux).


1. PowerShell'i **Yönetici olarak** çalıştırın.
2. Aşağıdaki komutu girerek gerekli araçları yükleyin:

**Kurulumu Doğrulama**

Kurulum başarılıysa, terminalde node komutu kullanılabilir hâlde olacaktır. Kurulumun doğru yapıldığını kontrol etmek için terminale şu komutu yazın ve Enter tuşuna basın:

`node --version`

Bu komut, yüklenmiş olan Node.js sürümünü gösterecektir. Sürüm numarası sizde farklı olabilir; bu normaldir çünkü Node.js sürekli güncellenmektedir.

## **🟢 Node.js Nedir?**

**Node.js**, JavaScript’i **tarayıcı dışında**, yani **bilgisayarın üzerinde** çalıştırmamızı sağlayan bir çalışma ortamıdır (runtime).

👉 Normalde JavaScript sadece **tarayıcıda** çalışır

👉 Node.js ile JavaScript:

- Terminalde
- Sunucu tarafında
- Geliştirme araçlarında
    
    çalıştırılabilir
    

---

## **🛠️ Node.js Ne İşe Yarar?**

### **1️⃣ Front-end geliştirmede (EN SIK KULLANIM)**

Node.js sayesinde:

- npm / yarn gibi paket yöneticilerini kullanırız
- Kütüphaneleri ve araçları kurarız
- Projeleri build ederiz

Örnek:

```
npm install
npm run dev
npm run build
```

📌 React, Vue, Vite, Webpack, ESLint, Prettier → **hepsi Node.js ister**

---

### **2️⃣ JavaScript ile Sunucu Yazmak**

Node.js ile:

- API yazılabilir
- Backend geliştirilebilir

Örnek:

```
const http = require("http");

http.createServer((req, res) => {
  res.end("Hello from Node.js");
}).listen(3000);
```

📌 Express, NestJS gibi backend framework’leri Node.js kullanır

---

### **3️⃣ Otomasyon ve Araçlar**

Node.js ile:

- Dosya işlemleri yapılır
- Script’ler yazılır
- Testler çalıştırılır

Örnek:

```
npm test
npm run lint
```

---

## **📦 npm Nedir?**

Node.js ile birlikte gelir.

**npm (Node Package Manager)**:

- Kütüphane indirir
- Projeye bağımlılık ekler

Örnek:

```
npm install lodash
npm install basiclightbox
```
