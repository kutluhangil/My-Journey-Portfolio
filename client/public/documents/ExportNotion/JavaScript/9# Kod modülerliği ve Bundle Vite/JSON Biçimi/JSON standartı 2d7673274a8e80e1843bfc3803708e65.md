# JSON standartı

**JSON (JavaScript Object Notation)**, yapılı ve yapılandırılmış verilerin metin biçiminde depolanması ve iletilmesi için kullanılan modern bir formattır. Bu format, verilerin sunucuya gönderilip alınmasında, yerel depolamada saklanmasında vb. işlemlerde kullanılır.

JSON’un standart, nesne benzeri sözdizimi oldukça kullanışlıdır. Ancak unutulmamalıdır ki, JSON bir nesne değil; bir nesnenin metinsel temsilidir.

Aşağıda bir JSON dosyası örneği yer almaktadır:

```
{
  "name": "Josh",
  "weight": 175,
  "age": 30,
  "eyecolor": "brown",
  "isHappy": true,
  "cars": ["Chevy", "Honda"],
  "favoriteBook": {
    "title": "The Last Kingdom",
    "author": "Bernard Cornwell",
    "rating": 8.38
  }
}
```

JSON sözdizimi, JavaScript nesnelerine benzese de bazı önemli farklar içerir:

- Anahtarlar her zaman çift tırnak (`"`) içinde olmalıdır.
- Dizi içindeki metin değerleri de çift tırnak içinde yazılmalıdır.
- Sayılar tam sayı veya ondalıklı olabilir; negatif değerler desteklenir.
- `true`, `false` ve `null` gibi değerler JavaScript’teki biçimleriyle aynıdır.
- Son özelliğin ardından **virgül konulmaz**.
- Özellik değeri `null` olabilir, ancak `undefined` kabul edilmez.
- JSON içinde **fonksiyonlar saklanamaz**; çünkü JSON yalnızca veri taşımak için tasarlanmıştır.

JSON yalnızca şu veri tiplerini destekler:

- number
- string
- boolean
- null
- array
- object

Geçerli bir **JSON** örneği şu şekilde olmalıdır ✅

```
{
  "username": "Jacob",
  "age": 32
}
```

### **Neden bu geçerli?**

- ✔ Anahtarlar **çift tırnak** içinde ("username", "age")
- ✔ Son özellikten sonra **virgül yok**
- ✔ Değer tipleri JSON tarafından destekleniyor (string ve number)

### **Neden?**

- **JSON.stringify()**
    - JavaScript içindeki bir **nesneyi, diziyi veya değeri**
    - **JSON formatında bir string’e** dönüştürür.
    - JSON’a veri gönderirken (API, localStorage vb.) kullanılan **doğru ve tek yöntemdir**.

```
const user = {
  username: "Jacob",
  age: 32,
};

const jsonData = JSON.stringify(user);
console.log(jsonData);
// '{"username":"Jacob","age":32}'
```

### 

### **Açıklama:**

JSON.stringify() verilen değeri **JSON formatında bir string’e** dönüştürür.

```
JSON.stringify(32);
```

Sonuç:

```
"32"
```

🔹 Sayı 32, JSON’a çevrilirken **string (dize)** haline gelir.

🔹 Bu yüzden sonuç **Sayı 32 değil**, **“32”** olur.

🔹 undefined yalnızca JSON.stringify(undefined) için geçerlidir.

📌 **Özet:**

JSON.stringify(32) → **“32”** ✅

### **Açıklama:**

JSON.stringify() verilen değeri **JSON formatında bir string (dize)** hâline çevirir.

```
JSON.stringify(true);
```

Sonuç:

```
"true"
```

🔹 true bir **Boolean** değerdir

🔹 JSON’a dönüştürüldüğünde **string** olur

🔹 Bu yüzden sonuç **1** değildir

🔹 **Boolean true** olarak da kalmaz

📌 **Özet:**

- JSON.stringify(true) → **“true”** ✅
