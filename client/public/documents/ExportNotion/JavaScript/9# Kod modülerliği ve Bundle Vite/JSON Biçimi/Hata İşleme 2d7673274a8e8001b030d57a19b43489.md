# Hata İşleme

`JSON.parse` yöntemine geçersiz bir JSON verildiğinde, bir hata oluşur. Bu durumda tüm script çöker; yani yürütme durur ve hatanın oluştuğu satırdan sonraki hiçbir kod çalıştırılmaz.

Buna örnek olarak, karakterlerle dolu geçersiz bir dizeyi ayrıştırma girişimi verilebilir:

```
const data = JSON.parse("Well, this is awkward");
console.log("❌ You won't see this log");
```

Bu tür hatalar, örneğin backend'den gelen geçersiz bir JSON nesnesi ayrıştırılmaya çalışıldığında da meydana gelebilir. Aşağıdaki örnekte, `username` özelliğinde çift tırnak eksiktir:

```
const data = JSON.parse('{username: "Mango"}'); // Error
console.log("❌ You won't see this log");

```

# **Çözüm**

Bu durumu önlemek için `try...catch` yapısı kullanılır. Bu yapı, script’in çalışma sırasında karşılaştığı hataları yakalayıp işlemenizi sağlar.

```
try {
  // Code that may throw a runtime error
} catch (error) {
  // Error handling
}
```

- İlk olarak `try` bloğundaki kod çalıştırılır.
- Hata oluşmazsa, `catch` bloğu atlanır ve normal yürütme devam eder.
- Eğer `try` bloğunda bir hata oluşursa, yürütme durur ve kontrol `catch`bloğuna geçer.

Bu sayede hata oluşsa bile script çalışmaya devam eder:

```
try {
  const data = JSON.parse("Well, this is awkward");
} catch (error) {
  console.log(error.name); // "SyntaxError"
  console.log(error.message); // Unexpected token W in JSON at position 0
}

console.log("✅ This is fine, we handled parsing error in try...catch");
```

`error` değişkeni, oluşan hatayla ilgili bilgileri içeren bir **hata nesnesidir**. Bu nesnenin bazı yararlı özellikleri şunlardır:

- `name`: Hata türü (örneğin `SyntaxError`).
- `message`: Hatanın neyle ilgili olduğuna dair açıklama.
- `stack`: Hatanın oluştuğu sırada işlev çağrılarının izini gösteren bir yığın. Hata ayıklamada kullanılır.

## **🧠 JSON Ayrıştırmada**

## **try...catch Neden Kullanılır?**

### **Amaç**

**JSON.parse() çalışırken hata oluştuğunda uygulamanın çökmesini engellemek** ve bu hatayı kontrollü şekilde yakalayabilmektir.

📌 Çünkü:

- JSON bozuk olabilir
- Eksik tırnak, virgül, yanlış format olabilir
- Bu durumda JSON.parse() **hata fırlatır (throw error)**

Eğer bu hata yakalanmazsa:

❌ Script tamamen durur

❌ Sayfa veya uygulama çalışmayı bırakabili

## **🧪 Örnek**

```
try {
  const data = JSON.parse('{ name: "Mango" }');
  console.log(data);
} catch (error) {
  console.log("JSON hatalı:", error.message);
}
```

🧠 Burada:

- JSON **geçersiz**
- JSON.parse() hata üretir
- catch devreye girer
- Program çalışmaya **devam eder**

---

## **❓ catch Bloğu Ne Zaman Çalışır?**

### **Sadece şu durumda:**

👉 **try bloğu içinde bir hata oluştuğunda**

---

### **Yanlış olanlar:**

❌ try tamamlandıktan sonra her zaman

❌ try bloğunda hata yokken

>

## **📌 JSON + try…catch Özet Notu**

- JSON.parse() **hata fırlatabilir**
- try…catch:
    - hatayı yakalar
    - uygulamanın çökmesini önler
    - kullanıcıya anlamlı mesaj gösterilmesini sağlar
- catch **sadece hata varsa** çalışır
