# Veri Silme

`removeItem(key)` yöntemi, depodan belirtilen `key` değerine sahip mevcut bir kaydı siler. Bu metodun çalışması sonucunda herhangi bir değer döndürülmez.

```
localStorage.setItem("ui-theme", "dark");
console.log(localStorage.getItem("ui-theme")); // "dark"

localStorage.removeItem("ui-theme");
console.log(localStorage.getItem("ui-theme")); // null
```

Saklanan tüm verilerin tamamen silinmesi gerekiyorsa, `clear()` yöntemini çağırmalısın.

```
localStorage.setItem("ui-theme", "light");
localStorage.setItem("notif-level", "mute");

console.log(localStorage);
// Storage {notif-level: 'mute', ui-theme: 'light', length: 2}

localStorage.clear();
console.log(localStorage); // Storage {length: 0}
```

Veritabanının tamamen temizlenmesi işlemi **risklidir**. Bu, projenin diğer geliştiricileri tarafından oluşturulmuş kayıtları da bozabilir.

Bu yüzden yalnızca gerçekten gerekli olmayan kayıtları silmek, tüm veritabanını temizlemeye kıyasla daha güvenli bir yaklaşımdır.

---

## **🗑️ localStorage.removeItem()**

### **Ne işe yarar?**

localStorage içindeki **belirli bir kaydı silmek** için kullanılır.

### **Aldığı argüman:**

```
localStorage.removeItem(key)
```

✅ **Kaldırılacak öğenin anahtarı (key)**

❌ İndeks almaz

❌ Değer almaz

### **Örnek:**

```
localStorage.removeItem("username");
```

➡️ "username" anahtarına ait veri localStorage’dan tamamen silinir.

---

## **🧹 localStorage.clear()**

### **Ne işe yarar?**

localStorage içindeki **tüm verileri tek seferde temizler**.

### **Kullanımı:**

```
localStorage.clear();
```

➡️ Tüm anahtar–değer çiftleri silinir.

---

## **📌 Önemli Fark (Notluk)**

| **Metot** | **Ne yapar** |
| --- | --- |
| removeItem(key) | Sadece **tek bir anahtarı** siler |
| clear() | **Tüm localStorage’ı** temizler |

---

## **🎯 Nerede kullanılır?**

- **Çıkış (logout)** işlemi → clear()
- Sadece tek bir veriyi silmek (tema, ayar vs.) → removeItem(key)
- Kullanıcı ayarlarını sıfırlamak
- Hatalı veya eski verileri temizlemek

---

İstersen bir **login / logout senaryosu** ile örnekleyebilirim 👌

---

## **🔐 Login / Logout Senaryosu (localStorage ile)**

### **🎯 Amaç**

- Kullanıcı giriş yaptığında bilgilerini **localStorage’a kaydetmek**
- Sayfa yenilense bile kullanıcıyı **hatırlamak**
- Çıkış yaptığında tüm bilgileri **temizlemek**

---

## **1️⃣ Login (Giriş Yapma)**

Kullanıcı giriş yaptığında:

```
const user = {
  username: "jacob",
  token: "abc123xyz",
};

// Nesne olduğu için JSON.stringify kullanılır
localStorage.setItem("user", JSON.stringify(user));
```

📌 **Ne oldu?**

- user nesnesi string’e çevrildi
- Tarayıcı kapansa bile saklanır
- Sayfa yenilense bile veri durur

---

## **2️⃣ Sayfa Yüklendiğinde Kullanıcıyı Kontrol Etme**

```
const savedUser = localStorage.getItem("user");

if (savedUser) {
  const parsedUser = JSON.parse(savedUser);
  console.log("Welcome back", parsedUser.username);
} else {
  console.log("User not logged in");
}
```

📌 **Mantık**

- Veri varsa → kullanıcı giriş yapmış
- Veri yoksa → kullanıcı giriş yapmamış

---

## **3️⃣ Logout (Çıkış Yapma)**

### **Seçenek 1: Sadece kullanıcıyı silmek (en yaygın)**

```
localStorage.removeItem("user");
```

📌 Sadece "user" anahtarı silinir

📌 Tema, ayarlar vs. kalabilir

---

### **Seçenek 2: Her şeyi silmek (tam çıkış)**

```
localStorage.clear();
```

📌 Tüm localStorage temizlenir

📌 Genelde **logout** butonunda kullanılır

---

## **🧠 Hangisini Ne Zaman Kullanırım?**

| **Senaryo** | **Kullanılacak Metot** |
| --- | --- |
| Sadece kullanıcıyı sil | removeItem("user") |
| Uygulamayı sıfırla | clear() |
| Tema / ayar sil | removeItem("theme") |
| Tam logout | clear() |

---

## **📝 Kısa Not (Ezberlik)**

> 🔹 localStorage sadece
> 
> 
> **string**
> 

> 🔹 Nesne / dizi → JSON.stringify()
> 

> 🔹 Okurken → JSON.parse()
> 

> 🔹 Tek kayıt sil → removeItem()
> 

> 🔹 Her şeyi sil → clear()
