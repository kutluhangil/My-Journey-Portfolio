# Vaka: Mesaj Formu

Mesaj girişi için bir form oluşturalım.

```
<form class="feedback-form">
  <textarea name="message"></textarea>
  <button type="submit">Send feedback</button>
</form>
```

Form gönderildiğinde, metin alanının değerini konsola yazdıracağız ve formu temizleyeceğiz:

```jsx
const form = document.querySelector(".feedback-form");

form.addEventListener("submit", evt => {
  evt.preventDefault();
	console.log(evt.target.elements.message.value);
  form.reset();
});
```

# **Sorun**

Kullanıcı metin kutusuna bir ileti girdi ve formu göndermeden sayfayı yeniden yüklediğinde, girilen ileti kaybolur.

# **Çözüm**

Sayfa yeniden yüklendiğinde girilen iletinin kaybolmaması için, metin kutusundaki değeri **yerel depoda (localStorage)** saklayacağız.

```jsx
const form = document.querySelector(".feedback-form");
const localStorageKey = "goit-example-message";

form.addEventListener("input", (evt) => {
  localStorage.setItem(localStorageKey, evt.target.value);
});

form.addEventListener("submit", (evt) => {
  evt.preventDefault();
	console.log(evt.target.elements.message.value);
  form.reset();
});
```

Her seferinde, alanın değeri değiştiğinde (yani "input" olayı gerçekleştiğinde):

- Olayı form üzerinden dinleriz,
- `evt.target.value` ile mevcut değeri alır,
- `localStorage.setItem` ile saklarız.

**Temizleme**

Form gönderildiğinde, `removeItem` yöntemiyle saklanan değeri silmemiz gerekir:

```jsx
const form = document.querySelector(".feedback-form");
const localStorageKey = "goit-example-message";

form.addEventListener("input", (evt) => {
  localStorage.setItem(localStorageKey, evt.target.value);
});

form.addEventListener("submit", (evt) => {
  evt.preventDefault();
	console.log(evt.target.elements.message.value);
  localStorage.removeItem(localStorageKey);
  form.reset();
});
```

**Sayfa Yüklenirken Mesajı Geri Yükleme**

Son olarak, sayfa yüklendiğinde yerel depodaki mesajı okuyup metin alanının başlangıç değeri olarak ayarlamalıyız:

```jsx
const form = document.querySelector(".feedback-form");
const textarea = form.elements.message;
const localStorageKey = "goit-example-message";

textarea.value = localStorage.getItem(localStorageKey) ?? "";

form.addEventListener("input", (evt) => {
  localStorage.setItem(localStorageKey, evt.target.value);
});

form.addEventListener("submit", (evt) => {
  evt.preventDefault();
	console.log(evt.target.elements.message.value);
  localStorage.removeItem(localStorageKey);
  form.reset();
});
```

Metin alanının değerini değiştirerek sayfayı yeniden yüklerseniz, henüz hiçbir şey yazmamış olsanız bile aynı metni görebilirsiniz.
