# find() Metodu

`filter(callback)` yönteminin tüm koşulları karşılayan tüm öğeleri bulmak için kullanıldığını biliyorsun zaten.

`find(callback)` yöntemi, koşulu sağlayan ilk öğeyi bulmanıza ve döndürmenize olanak tanır, ardından dizi üzerinde dolaşım durur. Yani, `filter(callback)`yönteminden farklı olarak, **ilk eşleşmeye kadar** arar.

```
array.find((element, index, array) => {
// callback fonksiyonun gövdesi
});
```

- Orijinal diziyi değiştirmez
- Orijinal diziyi eleman eleman dolaşır
- Koşulu sağlayan ilk elemanı döndürür, yani bir geri arama `true` döndüğünde
- Hiçbir eleman koşulu karşılamazsa, yani tüm elemanlar için geri arama `false`döndürürse, yöntem `undefined` döndürür

`find()` yöntemi, tek bir görev için kullanılır - koşulu sağlayan ilk öğeyi bulma. Örneğin, kullanıcıyı e-postaya göre arama, arabayı seri numarasına göre arama, kitabı başlığa göre arama vb.

```
const colorPickerOptions = [
  { label: "red", color: "#F44336" },
  { label: "green", color: "#4CAF50" },
  { label: "blue", color: "#2196F3" },
  { label: "pink", color: "#E91E63" },
  { label: "indigo", color: "#3F51B5" },
];

colorPickerOptions.find((option) => option.label === "blue"); // { label: "blue", color: "#2196F3" }
colorPickerOptions.find((option) => option.label === "pink"); // { label: "pink", color: "#E91E63" }
colorPickerOptions.find((option) => option.label === "white"); // undefined
```

# **Görev**

`find()` yöntemini kullanarak, kodu aşağıdaki şekilde tamamlayarak:

- `bookWithTitle` değişkeninde, `title` özelliği değeri `BOOK_TITLE` değişkeniyle eşleşen kitabın bir nesnesi oluşturulmalıdır.
- `bookByAuthor` değişkeninde, `author` özelliği değeri `AUTHOR` değişkeniyle eşleşen kitabın bir nesnesi oluşturulmalıdır.

# **Testler**

- `books` değişkeni tanımlanmıştır.
- `books` değişkeninin değeri dizi şeklindedir.
- `BOOK_TITLE` değişkeni tanımlanmıştır.
- `BOOK_TITLE` değişkeninin değeri `"The Dream of a Ridiculous Man"` dizesidir.
- `AUTHOR` değişkeni tanımlanmıştır.
- `AUTHOR` değişkeninin değeri `"Robert Sheckley"` dizesidir.
- `bookWithTitle` değişkeni tanımlanmıştır.
- `bookWithTitle` değişkeninin değeri, yukarıdaki isme sahip kitap nesnesidir `"The Dream of a Ridiculous Man"`.
- `bookByAuthor` değişkeni tanımlanmıştır.
- `bookByAuthor` değişkeninin değeri, yazarı `"Robert Sheckley"` olan kitap nesnesidir.
- `books` dizisini döngüde gezinmek için `find()` yöntemi kullanılmıştır.

### **🔹 Verilen başlangıç kodu:**

```
const books = [
  { title: "The Last Kingdom", author: "Bernard Cornwell", rating: 8.38 },
  { title: "Beside Still Waters", author: "Robert Sheckley", rating: 8.51 },
  { title: "The Tell-Tale Heart", author: "Edgar Allan Poe", rating: 7.75 },
  { title: "Redder Than Blood", author: "Tanith Lee", rating: 7.94 },
];

const BOOK_TITLE = "The Tell-Tale Heart";
const AUTHOR = "Robert Sheckley";

const bookWithTitle = books;
const bookByAuthor = books;
```

---

### **🔹 Yapmamız gereken:**

- find() metodu kullanarak:
    1. BOOK_TITLE ile **aynı başlığa** (title) sahip kitabı bulup bookWithTitle’a atamak.
    2. AUTHOR ile **aynı yazara** (author) sahip kitabı bulup bookByAuthor’a atamak.

---

### **✅ Çözüm:**

```
const books = [
  { title: "The Last Kingdom", author: "Bernard Cornwell", rating: 8.38 },
  { title: "Beside Still Waters", author: "Robert Sheckley", rating: 8.51 },
  { title: "The Tell-Tale Heart", author: "Edgar Allan Poe", rating: 7.75 },
  { title: "Redder Than Blood", author: "Tanith Lee", rating: 7.94 },
];

const BOOK_TITLE = "The Tell-Tale Heart";
const AUTHOR = "Robert Sheckley";

const bookWithTitle = books.find(book => book.title === BOOK_TITLE);
const bookByAuthor = books.find(book => book.author === AUTHOR);

console.log(bookWithTitle);
// { title: "The Tell-Tale Heart", author: "Edgar Allan Poe", rating: 7.75 }

console.log(bookByAuthor);
// { title: "Beside Still Waters", author: "Robert Sheckley", rating: 8.51 }
```

---

### **🔍 Açıklama:**

- **find()** → dizideki her öğe için callback’i çalıştırır.
- Callback **true** döndürdüğü anda aramayı durdurur ve o öğeyi döndürür.
- Eğer hiçbir öğe koşulu sağlamazsa → undefined döndürür.

Yani burada:

```
books.find(book => book.title === BOOK_TITLE);
```

book.title değeri "The Tell-Tale Heart" olan **ilk kitabı** bulur.

Ve:

```
books.find(book => book.author === AUTHOR);
```

book.author değeri "Robert Sheckley" olan **ilk kitabı** bulur.
