# Filtreleme() Metodu

`Filtreleme(callback)` yöntemi, bir dizi üzerinde tek bir işlem için kullanılır- diziye filtreleme yapmak. Diziyi filtrelemekten kasıt, bir koleksiyondaki tüm öğelerin belirli bir kriter üzerinde seçilmesidir.

```
array.filter((element, index, array) => {
// callback fonksiyonun gövdesi
});
```

- Orijinal diziyi değiştirmez.
- Orijinal diziyi eleman eleman gezer.
- Yeni bir dizi döndürür.
- Geri dönen diziye, callback fonksiyonun uygun olan öğeleri ekler.
- Callback fonksiyonu `true` değerini döndürürse, ilgili öğe geri dönen diziye eklenir.
- Callback fonksiyonu `false` değerini döndürürse, ilgili öğe geri dönen diziye eklenmez.
- Herhangi bir öğe koşulu karşılamazsa, boş bir dizi döndürür.

`const values = [51, -3, 27, 21, -68, 42, -37];`

```
const values = [51, -3, 27, 21, -68, 42, -37];

const positiveValues = values.filter(value => value >= 0);
console.log(positiveValues);// [51, 27, 21, 42]// positiveValues işlevin koşulunu sağlayan, yani >= 0 olan values dizisinin tüm öğeleri girmiştir

const negativeValues = values.filter(value => value < 0);
console.log(negativeValues);// [-3, -68, -37]// negativeValues, geriçağırma koşulunu sağlayan, yani <0 olan values dizisinin tüm elemanlarını içerir

const bigValues = values.filter(value => value > 1000);
console.log(bigValues);// []// `negatibigValues eValues`, geriçağırım koşulunu sağlayan yani > 1000 olan values dizisinin tüm elemanlarını içerirconsole.log(values);// [51, -3, 27, 21, -68, 42, -37]// Values'in orijinal dizisi değişmedi.
```

Bu nedenle, `filter` yöntemi, orijinal dizinin her elemanı için bir callback fonksiyonu çağırır. İşlevin çalıştırılması sonucunda `true` dönerse, mevcut eleman yeni diziye eklenir.

---

### **📘 Ne yapar?**

filter() bir dizi üzerinde çalışır ve **belirli bir koşulu sağlayan** elemanları **yeni bir diziye** ekler.

---

### **Ne döndürür?**

- **Yeni bir dizi** döndürür.
    
    (Yani orijinal diziyi değiştirmez.)
    

---

### **Kaç eleman döndürür?**

- **Callback fonksiyonundaki koşula bağlıdır.**
    - Koşulu sağlayan elemanlar → yeni diziye eklenir
    - Sağlamayanlar → atlanır
    - Sonuç olarak 0, 1 veya birçok eleman olabilir.

---

### **Orijinal diziyi değiştirir mi?**

- **Hayır!**
    
    filter() **saf (pure)** bir fonksiyondur.
    
    Yeni bir dizi döndürür, orijinal diziye dokunmaz.
    

---

### **Mini örnek**

```
const numbers = [1, 2, 3, 4, 5];
const even = numbers.filter(n => n % 2 === 0);

console.log(even);     // [2, 4]
console.log(numbers);  // [1, 2, 3, 4, 5] (değişmedi)
```

---

🧠 **Kısaca:**

> filter() → koşulu sağlayan elemanlardan
> 
> 
> **yeni bir dizi**
> 

> orijinali
> 
> 
> **asla değiştirmez.**

# **Görev**

Kodu, `numbers` dizisinden çift sayıların bulunduğu `evenNumbers` dizisini ve tek sayıların bulunduğu `oddNumbers` dizisini elde etmek için tamamla. Kesinlikle `filter()` yöntemini kullan.

# **Testler**

`numbers` değişkeni tanımlandı.

`numbers` değişkeninin değeri `[17, 24, 82, 61, 36, 18, 47, 52, 73]` dizisidir. `evenNumbers` değişkeni tanımlandı.

`evenNumbers` değişkeninin değeri `[24, 82, 36, 18, 52]` dizisidir.

`oddNumbers` değişkeni tanımlandı.

`oddNumbers` değişkeninin değeri `[17, 61, 47, 73]` dizisidir.

`numbers` dizisi için `filter()` yöntemi kullanıldı.

```
const numbers = [17, 24, 82, 61, 36, 18, 47, 52, 73];

const evenNumbers = numbers.filter((number) => number % 2 === 0);
const oddNumbers = numbers.filter((number) => number % 2 !== 0);
```
