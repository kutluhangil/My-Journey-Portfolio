# map() metodu

Çoğu dizi yineleyicisi saf fonksiyonlardır. Yeni bir dizi oluştururlar, her elemanın değerine belirtilen callback fonksiyonunu uygulayarak bu diziyi doldururlar ve ardından bu yeni diziyi döndürürler.

Bir diziyi dönüştürmek için `map(callback)` metodu kullanılır. Orijinal dizinin her elemanı için bir callback fonksiyonu çağrılır ve bu fonksiyonun döndürdüğü sonuçlar, yeni bir diziye yazılır.

```
array.map((element, index, array) => {
// callback fonksiyonun gövdesi
});
```

**Özellikleri:**

- Özgün dizi üzerinde eleman eleman yineleme yapar
- Orijinal diziyi **değiştirmez**
- Callback fonksiyonunun sonucu, yeni bir diziye yazılır
- Uygulandığı diziyle aynı uzunlukta yeni bir dizi döndürür

Bu yöntem, dizinin her bir elemanını dönüştürmek için kullanılabilir. Orijinal dizi, başka bir koleksiyonun temeli olarak referans görevi görür.

```
const planets = ["Earth", "Mars", "Venus", "Jupiter"];

const planetsInUpperCase = planets.map(planet => planet.toUpperCase());
console.log(planetsInUpperCase); // ["EARTH", "MARS", "VENUS", "JUPITER"]

const planetsInLowerCase = planets.map(planet => planet.toLowerCase());
console.log(planetsInLowerCase); // ["earth", "mars", "venus", "jupiter"]

// Orijinal dizi değişmedi
console.log(planets); // ["Earth", "Mars", "Venus", "Jupiter"]
```

Callback fonksiyonu olarak anonim arrow fonksiyonlarının kullanılması, kod kalabalığını ve tekrarı önemli ölçüde azaltarak kodun daha temiz ve okunabilir olmasını sağlar.

# **Görev**

Kodu, `planetsLengths` değişkeni bir dizi gezegen adı içerecek şekilde değiştirin. `map()` metodunu kullandığınızdan emin olun.

# **Testler**

- `planets` değişkeni tanımlanır
- `planets` değişkeninin değeri bir `["Dünya", "Mars", "Venüs", "Jüpiter"]`dizisidir.
- `planetsLengths` değişkeni şöyle tanımlanır
- `planetsLengths` değişkeninin değeri bir `[5, 4, 5, 7]` dizisidir.
- Bir gezegen dizisi üzerinde yineleme yapmak için `map()` yöntemini kullanın

```
const planets = ["Earth", "Mars", "Venus", "Jupiter"];

const planetsLengths = planets.map((planet) => planet.length);
```

### **🧠 Açıklama adım adım:**

1. map() metodu, bir dizinin **her elemanını işler** ve işlenen değerlerle **yeni bir dizi döndürür**.
2. Burada planet her döngüde "Earth", "Mars", "Venus", "Jupiter" olur.
3. planet.length ifadesi her gezegen adının harf sayısını verir:
    - "Earth" → 5
    - "Mars" → 4
    - "Venus" → 5
    - "Jupiter" → 7
4. map() bunları toplayıp yeni bir dizi döndürür:
    
    👉 [5, 4, 5, 7]
