# some() metodu

`some(callback)` yöntemi, **en azından bir öğe**nin callback fonksiyonun koşulunu karşılayıp karşılamadığını kontrol eder.

```
array.some((element, index, array) => {
// callback fonksiyonun gövdesi
});
```

- Orijinal diziyi değiştirmez
- Orijinal diziyi eleman eleman dolaşır
- Koşulu karşılayan en az bir dizi elemanı varsa `true` döndürür
- Hiçbir dizi elemanının koşulu karşılamadığı durumda `false` döndürür
- Callback fonksiyonu `true` döndürdüğünde dizi dolaşımı durdurulur.

```
// En az bir elemanın değeri sıfırdan büyük veya eşit mi? - evet
[1, 2, 3, 4, 5].some(value => value >= 0); // true

// En az bir elemanın değeri sıfırdan büyük veya eşit mi? - evet
[-7, -20, 3, -10, -14].some(value => value >= 0); // true

// En az bir elemanın değeri sıfırdan küçük mü? - hayır
[1, 2, 3, 4, 5].some(value => value < 0); // false

// En az bir elemanın değeri sıfırdan küçük mü? - evet
[1, 2, 3, -10, 4, 5].some(value => value < 0); // true
```

```
every yöntemi ilesome yöntemi arasındaki farka dikkat edin:
every() yöntemi, tüm öğelerin belirli koşulu gerçekleştirip gerçekleştirmediğini kontrol eder.
some() yöntemi, en az bir öğenin belirli bir koşulu karşılayıp karşılamadığını kontrol eder.
```

# **Testler**

- Belirtilen `users` dizisini dolaşmak için `some()` yöntemi kullanılmıştır.
- Belirtilen kullanıcı dizisi ile fonksiyon çağrısı `true` değerini döndürür.
- Rastgele ancak geçerli argümanlarla yapılan fonksiyon çağrısı doğru sonucu döndürür.

---

### **🔹 Hatırlatma — some() ne yapar?**

some() metodu, bir dizideki **en az bir** eleman koşulu sağlıyorsa true,

hiçbiri sağlamıyorsa false döndürür.

Yani:

- **“Bir tane bile aktif kullanıcı varsa → true”**
- **“Hiç aktif yoksa → false”**

---

### **✅ Çözüm:**

```
const isAnyUserActive = (users) => users.some(user => user.isActive);
```

---

### **🔍 Açıklama:**

- users.some(...) → her bir kullanıcıyı (user) sırayla kontrol eder.
- user.isActive → eğer kullanıcı aktifse true döner.
- some() → **ilk true bulduğu anda durur** ve sonucu döndürür.
- Eğer hiç isActive: true yoksa → false döner.

---

### **🧠 Örnek test:**

```
const users = [
  { name: "Moore Hensley", isActive: false },
  { name: "Sharlene Bush", isActive: true },
  { name: "Ross Vazquez", isActive: false },
];

console.log(isAnyUserActive(users)); // true
```

Çünkü dizide **en az bir kullanıcı aktif (Sharlene Bush)**.

---

### **💡 Özet:**

| **Metot** | **Ne kontrol eder** | **Döndürdüğü** |
| --- | --- | --- |
| every() | Tüm elemanlar koşulu sağlıyor mu? | true / false |
| some() | En az bir eleman koşulu sağlıyor mu? | true / false |
