# every() metodu

`her(callback)` yöntemi, **tüm öğelerin** callback fonksiyonun koşulunu karşılayıp karşılamadığını kontrol eder.

```
array.every((element, index, array) => {
// callback fonksiyonun gövdesi
});
```

- Orijinal diziyi değiştirmez
- Orijinal diziyi öğe bazında işler
- Dizi içindeki tüm öğelerin koşulu karşıladığı durumda `true` döndürür
- Dizi içinde en az bir öğenin koşulu karşılamadığı durumda `false` döndürür
- Callback fonksiyonu `false` döndürdüğünde dizi üzerinde işlem sonlandırılır.

```
// Tüm öğeler sıfırdan büyük veya eşit mi? - evet
[1, 2, 3, 4, 5].every((value) => value >= 0);// true// Tüm öğeler sıfırdan büyük veya eşit mi? - hayır
[1, 2, 3, -10, 4, 5].every((value) => value >= 0);// false
```

Bir nesne dizisiyle çalışırken belirli bir özellik değerini kontrol edilir. Örneğin, ürün nesnelerinin bir dizisini dolaşırken, tüm ürünlerin stokta olup olmadığını kontrol edebiliriz.

```
const products = [
	{ name: "apple", quantity: 2 },
	{ name: "orange", quantity: 5 },
	{ name: "plum", quantity: 0 },
];

const hasEveryProduct = products.every(product => product.quantity > 0);
console.log(hasEveryProduct); // false
```

# **Testler**

- `isEveryUserActive` adlı değişken tanımlanmıştır
- `isEveryUserActive` değişkenine bir parametre olan ok işlev atanmıştır `(users)`
- `users` parametresini döngüye sokmak için `every()` yöntemi kullanılmıştır
- Belirtilen kullanıcı dizisi ile işlev çağrısı `false` döndürür
- Geçerli ancak rastgele argümanlarla işlev çağrısı doğru değeri döndürür

---

### **🔹 Adım adım mantığı:**

- every() metodu, dizideki her elemanı kontrol eder.
- Callback fonksiyonu **her eleman için true dönerse**, sonuç **true** olur.
- Eğer **tek bir eleman bile false dönerse**, sonuç **false** olur.

---

### **✅ Çözüm:**

```
const isEveryUserActive = (users) => users.every(user => user.isActive);
```

---

### **🔍 Açıklama:**

- users.every(...) → users dizisindeki her kullanıcıyı sırayla kontrol eder.
- user.isActive → kullanıcı aktif mi değil mi kontrol eder.
- Eğer **bütün** kullanıcıların isActive değeri true ise → sonuç true.
- Eğer **bir tanesi bile** false ise → sonuç false.

---

### **🧠 Örnek test:**

```
const users = [
  { name: "Moore Hensley", isActive: false },
  { name: "Sharlene Bush", isActive: true },
  { name: "Ross Vazquez", isActive: false },
];

console.log(isEveryUserActive(users)); // false
```

Çünkü tüm kullanıcılar aktif değil (isActive: false olanlar var).

---

### **💡 Kısaca:**

> 🔸 every() — tüm elemanlar koşulu sağlıyorsa true,
> 

> 🔸 aksi halde false döndürür.
> 

Bu yüzden isEveryUserActive = users.every(user => user.isActive) doğru çözümdür ✅
