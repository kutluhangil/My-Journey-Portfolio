# reduce() metodu

`reduce(callback, initialValue)` yöntemi, her bir dizi öğesinin sırayla işlenmesi ve ara sonucun korunması için kullanılır. Diğer yöntemlere kıyasla biraz daha karmaşıktır ancak sonuç buna değer.

```
array.reduce((previousValue, element, index, array) => {
// callback fonksiyonun gövdesi
}, initialValue);
```

- Orijinal diziyi değiştirmez
- Orijinal diziyi eleman eleman dolaşır
- Ne olursa olsun (nesne, dizi, dize, sayı vs.) döndürür
- Herhangi bir diğer dizi metodu işlevini veya hatta onların kombinasyonunu değiştirebilir

`reduce()` yöntemi 2 parametre alır:

1. Parametre (zorunlu) - callback fonksiyonu, dizinin her elemanını işler;
2. Parametre (zorunlu değil) - `initialValue` biriktirmek için başlangıç değeri.

Callback fonksiyonu, fonksiyondan parametre olarak sırasıyla dört parametre bekler. Bu parametreler, diğer dizi metotlarının callback fonksiyonlarında olduğu gibi belirtilmeyebilir, ama sıraları bozulmamalıdır:

1. Parametre (`previousValue`) - birikimci, yani ara sonuç. Geri çağırma fonksiyonunun geçerli iterasyonda döndüreceği değer, bir sonraki iterasyonda bu parametrenin değeri olacaktır;
2. Parametre - dizinin geçerli elemanı;
3. Parametre - geçerli iterasyonun dizini;
4. Parametre - orijinal dizinin referansı.

En basit olarak, bir dizi elemanlarının toplamını hesaplama örneği üzerinden çalışmasını hayal etmek en kolaydır.

```
const total = [2, 7, 3].reduce((previousValue, number) => {
  return previousValue + number;
}, 0);

console.log(total);// 12
```

Yukarıdaki örnekte `reduce()` işlevini daha detaylı inceleyelim:

- Birikimci için ilk değer 0'dır.
- Callback fonksiyonun işlevindeki ilk iterasyon 0 + 2'yi döndürecektir, yani 2.
- İkinci callback fonksiyonunda ikinci iterasyon 2 + 7'yi döndürecektir, yani 9.
- Üçüncü callback fonksiyonundaki üçüncü iterasyon 9 + 3'ü döndürecektir, yani 12.

Yukarıdaki kodun çıktısı 12 olacaktır.

Yani `reduce()` yöntemi, "çok şeyi" alıp "bir şeye" dönüştürmek gerektiğinde kullanılır. Günlük görevlerde, genellikle sayılarla çalışmaya indirgenir.

## **🧩 Bir örnek düşünelim:**

Bir alışveriş sepetin var:

```
const prices = [10, 20, 30];
```

Hepsinin toplamını bulmak istiyorsun.

Bunu reduce() ile şöyle yaparsın 👇

```
const total = prices.reduce((previousValue, currentValue) => {
  return previousValue + currentValue;
}, 0);

console.log(total); // 60
```

---

## **💡 Ne oluyor burada?**

| **Aşama** | **previousValue** | **currentValue** | **Sonuç** |
| --- | --- | --- | --- |
| 1. | 0 | 10 | 10 |
| 2. | 10 | 20 | 30 |
| 3. | 30 | 30 | 60 |

Yani:

0 + 10 → 10

10 + 20 → 30

30 + 30 → 60

Sonuç olarak → **60** döner. ✅

---

## **🧮 reduce() nasıl çalışıyor?**

### **Söz dizimi:**

```
array.reduce((previousValue, currentValue, index, array) => {
  // her turda yapılacak işlem
}, initialValue);
```

- previousValue → birikmiş değer (örneğin toplam)
- currentValue → şu an işlenen eleman
- initialValue → başlangıç değeri (mesela 0)

---

## **🧱 Başka örnekler**

### **1️⃣ En büyük sayıyı bul:**

```
const numbers = [5, 12, 8, 130, 44];

const max = numbers.reduce((prev, current) => {
  return current > prev ? current : prev;
}, 0);

console.log(max); // 130
```

---

### **2️⃣ Bir dizideki tüm kelimeleri tek cümlede birleştir:**

```
const words = ["Hello", "world", "this", "is", "reduce"];

const sentence = words.reduce((acc, word) => acc + " " + word);
console.log(sentence); // "Hello world this is reduce"
```

---

### **3️⃣ Nesnelerin toplam fiyatını bul:**

```
const cart = [
  { item: "Book", price: 10 },
  { item: "Pen", price: 5 },
  { item: "Bag", price: 50 }
];

const total = cart.reduce((sum, product) => sum + product.price, 0);

console.log(total); // 65
```

# **Görev**

Oyun hizmetine, bir oyuncunun oyunlarda geçirdiği ortalama süreyi hesaplama işlevselliği eklenmesi gerekmektedir.

`players` değişkeninde, anahtar - oyuncu adı ve değer - oyun süresi olan bir nesne saklanmaktadır.

`playtimes` değişkeninde, `players` nesnesinin değerlerinin bir dizisi saklanmakta, yani tüm oyuncuların oyun süresi dizisi bulunmaktadır.

`averagePlayTime` değişkeninin değeri, bir oyuncunun oyunlarda geçirdiği ortalama süre olacaktır.

Kodu böyle tamamla ki `totalPlayTime` değişkeninde `playtimes` dizisindeki toplam oyun süresi elde edilsin. `reduce()` yöntemini kullan.

# **Testler**

- `players` değişkeni tanımlanmıştır
- `players` değişkeninin değeri - her oyuncunun oyun süresi olan bir nesne
- `playtimes` değişkeni tanımlanmıştır
- `playtimes` değişkeninin değeri - `[1270, 468, 710, 244]` dizisidir
- `totalPlayTime` değişkeni tanımlanmıştır
- `totalPlayTime` değişkeninin değeri - `2692` sayısıdır
- `playtimes` dizisini döngüde gezinmek için `reduce()` yöntemi kullanılmaktadır
- `averagePlayTime` değişkeni tanımlanmıştır

Harika 👍

Bu görevde bizden istenen şey şu:

1️⃣ Oyuncuların oyun süreleri (players nesnesinde tutuluyor) var.

2️⃣ Bu değerleri alıyoruz (Object.values() ile).

3️⃣ reduce() kullanarak **toplam oyun süresini** bulacağız.

4️⃣ Sonra ortalamayı hesaplayacağız.

---

### **✅ Çözüm:**

```
const players = {
  mango: 1270,
  poly: 468,
  ajax: 710,
  kiwi: 244,
};

const playtimes = Object.values(players); // [1270, 468, 710, 244]

const totalPlayTime = playtimes.reduce((total, time) => total + time, 0);

const averagePlayTime = totalPlayTime / playtimes.length;
```

---

### **🔍 Açıklama:**

- Object.values(players)
    
    → { mango: 1270, ... } nesnesinin **sadece değerlerini** alır.
    
    → Sonuç: [1270, 468, 710, 244]
    
- reduce((total, time) => total + time, 0)
    
    → 0’dan başlar, her elemanı toplar:
    
    → 0 + 1270 + 468 + 710 + 244 = 2692
    
- averagePlayTime = 2692 / 4 = 673

---

### **🧠 Sonuçlar:**

| **Değişken** | **Değer** |
| --- | --- |
| playtimes | [1270, 468, 710, 244] |
| totalPlayTime | 2692 |
| averagePlayTime | 673 |

---

### **💡 Özet:**

> reduce() burada tüm oyun sürelerini toplamak için kullanıldı.
> 

> Ardından toplamı eleman sayısına bölerek ortalamayı bulduk.
> 

Yani reduce sayesinde kolayca dizinin **toplam değerini** çıkarabildik ✅
