# Callback

Anonim ok fonksiyonları, özellikle fonksiyon gövdesindeki kod uzun değilse, daha kısa bildirim sözdizimi nedeniyle dizi callback fonksiyonlar için mükemmeldir.

```
const numbers = [5, 10, 15, 20, 25];

// Anonim (anonymous) fonksiyon
numbers.forEach(function (number, index) {
  console.log(`Index ${index}, value ${number}`);
});

// Arrow anonim fonksiyon
numbers.forEach((number, index) => {
  console.log(`Index ${index}, value ${number}`);
});
```

Ayrıca bir callback fonksiyonunu ayrı olarak tanımlayabilir ve ona bir referans iletebilirsiniz. Bunu, tek bir fonksiyon programın çeşitli yerlerinde kullanılıyorsa veya kullanışsızsa yapmalısınız.

```
const numbers = [5, 10, 15, 20, 25];

const logMessage = (number, index) => {
  console.log(`Index ${index}, value ${number}`);
};

numbers.forEach(logMessage);
```
