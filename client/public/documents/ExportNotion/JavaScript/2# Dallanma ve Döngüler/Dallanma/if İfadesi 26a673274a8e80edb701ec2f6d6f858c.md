# if İfadesi

Online kütüphaneden kitap indirmeyi mümkün kılan bir çevrimiçi hizmet hayal et.

Ziyaretçiler hizmetten ücretsiz yararlanabilirler (İndirme hızında kısıtlamayla). Bir kişi sınırsız kitap indirmek istiyorsa, yıllık 100$'a "pro" aboneliği satın almalıdır.

Bu, bir abonelik gerekliliğinin bulunduğu ve farklı indirme seçeneklerinin (kısıtlı veya sınırsız) gelecek senaryoların dallanmasını oluşturduğu basit bir dallanma örneğidir.

**Dallanmalar,** bir koşula bağlı olarak farklı kodların yürütülmesi için kullanılır.

# **if İfadesi**

`if` ifadesi, belirli bir koşulun **doğru** (yani `true`) olarak değerlendirilmesi durumunda, yalnızca o koşula bağlı bir kod bloğunun çalıştırılmasını sağlar.

`if` ifadesinin genel sözdizimi şöyle görünür:

`if (condition) {
  // Koşul (condition) doğru ise çalıştırılan kod
}`

Yorumlayıcı (`interpreter`) bir `if` ifadesiyle karşılaştığında, parantez içinde belirtilen koşulu (`condition`) değerlendirir ve bunu mantıksal (boolean) bir tipe dönüştürür.

Eğer bu koşul `true` olarak değerlendirilirse, süslü parantez `{ }` içinde yer alan kod bloğu çalıştırılır.

Koşul `false` olarak değerlendirilirse, bu kod bloğu atlanır ve program `if` ifadesinden sonraki satırdan devam eder.

![](https://s3.eu-north-1.amazonaws.com/lms.goit.files/e379b509-6138-43b2-b010-199161f68fc4Frame%2048583%20%281%29.jpg)

Aşağıdaki örneklerde kod, `subscription` değişkeninin değerini kontrol eder ve buna bağlı olarak `price` değişkeninin değerini günceller.

Eğer koşul `true`'ya dönüşürse yani `subscription` `"pro"` ise, `price` değeri `100` olarak ayarlanır.

`let price = 0*;*
const subscription = "pro"*;*

if (subscription === "pro") {
  price = 100*;*
}

console.log(price)*; // 100*`

Eğer koşul `false` olarak değişirse, süslü parantezler içindeki kod çalıştırılmayacak ve `price` `0` olarak kalacaktır.

`let price = 0*;*
const subscription = "free"*;*

if (subscription === "pro") {
  price = 100*;*
}

console.log(price)*; // 0*`

`checkAge(age)` işlevinin kodunu, parametre olarak verilen `age` değerinin `18`'den büyük veya eşit olup olmadığını kontrol ederek, bu değerin 18 veya daha büyük olması durumunda `"You are an adult"` dizesini döndürecek şekilde tamamlayın.

`age` değerini kontrol etmek için işlev gövdesinde `if`ifadesini kullanın.

- `checkAge(age)` işlevi tanımlanmalıdır.
- `checkAge(20)` çağırısı `"You are an adult"` dizesini döndürmelidir.
- `checkAge(17)` çağrısı `undefined` değerini döndürmelidir.
- `checkAge(10)` çağrısı `undefined` değerini döndürmelidir.
- `checkAge(30)` çağırısı `"You are an adult"` dizesini döndürmelidir.
- Rastgele ancak geçerli argümanlarla yapılan bir işlev çağrısı doğru değeri döndürmelidir.
