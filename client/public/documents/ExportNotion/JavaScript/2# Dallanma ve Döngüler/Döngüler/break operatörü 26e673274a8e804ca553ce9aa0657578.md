# break operatörü

`break` operatörü, bir döngüyü sonlandırmak için kullanılır. Bir döngü içinde `break` operatörüyle karşılaşıldığında, döngünün derhal yürütülmesi durdurulur ve kontrol döngünün sonrasındaki bir sonraki talimata aktarılır.

`break` operatörü genellikle döngü içinde belirli bir koşulu kontrol etmek ve eğer koşul sağlanıyorsa döngünün yürütümünü durdurmak için koşullu operatörler veya karşılaştırma operatörleri ile birlikte kullanılır.

İşte `for` döngüsünde `break` operatörünün kullanımına dair bir örnek:

`for (let i = 0; i < 10; i+=1) {
  console.log(i);

  if (i === 5) {
    console.log('Met the number 5, interrupt the execution of the cycle');
    break;
  }
}

console.log('Log after cycle');`

Bu örnekte, `for` döngüsü değişken `i`'nin `10`'dan küçük olduğu sürece çalışmalıdır. Ancak döngüde `if (i === 5)` koşulu yer alır; bu, `i` değerinin 5'e eşit olup olmadığını kontrol eder. Bu koşul doğru olduğunda, `if` bloğu çalışır ve `break` operatörü uygulanarak döngü sonlandırılır. Sonuç olarak, konsola 0'dan 5'e kadar olan sayılar (5 dahil) yazdırılacak ve döngü sona erecektir.

---

Bir döngü (for, while) aslında bir **tekrar makinesi** gibidir.

Mesela:

👉 “0’dan başlayarak 9’a kadar sayıları sırayla yazdır.”

Bu iş için bir döngü kullanırız. Normalde, bu döngü 0’dan 9’a kadar gider.

Ama bazen, “Eğer şu sayı gelirse daha fazla devam etme!” demek isteriz.

İşte **break operatörü** tam olarak bunu yapar.

---

📌 Örneğe bakalım:

```
for (let i = 0; i < 10; i += 1) {
  console.log(i);

  if (i === 5) {
    console.log('Met the number 5, interrupt the execution of the cycle');
    break;
  }
}

console.log('Log after cycle');
```

🔎 Adım adım:

1. Döngü başlar → i = 0
    
    Konsola **0** yazılır.
    
2. i = 1 → konsola **1** yazılır.
3. i = 2 → konsola **2** yazılır.
4. i = 3 → konsola **3** yazılır.
5. i = 4 → konsola **4** yazılır.
6. i = 5 → konsola **5** yazılır.
    - Bu sırada if (i === 5) koşulu **doğru** olur.
    - İçindeki break çalışır ve döngü hemen **durur** ❌

---

✅ Sonuç konsola şunu yazdırır:

```
0
1
2
3
4
5
Met the number 5, interrupt the execution of the cycle
Log after cycle
```

Yani:

- **break** → döngüyü durdurur.
- Döngüden sonra gelen kod çalışmaya devam eder.

---

👉 Kısaca:

Döngü “0’dan 9’a kadar devam et” diye ayarlanmış olsa da, break geldiği anda “Yeter artık, burada dur!” diyerek döngüyü **erken bitirir**.

# **Görev**

Kodu, `start` ile `end` arasındaki ilk `5`'e bölünebilen sayıyı `number` değişkenine atacak şekilde tamamlayın.

# **Testler**

- `start` değişkeni tanımlıdır.
- `end` değişkeni tanımlıdır.
- `number` değişkeni tanımlıdır.
- Eğer `start` değeri `6` ve `end` değeri `17` ise, `number` değişkeninin değeri `10` olmalıdır.
- Eğer `start` değeri `17` ve `end` değeri `24` ise, `number` değişkeninin değeri `20` olmalıdır.
- Eğer `start` değeri `8` ve `end` değeri `11` ise, `number` değişkeninin değeri `10` olmalıdır.
- Döngüde `for`, döngünün tüm iterasyonları tamamlanmadan çıkmak için `break` kullanılır.
- 

`const start = 6;
const end = 17;
let number;`

`for (let i = start; i <= end; i++) {
if (i % 5 === 0) {
number = i;
break; // İlk 5’e tam bölüneni bulunca döngüden çık
}
}`

`console.log(number); // 10`
