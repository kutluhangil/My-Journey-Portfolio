# while Döngüsü

# **Döngü**

Programlama alanındaki tipik görevler - tekrarlayan bir işlemi çok kez gerçekleştirmektir; örneğin, müşterileri tek tek bir listeden görüntülemek veya maaş toplamlarını dolaşmak ve her biri için aynı kodu çalıştırmak. Tekrarlanan bir kod parçasının bir bölümünü çok kez yürütmek için döngüler kullanılır.

- **Döngü** -bir dizi talimatın tekrar tekrar yürütülmesini sağlayan bir kontrol yapısıdır.
- **Döngünün gövdesi** - tekrarlanan yürütme için tasarlanmış talimat dizisi.
- **İterasyon** - döngünün tek bir yürütümü.
- **Çıkış koşulu** - bir sonraki yürütümün gerçekleşip gerçekleşmeyeceğini veya döngünün sona erip ermediğini belirleyen bir ifade.

**`while` Döngüsü**

`while` yapısı, çıkış koşulu değeri `true` olarak değerlendirildiği sürece döngüdeki kod bloğunu yürütür.

![](https://s3.eu-north-1.amazonaws.com/lms.goit.files/4823e6e4-88ca-4495-b32f-4b182e68ebbaFrame%2048590.jpg)

`while (condition) {
  statement *// kod, döngü gövdesi*
}`

- Her döngü iterasyonundan önce koşul hesaplanır.
- Eğer koşul `true` olarak değerlendirilirse, döngü gövdesindeki kod çalıştırılır (bir iterasyon).
- Eğer koşul `false` olarak değerlendirilirse, döngü durdurulur ve betik döngüden sonra gelen talimatları çalıştırmaya devam eder.

**`while` Döngüsü** — Bu, bir önkoşula sahip bir döngüdür; döngü başlamadan önce belirtilen önkoşul doğru olduğu sürece çalışır. Bu koşul döngü gövdesini çalıştırmadan önce kontrol edilir, bu nedenle koşul baştan beri yanlışsa, gövde hiçbir zaman çalıştırılmayabilir.

Sayac ile bir örnek inceleyelim:

`let count = 0;

while (count < 10) {
  console.log(`Count: ${count}`);
  count += 1;
}`

Bu örnekte, her yürütmede artan `count` değişkenimiz var.

`while` döngüsü, `count` değeri 10'dan küçük olduğu sürece çalışmaya devam eder. `count` 10'a eşit veya daha büyük olduğunda, koşul `false` olur ve döngü sona erer.

# **Görev: Otel Kaydı**

`clientCounter` değişkeni şu anda dolu olan odaların sayısını tutar.

`maxClients` değişkeni oteldeki toplam oda sayısını belirtir.

`while` döngüsü sayesinde oteldeki yerler, mevcut müşteri sayısı maksimum değere ulaşana kadar dolacaktır.

`let clientCounter = 18;
const maxClients = 25;

while (clientCounter < maxClients) {
  console.log(clientCounter);
  clientCounter += 1;
}`

`while` döngüsü genellikle önceden bilinmeyen tam sayıda tekrarlar gerektiğinde kullanılır. Bu nedenle, döngü belirli bir koşul karşılanana kadar devam etmelidir.

```
while döngüsünde koşuluneninde sonunda yanlış olacak şekilde tasarlanması önemlidir; aksi takdirde döngü sonsuza kadar devam edebilir (sonsuz döngü).
```

---

## **1. Döngü Nedir?**

- **Döngü**: Belirli bir koşul sağlandığı sürece aynı kodu tekrar tekrar çalıştıran yapıdır.
- **Döngü gövdesi**: Her tekrarda (iterasyonda) çalışan kod bloğu.
- **İterasyon**: Döngünün bir kez çalıştırılması.
- **Çıkış koşulu**: Döngünün devam edip etmeyeceğini belirleyen ifade.

---

## **2. while Döngüsü**

```
while (koşul) {
  // döngü gövdesi
}
```

- Döngü **her çalıştırmadan önce** koşulu kontrol eder.
- Eğer koşul true ise, gövde çalışır.
- Eğer koşul false olursa, döngü durur.
- Koşul baştan false ise, gövde **hiç çalışmaz**.

---

## **3. Sayac (Counter) Örneği**

```
let count = 0;

while (count < 10) {
  console.log(`Count: ${count}`);
  count += 1;
}
```

- Başlangıçta count = 0.
- Koşul: count < 10 → doğru olduğu sürece çalışır.
- Her çalışmada count bir artırılır.
- count 10 olunca koşul false olur ve döngü biter.

👉 Konsolda **0’dan 9’a kadar** sayılar yazdırılır.

---

## **4. Otel Kaydı Örneği**

```
let clientCounter = 18;
const maxClients = 25;

while (clientCounter < maxClients) {
  console.log(clientCounter);
  clientCounter += 1;
}
```

- Başlangıç: 18 müşteri.
- Maksimum kapasite: 25 oda.
- Koşul: clientCounter < maxClients → doğruysa yeni müşteri ekleniyor.
- Her seferinde clientCounter 1 artıyor.
- clientCounter 25 olunca koşul yanlış olur ve döngü biter.

👉 Yani döngü sayesinde otelde **25’e ulaşana kadar** yeni müşteri ekleniyor.

---

## **5. Sonsuz Döngü Uyarısı**

- Eğer koşul **hiç false olmayacak şekilde** yazılırsa, döngü sonsuza kadar çalışır → buna **sonsuz döngü** denir.
- Örneğin:

```
while (true) {
  console.log("Bu asla durmaz!");
}
```

Bu yüzden her while döngüsünde koşulun **eninde sonunda yanlış olacağından emin olmak** gerekir.

---

✅ **Kısacası:**

- while, koşul true olduğu sürece çalışır.
- Genelde tekrar sayısı önceden bilinmediğinde tercih edilir.
- Doğru koşul yazılmazsa sonsuz döngü oluşabilir.

# **Öyleydi**

`calculateTotal(number)` adında bir işlev yazın. Bu işlev, bir tamsayıyı (parametre `number`) alır ve 1'den bu sayıya kadar olan tüm tamsayıların toplamını döndürür. Örneğin, eğer `number` `3`'e eşitse, toplam şöyle olacaktır: `1 + 2 + 3`, yani `6`.

# **Olacak**

`calculateTotal(number)` fonksiyonu, bir tam sayı parametresi olan `number`'ı alır.

Fonksiyonun kodunu, parametrenin belirtilen sayıya kadar olan tüm tam sayıların toplamını döndürecek şekilde tamamlayın. Örneğin, eğer `number`'ın değeri `3` ise, toplamı hesaplanacak olan ifade `1 + 2 + 3` şeklinde olmalı ve sonuç `6` olmalıdır.

`function calculateTotal(number) {
}`

`function calculateTotal(number) {
  let count = 1;
  let total = 0;

  while (count <= number) {
    total += count;
    count += 1;
  }

  return total;
}`
