# Materyaller

**Mantıksal tip dönüşümü**, herhangi bir veri türündeki bir değerin Boolean (`true` veya `false`) değerine dönüştürülmesi anlamına gelir. Bir değerin `true` ya da `false` olarak değerlendirilip değerlendirilmeyeceğini belirleyen bazı kurallar vardır.

Bu kurallar, hem `Boolean()` fonksiyonu kullanılarak yapılan **açık (explicit) tür dönüşümleri** için hem de `if` yapıları veya mantıksal operatörlerde gerçekleşen **örtük (implicit) tür dönüşümleri** için geçerlidir.

1. `true` ve `false` mantıksal değerleri değişmeden kalır.

`console.log(Boolean(true)); *// true*console.log(Boolean(false)); *// false*`

2. `0` sayısı, `NaN`, `null` ve `undefined` değerleri her zaman `false` değerine dönüştürülür, diğer tüm sayılar `true` değerine dönüştürülür.

`console.log(Boolean(NaN)); *// false*console.log(Boolean(null)); *// false*console.log(Boolean(undefined)); *// false*console.log(Boolean(0)); *// false*console.log(Boolean(3.14)); *// true*console.log(Boolean(-10)); *// true*`

3. Aşağıdaki örneklerde, if komutu koşulundaki değerler false olarak ayarlanır ve else bloğundaki kod çalıştırılır.

`if(null) {
	console.log("if bloğu")
} else {
	console.log("else bloğu")
}

if(0) {
	console.log("if bloğu")
} else {
	console.log("else bloğu")
}`

Aşağıdaki örneklerde, `if` komutunun koşulundaki değer `true` olarak ayarlanır ve `if` bloğundaki kod çalıştırılır.

`if(5) {
	console.log("if bloğu")
} else {
	console.log("else bloğu")
}`

3. Boş bir dize (`""`) `false`'a dönüştürülür, boş olmayan diğer tüm dizeler `true`'ya dönüştürülür.

`console.log(Boolean("")); *// false*console.log(Boolean("hello")); *// true*console.log(Boolean("false")); *// true*`

Aşağıdaki örnekte, `if` komutunun koşulundaki boş dize `false` olarak ayarlanır ve `else` bloğundaki kod çalıştırılır.

`if("") {
	console.log("if bloğu")
} else {
	console.log("else bloğu")
}`

Aşağıdaki örnekte, `if` komutunun koşulundaki "`batman`" dizesi `true` olarak ayarlanır ve `if` bloğundaki kod çalıştırılır.

`if("batman") {
	console.log("if bloğu")
} else {
	console.log("else bloğu")
}`
