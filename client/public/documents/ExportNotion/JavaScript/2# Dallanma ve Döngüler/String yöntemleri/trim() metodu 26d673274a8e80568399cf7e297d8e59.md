# trim() metodu

`trim()` metodu, bir dizeden baştaki ve sondaki boşlukları kaldırmak için kullanılır.

Bu, örneğin kullanıcı girdisini form öğelerine işlerken, yanlışlıkla eklenebilecek gereksiz boşlukları kaldırarak dizeyi gereksiz boşluklardan "temizlemenizi" sağlar.

Sözdizimi:

`str.trim()`

Örnek:

`const input = " JavaScript is awesome!    ";
const trimmedInput = input.trim();
console.log(trimmedInput); *// "JavaScript is awesome!"*
console.log(input); *// " JavaScript is awesome!    "*`

Bu örnekte, `trim()` metodu dizenin başındaki ve sonundaki boşlukları kaldırır ve sonuç olarak `"JavaScript is awesome!"` içeriğine sahip yeni bir dize döndürülür.

```
Dikkat edin!trim() metodu orijinal dizeyi değiştirmez, ancak başında ve sonunda boşluk olmayan yeni bir dize döndürür.
```

# **Örnek**

Fonksiyon tam dosya adını `ext` parametresinde belirtilen ek uzantıyla birlikte `isim.uzantı` biçiminde döndürmelidir. Ayrıca, tam dosya adı başında veya sonunda fazladan boşluk içermemelidir.

`createFileName(name, ext)` işlevi iki parametre alır:

- `ext` — uzantısı bir dize biçiminde, örneğin `"txt"`, `"xml"`, vb.
- `name` — kullanıcının girdiği, satırın başında ve sonunda fazladan boşluklar bulunan, uzantısı olmayan bir dosya adı, örneğin, `"order"`, `"finance"`, vb.

`createFileName(name, ext)` işlevi iki parametre alır:

- `name` — kullanıcının girdiği uzantısız dosya adı, satırın başında ve sonunda olası ekstra boşluklarla birlikte, örneğin `"order"`, `"finance"`, vb.
- `ext` — uzantısı bir dize biçiminde, örneğin `"txt"`, `"xml"`, vb.

Fonksiyon kodunu, tam dosya adını `ext` parametresinde belirtilen uzantıyla birlikte `isim.uzantı` biçiminde döndürecek şekilde değiştirin. Ayrıca, tam dosya adı başında veya sonunda fazladan boşluk içermemelidir. Dosya adıyla bir dize oluşturmak için şablon dize sözdizimini kullanın.

`function createFileName(name, ext) {
  return `${name.trim()}.${ext}`;
}`

```
function createFileName(name, ext) {
  // name'in başındaki ve sonundaki boşlukları temizle
  const cleanName = name.trim();

  // şablon dizesi ile dosya adını ve uzantıyı birleştir
  return `${cleanName}.${ext}`;
}
```

📌 Burada önemli olan iki şey var:

1. **trim()** → baştaki ve sondaki boşlukları siliyor.
    - " order ".trim() → "order"
    - " presentation".trim() → "presentation"
2. **Şablon dizesi (template string)** → ${} ile string birleştirmeyi çok kolaylaştırıyor.
