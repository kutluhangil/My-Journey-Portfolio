# includes() metodu

`includes()` dize metodu, bir dizede bir alt dizenin bulunup bulunmadığını kontrol etmek için kullanılır. Alt dize bulunursa `true`, alt dize yoksa `false` boolean değerini döndürür.

`includes()` metodu sözdizimi aşağıdaki gibidir:

`str.includes(substring)`

Nerede?:

- `str` — içinde bir alt dize aradığımız orijinal dize;
- `substring` — kaynak dizede bulmak istediğimiz alt dize.

`includes()` metodu kullanımına bir örnek:

`const username = 'Jacob Mercer';

console.log(username.includes('Jacob')); *// true*console.log(username.includes('John')); *// false*console.log(username.includes('Mercer')); *// true*console.log(username.includes('Doe')); *// false*`

Bir dize ve alt dizedeki karakterlerin büyük/küçük **harf durumu önemlidir.** Örneğin `a` harfi, `A` harfine eşit değildir.

`const username = 'Jacob Mercer';

console.log(username.includes('Jacob')); *// true*console.log(username.includes('jacob')); *// false*console.log(username.includes('Mercer')); *// true*console.log(username.includes('mercer')); *// false*`

`includes()` metodu, dize belirli bir alt dizeyi içeriyorsa belirtilen eylemleri gerçekleştirmemiz gerektiğinde kullanışlıdır.

`const message = "Please buy our stuff!"*;*
const hasSpam = message.includes("buy")*;*

if (hasSpam) {
  console.log("Warning: This message contains forbidden words.")*;*
} else {
  console.log("You can safely open this message.")*;*
}`

Bu örnekte, `message` değişkeninin `"buy"` alt dizesini içerip içermediğini kontrol ediyoruz.

```
Bu durumda, mesajın yasak kelimeler içerdiğine dair bir uyarı görüntülenir. Aksi takdirde, mesajın güvenle açılabileceği belirtilir.
```

ÖRNEK:

`checkForName(fullName, firstName)` fonksiyonu iki parametre almalıdır ve `firstName` alt dizesinin `fullName` dizesine dahil edilip edilmediğini kontrol etmenin sonucu olarak bir boolean `true` veya `false`döndürmelidir.

- `fullName` - tam adı içeren bir dizedir
- `firstName` - tam adın içinde bulunup bulunmadığını kontrol etmek için kullanılan bir dizedir

Fonksiyonun kodunu tamamlayarak, adın (parametre `firstName`) tam ad (parametre `fullName`) içinde olup olmadığını kontrol eden ve sonucunu döndüren kodu yazın. `fullName` ve `firstName`parametrelerinde karakterlerin büyük/küçük harfe duyarlı olmadığını unutmayın.

- `checkForName(fullname, firstName)` fonksiyonu tanımlanmalıdır.
- `checkForName("Jason Neis", "Jason")` işlevinin çağrılması, `true`değerini döndürmelidir.
- `checkForName("Jason Neis", "jAsOn")` işlevinin çağrılması, `true`değerini döndürmelidir.
- `checkForName("Jason Neis", "Jacob")` işlevinin çağrılması, `false`değerini döndürmelidir.
- `checkForName("Caty Stars", "Caty")` işlevinin çağrılması, `true`değerini döndürmelidir.
- `checkForName("Caty Stars", "cAtY")` işlevinin çağrılması, `true`değerini döndürmelidir.
- `checkForName("Caty Stars", "Andromeda")` işlevinin çağrılması, `false`değerini döndürmelidir.
1. Hem fullName hem de firstName küçük harfe (veya büyük harfe) dönüştürülmeli → böylece **case-insensitive** (büyük/küçük harf duyarsız) kontrol yapılır.
2. includes() metodunu kullanarak firstName’in fullName içinde olup olmadığını kontrol edeceğiz.

---

### **✅ Çözüm**

```
function checkForName(fullName, firstName) {
  return fullName.toLowerCase().includes(firstName.toLowerCase());
}

// Testler
console.log(checkForName("Jason Neis", "Jason"));     // true
console.log(checkForName("Jason Neis", "jAsOn"));     // true
console.log(checkForName("Jason Neis", "Jacob"));     // false
console.log(checkForName("Caty Stars", "Caty"));      // true
console.log(checkForName("Caty Stars", "cAtY"));      // true
console.log(checkForName("Caty Stars", "Andromeda")); // false
```

---

### **📝 Açıklama**

- .toLowerCase() → tüm harfleri küçük yapar, böylece "Jason" ve "jAsOn" aynı hale gelir ("jason").
- .includes() → bir dizenin içinde başka bir dize geçip geçmediğini kontrol eder.
- Sonuç → **true** veya **false** döner.
