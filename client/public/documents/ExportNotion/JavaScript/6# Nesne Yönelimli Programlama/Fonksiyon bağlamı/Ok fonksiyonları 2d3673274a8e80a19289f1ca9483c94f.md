# Ok fonksiyonları

Bir ok fonksiyonunun içindeki bağlam, **çağrıldığı yere göre değil, tanımlandığı yere göre** belirlenir.

Bu, ok fonksiyonu içindeki `this` ifadesinin **bildirildiği üst kapsamın bağlamına atıfta bulunduğu** ve asla değişmediği anlamına gelir.

```
const showThis = () => {
  console.log("this in showThis: ", this);
};

showThis(); // this in showThis: window
```

Bir nesne özelliğine bir ok işlevi referansı atasanız ve bu işlevi o nesnenin bağlamında çağırsanız bile, `this` yine de işlevin tanımlandığı sıradaki bağlama (örneğin global) başvurur.

```
const showThis = () => {
  console.log("this in showThis: ", this);
};

const user = {
  username: "Mango",
};

user.showContext = showThis;

user.showContext(); // this in showThis: window
```

Ok fonksiyonları ayrıca strict modun varlığını da göz ardı eder.

Ok global bir bağlamda tanımlanmışsa, kodun katı modda yürütülüp yürütülmediğine bakılmaksızın, içindeki `this`, `window` öğesine bir referans içerecektir.

```
"use strict";

const showThis = () => {
  console.log("this in showThis: ", this);
};

showThis(); // this in showThis: window
```

Bağlamın ok fonksiyonları için nasıl çalıştığını gösteren bir örneğe göz atalım.

```
const hotel = {
  username: "Resort hotel",
  showThis() {
    const foo = () => {
      console.log("this in foo: ", this);
    };

    foo();
    console.log("this in showThis: ", this);
  },
};

hotel.showThis();
// this in foo: {username: 'Resort hotel', showThis: ƒ}
// this in showThis: {username: 'Resort hotel',showThis: ƒ}
```

`hotel.showThis()` metodunu çağırdığınızda, `foo()` ok fonksiyonu nesnesiz bir global bağlamda çağrılır, ancak içindeki `this` değeri `showThis` metodunun bağlamına (yani `hotel` nesnesine) başvurur. Çünkü `foo`, `showThis` yönteminin içinde tanımlanmıştır ve tanımlandığı anda üst bağlamın `this` referansını "hatırlar".

Bu özellik pratikte her zaman kullanılmasa da, klasik bir mülakat sorusu olarak karşınıza çıkabilir.

**Önemli fark:**

Normal fonksiyonların aksine, bir ok fonksiyonunun içindeki `this` değeri tanımlandıktan sonra **değiştirilemez**. Bu, `call`, `apply` ve `bind` metodlarının ok fonksiyonları üzerinde `this` bağlamını değiştiremeyeceği anlamına gelir.

```
const showThis = () => {
  console.log("this in showThis: ", this);
};

showThis.call({ username: "Mango" }); // this in showThis: window
showThis.apply({ username: "Mango" }); // this in showThis: window

const boundShowThis = showThis.bind({ username: "Mango" });
boundShowThis(); // this in showThis: window
```

JavaScript motorları, **`this`** değeri değiştirilebilen normal fonksiyonların aksine, ok fonksiyonlarını sabit bir bağlamla sınırlandırarak bunları daha iyi optimize edebilir.

**Özet: Ok fonksiyonlarındaki `this` hakkında neleri hatırlamalıyım?**

- `this` bağlamı çağrıldığı yere göre değil, **tanımlandığı yere göre** belirlenir.
- Ok fonksiyonları strict modun varlığını **göz ardı eder**. Global bağlamda `this`her zaman `window` olur.
- Tanımlandıktan sonra ok fonksiyonlarında `this` değeri **değiştirilemez**. `call`, `apply` ve `bind` işe yaramaz.
