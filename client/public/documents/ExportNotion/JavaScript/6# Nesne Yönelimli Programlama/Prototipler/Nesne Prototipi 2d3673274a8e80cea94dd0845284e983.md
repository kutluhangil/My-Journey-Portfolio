# Nesne Prototipi

Dizi metodları `push`, `map`, `reduce` ve diğerleri nereden geliyor?

Neden fonksiyonlarda `call` ve `bind` yöntemleri var?

Şimdiye kadar bunların var olduğunu ve bunları kullanabileceğimizi kabul ettik. Bu soruların cevaplarını bulma zamanı geldi.

Bunların tümü, nesne prototipi miras mekanizması sayesinde mümkün olur. Bu mekanizma, nesneleri zincirler halinde düzenlemeye olanak tanır; böylece bir özelliğin mevcut nesnede bulunamadığı durumda otomatik olarak başka bir nesnede arama yapılır. Diyagram halinde ise şöyle görünüyor:

![Screen Shot 2025-12-24 at 23.45.21 PM.png](Nesne%20Prototipi/Screen_Shot_2025-12-24_at_23.45.21_PM.png)

`[[Prototype]]` adlı özel bir servis özelliği, nesneler arasında otomatik bağlantı sağlamak için önceden belirlenmiş bir rol oynar, açıkça değiştirmemiz gerekmez.

`Object.create(obj)` metodu, `obj` nesnesi ile bağlantılı yeni bir nesne oluşturur ve döndürür. Örnek üzerinden inceleyelim:

```
const animal = {
  legs: 4,
};

const dog = Object.create(animal);
dog.name = "Mango";

console.log(dog); // { name: "Mango", [[Prototype]]: animal }
```

Özellikle, `[[Prototype]]` özelliğine atıfta bulunan nesne **prototip** olarak adlandırılır. Örneğimizde, `animal` nesnesi `dog` nesnesi için bir **prototip** olarak hizmet eder.

![Screen Shot 2025-12-24 at 23.46.06 PM.png](Nesne%20Prototipi/Screen_Shot_2025-12-24_at_23.46.06_PM.png)

```
console.log(dog.name); // "Mango"
console.log(dog.legs); // 4
```

`dog.name` çağrısı açıktır: `dog` nesnesinin `name` özelliğini döndürür. `dog.legs`çağrısında, yorumlayıcı `dog` nesnesinde `legs` özelliğini arar, bulamaz ve `[[Prototype]]` ile ilişkili nesnede aramaya devam eder, yani bu durumda `animal`nesnesinde - yani prototipi olan yerde.

Bu nedenle, prototip - **nesnenin özelliklerinin ve metodlarının yedek deposu,**bunlar aranırken otomatik olarak kullanılır.

## **Object.create(obj) Nedir?**

### **❓ Ne yapar?**

✔️ **Yeni bir nesne oluşturur**

✔️ **Oluşturulan nesnenin prototipi olarak obj’yi ayarlar**

```
const child = Object.create(obj);
```

- child → yeni nesne
- obj → child’ın **prototipi**
- Özellikler **kopyalanmaz**, **prototip zinciriyle devralınır**

---

### **❌ Yanlış Bilinenler**

- Nesneyi **klonlamaz**
- Özellikleri **doğrudan kopyalamaz**
- Prototipsiz nesne **oluşturmaz**


## **💡 Kısa Örnek**

```
const animal = {
  eats: true
};

const dog = Object.create(animal);

dog.eats; // true (prototipten)
```

---

İstersen bunu **prototype chain çizimi** veya **Object.create vs class vs constructor** karşılaştırmasıyla da özetleyebilirim 🤔

`const parent = {
name: "Stacey",
surname: "Moore",
age: 54,
heritage: "Irish",
};`

`const child = Object.create(parent);`

[`child.name](http://child.name/) = "Jason";
child.age = 27;`

Kodu, `parent` nesnesinin `child` değişkenindeki nesne için prototip olacak şekilde değiştirin.

- `parent` değişkeni tanımlanmalıdır.
- `parent` değişkeninin değeri bir nesnedir.
- `child` değişkeni tanımlanmalıdır.
- Değişken `child` değeri bir nesnedir.
- `Object.create()` metodu kullanılmalıdır.
- `parent.hasOwnProperty("surname")` çağrısı `true` değerini döndürmelidir.
- `parent.hasOwnProperty("heritage")` çağrısı `true` değerini döndürmelidir.
- `child.hasOwnProperty("name")` çağrısı `true` değerini döndürmelidir.
- `child.name` ifadesi "Jason" döndürmelidir.
- `child.hasOwnProperty("age")` çağrısı `true` değerini döndürmelidir.
- `child.age` ifadesi `27` döndürmelidir.
- `child.hasOwnProperty("surname")` çağrısı `false` değerini döndürmelidir.
- `child.surname` ifadesi "Moore" döndürmelidir.
- `child.hasOwnProperty("heritage")` çağrısı `false` değerini döndürmelidir.
- `child.heritage` başvurusu "Irish" döndürmelidir.
- `parent.isPrototypeOf(child)` çağrısı `true` değerini döndürmelidir.
