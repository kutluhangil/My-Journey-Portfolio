# Sınıfın İlanı

Nesne literalinin sözdizimi bir nesne oluşturmayı mümkün kılar. Ancak genellikle **aynı özellik setine sahip ancak farklı değerler ve metotlarla** etkileşimde bulunmak için birçok benzer nesne oluşturma ihtiyacı ortaya çıkar. Tüm bunlar programın çalışması sırasında dinamik olarak yapılmalıdır. Bu amaçla sınıflar kullanılır.

Sınıfın ilanı şu sözdizimine sahiptir:

- `class` anahtar kelimesi
- Sınıf adı (*Örnek: User*)
- Şekilli ayraçlar içinde sınıf gövdesi

```
class User{
  // Sınıf yapısı
}
```

```
Sınıflar büyük harfle yazılır ve oluşturulan nesnenin türünü açıkça yansıtan bir isimle adlandırılır.
```
