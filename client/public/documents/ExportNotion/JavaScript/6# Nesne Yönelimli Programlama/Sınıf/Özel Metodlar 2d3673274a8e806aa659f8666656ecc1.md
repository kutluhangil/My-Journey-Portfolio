# Özel Metodlar

Public metodların nasıl çalıştığını zaten biliyorsun. `User` sınıfının özel `#email` özelliği ve halka açık `name` özelliği örneği üzerinden bunu inceleyelim.

```
class User {
  name;
  #email;

  constructor({ name, email }) {
    this.name = name;
    this.#email = email;
  }

// E-posta adresini almak için genel yöntem
  getEmail() {
    return this.#email;
  }

// E-posta adresini değiştirmek için genel bir yöntem
  changeEmail(newEmail) {
    this.#email = newEmail;
  }
}

const mango = new User({
  name: "Mango",
  email: "mango@mail.com",
});

console.log(mango.getEmail()); // "mango@mail.com"
mango.changeEmail("mango@supermail.com");
console.log(mango.getEmail()); // "mango@supermail.com"
```

Bazen sadece e-posta adresini almak veya değiştirmek yeterli değildir, aynı zamanda bunun "dış dünyadan" gizlenmesi gereken belirli eylemleri gerçekleştirmek de gerekebilir.

Örneğin, e-posta adresi her değiştiğinde biçimini doğrulamak gerekebilir.

Bu, özel metodlar kullanılarak yapılabilmektedir. Bir metodun adının başına `#`sembolünü ekleyerek, bu metodun özel hale getirilebileceği belirtilmiş olur.

```
class User {
  name;
  #email;

  constructor({ name, email }) {
    this.name = name;
    this.#email = email;
  }

  // E-posta adresini almak için halka açık yöntem
  getEmail() {
    return this.#email;
  }

  // E-postayı değiştirmek için kullanılan genel yöntem
  changeEmail(newEmail) {
    if (this.#validateEmail(newEmail)) {
      this.#email = newEmail;
    } else {
      console.log('Invalid email format');
    }
  }

  // E-posta adresinin doğrulanması için özel bir yöntem
  #validateEmail(email) {
    return email.includes('@');
  }
}

const mango = new User({
  name: 'Mango',
  email: 'mango@mail.com',
});

// E-postayı değiştirmeye çalışalım
mango.changeEmail('newmail.com'); // "Invalid email format"
mango.changeEmail('new@mail.com');
console.log(mango.getEmail()); // "new@mail.com"

// Dışarıdan özel bir yöntemi doğrudan çağırmak hata ile sonuçlanır
mango.#validateEmail('test'); // Hata

```

Bu örnekte **`#validateEmail`** adlı özel metot, e-postaların doğrulanması için ek mantığı sağlar.

Bu metot sınıf dışından erişilebilir değildir, bu nedenle kullanıcılar (veya diğer geliştiriciler) doğrudan bunu çağıramaz. Onlar sadece doğrulama için özel bir metot kullanan **`changeEmail`** adlı genel metodu kullanabilirler.

Bu şekilde, iç mantığı kapsüllüyoruz ve sınıfın güvenli ve istikrarlı çalışmasını sağlıyoruz.
