# Sınıf Kalıtımı

`extends` anahtar kelimesi, bir sınıfın (alt, türetilmiş) başka bir sınıfın (üst, ana) özelliklerini ve yöntemlerini devralmasını sağlar. Buna sınıf kalıtımı denir.

Bir örneği inceleyelim:

```
class Parent{}

class Child extends Parent{
  // ...
}
```

`class Child extends Parent` ifadesinde, `Child` alt sınıfı `Parent` üst sınıfını miras alır (genişletir).

Bu, genel özellikleri ve yöntemleri grup olarak miras alan bir temel sınıf tanımlayabileceğimiz anlamına gelir. Türetilmiş sınıflar, üst sınıfın özelliklerini ve yöntemlerini miras alırken, kendi benzersiz özelliklerini de ekleyebilir.

![](https://s3.eu-north-1.amazonaws.com/lms.goit.files/3fdd6379-97cc-46d4-bc75-1cc0ab533a2cFrame%2048656.jpg)

Hayal edin, bir uygulamada farklı rollere sahip kullanıcılar var: yönetici, metin yazarı, içerik yöneticisi vb. Her kullanıcı türünün ortak özellikleri vardır (örneğin e-posta ve şifre), ancak aynı zamanda kendine özgü nitelikleri de bulunur.

Her kullanıcı türü için ayrı sınıflar oluşturmak, ortak özelliklerin ve yöntemlerin her sınıfta tekrarlanmasına neden olur. Bu da örneğin bir özelliğin adını değiştirmek gerektiğinde, tüm sınıfları tek tek düzenlemeyi gerektirir ve oldukça zahmetlidir.

Bunun yerine şunları yapabiliriz:

- Ortak özellikleri ve yöntemleri içeren bir `User` sınıfı oluştururuz.
- Ardından her kullanıcı türü için, `User` sınıfını miras alan sınıflar tanımlarız.
- Ortak bir şeyi değiştirmek gerektiğinde, yalnızca `User` sınıfında değişiklik yapmak yeterli olur.

```
class User{
  #email;

  constructor(email) {
    this.#email = email;
  }

  get email() {
    return this.#email;
  }

  set email(newEmail) {
    this.#email = newEmail;
  }
}

class ContentEditor extends User{
	// ContentEditor sınıfı'nın yapısı
}

const editor = new ContentEditor("mango@mail.com");
console.log(editor); // { #email: "mango@mail.com" }
console.log(editor.email); // "mango@mail.com"
```

`ContentEditor` sınıfı, `User` sınıfından hem yapıcı metodu (constructor) hem de `email` özelliğiyle ilgili getter ve setter yöntemlerini miras alır. Böylece, `#email` gibi özel özellikler bile türetilmiş sınıfın bir parçası olur.

Örnek:

Uygulamada, kullanıcıların e-postalarını kara listeye ekleyebilecek bir yönetici sınıfı oluşturulması gereklidir.

- `Admin` sınıfını `User` sınıfından türeyen şekilde tanımlayın.
- `Admin` sınıfına `{BASIC: "basic", SUPERUSER: "superuser"}` değerlerine sahip genel statik bir `role` (erişim seviyesi) özelliği ekleyin.
- `Admin` sınıfını tanımlanmalıdır.
- `Admin` sınıfı `User` sınıfından türetilmelidir.
- `Admin` sınıfı, `role` adlı genel bir statik özellik içermelidir.
- `Admin.role.BASIC` çağrısı `"basic"` dizesini döndürmelidir.
- `Admin.role.SUPERUSER` çağrısı `"superuser"` dizesini döndürmelidir.

Aşağıda **görevde istenenleri birebir karşılayan doğru çözüm** var ✔️

(ayrıca User sınıfındaki **getter/setter hatasını da düzelttim**, yoksa sonsuz döngü olurdu ❗)

---

## **✅ Doğru Çözüm**

```
class User {
  constructor(email) {
    this._email = email;
  }

  get email() {
    return this._email;
  }

  set email(newEmail) {
    this._email = newEmail;
  }
}

class Admin extends User {
  static role = {
    BASIC: "basic",
    SUPERUSER: "superuser",
  };
}
```

---

## **🧪 Beklenen Davranışlar**

```
Admin.role.BASIC;
// "basic"

Admin.role.SUPERUSER;
// "superuser"
```

---

## **📌 Şart Kontrolü**

| **Gereksinim** | **Durum** |
| --- | --- |
| Admin sınıfı tanımlı | ✅ |
| Admin → User’dan türetilmiş | ✅ (extends User) |
| static role özelliği var | ✅ |
| role.BASIC | ✅ "basic" |
| role.SUPERUSER | ✅ "superuser" |
