# Alt Sınıf Metodları

Alt sınıf, üst sınıfın metod ve özelliklerini kullanabilir. Buna ek olarak, yalnızca alt sınıf örneklerine özel yöntemler de tanımlanabilir.

```
// User sınıfının duyurusunun yukarıda olduğunu hayal edelim.

class ContentEditor extends User{
  constructor({ email, posts }) {
    super(email);
    this.posts = posts;
  }

  addPost(post) {
    this.posts.push(post);
  }
}

const editor = new ContentEditor({
	email: "mango@mail.com",
	posts: []
});

console.log(editor); // { #email: "mango@mail.com", posts: [], addPost: f }

editor.addPost("post-1");
editor.addPost("post-2");
console.log(editor.posts); // ['post-1', 'post-2']
```

Bu örnekte ContentEditor sınıfı, User sınıfından kalıtım alıyor.

- `User`, `#email` adlı özel bir özelliğe sahip temel (üst) bir sınıftır.
- `ContentEditor`, `User` sınıfını genişleterek kendine özgü `posts` özelliğini ekler.
- Ayrıca, `ContentEditor` sınıfına ait `addPost` adlı bir metod tanımlanmıştır. Bu metod yalnızca `ContentEditor` örneklerinde kullanılabilir.
