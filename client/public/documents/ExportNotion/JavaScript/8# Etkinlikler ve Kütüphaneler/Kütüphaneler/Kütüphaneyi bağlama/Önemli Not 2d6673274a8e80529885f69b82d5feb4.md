# Önemli Not

Ayrıca, kütüphaneye ait `<script>` etiketine `async` niteliğini eklemeyi unutmayın. Bu, kütüphane dosyasının mümkün olan en kısa sürede yüklenmesini sağlar.

---

## **🔑 Önemli Noktalar**

1. **CDN nedir?**
    
    Kütüphaneyi indirmeden, internet üzerinden doğrudan projeye eklemeyi sağlar.
    
2. **Script sırası önemlidir**
    
    Kütüphane <script> etiketi, **kendi JavaScript dosyandan önce** eklenmelidir.
    
    Aksi halde kütüphane henüz yüklenmeden kullanmaya çalışırsın → hata alırsın.
    
3. **</body> etiketinden önce eklenmeli**
    
    Sayfa içeriği yüklendikten sonra script çalışır, bu da performans için iyidir.
    
4. **Global erişim sağlar**
    
    CDN ile eklenen kütüphaneler window nesnesine eklenir.
    
    Örneğin Lodash → _
    
5. **Dokümantasyon şart**
    
    Her kütüphanenin erişim adı ve kullanımı farklıdır. Resmi dokümana bakmak gerekir.
    

---

## **🧪 Örnek: Lodash CDN ile Kullanımı**

### **HTML Dosyası**

```
<!DOCTYPE html>
<html lang="en">
  <head>
    <meta charset="UTF-8" />
    <title>Lodash Example</title>
  </head>
  <body>
    <h1>Lodash CDN Example</h1>

    <!-- Lodash kütüphanesi -->
    <script
      async
      src="https://cdn.jsdelivr.net/npm/lodash@4.17.21/lodash.min.js">
    </script>

    <!-- Kendi JavaScript dosyan -->
    <script src="script.js"></script>
  </body>
</html>
```

---

### **script.js**

```
// Lodash global olarak "_" ile gelir
const numbers = [4, 2, 8, 6];

console.log(_.sum(numbers));
// 20

console.log(_.shuffle(numbers));
// Örn: [6, 2, 8, 4]
```
