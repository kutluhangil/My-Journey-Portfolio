# Varsayılan değerler

Bir nesne özelliğinin değerini çıkardığınız değişkeni yeniden adlandırırken, aynı zamanda bu değişkene varsayılan bir değer de atayabilirsiniz.

Bunu yapmak için, yeni değişken adından sonra `=` koyarak varsayılan değeri belirtmeniz yeterlidir.

```
const book = {
  title: "The Last Kingdom",
  coverImage:
    "<https://images-na.ssl-images-amazon.com/images/I/51b5YG6Y1rL.jpg>",
};

const {
  title,
  coverImage: bookCoverImage = "<https://via.placeholder.com/640/480>",
} = book;

console.log(title); // "The Last Kingdom"
console.log(bookCoverImage); // "<https://images-na.ssl-images-amazon.com/images/I/51b5YG6Y1rL.jpg>"
```

Eğer nesnede böyle bir özellik varsa, değeri ilgili değişkene atanır.

Aksi takdirde, değişkene belirtilen varsayılan değer atanır.

```
const book = {
  title: "The Dream of a Ridiculous Man",
};

const {
  title,
  coverImage: bookCoverImage = "<https://via.placeholder.com/640/480>",
} = book;

console.log(title); // "The Dream of a Ridiculous Man"
console.log(bookCoverImage); // "<https://via.placeholder.com/640/480>"
```
