# Varsayılan değerler

Dizi elemanlarından daha fazla değişken bildirirseniz, bu değişkenlere `undefined`değeri atanır. Bunu önlemek için varsayılan değerler belirtebilirsiniz.

Sözdizimi, nesnelerdekiyle aynıdır: Değişken adından sonra `=` işareti konularak varsayılan değer belirtilir.

```
const color = [200, 100, 255];
const [ red, green, blue, alfa = 0.3 ] = color;

console.log(rgba(${red}, ${green}, ${blue}, ${alfa})); // “rgba(200, 255, 100, 0.3)"
```
