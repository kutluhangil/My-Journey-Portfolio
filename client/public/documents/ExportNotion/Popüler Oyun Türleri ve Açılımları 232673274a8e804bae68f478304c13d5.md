# Popüler Oyun Türleri ve Açılımları

| **Kısaltma** | **Açılımı** | **Türkçesi / Açıklama** |
| --- | --- | --- |
| **FPS** | First-Person Shooter | Birinci şahıs nişancı. Oyuncu, karakterin gözünden oynar. (Örn: Call of Duty, Counter-Strike) |
| **TPS** | Third-Person Shooter | Üçüncü şahıs nişancı. Oyuncu karakteri dışarıdan görerek oynar. (Örn: GTA, Fortnite) |
| **MOBA** | Multiplayer Online Battle Arena | Çok oyunculu çevrimiçi savaş arenası. Genellikle 5v5 oynanır. (Örn: League of Legends, Dota 2) |
| **MMORPG** | Massively Multiplayer Online Role-Playing Game | Devasa çok oyunculu çevrimiçi rol yapma oyunu. (Örn: World of Warcraft) |
| **RPG** | Role-Playing Game | Rol yapma oyunu. Oyuncu, karakter geliştirir ve hikayeye etki eder. (Örn: The Witcher, Skyrim) |
| **ARPG** | Action Role-Playing Game | Aksiyon rol yapma oyunu. (Örn: Diablo, Path of Exile) |
| **RTS** | Real-Time Strategy | Gerçek zamanlı strateji. (Örn: StarCraft, Age of Empires) |
| **TBS** | Turn-Based Strategy | Sıra tabanlı strateji. (Örn: Civilization serisi) |
| **BR** | Battle Royale | Hayatta kalan son kişi/kazanan takım temelli çok oyunculu oyun. (Örn: PUBG, Fortnite, Apex Legends) |
| **MO** | Multiplayer Online | Çevrimiçi çok oyunculu oyunlar genel kategorisi. |
| **PvP** | Player vs Player | Oyuncuya karşı oyuncu savaşı. |
| **PvE** | Player vs Environment | Oyuncuya karşı yapay zekâ/düşman ortam. |
| **RTT** | Real-Time Tactics | Gerçek zamanlı taktik. RTS’e benzer ama kaynak yönetimi daha azdır. |
| **TBT** | Turn-Based Tactics | Sıra tabanlı taktik oyunlar. (Örn: XCOM) |
| **VN** | Visual Novel | Görsel roman. Daha çok hikâye anlatımına odaklıdır. |
| **SIM** | Simulation | Simülasyon oyunu. Gerçek hayata benzeyen deneyimler sunar. (Örn: The Sims, Microsoft Flight Simulator) |
| **RHY** | Rhythm Game | Ritim oyunu. (Örn: Guitar Hero, Osu!) |
| **METROIDVANIA** | Metroid + Castlevania | Keşif ve yetenek geliştirmeye dayalı 2D oyun türü. (Örn: Hollow Knight) |
| **Roguelike** | - | Her oynanışta rastgele oluşturulmuş bölümler ve kalıcı ölüm içeren oyun türü. (Örn: Hades, Dead Cells) |
| **Idle / Incremental** | - | Oyuncunun çok az etkileşimle kaynak biriktirdiği oyunlar. (Örn: Cookie Clicker) |
| **Sandbox** | - | Açık dünya, özgür etkileşimli oyunlar. (Örn: Minecraft, Terraria) |
