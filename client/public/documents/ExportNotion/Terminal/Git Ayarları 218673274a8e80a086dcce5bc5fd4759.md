# Git Ayarları

Git ile bir proje üzerinde çalışırken, yaptığınız her değişiklik kaydedilir ve bu değişikliğin **kim tarafından yapıldığı** Git tarafından takip edilir. Bu, hem işbirliği hem de geçmişte yapılan değişikliklerin izlenebilirliği açısından çok önemlidir.

Bu nedenle Git'i kullanmaya başlamadan önce **kullanıcı adınızı** ve **e-posta adresinizi** tanımlamanız gerekir.

Bunun için Windows için **Git Bash** veya macOS için **Terminal** uygulamasını açın ve aşağıdaki komutları çalıştırın.

1. Aşağıdaki komutla kullanıcı adını ayarlayın:

`git config --global user.name "your_name"`

Buradaki `"your_name"` kısmına **gerçek adınızı** veya commit geçmişinde görünmesini istediğiniz bir takma adı yazabilirsiniz.

2. Elektronik postayı kurmak için aşağıdaki komutu kullanın:

`git config --global user.email "your_email"`

`"your_email"` yerine **gerçek e-posta adresinizi** yazmalısınız. Bu adres, Git commit'lerinde görünecek ve projede kimlerin hangi değişiklikleri yaptığı kolayca takip edilebilecek.

3. Ayarları aşağıdaki komutlarla kontrol edin:

Yaptığınız ayarların doğru olup olmadığını şu komutlarla kontrol edebilirsiniz

`git config --get user.name

*# ve*

git config --get user.email`

Bu komutlar size daha önce girdiğiniz kullanıcı adı ve e-posta adresini gösterecektir.

Eğer bir hata veya yanlış çıktı görürseniz, sadece ilgili komutu doğru verilerle baştan tekrarlayın.

Artık Git otomatik olarak bu bilgileri her projenizdeki her eyleme ekleyecektir.
