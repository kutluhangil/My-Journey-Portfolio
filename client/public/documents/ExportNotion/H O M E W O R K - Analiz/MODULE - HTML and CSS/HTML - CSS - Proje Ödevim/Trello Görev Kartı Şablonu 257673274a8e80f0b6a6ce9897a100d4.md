# Trello Görev Kartı Şablonu

## **Listeler**

Trello’da 4 temel liste olsun:

1. **Backlog** (Henüz başlamayan tüm görevler)
2. **In Progress** (Üzerinde çalışılan görevler)
3. **Review** (Kod inceleme aşamasındaki görevler)
4. **Done** (Tamamlanan görevler)

---

## **Görev Kartları (Hazır Şablon)**

### **Planlama (Gün 1)**

- Ekip adını belirle
- Team Lead seç
- Scrum Master seç
- Proje materyallerini incele
- Trello panosu oluştur ve ekip üyelerini davet et
- GitHub deposu oluştur (Team Lead)
- Depo linkini mentöre gönder (Team Lead)
- Görev dağılımı yap

---

### **Kodlama & Çalışma (Gün 2–6)**

- Günlük Stand Up toplantısını yap (Scrum Master)
- Her üye görevini Trello’da güncellesin
- Yeni özellik ekle (Frontend – X üye)
- Stil/CSS düzenlemeleri (Frontend – Y üye)
- API entegrasyonu (Backend – X üye)
- Merge request aç (her üye)
- Merge sonrası olası çatışmaları çöz (Team Lead)
- Günlük kısa durum raporu gönder (Team Lead → Mentor)

---

### **Demo Hazırlığı (Gün 7)**

- Projenin ön versiyonunu birleştir
- GitHub Pages’i çalıştır
- Kaynak kod + GitHub Pages linkini mentöre gönder
- Mentor feedback sonrası düzeltmeleri yap
- Roller ve görev açıklamasını mentöre gönder (Team Lead veya Scrum Master)

---

### **Sunum (Gün 8)**

- Son testleri yap (kritik hata var mı kontrol et)
- Final dağıtımı yap (Team Lead)
- Sunum slaytlarını hazırlayın (isteğe bağlı)
- Sunumu 10 dk içinde gerçekleştirin

---
