# CSS Ödev Kabul Kriterleri Kontrol Listesi

## Proje Kriterleri

- [x]  **`«A1»`** Projenin kök dizininde `images` adında bir klasör bulunmalı ve bu klasörde tüm görseller yer almalıdır.
- [x]  **`«A2»`** Projenin kök dizininde bir stil sayfası içeren bir `css` klasörü bulunmalıdır.
- [x]  **`«A3»`** Tüm stil kuralları `css` klasöründe bulunan `styles.css` dosyasına yazılmalıdır.
- [x]  **`«A4»`** Dosya adları büyük harf, boşluk veya harf çevirisi içermemelidir. İsimler yalnızca İngilizce harfler ve kelimelerden oluşmalıdır.
- [x]  **`«A5»`** Kaynak kodu `Prettier` kullanılarak biçimlendirilmiş olmalıdır.
- [x]  **`«A6»`** Tüm görseller ve metin içeriği mizanpajdan doğru bir şekilde alınmış olmalıdır.
- [x]  **`«A7»`** Stil normalleştirici olarak [`modern-normalize`](https://cdnjs.com/libraries/modern-normalize) etkinleştirilmiş olmalıdır.
- [x]  **`«A8»`** Tüm bit eşlem görüntüleri [squoosh](https://squoosh.app/) kullanılarak optimize edilmelidir.
- [x]  **`«A9»`** Kod [guidelines](https://codeguide.co/) ile uyumlu olarak yazılmalıdır.

## İşaretleme Kriterleri

- [x]  **`«B1»`** `Our Portfolio` bölümünün işaretlemesi `index.html` dosyasında yer almalıdır. Tasarımın tüm öğelerinin HTML düzenlemesi tamamlanmış olmalıdır.
- [x]  **`«B2»`** HTML etiketleri, semantik içeriklerine uygun olarak kullanılmalıdır.
- [x]  **`«B3»`** HTML [**validator**](http://validator.w3.org/nu/) aracılığıyla hatasız bir şekilde kontrol edilmelidir.
- [x]  **`«B4»`** Sınıf isimleri açıklayıcı ve başka bir geliştirici tarafından anlaşılabilir olmalıdır.
- [x]  **`«B5»`** Sınıf adları büyük harf, boşluk, transkripsiyon veya etiket adları içermemelidir. İsimler sadece İngilizce harfler ve kelimelerden oluşmalıdır. Bir sınıf adı birden fazla kelime içeriyorsa, kelimeler tire işareti ile ayrılmalıdır.
- [x]  **`«B6»`** `img` etiketlerinin `width` nitelikleri olmalıdır.
- [x]  **`«B7»`** Görüntüler düzenden `jpg` formatında dışa aktarılmalıdır.
- [x]  **`«B8»`** Aynı tip elemanlardan oluşan gruplar `<ul>` listelerinde toplanmalıdır.
- [x]  **`«B9»`** Düzen için gerekli tüm yazı tipleri ve bunların varyasyonları (ağırlık ve kontur) Google Fonts hizmetinden tek bir bağlantı ile bağlanmalıdır. `Raleway` için gerekli ağırlık 700 ve `Roboto` için - 400, 500, 700'dür.

## Tasarım Kriterleri

- [x]  **`«C1»`** Stil oluşturmak için sınıf seçiciler kullanılmalıdır.
- [x]  **`«C2»`** Stiller `!important` içermemelidir.
- [x]  **`«C3»`** Etkileşimli öğeler (butonlar ve bağlantılar), fare ile üzerine gelindiğinde veya klavyeden odaklanıldığında [Stil kılavuzu](https://www.figma.com/file/wuEpGhwCepGCOUw7mZFRac/Web-Studio-(Version-5.0)?type=design&node-id=296641-536&mode=design&t=HqslgV0OjDOknzIj-0)'nda belirtilen etkin duruma sahip olmalıdır (renk değişimi gibi).
- [ ]  **`«С4»`** Başlıktaki kişi metni, üzerine gelindiğinde ve odaklanıldığında renk değiştirmelidir.
- [x]  **`«С5»`** `<body>` öğesinin `font-family` özelliği `Roboto` düzenindeki baskın yazı tipine ayarlanmış olmalıdır.
- [x]  **`«С6»`** `<body>` öğesinin `font-family` listesinin sonunda alternatif yazı tipi seçenekleri ve aile türü (sans serif) belirtilmelidir.
- [x]  **`«С7»`** `Roboto` yazı tipi ailesi sadece `<body>` elemanı için açıkça belirtilmeli, diğer elemanlar bu yazı tipini miras almalıdır.
- [x]  **`«С8»`** `<body>` öğesi, düzen üzerindeki metnin baskın rengini içeren bir `colour` sahip olmalıdır. Metnin geri kalanı bu değeri takip eder veya geçersiz kılabilir.
- [x]  **`«С9»`** Tüm metin öğelerinin yazı tipi boyutu (`font-size` özelliği) düzendeki değerle tamamen aynı olmalıdır.
- [x]  **`«С10»`** Tüm metin öğelerinin satır yüksekliği (`line-height` özelliği) düzendeki değerlerle tam olarak eşleşmeli ve `px` cinsinden değil, bir çarpan olarak belirtilmelidir.
- [x]  **`«С11»`** Tüm öğelerin rengi (`colour` ve `background-colour` özellikleri) düzendeki değerlerle tam olarak eşleşmelidir.
- [x]  **`«С12»`** Tüm metin öğelerinin yazı tipi ağırlığı (`font-weight` özelliği) düzendeki değerlerle tam olarak eşleşmelidir. Yazı tipi ağırlığı, yalnızca düzendeki değer tarayıcıda bu öğe için standart değerden farklıysa açıkça belirtilmelidir.
- [x]  **`«С13»`** Butonlar `cursor` özelliği ile `pointer` değerine ayarlanmalıdır.
- [x]  **`«С14»`** Stiller, tarayıcı tarafından varsayılan olarak ayarlanan özelliklerin değerlerini tekrarlamamalıdır. Örneğin, bağlantıların `cursor: pointer` özelliğine ve paragrafların `font-style: normal` veya `font-weight: 400` özelliğine sahip olması gerekmez.
