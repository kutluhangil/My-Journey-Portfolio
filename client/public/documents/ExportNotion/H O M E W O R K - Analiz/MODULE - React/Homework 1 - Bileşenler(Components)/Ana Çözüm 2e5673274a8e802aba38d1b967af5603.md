# Ana Çözüm

### **1. Hazırlık ve Analiz Aşaması**

İlk olarak bana verdiğin proje klasörüne (

```
goit-react-hw-01
```

) baktım.

- **Ne Gördüm?**: Boş bir Vite + React .  klasöründe sadece temel dosyalar (**App.jsx**, **main.jsx** vb.) vardı.
    
    ```
    src
    ```
    
- **Eksik Olan**: React ödevlerinde genellikle veriler ( vb.) hazır verilir ama projede bunlar yoktu.
    
    ```
    user.json
    ```
    
- **Aksiyon**: Önce bir "Uygulama Planı" (Implementation Plan) hazırladım. Bu, kod yazmaya başlamadan önce ne yapacağımızı önceden görmemizi sağlar. Planımda, önce verileri oluşturmayı, sonra bileşenleri (Profile, FriendList vb.) yazmayı ve en son bunları birleştirmeyi hedefledim.

### **2. Veri Yapılarının Oluşturulması (Mock Data)**

Bileşenleri test edebilmek için elimizde veri olması gerekiyordu.

- **Neden JSON?**: React bileşenlerinin "prop" (özellik) alma mantığını simüle etmek için verileri harici dosyalardan çekmek en doğrusuydu.
- **Ne Yaptım?**:  klasörü içine **userData.json**, **friends.json**, **transactions.json** ve **data.json** dosyalarını oluşturdum. İlk başta standart ödev verilerini (tahmini olarak) koydum. Daha sonra sen gerçek verileri paylaşınca bu dosyaları tam senin istediğin içerikle güncelledim.
    
    ```
    src
    ```
    

### **3. Bileşen Mimarisi (Component Architecture)**

React'in en önemli kuralı "Bileşen Tabanlı" (Component Based) çalışmaktır. Her bir parçayı ayrı bir modül olarak düşündüm.

- **Dosya Düzeni**:  klasörü açtım ve her bileşen için ayrı bir klasör oluşturdum (Örn: ).
    
    ```
    src/components
    ```
    
    ```
    Profile/
    ```
    
- **Neden?**:  ve onun stili olan  yan yana dursun ki, projeyi yönetmek kolay olsun.
    
    ```
    Profile.jsx
    ```
    
    ```
    Profile.module.css
    ```
    

### **A. Profil Bileşeni (`Profile`)**

- **Görevi**: Kullanıcı kartını göstermek.
- **Props**: Bileşene , , ,  ve  verilerini  olarak gönderdim.
    
    ```
    name
    ```
    
    ```
    tag
    ```
    
    ```
    location
    ```
    
    ```
    image
    ```
    
    ```
    stats
    ```
    
    ```
    props
    ```
    
- **Yapısı**: Senin istediğin HTML yapısını (, , , ) birebir uyguladım.
    
    ```
    div
    ```
    
    ```
    img
    ```
    
    ```
    ul
    ```
    
    ```
    li
    ```
    
- **CSS Modülleri**: Stilleri  içine yazdım ve  diyerek dosyaya çektim. Sınıfları  yerine  şeklinde kullandım. Bu sayede bu stiller başka bileşenlerle karışmaz.
    
    ```
    Profile.module.css
    ```
    
    ```
    import styles from './Profile.module.css'
    ```
    
    ```
    className="profile"
    ```
    
    ```
    className={styles.profile}
    ```
    

### **B. Arkadaş Listesi (`FriendList` ve `FriendListItem`)**

Bu görev biraz daha kompleksti çünkü bir liste döngüsü içeriyordu.

1. **`FriendList`**: Bu ana kapsayıcıdır.  dizisini prop olarak alır ve  ile döngüye sokar.
    
    ```
    friends
    ```
    
    ```
    friends.map()
    ```
    
    - **Önemli Detay**: React'te listeleri dönerken her elemana benzersiz bir  (anahtar) vermemiz gerekir (). Bunu yapmazsak React konsolda uyarı verir ve performans düşer.
        
        ```
        key
        ```
        
        ```
        key={friend.id}
        ```
        
2. **`FriendListItem`**: Bu, tek bir arkadaş kartıdır.
    - **Mantık**: Avatar, isim ve online olma durumunu gösterir.
    - **Koşullu Stil (Conditional Styling)**: En can alıcı kısım burasıydı. Arkadaş "Online" ise yeşil, "Offline" ise kırmızı yazı olmalıydı. Bunu  kütüphanesi veya basit bir ternary operatörü ile yapabiliriz. Ben CSS modülünde  ve  sınıfları tanımladım.
        
        ```
        clsx
        ```
        
        ```
        .online
        ```
        
        ```
        .offline
        ```
        
    - **Kod Mantığı**:  diyerek duruma göre doğru sınıfın uygulanmasını sağladım.
        
        ```
        isOnline ? styles.online : styles.offline
        ```
        

### **C. İşlem Geçmişi (`TransactionHistory`)**

Bu bir tablo bileşeniydi.

- **Yapısı**: Standart , , , ,  etiketlerini kullandım.
    
    ```
    table
    ```
    
    ```
    thead
    ```
    
    ```
    tbody
    ```
    
    ```
    tr
    ```
    
    ```
    td
    ```
    
- **Zebra Çizgileri (Striping)**: Tablonun okunaklı olması için satırların bir gri bir beyaz olmasını istedim. Bunu CSS'te  seçicisi ile yaptım. Çift numaralı satırlara farklı renk verdim.
    
    ```
    :nth-child(even)
    ```
    
- **Son Dokunuş**: Sen tablo başlığının koyu renk olmasını istediğinde, CSS dosyasındaki  stilini güncelleyerek arka plan rengini koyu gri/siyah yaptım.
    
    ```
    th
    ```
    

### **4. Entegrasyon (`App.jsx`)**

Tüm bu parçaları birleştirdiğimiz yer ana

```
App.jsx
```

dosyasıdır.

- **İçe Aktarma (Import)**: Önce oluşturduğum tüm bileşenleri ve JSON verilerini import ettim.
- **Kullanım**:
    
    ```
    jsx
    
    <Profile
    name={userData.username}// JSON'dan gelen veriyi prop olarak aktardık
    ...
    />
    <FriendListfriends={friends}/>// Arkadaş dizisini olduğu gibi verdik
    
    ```
    
- Böylece  bileşeni sadece yönetici rolünü üstlendi, çizim işini alt bileşenlere bıraktı.
    
    ```
    App
    ```
    

### **5. Doğrulama ve Test (Verification)**

Kod yazmak yetmez, çalıştığından emin olmak gerekir.

1. **Linting**: Terminalde  çalıştırarak kodun yazım kurallarına (boşluklar, noktalı virgüller, kullanılmayan değişkenler vb.) uygun olup olmadığını kontrol ettim. Hata çıkmadı.
    
    ```
    npm run lint
    ```
    
2. **Görsel Kontrol**: Tarayıcıda projeyi açtım ().
    
    ```
    localhost
    ```
    
    - Profil kartı düzgün görünüyor mu?
    - Arkadaş listesinde Online yazısı yeşil mi?
    - Tablo çizgileri ve başlık rengi doğru mu?
    - Tarayıcı konsolunda (F12) kırmızı bir hata var mı? (Konsol tertemizdi).

### **Özet**

Sıfırdan başladık, eksik verileri tamamladık, bileşenleri modüler bir yapıda (klasör klasör) oluşturduk, CSS modülleri ile stillerin karışmasını önledik ve en son senin verdiğin özel verilerle (Mango, Kiwi vb.) projeyi son haline getirdik. Şu an elinde temiz, genişletilebilir ve kurallara uygun profesyonel bir React projesi var.
