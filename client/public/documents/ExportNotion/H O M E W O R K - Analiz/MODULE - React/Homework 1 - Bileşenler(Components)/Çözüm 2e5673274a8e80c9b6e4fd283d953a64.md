# Çözüm

---

## **1️⃣ GitHub Repo Oluşturduk**

- GitHub’da **boş bir repo** açtın (goit-react-hw-01)
- Amacı: **kodları saklamak ve paylaşmak**

---

## **2️⃣ Repo’yu Bilgisayara Klonladık**

- Repo’yu kendi bilgisayarına indirdin (clone)
- Artık projeyi **VS Code’da** açıp düzenleyebiliyorsun

---

## **3️⃣ Vite + React Projesi Oluşturduk**

- Repo içine **Vite kullanarak React proje yapısını kurduk**
- Bu işlemle:
    - package.json
    - src/
    - index.html
    - vite.config.js
        
        gibi dosyalar oluştu
        
        👉 **Asıl proje burada başladı**
        

---

## **4️⃣ Prettier Kurduk ve Ayarladık**

- VS Code’a **Prettier eklentisini** kurdun
- Default formatter olarak **Prettier** seçtin
- Format on Save açıldı
    
    👉 Kodun artık **otomatik düzgün formatlanıyor**
    

---

## **5️⃣ ESLint Kurulu Olduğunu Kontrol Ettik**

- Vite’in getirdiği **ESLint yapılandırmasını** kullandık
- react/prop-types kuralını kapattık
    
    👉 Kırmızı/sarı uyarılar azaldı
    

---

## **6️⃣ React Bileşenlerini Düzenledik**

- App.jsx, Product.jsx gibi bileşenler oluşturduk
- props kullandın
- export / import mantığını öğrendin
- Dosyaları components/ klasörüne taşıdın

---

## **7️⃣ Hata Aldık → Sorunu Anladık 😄**

- Repo’nun başta **boş olduğunu**
- package.json olmadığı için **Vercel build hatası aldığını** fark ettik

👉 Sonra:

- Proje yapısını **doğru şekilde** oluşturdun
- GitHub’a tekrar pushladın

---

## **8️⃣ Vercel’e Deploy Ettik 🚀**

- GitHub repo’yu Vercel’e bağladın
- Framework: **Vite**
- Build command: npm run build
- Output: dist
- Install command: **boş / npm install**

✅ Deploy başarılı oldu

✅ Sana **canlı bir link** verildi

---

## **9️⃣ Şu Anda Elinde Ne Var?**

✔️ GitHub repo (kodlar)

✔️ Vercel linki (canlı site)

✔️ React + Vite çalışan proje

✔️ Ödev teslimi için gereken **2 link**
