# İlk Adım Açılış

---

## **🎯 BU ÖDEVİN AMACI NE?**

**Anahtar kelime ile görsel arama yapan bir React uygulaması** geliştireceksin.

Kullanıcı:

- Bir kelime yazacak (ör: *cat, nature, car*)
- Arama yapacak
- Uygulama **Unsplash API**’den görselleri çekecek
- Görseller bir galeri halinde gösterilecek
- Bir görsel tıklanınca **modal** açılacak ve büyük hali + detaylar gösterilecek

---

## **🧠 NEDEN UNSPLASH?**

Unsplash:

- Gerçek bir backend API
- Gerçek HTTP istekleri
- **axios + useEffect + state yönetimi** pratiği

Yani bu ödev:

> “Gerçek hayatta API ile çalışan React uygulaması nasıl yapılır?”
> 

> sorusunun cevabı.
>

## **🔑 UNSPLASH KISMI – NE YAPMAN GEREKİYOR?**

### **1️⃣ Unsplash Developer hesabı aç**

👉 https://unsplash.com/developers

- GitHub ile giriş yapabilirsin
- Ücretsiz

---

### **2️⃣ Yeni Application oluştur**

Dashboard’ta:

- **New Application** → Create
- İsim:
    
    👉 *Image Gallery* veya *Photo Search* (fark etmez)
    

⚠️ **Bu zorunlu** – yoksa API çalışmaz

---

### **3️⃣ Access Key al**

Application sayfasında:

- **Keys** sekmesi
- **Access Key** → bunu kopyala

Bu anahtar:

- API’ye “Ben yetkiliyim” demek için
- HTTP isteğine eklenecek

---

### **4️⃣ API Limiti (önemli ama korkma)**

- Ücretsiz planda: **saatte 50 istek**
- Bizim uygulama için yeterli
- Sürekli reload yapma yeter 🙂

---

## **🌐 BACKEND’DEN NE GELİYOR?**

Unsplash arama isteği sonucunda:

- Bir **nesne** gelir
- İçinde:
    - results → resimler dizisi
    - total_pages → sayfalama için

Her resim nesnesinde:

- urls.small → galeri için
- urls.regular → modal için
- user.name → fotoğrafçı
- likes → beğeni sayısı
- description → açıklama

📌 Biz:

- **Listede → small**
- **Modalda → regular** kullanacağız

## **🧠 ÖZETLE MANTIK**

1. Kullanıcı kelime yazar
2. Submit eder
3. axios → Unsplash API’ye istek atar
4. Gelen görseller state’e yazılır
5. Galeri render edilir
6. Görsele tıklanır
7. Modal açılır, detay gösterilir
