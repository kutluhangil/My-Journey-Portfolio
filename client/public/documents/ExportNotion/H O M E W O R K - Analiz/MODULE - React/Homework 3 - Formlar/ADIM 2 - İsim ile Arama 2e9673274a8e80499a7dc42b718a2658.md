---

- Üstte bir **arama inputu** olacak

## **🧠 MANTIK (ÖNCE BUNU ANLA)**

1️⃣ Arama yazısı **state**’te tutulur

2️⃣ SearchBox sadece:

- değeri gösterir
- değişince App’e haber verir
    
    3️⃣ App:
    
- kişileri filtreler
- sonucu ContactList’e gönderir

> 🔑
> 
> 
> **SearchBox filtrelemez, sadece inputtur**
> 

---

## **1️⃣ SearchBox BİLEŞENİNİ OLUŞTURALIM**

### **📁 Klasör yapısı**

```
src/components/SearchBox/
  ├─ SearchBox.jsx
  └─ SearchBox.module.css (şimdilik boş olabilir)
```

---

### **✏️**

### **SearchBox.jsx**

```
export default function SearchBox({ value, onChange }) {
  return (
    <div>
      <p>Find contacts by name</p>
      <input
        type="text"
        value={value}
        onChange={e => onChange(e.target.value)}
      />
    </div>
  );
}
```

📌 Burada önemli olan:

- value → **kontrollü input**
- onChange → App’teki state’i güncelleyecek

---

## **2️⃣ App.jsx İÇİNE FİLTRE STATE’İ EKLEYELİM**

### **🔽 App.jsx’te**

### **useState**

### **altına EKLE**

```
// 2️⃣ Arama filtresi state'i
const [filter, setFilter] = useState("");
```

---

## **3️⃣ KİŞİLERİ FİLTRELE (EN ÖNEMLİ KISIM)**

### **🔽 App.jsx’te, return’dan ÖNCE EKLE**

```
// 3️⃣ Filtrelenmiş kişiler
const filteredContacts = contacts.filter(contact =>
  contact.name.toLowerCase().includes(filter.toLowerCase())
);
```

📌 Burada olan:

- toLowerCase() → **büyük/küçük harf duyarsız**
- includes() → isim içinde arama

---

## **4️⃣ SearchBox’U App.jsx’TE KULLAN**

### **🔽 Import ekle**

```
import SearchBox from "./components/SearchBox/SearchBox";
```

---

### **🔽 JSX içinde,**

### **<ContactList />**

### **’in ÜSTÜNE ekle**

```
<SearchBox value={filter} onChange={setFilter} />
```

---

## **5️⃣ ContactList’E FİLTRELİ LİSTEYİ GÖNDER**

### **❌ ESKİ**

```
<ContactList contacts={contacts} />
```

### **✅ YENİ**

```
<ContactList contacts={filteredContacts} />
```
