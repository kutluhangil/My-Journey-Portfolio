### **1. Proje Kurulumu ve Yapılandırma**

İlk olarak modern bir geliştirme ortamı kurduk.

- **Vite Kullanımı:** Projeyi sıfırdan oluşturmak yerine  kullandık. Vite, yazdığımız kodları tarayıcının anlayacağı hale hızlıca getiren modern bir araçtır.
    
    ```
    Vite
    ```
    
- **Kütüphaneler:** İhtiyacımız olan iki dış kütüphaneyi yükledik:
    - `flatpickr`: Tarih ve saat seçici takvimi oluşturmak için.
    - `izitoast`: Kullanıcıya şık bildirimler (hata veya başarı mesajları) göstermek için.
- **Dosya Düzeni:** Projeyi  (kaynak) klasörü altında düzenledik. HTML, CSS ve JS dosyalarını buraya taşıyarak çalışmayı daha modüler ve düzenli hale getirdik.
    
    ```
    src
    ```
    

### **2. Görev 1: Geri Sayım Sayacı (Countdown Timer)**

Bu görevde amaç, seçilen bir tarihe ne kadar zaman kaldığını canlı olarak göstermekti.

- **HTML Tarafı:** Kullanıcının tarih seçmesi için bir  alanı ve sayacı başlatmak için bir  düğmesi ekledik. Altına da Gün, Saat, Dakika ve Saniye kutucuklarını yerleştirdik.
    
    ```
    input
    ```
    
    ```
    Start
    ```
    
- **JavaScript Mantığı (01-timer.js):**
    1. **Tarih Seçimi (`flatpickr`):**  kütüphanesini  alanına bağladık. **onClose** olayı ile takvim kapandığında seçilen tarihi kontrol ettik.
        
        ```
        flatpickr
        ```
        
        ```
        input
        ```
        
        - *Kontrol:* Eğer geçmiş bir tarih seçildiyse  ile "Gelecek bir tarih seçin" uyarısı verdik ve düğmeyi kilitledik ().
            
            ```
            iziToast.error
            ```
            
            ```
            disabled
            ```
            
        - *Onay:* Gelecek bir tarihse düğmeyi aktif hale getirdik.
    2. **Sayacın Başlatılması:** "Start" düğmesine basıldığında:
        - Düğmeyi ve input'u kilitledik (kullanıcı tekrar basamasın diye).
        - `setInterval` fonksiyonunu kullanarak her 1 saniyede (1000ms) çalışan bir döngü başlattık.
    3. **Zaman Hesabı:** Her saniye şu hesabı yaptık: .
        
        ```
        Seçilen Tarih - Şu Anki Zaman = Kalan Süre (ms)
        ```
        
    4. **Dönüştürme (convertMs):** Kalan milisaniyeyi Gün/Saat/Dakika/Saniye cinsine çeviren hazır fonksiyonu kullandık.
    5. **Arayüzü Güncelleme:** Hesaplanan değerleri ekrana yazdırdık. **addLeadingZero** fonksiyonu ile tek haneli sayıların başına "0" ekledik (örneğin "5" yerine "05" görünmesi için).
    6. **Bitiş:** Kalan süre 0 veya altına düştüğünde  ile sayacı durdurduk.
        
        ```
        clearInterval
        ```
        

### **3. Görev 2: Promise Üreteci (Promise Generator)**

Bu görevde amaç, Asenkron (eşzamansız) programlamanın temeli olan Promise yapısını ve

```
.then()
```

,

```
.catch()
```

bloklarını anlamaktı.

- **HTML Tarafı:** Kullanıcıdan "Gecikme süresi (ms)" alan bir input ve işlemin sonucunu belirleyen (Fulfilled/Rejected) iki radyo düğmesi ekledik.
- **JavaScript Mantığı (02-snackbar.js):**
    1. **Form Dinleme:** Formun gönderilme () olayını dinledik ve sayfanın yenilenmesini engelledik ().
        
        ```
        submit
        ```
        
        ```
        preventDefault
        ```
        
    2. **Promise Oluşturma:** Yeni bir  oluşturduk. Bu Promise'in içine bir  koyduk. Gecikme süresi kullanıcının girdiği değer kadar ayarlandı.
        
        ```
        new Promise
        ```
        
        ```
        setTimeout
        ```
        
    3. **Karar Mekanizması:** Süre dolduğunda:
        - Eğer kullanıcı "Fulfilled" seçtiyse  dedik (Söz tutuldu).
            
            ```
            resolve(gecikme Süresi)
            ```
            
        - Eğer "Rejected" seçtiyse  dedik (Söz reddedildi).
            
            ```
            reject(gecikme Süresi)
            ```
            
    4. **Sonucun İşlenmesi:**
        - `.then()` bloğu: Promise başarılı () olduğunda çalıştı -> Yeşil  bildirimi gösterdik.
            
            ```
            resolve
            ```
            
            ```
            iziToast
            ```
            
        - `.catch()` bloğu: Promise başarısız () olduğunda çalıştı -> Kırmızı  bildirimi gösterdik.
            
            ```
            reject
            ```
            
            ```
            iziToast
            ```
            

### **4. Yayınlama (Deployment)**

Son olarak ödevi GitHub Pages üzerinde canlıya aldık.

- **Sorun:** GitHub Pages normalde sadece statik HTML dosyalarını sunar. Ancak biz  gibi modern modül yapıları kullandığımız için tarayıcılar bunu doğrudan çalıştıramazdı.
    
    ```
    import
    ```
    
- **Çözüm:**  komutu ile projemizi "derledik". Vite, kodlarımızı tüm tarayıcıların anlayacağı tek bir paket haline ( klasörü) getirdi.
    
    ```
    npm run build
    ```
    
    ```
    dist
    ```
    
- **Ayar:** **vite.config.js** dosyası oluşturarak çoklu sayfa ayarlarını yaptık (hem timer hem snackbar sayfasının derlenmesi için).
- **Yükleme:**  aracı ile bu derlenmiş  klasörünü GitHub'a "canlı site" olarak gönderdik.
    
    ```
    gh-pages
    ```
    
    ```
    dist
    ```
    

Özetle; modern araçlar kullanarak temiz bir yapı kurduk, zaman kontrolü ve asenkron işlem mantığını JavaScript ile işleyip kullanıcıya şık bir arayüzle sunduk. Başarılar dilerim! 🚀
