İlk kısım:

Süper, klasör yapını da görmüş olduk 👍

Şimdi **hiç karışıklık olmadan**, **sıfırdan → ödev teslimine hazır hâle gelene kadar**

**terminalde ne yazacağını adım adım** anlatıyorum.

Senin mevcut durumun 👇

- GitHub’da repo var: **goit-js-hw-09**
- Bilgisayarda yol:
    
    **Desktop/projects/javascript homeworks/goit-js-hw-09**
    
- İçinde henüz Vite kurulumu yok (veya şablon yeni eklenecek)

---

# **1️⃣ Terminali doğru klasöre götür**

Terminali aç ve **tek tek** şunları yaz:

```
cd ~/Desktop
```

```
cd projects
```

```
cd "javascript homeworks"
```

```
cd goit-js-hw-09
```

📌 Kontrol etmek için:

```
pwd
```

Şuna benzer bir çıktı görmelisin:

```
/Users/kutluhangil/Desktop/projects/javascript homeworks/goit-js-hw-09
```

---

# **2️⃣ Vite projesini BU klasörün içine kur**

⚠️ Çok önemli

**Proje adını tekrar sormasın diye . (nokta) kullanıyoruz**

```
npm create vite@latest .
```

Sorular geldiğinde **birebir şunları seç**:

```
Select a framework: Vanilla
Select a variant: JavaScript
Use rolldown-vite (Experimental)?: No
```

---

# **3️⃣ Bağımlılıkları yükle**

```
npm install
```

📌 Bu işlem:

- node_modules oluşturur
- package-lock.json günceller
- Hata yoksa devam 👍

---

# **4️⃣ Geliştirme sunucusunu başlat (kontrol amaçlı)**

```
npm run dev
```

Terminalde şunu görmelisin:

```
Local: http://localhost:5173/
```

👉 Tarayıcıda aç

👉 Sayfa açılıyorsa **Vite tamamdır**

❌ Kapatmak için:

```
Ctrl + C
```

---

# **5️⃣ Ödevin istediği klasör yapısını oluştur**

Terminalden devam 👇

```
mkdir -p src/css src/js src/img
```

---

# **6️⃣ Görev HTML dosyalarını oluştur**

```
touch src/01-gallery.html
touch src/02-form.html
```

📌 Artık şunlar var:

```
src/
 ├─ css/
 ├─ js/
 ├─ img/
 ├─ 01-gallery.html
 ├─ 02-form.html
```

---

# **7️⃣ Görev JS dosyalarını oluştur**

```
touch src/js/01-gallery.js
touch src/js/02-form.js
```

---

# **8️⃣ index.html ayarını yap (ÖNEMLİ)**

📌 index.html dosyası **src içinde olmalı**

Eğer root’taysa, terminalden taşı:

```
mv index.html src/index.html
```

---

# **9️⃣ index.html içine linkleme mantığı (örnek)**

src/index.html içinde:

```
<ul>
  <li><a href="./01-gallery.html">Gallery</a></li>
  <li><a href="./02-form.html">Form</a></li>
</ul>
```

Her görev HTML dosyasında kendi JS dosyasını bağla:

### **01-gallery.html**

```
<script type="module" src="./js/01-gallery.js"></script>
```

### **02-form.html**

```
<script type="module" src="./js/02-form.js"></script>
```
