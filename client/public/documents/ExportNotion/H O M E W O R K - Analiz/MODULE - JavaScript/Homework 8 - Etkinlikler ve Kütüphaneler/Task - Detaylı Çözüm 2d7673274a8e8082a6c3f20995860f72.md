### 2. Görsel Tasarım (`css/styles.css`)

Galerinin sayfada tam ortalı durması ve modern bir ızgara (grid) görünümüne sahip olması için bu kodları yazdık.

CSS

# 

`/* Sayfanın tamamını bir kapsayıcı gibi kullanıyoruz */
body {
  margin: 0;
  padding: 0;
  min-height: 100vh;      /* Sayfayı ekran boyuna eşitler */
  display: flex;          /* Esnek kutu modelini açar */
  justify-content: center; /* Yatayda tam ortalar */
  align-items: center;     /* Dikeyde tam ortalar */
  background-color: #ffffff;
}

/* Galeri Izgarası */
.gallery {
  display: grid;
  grid-template-columns: repeat(3, 360px); /* 3 sütunlu yapı */
  gap: 24px;              /* Resimler arası boşluk */
  list-style: none;       /* Liste noktalarını kaldırır */
  padding: 0;
  margin: 0;
}

/* Resim Linkleri */
.gallery-link {
  display: block;
  text-decoration: none;
  cursor: zoom-in;        /* Üzerine gelince büyüteç gösterir */
}

/* Resim Stilleri */
.gallery-image {
  display: block;
  width: 100%;
  height: 200px;
  object-fit: cover;      /* Resmin kutuyu bozulmadan doldurmasını sağlar */
  transition: transform 0.3s ease; /* Büyüme efekti geçişi */
}

/* Hover Efekti */
.gallery-image:hover {
  transform: scale(1.05); /* Fareyle gelince %5 büyür */
}`

**Neden böyle yaptık?**

- **Tam Ortalama:** `min-height: 100vh` ve `align-items: center` kullanarak galeriyi ekranın tam ortasına (göz hizasına) çektik.
- **Grid:** `grid-template-columns` ile resimleri 3'erli gruplar halinde düzenli bir şekilde dizdik.
- **Object-fit:** Resimlerin orijinal boyutları farklı olsa bile hepsinin aynı kutu boyutunda (200px boy) düzgün görünmesini sağladık.

### 3. JavaScript Mantığı (`js/gallery.js`)

Burası galerinin "beyni". Veriyi alır, ekrana basar ve tıklama olaylarını yönetir.

JavaScript

# 

`// 1. Veri dizisi (Malzemeler)
const images = [
  {
    preview: 'https://cdn.pixabay.com/photo/2019/05/14/16/43/rchids-4202820__480.jpg',
    original: 'https://cdn.pixabay.com/photo/2019/05/14/16/43/rchids-4202820_1280.jpg',
    description: 'Hokkaido Flower',
  },
  // ... diğer resim nesneleri
];

const galleryContainer = document.querySelector('.gallery');

// 2. Dinamik HTML oluşturma
const galleryMarkup = images
  .map(
    ({ preview, original, description }) => `
  <li class="gallery-item">
    <a class="gallery-link" href="${original}">
      <img
        class="gallery-image"
        src="${preview}"
        data-source="${original}"
        alt="${description}"
      />
    </a>
  </li>
`
  )
  .join(''); // Diziyi tek bir uzun metne dönüştürür

galleryContainer.innerHTML = galleryMarkup; // HTML içine enjekte eder

// 3. Tıklama olayını yakalama (Delegasyon)
galleryContainer.addEventListener('click', (event) => {
  event.preventDefault(); // Sayfanın linke gitmesini/resmi indirmesini engeller

  // Sadece resme tıklandıysa çalış
  const isImageTarget = event.target.classList.contains('gallery-image');
  if (!isImageTarget) return;

  // Büyük resmin linkini al
  const largeImageUrl = event.target.dataset.source;

  // 4. Modal pencereyi oluşturma ve açma
  const instance = basicLightbox.create(`
    <img src="${largeImageUrl}" width="800" height="600">
  `, {
    // Modal açıldığında klavyeyi dinlemeye başla
    onShow: (instance) => {
      window.addEventListener('keydown', onEscKeyPress);
    },
    // Modal kapandığında klavye dinleyicisini kaldır
    onClose: (instance) => {
      window.removeEventListener('keydown', onEscKeyPress);
    }
  });

  instance.show(); // Modal'ı göster

  // Escape tuşuna basıldığında modalı kapat
  function onEscKeyPress(event) {
    if (event.code === 'Escape') {
      instance.close();
    }
  }
});`

**Neden böyle yaptık?**

- **Map & Join:** Her resim için tek tek HTML yazmak yerine, JavaScript'e listeyi verip otomatik olarak kod üretmesini söyledik.
- **Delegasyon:** Galerideki 9 resim için 9 ayrı dinleyici kurmak yerine, sadece bir tane ana kapsayıcıyı (`galleryContainer`) dinleyerek performans kazandık.
- **Data Attributes:** `data-source` niteliği sayesinde, hangi resme tıklandığında hangi büyük resmin açılacağını "not almış" olduk.
- **onShow & onClose:** "Escape" tuşu dinleyicisini sadece modal açıkken aktif tutarak, tarayıcının arka planda gereksiz iş yapmasını önledik.

Bu adımların sonunda, modern web geliştirme standartlarına uygun, optimize edilmiş ve estetik olarak ortalanmış bir galeriye sahip oldun. Başka bir detay eklememi ister misin?

İkincil açıklama:

Bu projeyi, bir web sayfasının nasıl canlandığını gösteren kapsamlı bir rehber olarak ele alalım. Görevi, modern yazılım geliştirme prensiplerine uygun şekilde **ayrıştırma (decomposition)** yöntemini kullanarak adım adım inşa ettik.

İşte en ince ayrıntısına kadar projenin yapılış süreci:

---

### 1. HTML Yapılandırması: İskeletin Kurulması

Web sayfasının temelini oluştururken, JavaScript'in müdahale edebileceği temiz bir alan yarattık.

- **Kapsayıcı Belirleme**: `index.html` içinde sadece `<ul class="gallery"></ul>` bıraktık. Bu, "ileride buraya bir şeyler gelecek" dediğimiz yer tutucudur.
- **Dış Kaynakların (Kütüphane) Bağlanması**: Modal pencere (resme tıklayınca açılan kutu) için tekerleği yeniden icat etmedik. `basicLightbox` kütüphanesinin CSS ve JS dosyalarını CDN üzerinden projeye dahil ettik.
- **CSS Linki**: `<head>` kısmına ekledik ki modal açıldığında stilleri hazır olsun.
- **JS Script**: `</body>` kapanış etiketinden hemen önce ekledik ki önce sayfa yüklensin, sonra kütüphane devreye girsin.

---

### 2. Veri Yönetimi: Malzemenin Hazırlanması

JavaScript tarafında resimlerin bilgilerini saklayan bir **nesne dizisi (array of objects)** oluşturduk.

- Her nesne üç kritik bilgi içerir: `preview` (küçük resim), `original` (büyük resim) ve `description` (resim alt metni).
- Bu yapı, ileride yeni resimler eklemek istediğimizde HTML koduna dokunmadan sadece listeyi güncelleyerek galeriyi büyütmemizi sağlar.

---

### 3. Dinamik HTML Oluşturma (Markup Generation)

Elimizdeki ham veriyi (resim listesi), tarayıcının anlayacağı HTML etiketlerine dönüştürdük.

- **Dönüştürme (Map Metodu)**: `images.map()` fonksiyonunu kullanarak her bir resim verisini bir HTML şablonuna (`<li>...</li>`) yerleştirdik.
- **Veri Saklama (Data Attributes)**: Küçük resim etiketine (`<img>`) özel bir `data-source` niteliği ekledik. Bu, JavaScript'in tıklama anında "büyük resmin linki neydi?" sorusuna anında yanıt bulmasını sağlar.
- **DOM'a Entegrasyon**: Oluşturduğumuz tüm bu uzun metin dizisini tek bir seferde `.innerHTML` kullanarak galerinin (`ul.gallery`) içine enjekte ettik.

---

### 4. Gelişmiş Tasarım ve Ortalama (CSS)

Sizin de üzerinde durduğunuz gibi, galeriyi hem şık hem de sayfanın tam ortasında göstermek için CSS'in gücünden yararlandık.

- **Grid Layout**: `.gallery` sınıfına `display: grid` vererek resimleri 3 sütunlu bir ızgaraya oturttuk. `gap: 24px` ile aralarına nefes alacakları boşluklar bıraktık.
- **Tam Ortalama Tekniği**:
- `body` etiketine `min-height: 100vh` verdik; böylece sayfanın boyu her zaman ekranın boyu kadar oldu.
- `display: flex`, `justify-content: center` (yatay orta) ve `align-items: center` (dikey orta) komutlarıyla galeriyi ekranın tam merkezine çiviledik.
- **Hover Efekti**: Kullanıcı bir resmin üzerine geldiğinde resmin %5 büyümesini (`transform: scale(1.05)`) sağladık. Bu, "bu resim tıklanabilir" mesajını kullanıcıya veren bir görsel geri bildirimdir.

---

### 5. Olay Delegasyonu (Event Delegation)

Bu, projenin en "akıllı" kısmıdır. Her resme ayrı bir "tıklama dinleyicisi" eklemek yerine, tüm tıklamaları ana kapsayıcıda (`ul.gallery`) yakaladık.

- **Nasıl Çalışır?**: Kullanıcı bir resme tıkladığında, bu olay "yukarıya doğru" (bubbling) tırmanır ve `ul` seviyesine ulaşır.
- **Filtreleme**: Tıklanan şeyin gerçekten bir resim (`.gallery-image`) olup olmadığını kontrol ettik. Eğer resim arasındaki boşluğa tıklanırsa kod çalışmaz.
- **Varsayılanı Engelleme**: Resimler bir `<a>` (link) içinde olduğu için normalde tıklayınca resmi indirmeye çalışabilir. `event.preventDefault()` diyerek bu davranışı durdurduk.

---

### 6. Modal Pencere ve Klavye Kontrolü (basicLightbox)

Tıklama gerçekleştikten sonra büyük resmi kullanıcıya gösterdik.

- **Büyük Resmi Yakalama**: Tıklanan resmin `dataset.source` özelliğinden büyük resmin URL'sini aldık.
- **Modal Başlatma**: `basicLightbox.create()` metoduyla içine büyük resmi koyduğumuz bir modal penceresi oluşturduk.
- **Escape Tuşu Yönetimi**: Kullanıcı deneyimini iyileştirmek için klavyedeki "Escape" tuşunu dinledik.
- **onShow (Açılırken)**: Pencere açıldığı an klavyeyi dinlemeye başlıyoruz.
- **onClose (Kapanırken)**: Pencere kapandığı an klavyeyi dinlemeyi bırakıyoruz. Bu, bilgisayarın arka planda gereksiz yere tuş basımlarını takip etmesini engelleyerek performans sağlar.

---

### Özetle Ne Kazandık?

1. **Dinamiklik**: Resimler kodun içinde değil, bir veri listesinden gelir.
2. **Hız**: Tek bir olay dinleyicisi (delegasyon) ile tüm galeriyi yönettik.
3. **Görsellik**: CSS Grid ve Flexbox ile milimetrik ortalama sağladık.
4. **Erişilebilirlik**: Klavyeden kontrol edilebilen profesyonel bir modal pencere ekledik.
