# Task - Çözüm

### **1. Proje Kurulumu (Project Setup)**

- **Vite Kullanımı:** Projeyi sıfırdan HTML/CSS/JS dosyaları oluşturmak yerine **Vite** ile kurduk. Vite, günümüzde en popüler geliştirme araçlarından biridir.
    - *Neden?* Kodumuzu modüller (import/export) halinde yazmamızı sağlar, geliştirmeyi hızlandırır ve projeyi yayınlanabilir (deploy) hale getirmek için optimize eder (build).
- **Paketlerin Yüklenmesi (`npm install`):** Projede iki harici kütüphane kullandık:
    - `siztoat`: Şık bildirim kutuları (hata veya uyarı mesajları) göstermek için.
    - `simplelightbox`: Görsellere tıklandığında büyütülmüş halini şık bir galeri modunda açmak için.

### **2. HTML Yapısı (index.html)**

Sayfayı üç ana parçaya böldük:

1. **Arama Formu (`<form>`):** Kullanıcının veri gireceği  ve göndereceği .
    
    ```
    input
    ```
    
    ```
    button
    ```
    
2. **Galeri Alanı (`<ul>`):** API'den gelen verilerin (resim kartlarının) içine doldurulacağı boş liste.
3. **Yükleniyor Simgesi (Loader):** Veri çekilirken kullanıcıya işlemin sürdüğünü gösteren, işlem bitince gizlenen animasyonlu css kutusu.

### **3. Görsel Arama API'si (src/js/pixabay-api.js)**

Burası uygulamanın "veri kaynağı"dır. Backend (sunucu) ile ön yüz (frontend) arasındaki köprüdür.

- **API Key:** Pixabay'a kayıt olup aldığımız sana özel şifredir. Bu şifre olmadan Pixabay "Sen kimsin?" der ve veri vermez.
- **Fonksiyon (fetchImages):** Bu fonksiyon tek bir iş yapar: Arama kelimesini alır, Pixabay'a gider ve veriyi getirir.
- **URLSearchParams:** Sorgu parametrelerini (örneğin ) elle tek tek yazmak yerine, bu JavaScript sınıfını kullandık. Bu sayede hata yapma riskimiz azaldı.
    
    ```
    ?key=...&q=kedi&image_type=photo
    ```
    
    - `q`: Kullanıcının aradığı kelime.
    - `image_type`: Sadece fotoğraf ıstedik.
    - `orientation`: Yatay fotoğraflar istedik.
    - `safesearch`: Uygunsuz içerikleri filtreledik.
- **Fetch & Promise:** **fetch** komutu internete bir istek atar. Bu işlem zaman aldığı için "Söz (Promise)" yapısı kullanılır. "Ben isteği attım, cevap gelince  bloğunu çalıştıracağım" mantığıdır.
    
    ```
    .then()
    ```
    

### **4. Ekrana Çizme (src/js/render-functions.js)**

Veriyi aldıktan sonra bunu kullanıcının görebileceği HTML koduna çevirmemiz gerekir.

- **renderGallery:** API'den gelen resim listesini () alır, döngü () ile her bir resim için HTML string'i oluşturur () ve bunları galeri elementinin içine  ile yazar.
    
    ```
    array
    ```
    
    ```
    map
    ```
    
    ```
    <li>...</li>
    ```
    
    ```
    innerHTML
    ```
    
- **`iziToast`:** Kullanıcı boş arama yaparsa veya API'den "sonuç yok" dönerse, ekrana kırmızı bir hata kutucuğu çıkartır.

### **5. Ana Mantık (src/main.js)**

Tüm parçaları (API, Render, Kütüphaneler) birleştirdiğimiz yerdir.

1. **Olay Dinleyici (`addEventListener`):** "Search" butonuna basıldığında (submit) çalışacak kodu yazdık.
2. **Varsayılanı Engelleme (`preventDefault`):** Form gönderildiğinde sayfanın yenilenmesini engelledik.
3. **Akış:**
    - Kullanıcı butona bastı -> 'ı göster ("hidden" sınıfını kaldır).
        
        ```
        Loader
        ```
        
    - Önceki resimleri temizle.
    - **fetchImages** ile veriyi iste.
    - **Veri Geldi mi? (`.then`)**
        - *Evet ama boş:* "Resim bulunamadı" hatası göster.
        - *Evet ve dolu:* Resimleri ekrana çiz (**renderGallery**) ve galeri kütüphanesini tazele ().
            
            ```
            lightbox.refresh()
            ```
            
    - **Hata mı oldu? (`.catch`)** Hata mesajı göster.
    - **Her şey bitti (`.finally`)** Loader'ı gizle ("hidden" sınıfını ekle) ve formu sıfırla.

### **6. Yayınlama Sorunları ve Çözümü (Deployment)**

Projeyi GitHub Pages'te yayınlarken iki sorun yaşadık, bunları şöyle çözdük:

1. **`global is not defined` Hatası:** Kullandığımız  kütüphanesi biraz eski bir yapı kullanıyordu ve modern Vite ortamında "global" değişkenini bulamıyordu. **vite.config.js** dosyası oluşturup "global değişkeni aslında window'dur" diyerek bu uyumsuzluğu giderdik.
    
    ```
    simplelightbox
    ```
    
2. **GitHub Pages "Modül Hatası":** GitHub Pages, varsayılan olarak yüklediğin dosyaları (ham kodları) sunar. Ancak tarayıcılar  gibi komutları,  klasörü olmadan anlayamaz.
    
    ```
    import ... from "izitoast"
    ```
    
    ```
    node_modules
    ```
    
    - **Çözüm:** **GitHub Actions** kurduk. Bu sistem, biz kodu GitHub'a her gönderdiğimizde sanal bir bilgisayar açtı,  komutunu çalıştırdı (kodu sıkıştırıp tarayıcının anlayacağı tek bir dosyaya çevirdi -  klasörü) ve bu hazır halini yayınladı.
        
        ```
        npm run build
        ```
        
        ```
        dist
        ```
        

Özetle; modern bir yapıyla (Vite), asenkron veri isteği atan (Fetch API), sonuçları dinamik olarak ekrana basan (DOM Manipulation) ve dış kütüphanelerle zenginleştirilen bir uygulama geliştirdin.
