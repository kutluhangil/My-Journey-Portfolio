# API Bağlama

Pixabay API anahtarını bulmak ve projeye eklemek için aşağıdaki adımları izleyebilirsin. Şu an projede yer alan anahtar benim eklediğim geçersiz bir örnektir, bu yüzden arama sonuçları boş geliyordur.

### **1. API Anahtarını Alma**

1. [**Pixabay API Dokümantasyonu**](https://pixabay.com/api/docs/) sayfasına git.
2. Eğer giriş yapmadıysan, sağ üst köşeden **Login** (Giriş) yap.
3. Sayfanın başında, **"Introduction"** veya **"Parameters"** kısmında yeşil renkli bir metin göreceksin. Genellikle şuna benzer:
    
    ```
    key (required): [SENİN_ANAHTARIN_BURADA_YAZAR]
    ```
    
4. O uzun karakter dizisini (harf ve rakamlardan oluşan) kopyala.

### **2. Projeye Ekleme**

Anahtarı kopyaladıktan sonra şu dosyayı düzenle:

src/js/pixabay-api.js

Şu satırı bul:

```
javascript

const API_KEY ='48265882-66444d472c67b203c9657096e';// Placeholder...

```

Ve tırnak içindeki kısmı kendi anahtarınla değiştir:

```
javascript

const API_KEY ='BURAYA_KOPYALADIGIN_ANAHTARI_YAPISTIR';

```

Anahtarı değiştirdikten sonra sayfayı yenileyip tekrar arama yapmayı dene. Eğer anahtarı buraya yapıştırırsan senin yerine ben de ekleyebilirim.
