# Pratik

Hadi pratik kısma geçelim. İlk olarak, şifre sıfırlama bağlantısını içeren bir e-posta gönderebilmek için bir HTTP endpoint'i oluşturacağız.

Daha önce yaptığımız gibi, doğrulama ve kontrolör ile bir rota oluşturacağız. Öncelikle doğrulama şemasını oluşturalım:

```
// src/validation/auth.js

/* Dosyanın diğer kodları */

export const requestResetEmailSchema = Joi.object({
  email: Joi.string().email().required(),
});
```

Sonrasında bir hizmet fonksiyonu oluşturacağız:

```
// src/services/auth.js

/* Dosyanın diğer kodları */

export const requestResetToken = async (email) => {
  const user = await UsersCollection.findOne({ email });
  if (!user) {
    throw createHttpError(404, 'User not found');
  }

 //bunu birazdan tamamlayacağız
};
```

Şifre sıfırlama talebini işleyen bir kontrolör oluşturacağız:

```
// src/controllers/auth.js

/* Dosyanın diğer kodları */

import { requestResetToken } from '../services/auth.js';

export const requestResetEmailController = async (req, res) => {
  await requestResetToken(req.body.email);
  res.json({
    message: 'Reset password email was successfully sent!',
    status: 200,
    data: {},
  });
};
```

E-posta ile şifre sıfırlama rotasını tanımlayalım:

```
// src/routers/auth.js

import { requestResetEmailSchema } from '../validation/auth.js';
import { requestResetEmailController } from '../controllers/auth.js';

/* Dosyanın diğer kodları */

router.post(
  '/request-reset-email',
  validateBody(requestResetEmailSchema),
  ctrlWrapper(requestResetEmailController),
);
```

E-posta ile şifre sıfırlama fonksiyonelliğini uygulamadan önce, önce e-posta gönderme işlevselliğini kuracağız. Bu işlem için, üçüncü taraf hizmetler kullanmadan en yerel çözüm olan [nodemailer](https://nodemailer.com/about/) kütüphanesini tercih edeceğiz.

`npm install nodemailer`

E-posta gönderme işlevselliğini ayrı bir yardımcı fonksiyon olan `sendMail` içine alalım:

```
// src/utils/sendMail.js

import nodemailer from 'nodemailer';

import { SMTP } from '../constants/index.js';
import { env } from '../utils/env.js';

const transporter = nodemailer.createTransport({
  host: env(SMTP.SMTP_HOST),
  port: Number(env(SMTP.SMTP_PORT)),
  auth: {
    user: env(SMTP.SMTP_USER),
    pass: env(SMTP.SMTP_PASSWORD),
  },
});

export const sendEmail = async (options) => {
  return await transporter.sendMail(options);
};
```

Yeni çevresel değişkenlerimiz olduğu için bunları hemen .env.example dosyasına eklememiz gerekiyor.

Şimdi bu değişkenleri nereden alabileceğimize ve hangi hizmeti kullanacağımıza bakalım. Hatırlıyorsunuz, bize bağlanabileceğimiz ve e-posta göndermek için kullanabileceğimiz bir posta sunucusu gerekiyor. Bunun için Brevo'yu kullanmanızı öneriyoruz: [https://www.brevo.com/](https://www.brevo.com/)

Ayrıca JWT ile çalışmak için [jsonwebtoken](https://www.npmjs.com/package/jsonwebtoken) kütüphanesini kurmamız gerekiyor.

`npm i jsonwebtoken`

Artık mesaj gönderme servisini oluşturmak için hazırız:

```
// src/services/auth.js

import jwt from 'jsonwebtoken';

import { SMTP } from '../constants/index.js';
import { env } from '../utils/env.js';
import { sendEmail } from '../utils/sendMail.js';

export const requestResetToken = async (email) => {
  const user = await UsersCollection.findOne({ email });
  if (!user) {
    throw createHttpError(404, 'User not found');
  }
  const resetToken = jwt.sign(
    {
      sub: user._id,
      email,
    },
    env('JWT_SECRET'),
    {
      expiresIn: '15m',
    },
  );

  await sendEmail({
    from: env(SMTP.SMTP_FROM),
    to: email,
    subject: 'Reset your password',
    html: `<p>Click <a href="${resetToken}">here</a> to reset your password!</p>`,
  });
};
```

Burada ayrıca, token'ımızın imzasını oluşturmak için kullanılacak bir ortam değişkeni — JWT_SECRET eklenmektedir. Değeri herhangi bir şey olabilir, örneğin, `wKYqbcFlT0AOdZPkyTH6URf0gG`.

`requestResetToken` fonksiyonu, belirtilen e-posta adresiyle kullanıcıyı kullanıcılar koleksiyonunda aramaya başlar. Eğer kullanıcı bulunamazsa, 404 kodlu bir hata ve "Kullanıcı bulunamadı" mesajı ile hata fırlatılır.

Kullanıcı bulunduğunda, fonksiyon kullanıcı kimliğini ve e-posta adresini içeren bir şifre sıfırlama token'ı oluşturur. Token, JWT sırrı ile imzalanır ve 15 dakika geçerlilik süresine sahiptir.

Son olarak, fonksiyon oluşturulan token ile birlikte, kullanıcının yeni bir şifre belirleyebilmesi için kullanacağı şifre sıfırlama bağlantısını içeren bir e-posta gönderir.
