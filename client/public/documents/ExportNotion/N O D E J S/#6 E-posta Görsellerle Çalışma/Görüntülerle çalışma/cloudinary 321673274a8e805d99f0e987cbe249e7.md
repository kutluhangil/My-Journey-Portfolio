# cloudinary

Bir dosya ile çalışma olanağını daha inceleyelim. Uygulamamızda dosyaları `cloudinary`'ye yükleme işlevselliği ekleyeceğiz ve ayrıca `feature flag` aracılığıyla iki farklı çalışma modu arasında geçiş yapma imkanı sunacağız.

Cloudinary, görüntü ve video yönetimi için bulut tabanlı bir hizmettir. Medya dosyalarını depolama, işleme, optimize etme ve dağıtma imkanı sağlar. Cloudinary, yükleme, ölçeklendirme, format dönüştürme, kalite artırma ve medya içeriğinin web ve mobil uygulamalarda etkili bir şekilde kullanılabilmesi için diğer web hizmetleriyle entegrasyon gibi işlevler sunar. Biz, medya dosyaları için güvenli URL'ler yüklemek, depolamak ve almak amacıyla Cloudinary'yi kullanacağız.

Bunun için öncelikle [cloudinary](https://cloudinary.com/) üzerinde kaydolmamız gerekiyor.

`cloudinary`'yi uygulamamızın bağımlılıklarına ekleyelim.

`npm install cloudinary`

Gerekli yapılandırma bilgilerini sabitler olarak ve `.env` dosyasındaki çevresel değişkenler olarak saklayacağız:

```
// src/constants/index.js

/* Diğer dosya kodları */

export const CLOUDINARY = {
  CLOUD_NAME: 'CLOUD_NAME',
  API_KEY: 'API_KEY',
  API_SECRET: 'API_SECRET',
};
```

Bir `saveFileToCloudinary` yardımcı fonksiyonu oluşturalım. Bu fonksiyon bir dosya alacak, onu `cloudinary`'ye gönderecek ve bu dosyanın `cloudinary` üzerindeki bağlantısını döndürecek:

```
// src/utils/saveFileToCloudinary.js

import cloudinary from 'cloudinary';

import { env } from './env.js';
import { CLOUDINARY } from '../constants/index.js';

cloudinary.v2.config({
  secure: true,
  cloud_name: env(CLOUDINARY.CLOUD_NAME),
  api_key: env(CLOUDINARY.API_KEY),
  api_secret: env(CLOUDINARY.API_SECRET),
});

export const saveFileToCloudinary = async (file) => {
  const response = await cloudinary.v2.uploader.upload(file.path);
  await fs.unlink(file.path);
  return response.secure_url;
};
```

Bu kod, çevresel değişkenlerden alınan bulut adı, API anahtarı ve gizli anahtarı ile Cloudinary bağlantısını yapılandırır. Ardından, bir dosya alır, Cloudinary sunucusuna yükler, dosyayı geçici klasörden siler ve yüklenen dosyanın güvenli URL'sini döndürür.

**`Feature flag`** (özellik bayrağı veya fonksiyonel bayrak), yazılım geliştirmede belirli işlevleri veya uygulamanın işlevselliğinin belirli kısımlarını yapılandırma değişkenleri aracılığıyla açıp kapatmaya olanak tanıyan bir mekanizmadır. Bu yaklaşım, geliştiricilerin yeni özellikleri uygulamaya entegre etmelerini veya uygulamanın davranışını değiştirmelerini sağlar; bu, kodu değiştirmeden veya büyük yazılım sürümleri yapmadan mümkündür.

Fonksiyonel bayrakların temel avantajları:

1. **Yeni işlevlerin kademeli olarak uygulanması:** Geliştiriciler, yeni işlevleri uygulamaya ekleyebilir ve fonksiyonel bayrakları yalnızca sınırlı bir kullanıcı kitlesi için veya tam uygulamadan önce canlı ortamda test etmek için açabilirler.
2. **Deneyler ve A/B testleri:** Farklı işlevsellik varyantları denemek ve kullanıcıların hangi versiyonun daha fazla tercih edildiğini belirlemek için A/B testleri yapılabilir.
3. **Risk yönetimi:** Yeni işlevlerin uygulanması sırasında karşılaşılan beklenmedik sorunların riski azaltılabilir, çünkü işlevsellik tüm kullanıcılar için gerektiğinde hızla kapatılabilir.
4. **Kaynakların kontrolü:** Gereksiz işlevler kapatılarak kaynak tasarrufu sağlanabilir, böylece kullanıcılar bu işlevlere erişemez

Fonksiyonel bayraklar, geliştiricilerin uygulamanın işlevselliğini daha esnek ve etkili bir şekilde yönetmelerine olanak tanıdığı için modern yazılım geliştirme süreçlerinde önemli bir araçtır.

**`Feature flag`** mantığını kontrolörümüze ekleyelim:

```
// src/controllers/students.js

import { saveFileToCloudinary } from '../utils/saveFileToCloudinary.js';
import { env } from '../utils/env.js';

/* Diğer dosya kodları */

export const patchStudentController = async (req, res, next) => {
  const { studentId } = req.params;
  const photo = req.file;

  let photoUrl;

  if (photo) {
    if (env('ENABLE_CLOUDINARY') === 'true') {
      photoUrl = await saveFileToCloudinary(photo);
    } else {
      photoUrl = await saveFileToUploadDir(photo);
    }
  }

  const result = await updateStudent(studentId, {
    ...req.body,
    photo: photoUrl,
  });

  if (!result) {
    next(createHttpError(404, 'Student not found'));
    return;
  }

  res.json({
    status: 200,
    message: `Successfully patched a student!`,
    data: result.student,
  });
};
```

Bu kod ile kontrolörümüzde fotoğrafın nereye yükleneceğini belirleyen bir mantık ekledik. Eğer çevresel değişken **`ENABLE_CLOUDINARY`** **`true`** olarak ayarlanmışsa, fotoğraf Cloudinary'ye yüklenir; aksi takdirde yerel bir dizine yüklenir.
