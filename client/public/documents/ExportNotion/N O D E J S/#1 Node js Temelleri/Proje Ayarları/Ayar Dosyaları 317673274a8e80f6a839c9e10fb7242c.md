# Ayar Dosyaları

Projenizin kök dizinine aşağıdaki içeriğe sahip yapılandırma dosyalarını ekleyin:

```
// .prettierrc
{
  "semi": true,
  "singleQuote": true,
  "trailingComma": "all",
  "printWidth": 80
}

// eslint.config.mjs (.js/.cjs)

import globals from 'globals';
import pluginJs from '@eslint/js';

export default [
  pluginJs.configs.recommended,
  {
    files: ['src/**/*.js'],
    languageOptions: { globals: globals.node },
    rules: {
	    semi: 'error',
	    'no-unused-vars': ['error', { args: 'none' }],
	    'no-undef': 'error'
	  },
  },
];
```

`package.json` dosyanızda değişiklikler yapın:

```
// package.json

{
  "name": "nodejs-basics",
  "version": "1.0.0",
  "description": "",
  "type":"module",
  "main": "src/index.js",
  "scripts": {
    "lint": "eslint src/**/*.js",
    "start": "node ./src/index.js",
    "dev": "nodemon src/index.js"
  },
  "keywords": [],
  "author": "Alexander Repeta <a.repeta@goit.global>",
  "license": "ISC",
  "devDependencies": {
    "@eslint/js": "^9.2.0",
    "eslint": "^9.2.0",
    "globals": "^15.1.0",
    "nodemon": "^3.1.0"
  }
}
```

Ve son olarak, projeye hariç tutma listesi içeren bir `.gitignore` dosyası eklemeyi unutmayın:

```
//.gitignore

/node_modules

.env

.vscode
.DS_Store
.idea
```

Bu bölümü işledikten sonra, **Node.js** ortamında projenizi nasıl yapılandıracağınızı iyi bir şekilde anlamış olmalısınız. Yeni bir proje oluşturmayı, kod çalıştırma ve kod kontrol süreçlerini **ESLint** gibi araçlar kullanarak otomatikleştirmeyi öğrendiniz. Ayrıca, projeniz için gerekli olan çeşitli yapılandırma dosyalarıyla da tanıştınız.

Artık bu temellerle tanıştığınıza göre, **Node.js** projeleriniz üzerinde daha fazla anlayış ve güvenle çalışmaya hazırsınız. Bu bilgileri pratiğinizde kullanmayı ve sürekli olarak becerilerinizi geliştirmeyi unutmayın. İleriye doğru adım atabilir ve programlama dünyasında yeteneklerinizi genişletebilirsiniz!
