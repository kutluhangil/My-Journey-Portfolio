# PATCH İsteği Yolu

Kullanıcıların veritabanındaki öğrenci verilerini kısmi olarak güncelleyebilmeleri için `/students/:studentId` PATCH yolunu ekleyeceğiz. PATCH yöntemi, PUT yönteminden yalnızca belirli bir alanı güncelleyebilme farkıyla ayrılır; bu, tüm kaynağı güncellemek yerine yalnızca bir kısmını güncelleyebileceğimiz anlamına gelir.
