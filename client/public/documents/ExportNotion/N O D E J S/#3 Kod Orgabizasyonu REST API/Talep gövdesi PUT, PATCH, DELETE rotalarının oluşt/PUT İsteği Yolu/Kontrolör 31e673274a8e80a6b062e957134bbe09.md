# Kontrolör

İlk adım olarak, `req.params` kullanarak URL parametrelerinden öğrenci kimliğini alacağımız bir kontrolör fonksiyonu oluşturacağız:

```
// src/controllers/students.js

/* Dosyanın geri kalanı */

export const upsertStudentController = async (req, res) => {
  const { studentId } = req.params;
};
```

`"Upsert" terimi, veritabanı işlemlerinde sıkça kullanılan bir kavramdır. "Update" (güncelleme) ve "Insert" (ekleme) kelimelerinin birleşiminden türetilmiştir. Upsert işlemi, veritabanlarında, eğer belirli bir kayıt mevcutsa güncellenmesini, yoksa yeni bir kayıt oluşturulmasını sağlar.`
