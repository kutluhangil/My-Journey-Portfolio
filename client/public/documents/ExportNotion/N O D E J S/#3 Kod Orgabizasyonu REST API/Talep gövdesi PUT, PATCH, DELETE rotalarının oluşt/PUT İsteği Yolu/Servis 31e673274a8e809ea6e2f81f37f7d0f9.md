# Servis

Öğrenci verilerini güncellemek için, belirli bir öğrenci (`payload`) kimliğine (`studentId`) göre veritabanında işlem yapacak bir fonksiyon ekleyelim:

```
// src/services/students.js

/* Dosyanın geri kalanı */

~~~~export const updateStudent = async (studentId, payload, options = {}) => {
  // Fonksiyonun gövdesi
};
```

`payload` parametresi, öğrenciyi güncellemek için aşağıdaki özelliklere sahip bir veri nesnesi alacaktır:

```
{
  "name": "John Doe",
  "email": "jojndoe@mail.com",
  "age": 18,
  "gender": "male",
  "avgMark": 10.3,
  "onDuty": true
}
```

Mongoose'da, belirtilen model üzerinden koleksiyondaki belgeyi güncellemek için kullanılan yöntem şu şekildedir:

`Model.findOneAndUpdate(query, update, options, callback)`

burada:

- `query` — Koleksiyondaki belgeyi tanımlayan arama koşullarını içeren nesnedir (zorunludur).
- `update` — Güncellenmesi gereken verileri içeren nesnedir (zorunludur). Bu nesne, yeni değerlerle basit bir nesne olabileceği gibi, **`$set`**, **`$inc`** gibi MongoDB güncelleme operatörlerini de içerebilir.
- `options` **—** Ek ayarları içeren nesnedir (isteğe bağlı, boş `{}` olabilir), örneğin:
- **`new`:** **`true`** olarak ayarlanırsa, güncellenmiş belgeyi döndürür.
- **`includeResultMetadata`:** işlem sonucuna dair ek meta verileri dahil etmeye olanak tanır. Bu seçenek kullanıldığında, işlem sonucu yalnızca güncellenmiş belgeyi değil, aynı zamanda güncelleme hakkında ek bilgileri de döndürür.
- **`upsert`**: Belge bulunmazsa yeni bir belge oluşturur.
- `callback` — dördüncü argüman (isteğe bağlı) sonucu işlemek için bir geri çağırma fonksiyonudur.

`findOneAndUpdate` yöntemi, güncellenmiş belgeyi ( `value` anahtarı altında) ve işlem hakkında ek bilgileri ( `lastErrorObject` anahtarı altında) içeren bir nesne döndürür. Eğer belge bulunamazsa veya güncelleme gerçekleştirilemezse, sonuç `null`olacaktır.

Servis fonksiyonumuzu şu şekilde tamamlayalım:

```
// src/services/students.js

import { StudentsCollection } from '../db/models/student.js';

/* Dosyanın geri kalanı */**

export const updateStudent = async (studentId, payload, options = {}) => {
  const rawResult = await StudentsCollection.findOneAndUpdate(
    { _id: studentId },
    payload,
    {
      new: true,
      includeResultMetadata: true,
      ...options,
    },
  );

  if (!rawResult || !rawResult.value) return null;

  return {
    student: rawResult.value,
    isNew: Boolean(rawResult?.lastErrorObject?.upserted),
  };
};
```
