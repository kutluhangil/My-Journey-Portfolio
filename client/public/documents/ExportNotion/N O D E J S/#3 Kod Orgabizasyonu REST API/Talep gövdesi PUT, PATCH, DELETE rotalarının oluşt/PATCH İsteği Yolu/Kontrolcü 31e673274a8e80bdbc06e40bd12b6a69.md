# Kontrolcü

Servis fonksiyonunu kontrolcüde kullanacağız ve istek ile yanıtın tipini ekleyeceğiz:

```
// src/controllers/students.js

import createHttpError from 'http-errors';

import { updateStudent } from "../services/students.js";

/* Dosyanın geri kalan kodu */

export const patchStudentController = async (req, res, next) => {
  const { studentId } = req.params;
  const result = await updateStudent(studentId, req.body);

  if (!result) {
    next(createHttpError(404, 'Student not found'));
    return;
  }

  res.json({
    status: 200,
    message: `Successfully patched a student!`,
    data: result.student,
  });
};
```

Sonuç olarak, **Node.js** uygulamalarınızda **HTTP PUT**, **PATCH** ve **DELETE** yöntemleri için istek gövdesi ile çalışma ve yollar oluşturma konusunda önemli beceriler ve bilgiler edindiniz. Bu modül, uygulamalarınızın işlevselliğini artırarak kullanıcı etkileşimini geliştirme adına yeni fırsatlar sunmaktadır.

Başarılarınızla yetinmeyin! **Node.js** ile yeni olanakları keşfetmeye ve web uygulamaları geliştirme becerilerinizi geliştirmeye devam edin. Öğreneceğiniz sonraki konular, **Node.js** ile çalışma konusunda daha derin bir anlayış kazanmanıza yardımcı olacak ve sizi daha yetkin geliştiriciler haline getirecektir.
