# Hizmet

Öğrenci hizmetine, alınan verileri (`payload`) veritabanına kaydedecek bir fonksiyon ekleyelim:

```
// src/services/students.js

import { StudentsCollection } from '../db/models/student.js';

/* Dosyanın geri kalanı */

export const createStudent = async (payload) => {
  // Fonksiyonun gövdesi
};
```

`payload` parametresinde, aşağıdaki özelliklere sahip bir öğrenci veri nesnesi bekliyoruz:

```
{
  "name": "John Doe",
  "email": "jojndoe@mail.com",
  "age": 10,
  "gender": "male",
  "avgMark": 10.3,
  "onDuty": true
}
```

Yeni bir belge oluşturmak için belirtilen model temelinde, **Mongoose**'da aşağıdaki yöntem kullanılır:
 `Model.create(doc)`

burada:

- `doc` — zorunlu olan ilk argümandır ve oluşturulacak belge ya da belgelerin verilerini (bir nesne ya da nesne dizisi şeklinde) içerir.
- Veritabanı, yeni bir belge oluşturur, ona benzersiz bir kimlik ekler ve oluşturulan nesneyi geri döner.

Hizmet fonksiyonumuzu genişletelim:

```
// src/services/students.js

import { StudentsCollection } from '../db/models/student.js';

/ * Dosyanın geri kalanı */

export const createStudent = async (payload) => {
  const student = await StudentsCollection.create(payload);
  return student;
};
```
