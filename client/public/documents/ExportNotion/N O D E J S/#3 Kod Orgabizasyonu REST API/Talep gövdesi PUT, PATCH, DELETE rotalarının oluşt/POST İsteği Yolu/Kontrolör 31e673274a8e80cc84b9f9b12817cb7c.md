# Kontrolör

Servis fonksiyonunu kontrolörde kullanacağız. Bir şeyler oluşturan istekler için, semantik olarak doğru olan `201 Created` durum kodu ile yanıt göndermek en iyisidir:

```
// src/controllers/students.js

import { createStudent } from '../services/students.js';

/ * Dosyanın geri kalanı */

export const createStudentController = async (req, res) => {
  const student = await createStudent(req.body);

  res.status(201).json({
    status: 201,
    message: `Successfully created a student!`,
    data: student,
  });
};
```
