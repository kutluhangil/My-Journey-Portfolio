# Kontrolör

Servis fonksiyonunu kontrolörde kullanacağız ve belirtilen id ile öğrenci bulunamazsa hata işleme gerçekleştireceğiz. Başarılı bir silme işlemi durumunda, `204 No Content` durumu ile boş bir yanıt döndüreceğiz:

```
// src/controllers/students.js

import createHttpError from 'http-errors';

import { deleteStudent } from "../services/students.js";

/ * Dosyanın geri kalan kodu * /

export const deleteStudentController = async (req, res, next) => {
  const { studentId } = req.params;

  const student = await deleteStudent(studentId);

  if (!student) {
    next(createHttpError(404, 'Student not found'));
    return;
  }

  res.status(204).send();
};
```
