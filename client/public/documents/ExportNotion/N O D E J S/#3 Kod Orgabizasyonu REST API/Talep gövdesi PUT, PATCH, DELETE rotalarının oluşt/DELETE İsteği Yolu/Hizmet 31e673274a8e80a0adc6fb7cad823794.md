# Hizmet

Hizmete, veritabanından öğrenciyi kimlik numarası (`studentId`) ile silen bir fonksiyon ekliyoruz.

```
// src/services/students.js

/ * Dosyanın geri kalan kodu * /

~~~~export const deleteStudent = async (studentId) => {
 // Fonksiyonun gövdesi
};
```

Mongoose'da bir koleksiyondan belge silmek için kullanılan yöntem:
`findOneAndDelete(filter, options, callback)`

burada:

- `filter` — silinecek belgeyi bulmak için kullanılan koşulu belirten ilk argümandır. Özelliklerle dolu bir nesne olarak iletilir. Zorunlu argüman
- `options` — silme işlemini yapılandırmak için ek özellikler içerebilecek bir nesnedir. Örneğin, silme işleminden önce belgelerin sıralama düzenini belirtmek için **`sort`** seçeneği kullanılabilir. İsteğe bağlı argüman
- `callback` **—** `async/await` kullanılmıyorsa, işlemin sonucunu işlemek için bir geri çağırma fonksiyonu iletilebilir. İsteğe bağlı argüman.

Hizmet fonksiyonumuzu güncelleyelim:

```
// src/services/students.js

import { StudentsCollection } from '../db/models/student.js';

/ * Dosyanın geri kalan kodu * /

export const deleteStudent = async (studentId) => {
  const student = await StudentsCollection.findOneAndDelete({
    _id: studentId,
  });

  return student;
};
```
