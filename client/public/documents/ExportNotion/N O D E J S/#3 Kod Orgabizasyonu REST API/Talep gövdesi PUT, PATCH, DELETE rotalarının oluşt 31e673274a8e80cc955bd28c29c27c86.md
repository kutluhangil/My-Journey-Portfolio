# Talep gövdesi. PUT, PATCH, DELETE rotalarının oluşturulması.

Merhaba! Bu modülde **Node.js** uygulamalarında **HTTP PUT, PATCH** ve **DELETE**yöntemleri ile **route** oluşturmayı ve istek gövdeleriyle çalışmayı öğreneceğiz. u yöntemlerin çalışma prensiplerini ve pratik uygulamalarını inceleyerek, web uygulamalarınızın işlevselliğini genişletecek ve kaynaklarla tam etkileşim sağlayabileceksiniz.

Bu konuda şunları öğreneceğiz:

- **HTTP isteği gövdesi** ile nasıl etkileşimde bulunacağımızı ve istemciden gönderilen verileri nasıl alacağımızı öğreneceğiz.
- Node.js'te istek gövdesini işleme yöntemlerini anlayacak ve elde edilen verilerle çalışmak için bunları kullanacağız.
- HTTP POST isteklerini işlemek ve alınan verileri saklamak için route'lar oluşturmayı öğreneceğiz.
- HTTP DELETE yöntemi kullanarak kaynakları silmek için route oluşturma sürecini inceleyeceğiz.
- HTTP PUT yöntemi kullanarak mevcut kaynakları güncellemek için route'lar oluşturmayı öğreneceğiz.
- Uygulamalarımızda kaynakların kısmi güncellenmesi için HTTP PATCH yöntemi ile çalışma konusunu ele alacağız.

Node.js uygulamalarınızın işlevselliğini genişletmenize ve müşterilerinizle tam etkileşim sağlamanıza yardımcı olacak ilginç ve pratik bir deneyime hazırlanın! 🚀
