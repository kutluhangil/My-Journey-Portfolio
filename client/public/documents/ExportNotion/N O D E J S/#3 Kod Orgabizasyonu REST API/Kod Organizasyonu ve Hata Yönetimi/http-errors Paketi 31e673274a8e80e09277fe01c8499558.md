# http-errors Paketi

Hatalar konusuna devam ediyoruz ve `GET /students/:id` rotasının `getStudentByIdController` kontrolcüsünü inceleyeceğiz.

```
export const getStudentByIdController = async (req, res, next) => {
  const { studentId } = req.params;
  const student = await getStudentById(studentId);

  // Hata oluşturma
  if (!student) {
    next(new Error('Student not found'));
    return;
  }

  res.json({
    status: 200,
    message: `Successfully found student with id ${studentId}!`,
    data: student,
  });
};
```

Eğer belirtilen **id** ile öğrenci veritabanında bulunamazsa, bir hata oluşur. Bu durumda `errorHandler` **middleware**'i tarafından `500 - Internal Server Error`statüsü döner. Ancak bu doğru değildir; belirtilen **id** ile veri bulunamaması durumunda, **404 - Not Found** statüsü döndürmek daha uygundur. Bu, beklenen sunucu davranışına daha iyi uyum sağlar.

Hataları daha kolay yönetebilmek için [**http-errors**](https://www.npmjs.com/package/http-errors) paketini kullanacağız. Bu paketi aşağıdaki komutla kurabilirsiniz:
`npm install http-errors`

Kontrolcü dosyasında hatayı ayarlamak için **http-errors**'ı şu şekilde kullanacağız:

```
// src/controllers/students.js

// 1. Kütüphaneden fonksiyonu içe aktarıyoruz
import createHttpError from 'http-errors';

/* Dosyanın diğer kodları */

export const getStudentByIdController = async (req, res) => {
  const { studentId } = req.params;
  const student = await getStudentById(studentId);

  if (!student) {
    // 2. Hata oluşturup ayarlıyoruz
    throw createHttpError(404, 'Student not found');
  }

  res.json({
    status: 200,
    message: `Successfully found student with id ${studentId}!`,
    data: student,
  });
};
```

İçe aktarılan fonksiyona 2 argüman gönderiyoruz. İlk argüman hata kodu, ikinci argüman ise yanıt nesnesi için hata açıklamasını içeren bir dizedir.

Sonrasında `errorHandler` **middleware**'ini, **http-errors** ile oluşturulan hataları işleyebilmesi için aşağıdaki gibi yeniden yapılandıracağız:

```
// src/middlewares/errorHandler.js

// İlgili durum kodları ile HTTP hatalarını işlemek için HttpError sınıfını içe aktarıyoruz
import { HttpError } from 'http-errors';

export const errorHandler = (err, req, res, next) => {
  // createHttpError'dan bir hata alıp almadığımızı kontrol ediyoruz
  if (err instanceof HttpError) {
    res.status(err.status).json({
      status: err.status,
      message: err.name,
      data: err,
    });
    return;
  }

  res.status(500).json({
    status: 500,
    message: 'Something went wrong',
    data: err.message,
  });
};
```

Bu yapı sayesinde, veritabanında mevcut olmayan bir **id** ile öğrenci verilerini almak için bir istek gönderdiğimizde, **404 - Not Found** durumu ve ilgili hata mesajı dönecek:
