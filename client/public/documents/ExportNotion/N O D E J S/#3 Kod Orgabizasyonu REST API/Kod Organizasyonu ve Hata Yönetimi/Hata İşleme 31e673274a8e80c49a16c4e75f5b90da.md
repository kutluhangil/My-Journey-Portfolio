# Hata İşleme

`getStudentByIdController` kontrolcüsünde `getStudentById` fonksiyonu, belirtilen kimlik numarasıyla bir öğrenci bulunamadığında `null` dönecektir. Bu durumu doğru bir şekilde ele almak, uygulamanın hata yönetimini sağlamlaştırmak için oldukça önemlidir.

Şimdilik, `student` değişkeninde bir değer olup olmadığını kontrol etmek yeterli olacak ve eğer `null` ise, öğrenci bulunamadığına dair bir hata nesnesi ile `next`fonksiyonunu çağıracağız.

`getStudentByIdController` kontrolcüsünün kodunu, öğrenci bulunamadığında hata nesnesi oluşturacak şekilde `next` parametresi ile güncelleyelim:

```
// src/controllers/students.js

export const getStudentByIdController = async (
  req,
  res,
  next,) => {
  const { studentId } = req.params;
  const student = await getStudentById(studentId);

  // Önceki kod
	// if (!student) {
	//   res.status(404).json({
	//     message: "Student not found",
	//   });
	//   return;
	// }

	// Şimdi, res.status(404 yerine temel hata işleme ekliyoruz
  if (!student) {
    next(new Error('Student not found'));
    return;
  }

  res.json({
    status: 200,
    message: `Successfully found student with id ${studentId}!`,
    data: student,
  });
};
```

`next` çağrıldıktan sonra, uygulamamızdaki hata işleyici (**error middleware**) `server.js` dosyasında bu hatayı yakalayacak ve işleyecektir.

```
next fonksiyonu çağrıldıktan sonra kontrol akışı bir sonraki middleware'e aktarılır. Ancak return kullanmayı unutmamak önemlidir. Aksi takdirde next çağrıldıktan sonra kontrolördeki diğer kodlar çalışmaya devam eder ve istenmeyen durumlar oluşabilir.
```
