# logoutUser

Sonuç olarak, **`logoutUserController`** fonksiyonu, çıkış talebini işler, **`logoutUser`**fonksiyonunu çağırarak oturumu sonlandırır, çerezleri temizler ve istemciye başarılı bir çıkış yanıtı gönderir.

1. Çıkış işlemi için ayrı bir yönlendirici oluşturacağız:

```
// src/routers/auth.js

import { logoutUserController } from '../controllers/auth.js';

/* Dosyanın diğer kodları */

router.post('/logout', ctrlWrapper(logoutUserController));
```

Artık projemizde yetkilendirme ve kimlik doğrulama temellerinin uygulanmasında son aşamaya geldik. Sadece refresh token kullanarak token rotasyonunu uygulamak kaldı:

1. Refresh için bir fonksiyon oluşturacağız:

```
// src/services/auth.js

/* Dosyanın diğer kodları */

const createSession = () => {
  const accessToken = randomBytes(30).toString('base64');
  const refreshToken = randomBytes(30).toString('base64');

  return {
    accessToken,
    refreshToken,
    accessTokenValidUntil: new Date(Date.now() + FIFTEEN_MINUTES),
    refreshTokenValidUntil: new Date(Date.now() + ONE_DAY),
  };
};

export const refreshUsersSession = async ({ sessionId, refreshToken }) => {
  const session = await SessionsCollection.findOne({
    _id: sessionId,
    refreshToken,
  });

  if (!session) {
    throw createHttpError(401, 'Session not found');
  }

  const isSessionTokenExpired =
    new Date() > new Date(session.refreshTokenValidUntil);

  if (isSessionTokenExpired) {
    throw createHttpError(401, 'Session token expired');
  }

  const newSession = createSession();

  await SessionsCollection.deleteOne({ _id: sessionId, refreshToken });

  return await SessionsCollection.create({
    userId: session.userId,
    ...newSession,
  });
};
```

**`refreshUsersSession`** fonksiyonu, kullanıcı oturumunu yenileme sürecini ve veritabanıyla etkileşimi asenkron istekler aracılığıyla gerçekleştirir. İşleyişinin detaylı açıklaması:

**1. Mevcut oturumun aranması**:

- Fonksiyon, **`sessionId`** ve **`refreshToken`** içeren bir nesne alır.
- **`SessionsCollection`** koleksiyonunda ilgili **`sessionId`** ve **`refreshToken`** ile bir oturum arar.
- Eğer oturum bulunamazsa, fonksiyon 401 koduyla bir hata fırlatır (Oturum bulunamadı).

**2. Oturum tokeninin süresinin kontrolü**:

- Fonksiyon, **`refreshToken`** süresinin dolup dolmadığını kontrol eder. Eğer mevcut tarih **`refreshTokenValidUntil`** değerini aşarsa, bu oturum tokeninin süresinin dolduğunu gösterir.
- Eğer oturum tokeni süresi dolmuşsa, fonksiyon 401 koduyla bir hata fırlatır (Oturum tokeni süresi dolmuş).

**3. Yeni oturumun oluşturulması**:

- Fonksiyon, yeni **`accessToken`** ve **`refreshToken`** üreten **`createSession`**fonksiyonunu çağırır ve bunların geçerlilik sürelerini ayarlar.
- **`createSession`**, yeni tokenler ve geçerlilik süreleriyle bir nesne döner.

**4. Yeni oturumun veritabanında kaydedilmesi**:

- Fonksiyon, mevcut oturumdan kullanıcı kimliğini ve **`createSession`**fonksiyonu tarafından üretilen yeni oturum verilerini kullanarak **`SessionsCollection`** koleksiyonunda yeni bir oturum oluşturur.
- Yeni oturum veritabanında kaydedilir ve fonksiyon onu döner.

Böylece, **`refreshUsersSession`** fonksiyonu, kullanıcı oturumunu yenileme talebini işler, mevcut oturumun varlığını ve süresini kontrol eder, yeni bir oturum oluşturur ve bunu veritabanında saklar.

2. Sonraki adımda bir kontrolör oluşturacağız:

```
// src/controllers/auth.js

import { refreshUsersSession } from '../services/auth.js';

/* Dosyanın diğer kodları */

const setupSession = (res, session) => {
  res.cookie('refreshToken', session.refreshToken, {
    httpOnly: true,
    expires: new Date(Date.now() + ONE_DAY),
  });
  res.cookie('sessionId', session._id, {
    httpOnly: true,
    expires: new Date(Date.now() + ONE_DAY),
  });
};

export const refreshUserSessionController = async (req, res) => {
  const session = await refreshUsersSession({
    sessionId: req.cookies.sessionId,
    refreshToken: req.cookies.refreshToken,
  });

  setupSession(res, session);

  res.json({
    status: 200,
    message: 'Successfully refreshed a session!',
    data: {
      accessToken: session.accessToken,
    },
  });
};
```

**`refreshUserSessionController`** fonksiyonu, kullanıcı oturumunu yenileme sürecini ve HTTP aracılığıyla istemciyle etkileşimi gerçekleştirir. İşleyişinin detaylı açıklaması:

**1. Oturum yenileme fonksiyonunun çağrılması**:

- Fonksiyon, istek (**`req`**) ve yanıt (**`res`**) nesnelerini alır.
- **`refreshUsersSession`** fonksiyonunu çağırarak, istekten alınan **`sessionId`** ve **`refreshToken`** nesnesini iletir (**`req.cookies.sessionId`** ve **`req.cookies.refreshToken`**).
- **`refreshUsersSession`**, oturumu yenileme sürecini gerçekleştirir ve yeni oturum nesnesini döner.

**2. Yeni çerezlerin ayarlanması**:

- Fonksiyon, yanıt nesnesi (**`res`**) ve yeni oturumu alarak **`setupSession`**fonksiyonunu çağırır.
- **`setupSession`**, iki çerez ayarlar: **`refreshToken`** ve **`sessionId`**, **`res.cookie`**metodunu kullanarak.
- **`refreshToken`**, yalnızca HTTP istekleri aracılığıyla erişilebilen http-only cookie olarak saklanır. Süresi bir gün olarak belirlenmiştir.
- **`sessionId`** de benzer bir süreyle http-only cookie olarak saklanır.

**3. İstemciye yanıt gönderilmesi**:

- Fonksiyon, 200 durum kodu, oturumun başarıyla yenilendiğine dair bir mesaj ve **`accessToken`** içeren verileri içeren bir JSON yanıtı oluşturur.
- İstemciye yanıt göndermek için **`res.json`** metodu kullanılır.

Böylece, **`refreshUserSessionController`** fonksiyonu, kullanıcı oturumunu yenileme talebini işler, oturum yenileme fonksiyonunu çağırır, tokenler ve oturum kimliği için yeni çerezler ayarlar ve istemciye oturumun başarıyla yenilendiği bilgisiyle birlikte yeni erişim tokenini içeren bir yanıt gönderir.

3. Şimdi refresh için ayrı bir yönlendirici oluşturacağız:

```
// src/routers/auth.js

import { refreshUserSessionController } from '../controllers/auth.js';

/* Dosyanın diğer kodları */

router.post('/refresh', ctrlWrapper(refreshUserSessionController));
```
