# Çıkış (LogOut)

Bir sonraki adım, yetkilendirme sistemimizi geliştirmek için çıkış (logout) işlemini eklemektir.

Bu işlem sırasında, sadece sunucunun erişebileceği `httpOnly` çerezlerini temizlememiz ve veritabanından oturumu silmemiz gerekecek:

1. Çıkış işlemi için bir fonksiyon oluşturacağız:

```
// src/services/auth.js

/* Dosyanın diğer kodları */

export const logoutUser = async (sessionId) => {
  await SessionsCollection.deleteOne({ _id: sessionId });
};
```

2. Bir kontrolör oluşturacağız:

```
// src/controllers/auth.js

import { logoutUser } from '../services/auth.js';

/* Dosyanın diğer kodları */

export const logoutUserController = async (req, res) => {
  if (req.cookies.sessionId) {
    await logoutUser(req.cookies.sessionId);
  }

  res.clearCookie('sessionId');
  res.clearCookie('refreshToken');

  res.status(204).send();
};
```

Bu **`logoutUserController`** fonksiyonu, kullanıcının çıkış talebini işleme sürecini ve HTTP üzerinden istemci ile etkileşimi gerçekleştirir. İşleyişinin detaylı açıklaması:

**1. SessionId'nin varlığının kontrolü**:

- Fonksiyon, istek (**`req`**) ve yanıt (**`res`**) nesnelerini alır.
- İstek içinde **`sessionId`** çerezi olup olmadığını kontrol eder. Eğer **`sessionId`**mevcutsa, fonksiyon **`logoutUser`** fonksiyonunu çağırarak **`sessionId`** değerini iletir. Bu, kullanıcının oturumunu veritabanından silmeyi veya çıkış işlemi için gerekli diğer adımları gerçekleştirmeyi sağlar.

**2. Çerezlerin temizlenmesi**:

- Fonksiyon, **`sessionId`** ve **`refreshToken`** çerezlerini **`res.clearCookie`**metodunu kullanarak temizler. Bu, ilgili çerezleri istemcinin tarayıcısından silerek kullanıcının sistemden çıkış yapmasını sağlar.

**3. Yanıt gönderimi**:

- Fonksiyon, istemciye 204 (No Content) durum kodu ile bir yanıt gönderir. Bu, talebin başarıyla işlendiği ancak yanıtın gövdesinde bir mesaj bulunmadığı anlamına gelir.

Sonuç olarak, **`logoutUserController`** fonksiyonu, çıkış talebini işler, **`logoutUser`**fonksiyonunu çağırarak oturumu sonlandırır, çerezleri temizler ve istemciye başarılı bir çıkış yanıtı gönderir.

1. Çıkış işlemi için ayrı bir yönlendirici oluşturacağız:

```
// src/routers/auth.js

import { logoutUserController } from '../controllers/auth.js';

/* Dosyanın diğer kodları */

router.post('/logout', ctrlWrapper(logoutUserController));
```
