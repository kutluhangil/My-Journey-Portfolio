# MongoDB Bağlantısı

Oluşturduğumuz veritabanına bağlanmak için bir fonksiyon oluşturacağız. Bunun için `src` klasöründe `db` adında bir klasör oluşturacak ve içinde `initMongoDB.js`dosyasını yerleştireceğiz.

```
// src/db/initMongoDB.js

export const initMongoDB = async () => {
  try {
    console.log('Mongo connection successfully established!');
  } catch (e) {
    console.log('Error while setting up mongo connection', e);
    throw e;
  }
};
```

[**Mongoose**](https://mongoosejs.com/) — **Node.js** ortamında **MongoDB** ile çalışmayı kolaylaştıran bir kütüphanedir. MongoDB için veri modelleme ve doğrulama işlemlerini basit bir şekilde yapmanın yanı sıra, veritabanına sorgu gönderme konusunda da kullanışlı bir arayüz sunar. Uygulamamızda kurmak için uygun komutla yükleyelim:

`npm install mongoose`

`initMongoDB` fonksiyonunda bazı değişiklikler yapalım.

Veritabanına bağlanmak için, `try` bloğu içinde `mongoose` kütüphanesinin `connect`metodunu çağıracağız. Bu çağrıda, bağlantı dizesini (**connection string**) argüman olarak vereceğiz. Bu dizeyi oluşturmak için, ortam değişkenlerine erişim sağlayan `env` yardımcı fonksiyonunu kullanacağız.

```
// src/db/initMongoDB.js

import mongoose from 'mongoose';

import { env } from '../utils/env.js';

export const initMongoDB = async () => {
  try {
    const user = env('MONGODB_USER');
    const pwd = env('MONGODB_PASSWORD');
    const url = env('MONGODB_URL');
    const db = env('MONGODB_DB');

    await mongoose.connect(
      `mongodb+srv://${user}:${pwd}@${url}/${db}?retryWrites=true&w=majority`,
    );
    console.log('Mongo connection successfully established!');
  } catch (e) {
    console.log('Error while setting up mongo connection', e);
    throw e;
  }
};
```

Artık `src/index.js` dosyasında, veritabanı bağlantısını başlatacak ve ardından sunucuyu çalıştıracak `bootstrap` fonksiyonunu oluşturacağız.

```
// src/index.js

import { initMongoDB } from './db/initMongoDB.js';
import { startServer } from './server.js';

const bootstrap = async () => {
  await initMongoDB();
  startServer();
};

bootstrap();
```
