# Ortam Değişkenleri

Bir uygulamanın farklı ortamlarda (örneğin, yerel geliştirme, test, üretim) çalışacak şekilde yapılandırılması gerekir. Bu, her ortam için ayrı veritabanı bağlantıları, özel **API anahtarları** ve ortama özgü diğer ayarların kullanılmasını zorunlu kılar. Bu tür ihtiyaçların karşılanmasında **ortam değişkenleri** kullanılır.

**Ortam değişkenleri (environment variables)**, bir programın veya sistemin belirli bir çalışma ortamı hakkında bilgi içeren değişkenlerdir. Yapılandırma parametrelerini, gizli anahtarları, dosya yollarını, sunucu ayarlarını ve bir ortamdan diğerine farklılık gösterebilecek diğer hassas bilgileri saklamak için kullanılırlar.

Varsayılan olarak, ortam değişkenleri projenin kökünde oluşturulan `.env` adlı bir dosyada belirtilir. Sunucu kodunda, ortam değişkeni ile değiştirebileceğimiz güzel bir örneğimiz vardı. Bu, hizmetin çalışacağı porttur.

Geleneksel olarak, **`.env`** dosyasındaki ortam değişkenleri büyük harflerle yazılır, ancak bu katı bir gereklilik değildir. Büyük harf kullanımı, ortam değişkenlerini koddaki sıradan değişkenlerden kolayca ayırt etmeye yardımcı olan bir konvansiyondur ve böylece kodun okunabilirliğini ve sürdürülebilirliğini artırır.

O halde, projenin kökünde bir `.env` dosyası oluşturalım ve içinde ilk ortam değişkenimiz olan `PORT`'u tanımlayalım.

`// .env

PORT=3000`

```
.env dosyası hemen .gitignore dosyasına eklenmeli ve kesinlikle GitHub'a commit edilmemelidir. Eğer bunu yaptıysanız, bu dosyada bulunan tüm şifreleri ve anahtarları acilen değiştirmeniz gerekir. Bu dosyanın bir sonraki commit ile silinmesi, ona erişimin geri kazanılamayacağı garantisini vermez.
```

`.env` dosyasında değişkenler oluşturduktan sonra, iyi bir uygulama olarak `.env.example` dosyası oluşturmak olacaktır. Bu dosya, projeye gerekli olan tüm çevresel değişken adlarını gerçek değerler olmadan içermelidir, böylece diğer geliştiriciler projenin ihtiyaç duyduğu değişkenlerin yapısını anlayabilir ve hassas bilgileri ifşa etmeden kendi geliştirme ortamlarını ayarlayabilirler. Bu dosyanın `.gitignore` dosyasına eklenmediğine dikkat edin.

`// .env.example

PORT=`

Uygulamada ortam değişkenlerini okumak ve kullanmak için [`dotenv`](https://www.npmjs.com/package/dotenv) paketini şu komutla kurmanız gerekecek:

`npm install dotenv`

Daha sonra, uygulamada `dotenv.config()` metodunu çağırarak onu başlatmalısınız:

```
// src/server.js

import dotenv from "dotenv";

dotenv.config();

// Dosyanın geri kalanı
```

Node.js ortamında çevresel değişkenlere erişim için `process.env` adlı küresel nesne kullanılır; bu nesne, herhangi bir modülün kodunda erişilebilir (tıpkı `window` veya `document`'ın tarayıcıda erişilebilir olması gibi).

```
// src/server.js

import express from 'express';
import pino from 'pino-http';
import cors from 'cors';
import dotenv from 'dotenv';

dotenv.config();

// Ortam değişkeni PORT'u okuyoruz
const PORT = Number(process.env.PORT);

export const startServer = () => {

	// Fonksiyonun geri kalanı

	app.listen(PORT, () => {
	  console.log(`Server is running on ${PORT}`);
	});
};
```

**`Not:** Çevresel değişkenler her zaman **string** türünde saklanır. Eğer sayı veya boolean türü gerekiyorsa, Number() veya diğer dönüşüm fonksiyonları kullanarak uygun türe dönüştürmelisiniz.`

Çevresel değişkenin mevcut olmama olasılığını göz önünde bulundurarak, varlığını kontrol edecek ve değişken ayarlanmamışsa hata üretecek bir yardımcı fonksiyon oluşturmak faydalı olacaktır. Bu nedenle, `utils` klasöründe `env.js` adında bir dosya oluşturarak `dotenv`'in başlatılmasını buraya taşıyacağız. Bu dosyada, çevresel değişkenleri okumak için tasarlanmış `env` fonksiyonunu tanımlayacağız.

```
// src/utils/env.js

import dotenv from 'dotenv';

dotenv.config();

export function env(name, defaultValue) {
  const value = process.env[name];

  if (value) return value;

  if (defaultValue) return defaultValue;

  throw new Error(`Missing: process.env['${name}'].`);
}

// Onu şu şekilde kullanabiliriz: env('PORT', '3000');
// Eğer bu isimde bir ortam değişkeni belirtilmemişse ve varsayılan bir değer de verilmemişse,
// bu fonksiyonun çağrılması Missing: process.env['PORT'] mesajıyla bir hata fırlatır.
```

`server.js` dosyasına `env` fonksiyonunu import ediyoruz ve bunu `PORT` ortam değişkenini okumak için kullanıyoruz.

```
// src/server.js

import express from 'express';
import pino from 'pino-http';
import cors from 'cors';

import { env } from './utils/env.js';

const PORT = Number(env('PORT', '3000'));

export const startServer = () => {
  const app = express();

  app.use(express.json());
  app.use(cors());

  app.use(
    pino({
      transport: {
        target: 'pino-pretty',
      },
    }),
  );

  app.get('/', (req, res) => {
    res.json({
      message: 'Hello World!',
    });
  });

  app.use('*', (req, res, next) => {
    res.status(404).json({
      message: 'Not found',
    });
  });

  app.use((err, req, res, next) => {
    res.status(500).json({
      message: 'Something went wrong',
      error: err.message,
    });
  });

  app.listen(PORT, () => {
    console.log(`Server is running on port ${PORT}`);
  });
};
```

Bu uzun yazıda şunları yaptık:

- Express ile tanıştık ve nasıl çalıştığını öğrendik
- Basit bir web servisi oluşturmayı öğrendik
- Middleware kullanmayı, özel olanlar da dahil, öğrendik
- Ortam değişkenlerinin ne olduğunu ve neden kullanıldığını
