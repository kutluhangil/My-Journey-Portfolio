# Özel Middleware

Bu bölümde, **Express** uygulamalarında özel **middleware** kullanımını inceleyeceğiz. Standart durumları ele almak için pratik örnekler üzerinde duracağız.

Öncelikle, mevcut olmayan bir yola erişildiğinde (örneğin, sunucumuzun işleyemediği bir URL'ye yapılan istekler) bir **middleware** ekleyelim:

```
app.use('*', (req, res, next) => {
  res.status(404).json({
    message: 'Route not found',
  });
});
```

Bu **middleware**, tanımlı rotalara uymayan tüm istekleri işler. Burada `'*'` kullanarak, **tüm yollar** için geçerli olduğunu belirtiyoruz. Alternatif olarak, yol belirtmeden de kullanabilirsiniz.

**Not:** Bu middleware'in, tanımlanan diğer middleware'lerden sonra eklenmesi önemlidir. Böylece yalnızca önceki rotalardan hiçbiri eşleşmediğinde çalışır. Bu durum, `switch` yapısındaki `default` bloğu ile benzerlik gösterir.

```
// src/index.js

import express from 'express';

const PORT = 3000;

const app = express();

app.use(express.json());

app.get('/', (req, res) => {
  res.json({
    message: 'Hello world!',
  });
});

app.use('*', (req, res, next) => {
  res.status(404).json({
    message: 'Not found',
  });
});

app.listen(PORT, () => {
  console.log(`Server is running on port ${PORT}`);
});
```

Artık `'/'` dışındaki herhangi bir rota için, örneğin [http://localhost:3000/random](http://localhost:3000/random)adresine **GET isteği** yaptığımızda, aşağıdaki yanıtı alacağız.

Beklenmeyen hataları (500 hataları) ele almak için özel bir hata işleme **middleware**ekleyelim:

```
app.use((err, req, res, next) => {
  res.status(500).json({
    message: 'Something went wrong',
    error: err.message,
  });
});
```

Bu **middleware**, isteklerin işlenmesi sırasında meydana gelen hataları işler. Beklenmedik bir hata oluştuğunda kullanılmak üzere tasarlanmıştır. Eğer önceki **middleware**'ler **`next(err)`** çağrısı yaparak hata nesnesini argüman olarak ilettiyse, bu **middleware** otomatik olarak çalıştırılacaktır. Gelecekte bu işlevi geliştirecek ve daha esnek hale getireceğiz.

İlk argüman olarak aldığımız `err` hatası, **`message`**, **`name`** ve **`stack`** gibi önemli özellikleri içerir; bu özellikler sorunları analiz etmek için etkili bir şekilde kullanılabilir. Bu nedenle, sunucumuzu bu **middleware** ile biraz genişletelim:

```
// src/index.js

import express from 'express';

const PORT = 3000;

const app = express();

app.use(express.json());

app.get('/', (req, res) => {
  res.json({
    message: 'Hello world!',
  });
});

app.use('*', (req, res, next) => {
  res.status(404).json({
    message: 'Not found',
  });
});

app.use((err, req, res, next) => {
  res.status(500).json({
    message: 'Something went wrong',
    error: err.message,
  });
});

app.listen(PORT, () => {
  console.log(`Server is running on port ${PORT}`);
});
```

Bu bölümde, **Node.js** uygulamamızda standart durumları işlemek için özel **middleware** oluşturmayı inceledik. **Middleware** kullanarak, mevcut hiçbir rotaya uymayan istekleri etkili bir şekilde nasıl işleyebileceğimizi ve beklenmeyen hataları nasıl ele alabileceğimizi gördük. **Middleware** kullanımı, kodun daha yapılandırılmış olmasını sağlarken, kullanıcı isteklerinin güvenilir bir şekilde işlenmesine olanak tanır.
